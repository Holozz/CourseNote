## 1. 引言与动机

有限自动机（Finite Automata, FA）是**有限个状态**以及状态间**转移规则**组成的计算模型。最初用于顺序开关电路，如今广泛用于软件建模，如词法分析、协议验证、文本搜索（`grep` 中的正则表达式）等。

**核心思想**：自动机从左到右逐个读入输入符号，根据当前状态和输入符号决定下一个状态。读完整个输入串后，若停在**接受状态**，则接受该串，否则拒绝。

**为什么不用程序做计算模型？**  
程序可以有无限变量、循环、递归，而 FA 只有有限状态，无法计数任意大的整数。但 FA 简单、快速，适合识别**正则语言**。

---

## 2. 有限自动机的直观理解

- **状态**：有限个，表示“记忆”的摘要。
- **转移**：读入一个符号，从一个状态跳到另一个状态。
- **起始状态**：开始读输入前所在状态。
- **接受状态（终止状态）**：读完输入后若在此状态，则接受。

**示例**：识别以 `"ing"` 结尾的字符串。状态图：
```
nothing --i--> Saw i --n--> Saw in --g--> Saw ing
```
非 `i` 或 `g` 的字符回到 `nothing`，非 `i` 或 `n` 的字符从 `Saw i` 回到 `nothing` 等。

**自动机到代码**：每个状态对应一段代码，读入下一个字符，决定下一个状态，跳转。Java 示例（用 `switch` 实现状态转移）：
```java
int q = 0; // 0: nothing, 1: Saw i, 2: Saw in, 3: Saw ing
for (char c : s.toCharArray()) {
    switch (q) {
        case 0: q = (c=='i')? 1 : 0; break;
        case 1: q = (c=='n')? 2 : ((c=='i')? 1 : 0); break;
        case 2: q = (c=='g')? 3 : ((c=='i')? 1 : 0); break;
        case 3: q = (c=='i')? 1 : 0;
    }
}
if (q==3) accept(); else reject();
```

## 3. 形式化定义

### 3.1 字母表（Alphabet）

**定义**：字母表是任意**有限符号集合**，通常记作 `Σ`。符号是信息表示的基本单位
例如：`Σ = {0,1}`，`Σ = {a,b,c}`，ASCII，Unicode

### 3.2 字符串（String）

**定义**：字母表 `Σ` 上的字符串是 `Σ` 中符号的有限序列，例如 `abc`
`Σ*` 表示 `Σ` 上所有字符串的集合。`ε` 表示空串（长度为 0）

**注意**：符号 `0` 和字符串 `"0"` 看起来一样，但类型不同，上下文决定

### 3.3 语言（Language）

**定义**：字母表 `Σ` 上的语言是 `Σ*` 的一个子集
例如：不含两个连续 `1` 的 0/1 串集合  
`L = {ε, 0, 1, 00, 01, 10, 000, 001, 010, 100, 101, ...}`

### 3.4 确定性有限自动机（DFA）

**定义**：DFA 是一个五元组 `(Q, Σ, δ, q₀, F)`：

1. `Q`：有限状态集
2. `Σ`：输入字母表
3. `δ`：转移函数，`δ: Q × Σ → Q`。对于每个状态和每个输入符号，有且仅有一个下一个状态（**确定性**）
4. `q₀ ∈ Q`：起始状态
5. `F ⊆ Q`：接受状态集（终止状态集）。接受与终止同义

### 3.5 转移函数与扩展转移函数

**转移函数** `δ(q, a) = p`：当前状态 `q`，读入符号 `a`，下一个状态 `p`

**扩展转移函数** `δ̂(q, w)`：当前状态 `q`，读入字符串 `w` 后到达的状态。定义：
- **基础**：`δ̂(q, ε) = q`
- **归纳**：`δ̂(q, wa) = δ(δ̂(q, w), a)`，其中 `w` 是字符串，`a` 是符号

**直观**：沿着状态图，从 `q` 出发，依次按 `w` 的符号走弧，最终到达的状态

**注意**：通常 `δ̂` 也简写为 `δ`，但含义扩展。两者对单个符号一致：`δ(q,a) = δ̂(q,a)`

## 4. DFA 的表示方法

### 4.1 状态图

- 节点 = 状态。
- 有向边 = 转移，边标签为导致该转移的输入符号。
- 起始状态用“Start”箭头指向。
- 接受状态用**双圈**表示。

**示例**：接受不含连续两个 `1` 的字符串的 DFA。  
状态 `A`（初始，接受）：之前串 OK 且不以 `1` 结尾；  
状态 `B`（接受）：之前串 OK 且以单个 `1` 结尾；  
状态 `C`（非接受）：已出现连续 `1`。  
转移：`A` 读 `0`→`A`，读 `1`→`B`；`B` 读 `0`→`A`，读 `1`→`C`；`C` 读 `0,1`→`C`。

### 4.2 转移表

行 = 状态，列 = 输入符号。表项 = 下一个状态。起始状态用 `→` 标记，接受状态用 `*` 标记。

**示例**：

| 状态 | 0 | 1 |
|------|---|---|
| →A*  | A | B |
| B*   | A | C |
| C    | C | C |

### 4.3 代码表示

**Python 字典**：
```python
dfa = {
    'Q': {'A','B','C'},
    'SIGMA': {'0','1'},
    'DELTA': {
        ('A','0'): 'A', ('A','1'): 'B',
        ('B','0'): 'A', ('B','1'): 'C',
        ('C','0'): 'C', ('C','1'): 'C'
    },
    'q0': 'A',
    'F': {'A','B'}
}
```

## 5. DFA 接受的语言

**定义**：DFA `A` 的语言 `L(A)` 是所有使 `δ̂(q₀, w) ∈ F` 的字符串 `w` 的集合。即从起始状态读 `w` 后到达接受状态。

**示例**：字符串 `101` 在语言中：  
`A --1--> B --0--> A --1--> B`，`B` 是接受状态，所以接受。

**语言描述**：`L = {w | w ∈ {0,1}* 且 w 不含两个连续 1}`。

---

## 6. 证明 DFA 语言与集合等价

要证明 `S = T`，需证明 `S ⊆ T` 且 `T ⊆ S`。

**示例**：`S` = DFA 语言（不含连续 `1`），`T` = 自然语言描述（不含连续 `1`）。

### 6.1 归纳证明 S ⊆ T

**命题**：若 `w` 被 DFA 接受，则 `w` 不含连续 `1`。

**归纳假设（强化）**：
- IH(1)：若 `δ(A,w)=A`，则 `w` 不含连续 `1` 且不以 `1` 结尾。
- IH(2)：若 `δ(A,w)=B`，则 `w` 不含连续 `1` 且以单个 `1` 结尾。

**基础**：`|w|=0`，`w=ε`。`δ(A,ε)=A`，`ε` 不含 `1`，IH(1) 成立；IH(2) 前件假， vacuously true。

**归纳步**：`w = xa`，`|x| < |w|`。假设 IH 对 `x` 成立。
- 若 `δ(A,w)=A`：则 `δ(A,x)` 必为 `A` 或 `B`，且 `a=0`。由 IH，`x` 不含连续 `1`。加 `0` 后仍不含连续 `1`，且不以 `1` 结尾。
- 若 `δ(A,w)=B`：则 `δ(A,x)=A`，`a=1`。由 IH，`x` 不含连续 `1` 且不以 `1` 结尾。加 `1` 后，`w` 不含连续 `1` 且以单个 `1` 结尾。

### 6.2 逆否命题技巧 T ⊆ S

要证：若 `w` 不含连续 `1`，则 `w` 被接受。  
逆否：若 `w` 不被接受，则 `w` 含连续 `1`。

不被接受意味着 `δ(A,w)=C`。到达 `C` 的唯一方式是 `w = x1y`，其中 `δ(A,x)=B`，且 `y` 是首次到达 `C` 的后缀。若 `δ(A,x)=B`，则 `x = z1`，所以 `w = z11y`，含连续 `1`。证毕。

**关键**：逆否命题与原命题等价。

## 7. 典型例题与设计技巧

- **偶数个 1**：状态 `even/odd`，转移读 `1` 翻转，读 `0` 不变。
- **密码/关键字**：顺序识别 `then`，非匹配字符进入**死状态**（dead state）。安全风险：过早报告失败。
- **恰好两个 a**：状态 `0,1,2,3+`，读 `a` 递增，读 `b` 不变。
- **至少两个 b**：状态 `0,1,2+`，读 `b` 递增，读 `a` 不变。
- **恰好两个 a 且至少两个 b**：网格状态 `(a_count, b_count)` 组合。
- **包含子串 "baba"**：用状态记录已匹配的前缀。不包含则接受状态为未匹配到。
- **二进制被 23 整除**：状态对应余数 `0..22`，`δ(i,0)=(2i)%23`，`δ(i,1)=(2i+1)%23`，起始和接受为 `0`。设计思想：状态记住必要的历史信息（当前余数）。
- **反转二进制被 23 整除**：难直接构造，但定理：正则语言的逆转也是正则。

## 8. 正则语言与非正则语言

**正则语言**：能被某个 DFA 接受的语言。

**非正则语言例子**：
- `L1 = {0^n1^n | n≥1}`，需要计数任意 `n`，DFA 不能。
- `L2` = 平衡括号语言，同样需要计数。

**直观**：正则语言“不能计数到任意大的整数”。后续用泵引理严格证明。

**但许多语言是正则的**：如浮点数表示、模运算等。

## 9. 难点与易错点总结

1. **确定性**：每个状态对每个输入符号必须有且仅有一个转移。不能有多余或缺失。
2. **空串处理**：`δ̂(q, ε)=q`，空串可能被接受（若 `q₀ ∈ F`）。
3. **接受时机**：读完整个输入串后，若在 `F` 中则接受，中途到达 `F` 不代表接受。
4. **死状态**：一旦进入无法到达接受状态的状态，可称为死状态。设计时不要遗漏转移。
5. **状态设计**：状态应记住必要的历史信息，不多不少。例如模 23 只需记住余数。
6. **归纳证明**：归纳假设要足够强，覆盖所有可能状态，否则无法完成证明。
7. **逆否命题**：证明 `T ⊆ S` 时，逆否命题往往更容易。
8. **正则语言的局限**：不能计数任意大整数，不能比较数量。
9. **符号与字符串**：注意区分字母表中的符号和由符号组成的字符串。
10. **扩展转移函数**：`δ̂` 与 `δ` 不同，`δ̂` 接受字符串。

## 10. 生成例题（难度稍高）

### 例题 1：设计 DFA 接受 `L = {w ∈ {0,1}* | w 中 0 的个数为偶数，1 的个数为 3 的倍数}`

**分析**：需要同时跟踪两个条件：0 的个数的奇偶性（2 种），1 的个数模 3 的余数（3 种）。组合状态共 `2×3=6` 个。

**状态**：`q_{i,j}`，其中 `i ∈ {even, odd}` 表示 0 的个数的奇偶，`j ∈ {0,1,2}` 表示 1 的个数模 3。

**起始**：`q_{even,0}`。  
**接受**：`q_{even,0}`（0 的个数为偶数，1 的个数为 3 的倍数）。

**转移**：
- 读 `0`：`i` 翻转，`j` 不变。
- 读 `1`：`i` 不变，`j = (j+1) mod 3`。

**状态表**：

| 状态 | 0 | 1 |
|------|---|---|
| →*q_{even,0} | q_{odd,0} | q_{even,1} |
| q_{odd,0} | q_{even,0} | q_{odd,1} |
| q_{even,1} | q_{odd,1} | q_{even,2} |
| q_{odd,1} | q_{even,1} | q_{odd,2} |
| q_{even,2} | q_{odd,2} | q_{even,0} |
| q_{odd,2} | q_{even,2} | q_{odd,0} |

### 例题 2：设计 DFA 接受所有二进制串，其值模 5 为 2

**分析**：读入二进制串时，值不断更新：`新值 = 旧值 × 2 + 当前位`。因此只需记住当前值模 5 的余数。

**状态**：`0, 1, 2, 3, 4` 表示当前余数。  
**起始**：`0`。  
**接受**：`2`。

**转移**：
- `δ(i, 0) = (2i) mod 5`
- `δ(i, 1) = (2i+1) mod 5`

**状态表**：

| 状态 | 0 | 1 |
|------|---|---|
| →0 | 0 | 1 |
| 1 | 2 | 3 |
| 2 | 4 | 0 |
| 3 | 1 | 2 |
| 4 | 3 | 4 |
| *2 | - | - |

（注：表中 `*2` 表示接受状态，实际表中应合并。完整表：）

| 状态 | 0 | 1 |
|------|---|---|
| →0 | 0 | 1 |
| 1 | 2 | 3 |
| *2 | 4 | 0 |
| 3 | 1 | 2 |
| 4 | 3 | 4 |

### 例题 3：设计 DFA 接受 `L = {w ∈ {0,1}* | w 包含奇数个 0 和偶数个 1}`

**分析**：跟踪两个奇偶性。状态 `(p, q)`，`p` 表示 0 的个数奇偶，`q` 表示 1 的个数奇偶。

**状态**：`(偶,偶), (偶,奇), (奇,偶), (奇,奇)`。  
**起始**：`(偶,偶)`。  
**接受**：`(奇,偶)`。

**转移**：读 `0` 翻转 `p`，读 `1` 翻转 `q`。

**状态表**：

| 状态 | 0 | 1 |
|------|---|---|
| →(偶,偶) | (奇,偶) | (偶,奇) |
| (偶,奇) | (奇,奇) | (偶,偶) |
| *(奇,偶) | (偶,偶) | (奇,奇) |
| (奇,奇) | (偶,奇) | (奇,偶) |

## 11. 代码实现简洁示例

**Python 模拟 DFA 运行**：
```python
def run_dfa(delta, q0, F, s):
    q = q0
    for c in s:
        q = delta[(q, c)]
    return q in F

# 示例：不含连续 1 的 DFA
delta = {
    ('A','0'): 'A', ('A','1'): 'B',
    ('B','0'): 'A', ('B','1'): 'C',
    ('C','0'): 'C', ('C','1'): 'C'
}
print(run_dfa(delta, 'A', {'A','B'}, '101'))  # True
print(run_dfa(delta, 'A', {'A','B'}, '110'))  # False
```

## 12. 总结

DFA 是形式语言的基础，核心是**有限状态、确定性转移、接受语言**。掌握定义、表示、扩展转移函数、语言接受、等价证明。理解正则语言的局限，通过大量例题熟悉状态设计。后续将学习非确定性有限自动机（NFA）、正则表达式、泵引理等。
