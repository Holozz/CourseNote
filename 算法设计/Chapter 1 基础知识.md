## 1 算法的起源与发展

### 1.1 算法的历史演进

#### 通俗理解
算法就像是一套精确的烹饪食谱，每一步都有明确的规定，确保最终得到想要的结果。从古代的数学计算到现代的计算机程序，算法一直在推动人类文明的进步。

#### 严谨定义
算法是解题方案的准确而完整的描述，是解决问题的一系列明确的、可执行的步骤。算法的研究是计算机科学的核心任务之一。

#### 历史发展脉络

| 时期 | 算法实例 | 提出者/出处 | 历史意义 |
|------|----------|-------------|----------|
| **公元前1世纪** | 勾股定理计算 | 《周髀算经》 | 中文字"算法"的词源 |
| **公元前300年** | 辗转相除法 | 欧几里得《几何原本》 | 最早的有明确步骤的算法之一 |
| **魏晋时期** | 割圆术 | 刘徽《九章算术注》 | 计算圆周率的创新方法 |
| **唐代** | 《算经十书》 | 唐高宗显庆元年(656年) | 国家数学教育标准 |
| **9世纪** | Algorithm概念 | 阿尔·花拉子密 | "Algorithm"一词的起源 |
| **1936年** | 图灵机 | 艾伦·图灵 | 计算机理论的奠基 |
| **1946年** | 存储程序原理 | 冯·诺依曼 | 现代计算机体系结构 |

> [!important] 
> 算法与计算机的结合标志着信息时代的开始。图灵奖（计算机界的"诺贝尔奖"）中约18%的获奖者来自算法与计算复杂性领域。

### 1.2 算法的现代定义

#### 通俗理解
想象你有一堆乐高积木，算法就像是搭建模型的说明书。它告诉你：
1. 需要哪些积木（输入）
2. 按什么顺序摆放（步骤）
3. 最终要搭成什么样子（输出）
4. 每一步都明确无误（确定性）
5. 不能无限进行下去（有穷性）

#### 严谨定义
**算法**是解题方案的准确而完整的描述，是解题的方法和步骤。利用计算机解决实际问题时，首先选择合适的数学模型表示问题，然后寻找算法作为解法。

#### 算法与程序的关系
- **算法**：解决问题的抽象方法和步骤，独立于具体实现
- **程序**：算法在特定编程语言中的具体实现

> [!warning] 
> 算法不等于程序。同一个算法可以用不同语言实现，同一个程序可能包含多个算法。

## 2 算法的定义与特征

### 2.1 算法的严格定义

**定义**：算法是为解决特定问题而设计的一系列明确、有限、有效的步骤。

**形式化描述**：算法是一个五元组 $(I, O, S, f, g)$：
- $I$：输入集合
- $O$：输出集合
- $S$：状态集合
- $f$：状态转移函数
- $g$：输出函数

### 2.2 算法的五大特征

#### 2.2.1 输入（Input）

**通俗理解**：算法需要处理的原材料。就像做菜需要食材一样。

**严谨定义**：一个算法可以有零个或多个输入。输入是算法加工处理的对象。

**关键点**：
- 输入可以是零个（如常数计算）
- 输入通常是算法的参数
- 输入决定了算法的规模 $n$

**示例**：
```cpp
// 无输入的算法
void printHello() {
    cout << "Hello World" << endl;
}

// 有输入的算法
int max(int a, int b) {
    return a > b ? a : b;
}
```

> [!tip] 
> 输入规模 $n$ 是算法分析的重要指标，如排序算法中 $n$ 是待排序元素的数量。

#### 2.2.2 输出（Output）

**通俗理解**：算法处理后的结果。就像做菜后的成品。

**严谨定义**：一个算法应有一个或多个输出，作为算法进行信息加工的结果。

**关键点**：
- 输出必须与输入有明确的对应关系
- 输出是算法执行的目的
- 没有输出的算法是没有意义的

#### 2.2.3 确定性（Definiteness）

**通俗理解**：算法的每一步都不能含糊不清，必须像GPS导航一样明确指示下一步该做什么。

**严谨定义**：算法中的每一个步骤都必须是有明确定义的，无歧义、无二义性。

**示例对比**：
```cpp
// 确定性的算法步骤
if (a > b) {
    return a;
} else {
    return b;
}

// 非确定性的描述（错误示例）
if (a差不多大于b) {  // "差不多"模糊不清
    return a吧；        // "吧"表示不确定
}
```

> [!warning] 
> 随机算法看似不满足确定性，但它的随机性是通过确定的随机数生成的，整体仍是确定性的。

#### 2.2.4 可行性（Effectiveness）

**通俗理解**：算法的每一步都能在有限时间内完成，不能是"画饼充饥"的步骤。

**严谨定义**：算法中所有的操作都必须足够基本，使算法的执行者或阅读者明确其含义以及如何执行。

**关键点**：
- 每个操作都必须是基本操作
- 基本操作可以在有限时间内完成
- 不能包含未定义的操作

**反例**：
```cpp
// 不可行的算法步骤（错误示例）
int magic_number = solve_all_problems();  // 没有明确的定义
```

#### 2.2.5 有穷性（Finiteness）

**通俗理解**：算法不能无限运行下去，就像不能永远"明天开始减肥"一样，必须有结束的时候。

**严谨定义**：算法的有穷性是指算法必须总能在执行有限步骤之后终止。

**关键点**：
- 任何输入下，算法都能终止
- 执行步骤数必须是有限的
- 不能包含无限循环

> [!important] 
> **有穷性是算法与非算法程序的根本区别**。操作系统是程序，但不是算法，因为它永不停止。

## 3 算法的基本要素

### 3.1 基本运算与操作

#### 通俗理解
算法就像做菜，基本运算就是锅碗瓢盆这些工具，控制结构就是菜谱的步骤编排。

#### 严谨定义
算法的基本要素包括：对数据对象的运算操作和算法的控制结构。

#### 四类基本运算

| 运算类型 | 包含操作 | 数学表示 | 示例 |
|----------|----------|----------|------|
| **算术运算** | 加、减、乘、除、模 | $+$, $-$, $\times$, $\div$, $\bmod$ | $x = a + b$ |
| **逻辑运算** | 与、或、非、异或 | $\land$, $\lor$, $\lnot$, $\oplus$ | $p \land q$ |
| **关系运算** | 大于、小于、等于等 | $>$, $<$, $=$, $\neq$ | $if\ a > b$ |
| **数据传输** | 赋值、输入、输出 | $:=$, $read$, $write$ | $x := y$ |

> [!tip] 
> **基本运算的层级性**：高级运算可以分解为基本运算。例如乘法可以分解为多次加法。

### 3.2 控制结构

#### 三种基本控制结构

1. **顺序结构**
   - 按语句出现的先后顺序执行
   - 最简单的控制结构
   - 示例：$S_1; S_2$ 表示先执行 $S_1$，再执行 $S_2$

2. **选择结构**
   - 根据条件选择执行不同分支
   - if-else 语句实现
   - 数学表示：
     $$
     if\ condition\ then\ S_1\ else\ S_2
     $$

3. **循环结构**
   - 重复执行某些操作
   - 分为当型循环（while）和直到型循环（do-while）
   - 数学表示：
     $$
     while\ condition\ do\ S
     $$
     $$
     do\ S\ while\ condition
     $$

> [!important] 
> **Böhm-Jacopini定理**：任何算法都可以只用这三种基本控制结构表示。

### 3.3 算法的描述工具

#### 四种描述方式对比

| 描述方式 | 优点 | 缺点 | 适用场景 |
|----------|------|------|----------|
| **自然语言** | 易理解 | 冗长、歧义 | 初步设计 |
| **流程图** | 直观 | 空间效率低 | 算法可视化 |
| **伪代码** | 抽象、简洁 | 需要学习 | 算法设计 |
| **程序代码** | 可执行 | 语言依赖 | 实现 |

#### 伪代码规范

```cpp
// 伪代码示例：欧几里得算法
function gcd(a, b):
    while b ≠ 0:
        temp ← b
        b ← a mod b
        a ← temp
    return a
```

> [!tip] 
> 伪代码应该既保持算法的清晰性，又避免特定语言的语法细节。

## 4 算法的分类

### 4.1 按应用领域分类

#### 数值计算算法

**通俗理解**：主要用于科学计算，处理数值问题。就像计算器能做加减乘除。

**严谨定义**：数值计算算法主要用于科学计算，如求解方程根、建立数学模型、数值积分等。

**特点**：
- 算术运算占主导地位
- 结果通常是数值
- 精度是重要考量

**典型算法**：
- 迭代法：$x_{n+1} = g(x_n)$
- 插值法：$p(x_i) = y_i$，求 $p(x)$
- 数值积分：$\int_a^b f(x)dx \approx \sum_{i=1}^n w_i f(x_i)$

#### 非数值计算算法

**通俗理解**：处理非数值信息，如文字、图像、逻辑关系。就像搜索引擎处理文字信息。

**严谨定义**：非数值计算算法主要用于数据管理、实时控制以及人工智能等领域。

**特点**：
- 逻辑判断占主导地位
- 处理图形信息和字符信息
- 算法结构复杂多样

**典型算法**：
- 搜索算法：查找、匹配
- 排序算法：按特定顺序排列
- 图算法：最短路、最小生成树

### 4.2 按设计方法分类

#### 分治法（Divide and Conquer）

**思想**：将问题分解为若干个规模较小的相同子问题，递归求解子问题，最后合并子问题的解。

**适用问题**：问题可以自然分解的场合

**经典例子**：
- 归并排序：$T(n) = 2T(n/2) + O(n)$
- 快速排序：$T(n) = T(n/2) + O(n^2)$
- 二分查找：$T(n) = T(n/2) + O(1)$

#### 动态规划法（Dynamic Programming）

**思想**：将问题分解为相互重叠的子问题，通过存储子问题的解避免重复计算。

**适用问题**：最优子结构性质的问题

**关键要素**：
- 最优子结构
- 重叠子问题
- 状态转移方程

**经典例子**：
- 斐波那契数列：$F(n) = F(n-1) + F(n-2)$
- 背包问题：$v[i][w] = \max(v[i-1][w], v[i][w-w[i]] + v[i])$

#### 贪心法（Greedy Algorithm）

**思想**：每一步都选择当前最优的局部解，希望最终得到全局最优解。

**适用问题**：贪心选择性质的问题

**关键要素**：
- 贪心选择性质
- 最优子结构

**经典例子**：
- 活动选择问题：选择不冲突的活动
- 最小生成树：Prim算法、Kruskal算法

> [!warning] 
> 贪心法不一定得到最优解，需要证明贪心选择性质。

## 5 算法设计实例

### 补丁与Bug问题

#### 问题重述

T公司发行的字处理软件可能出现 $n$ 个特定的错误 $B = \{b_1, b_2, \ldots, b_n\}$。公司发放了 $m$ 个补丁 $P = \{p_1, p_2, \ldots, p_m\}$。

每个补丁 $p_i$ 的特点：
- **适用环境**：必须包含错误集合 $B_i^+$，且不包含错误集合 $B_i^-$（$B_i^+ \cap B_i^- = \emptyset$）
- **使用效果**：修复某些错误，加入某些错误，得到新的错误集合 $B_i^+$
- **使用时间**：消耗时间 $t_i$

初始版本包含所有 $n$ 个错误，问：
1. 能否通过使用补丁序列使软件无错误？
2. 若能，求总耗时最少的方案？

#### 问题建模

> [!example] 
> **状态表示**

将 $n$ 个bug的存在与否用二进制向量表示：
- 全1向量：$\underbrace{[1,1,\ldots,1]}_n$（初始状态，所有错误都存在）
- 全0向量：$\underbrace{[0,0,\ldots,0]}_n$（目标状态，所有错误都不存在）
- 一般状态：$[s_1, s_2, \ldots, s_n]$，其中 $s_i \in \{0,1\}$

**状态转换**：使用补丁 $p_i$ 将状态 $s$ 转换为 $s'$：
$$
s' = s \oplus (B_i^+ \cup B_i^-)
$$
其中 $\oplus$ 表示异或操作。

#### 算法设计

> [!tip] 
> **问题转化**：将补丁问题转化为图论中的最短路径问题。

**构建图模型**：
- 顶点：所有可能的状态（$2^n$ 个）
- 边：补丁 $p_i$ 从状态 $u$ 到状态 $v$
- 权：补丁的使用时间 $t_i$

**算法步骤**：
1. 构建状态空间图
2. 使用Dijkstra算法求从全1状态到全0状态的最短路径
3. 输出最短路径和总时间

#### 伪代码实现

```cpp
// 使用位掩码表示状态
int shortestPatchSequence(int n, vector<Patch> patches) {
    int target = (1 << n) - 1;  // 全1状态
    vector<int> dist(1 << n, INT_MAX);
    vector<int> prev(1 << n, -1);
    priority_queue<State> pq;
    
    dist[target] = 0;
    pq.push(State(target, 0));
    
    while (!pq.empty()) {
        State current = pq.top(); pq.pop();
        
        if (current.state == 0) break;  // 达到目标状态
        
        for (Patch p : patches) {
            if ((current.state & p.mask_in) == p.mask_in && 
                (current.state & p.mask_out) == 0) {
                int next_state = current.state ^ (p.mask_in | p.mask_out);
                if (dist[next_state] > dist[current.state] + p.time) {
                    dist[next_state] = dist[current.state] + p.time;
                    prev[next_state] = current.state;
                    pq.push(State(next_state, dist[next_state]));
                }
            }
        }
    }
    
    return dist[0];  // 返回最短时间
}
```

## 6 算法分析基础

### 6.1 分析的基本原则

#### 独立于机器的度量

**核心思想**：算法分析应该独立于具体的计算机硬件，关注算法本身的特性。

**为什么需要独立于机器？**
- 不同机器有不同的运算速度
- 不同的编译器优化级别
- 不同的编程语言效率

**分析标准**：
- **时间复杂度**：算法执行的基本操作次数
- **空间复杂度**：算法使用的额外空间

#### 最坏情况分析

**为什么使用最坏情况？**
- 提供性能的上界
- 保证在任何输入下的性能
- 便于不同算法的比较

**三种情况分析**：
1. **最好情况**（Best Case）：$\min_{inputs} T(I)$
2. **最坏情况**（Worst Case）：$\max_{inputs} T(I)$
3. **平均情况**（Average Case）：$\mathbb{E}[T(I)] = \sum_{I} p(I)T(I)$

> [!important] 
> 在算法分析中，最坏情况分析是最常用的，因为它提供的是性能保证。

### 6.2 时间复杂度的定义

#### 通俗理解
时间复杂度就像跑步的配速，描述的是"随着问题规模增大，算法运行时间增长的速度"。

#### 严谨定义

对于算法A的复杂度函数 $T(n)$，如果存在 $T'(n)$，使得当 $n \to \infty$ 时：
$$
\lim_{n \to \infty} \frac{T(n) - T'(n)}{T(n)} = 0
$$
那么 $T'(n)$ 称为算法A当 $n \to \infty$ 时的渐近复杂性。

#### 函数简化的原则

**忽略低阶项和常数因子**：
- $T(n) = 10n^2 + 100n + 10000$ → $T'(n) = n^2$
- $T(n) = n^2 + \sum_{i=1}^n i \times n + 10^{12}$ → $T'(n) = n^2$

> [!tip] 
> **为什么可以忽略常数因子？**因为不同的算法在不同机器上，常数因子的差异会被硬件性能的差异所掩盖。

### 6.3 渐近分析方法

#### 插入排序分析

> [!example] 
> **插入排序的最坏情况分析**

```cpp
for j ← 2 to n do           // 第1行：执行 n-1 次
    x ← A[j]                // 第2行：执行 n-1 次
    i ← j-1                 // 第3行：执行 n-1 次
    while i > 0 and x < A[i] do  // 第4-6行
        A[i+1] ← A[i]       // 第5行：执行 ∑(k=1 to n-1) (k-1) 次
        i ← i-1             // 第6行：执行 ∑(k=1 to n-1) (k-1) 次
    A[i+1] ← x              // 第7行：执行 n-1 次
```

计算总操作次数：
$$
W(n) = (n-1) + (n-1) + \sum_{k=1}^{n-1} (k-1) + \sum_{k=1}^{n-1} (k-1) + (n-1)
$$

$$
= 2(n-1) + 2\sum_{k=1}^{n-1} (k-1)
$$

$$
= 2n - 2 + 2 \times \frac{(n-1)(n-2)}{2}
$$

$$
= 2n - 2 + (n-1)(n-2)
$$

$$
= n^2 - n
$$

#### 选择排序分析

```cpp
for j ← 2 to n do           // 第1行：执行 n-1 次
    i ← min_index(A, j, n)  // 第2-3行：执行 n-1 次
    swap(A, j-1, i)         // 第6行：执行 n-1 次
```

其中 `min_index` 函数：
```cpp
for k ← j to n do           // 执行 n-j+1 次
    if A[k] < min_value      // 执行 n-j+1 次
        min_value = A[k]     // 执行 n-j+1 次
        min_index = k        // 执行 n-j+1 次
```

计算总操作次数：
$$
T(n) = (n-1) + \sum_{j=2}^n (n-j+1)
$$

$$
= n-1 + \sum_{k=1}^{n-1} k \quad (\text{令} k = n-j+1)
$$

$$
= n-1 + \frac{(n-1)n}{2}
$$

$$
= \frac{n^2 + n - 2}{2}
$$

#### 渐近比较

**插入排序**：$W(n) = n^2 - n = \Theta(n^2)$

**选择排序**：$T(n) = \frac{n^2 + n - 2}{2} = \Theta(n^2)$

> [!important] 
> 虽然两个算法的最坏情况时间复杂度相同（都是 $\Theta(n^2)$），但插入排序在某些情况下可能更快。

## 7 数学基础

### 7.1 函数的渐近表示

#### 五种渐近记号

| 记号       | 定义                                                                      | 含义   | 示例                  |
| -------- | ----------------------------------------------------------------------- | ---- | ------------------- |
| $O$      | $\exists c>0, \exists n_0, \forall n \geq n_0, 0 \leq f(n) \leq c g(n)$ | 上界   | $n^2 = O(n^3)$      |
| $\Omega$ | $\exists c>0, \exists n_0, \forall n \geq n_0, 0 \leq c g(n) \leq f(n)$ | 下界   | $n^2 = \Omega(n)$   |
| $\Theta$ | $f(n) = O(g(n)) \land f(n) = \Omega(g(n))$                              | 同阶   | $n^2 = \Theta(n^2)$ |
| $o$      | $\forall c>0, \exists n_0, \forall n \geq n_0, 0 \leq f(n) < c g(n)$    | 严格小于 | $n = o(n^2)$        |
| $\omega$ | $\forall c>0, \exists n_0, \forall n \geq n_0, 0 \leq c g(n) < f(n)$    | 严格大于 | $n^2 = \omega(n)$   |
|          |                                                                         |      |                     |

> [!tip] 
> - $f(n) = \Theta(g(n))$ 当且仅当 $\lim_{n \to \infty} \frac{f(n)}{g(n)} = c > 0$
> - $f(n) = o(g(n))$ 当且仅当 $\lim_{n \to \infty} \frac{f(n)}{g(n)} = 0$

#### 运算法则

1. **加法法则**：$O(f) + O(g) = O(\max(f, g))$
2. **乘法法则**：$O(f) \cdot O(g) = O(f \cdot g)$
3. **常数因子**：$O(c \cdot f(n)) = O(f(n))$，$c > 0$
4. **传递性**：若 $f(n) = O(g(n))$ 且 $g(n) = O(h(n))$，则 $f(n) = O(h(n))$

### 7.2 求和的技巧

#### 常见求和公式

| 求和类型 | 公式 | 示例 |
|----------|------|------|
| **算术级数** | $\sum_{k=1}^n k = \frac{n(n+1)}{2}$ | $\sum_{k=1}^{100} k = 5050$ |
| **平方和** | $\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$ | $\sum_{k=1}^{10} k^2 = 385$ |
| **立方和** | $\sum_{k=1}^n k^3 = \left(\frac{n(n+1)}{2}\right)^2$ | $\sum_{k=1}^{10} k^3 = 3025$ |
| **几何级数** | $\sum_{k=0}^n r^k = \frac{1-r^{n+1}}{1-r}$ | $\sum_{k=0}^{10} 2^k = 2047$ |
| **调和级数** | $\sum_{k=1}^n \frac{1}{k} = H_n \approx \ln n + \gamma$ | $\sum_{k=1}^{100} \frac{1}{k} \approx 5.187$ |

> [!important] 
> 调和级数 $H_n = \sum_{k=1}^n \frac{1}{k}$ 的增长速度是 $\Theta(\log n)$。

#### 求和上界估计

> [!example] 
> **估计 $\sum_{k=1}^n \frac{1}{k}$ 的上界**

使用积分比较：
$$
\sum_{k=1}^n \frac{1}{k} \leq 1 + \int_1^n \frac{1}{x} dx = 1 + \ln n
$$

因此：
$$
\sum_{k=1}^n \frac{1}{k} = O(\log n)
$$

### 7.3 递推方程的求解

#### 递推方程的定义

**定义**：设序列 $\{a_0, a_1, \ldots, a_n, \ldots\}$，一个把 $a_n$ 与某些个 $a_i$（$i < n$）联系起来的等式叫做关于序列 $\{a_n\}$ 的递推方程。

**一般形式**：
$$
T(n) = 
\begin{cases} 
c & \text{if } n \leq n_0 \\
\sum_{i=1}^k a_i T(b_i(n)) + f(n) & \text{if } n > n_0
\end{cases}
$$

#### 求解方法

1. **迭代法**
   - 直接迭代：展开递推式
   - 换元迭代：变量替换
   - 差消迭代：消去交叉项

2. **递归树法**：将递推关系可视化为树

3. **主定理**：特定形式的递推式快速求解

> [!example] 
> **汉诺塔问题**

递推方程：$T(n) = 2T(n-1) + 1$，$T(1) = 1$

**迭代求解**：
$$
\begin{align*}
T(n) &= 2T(n-1) + 1 \\
&= 2(2T(n-2) + 1) + 1 = 2^2 T(n-2) + 2 + 1 \\
&= 2^2(2T(n-3) + 1) + 2 + 1 = 2^3 T(n-3) + 2^2 + 2 + 1 \\
&\vdots \\
&= 2^{n-1} T(1) + 2^{n-2} + \cdots + 2 + 1 \\
&= 2^{n-1} \cdot 1 + (2^{n-1} - 1) \\
&= 2^n - 1
\end{align*}
$$

## 8 高级分析技术

### 8.1 主定理

> [!important] 
> **主定理**是分析分治算法时间复杂度的强大工具。

**定理**：设 $a \geq 1$，$b > 1$ 为常数，$f(n)$ 为函数，$T(n)$ 为非负整数，且
$$
T(n) = aT\left(\frac{n}{b}\right) + f(n)
$$
则有：

1. **情况1**：若 $f(n) = O(n^{\log_b a - \epsilon})$，其中 $\epsilon > 0$，则
   $$
   T(n) = \Theta(n^{\log_b a})
   $$

2. **情况2**：若 $f(n) = \Theta(n^{\log_b a})$，则
   $$
   T(n) = \Theta(n^{\log_b a} \log n)
   $$

3. **情况3**：若 $f(n) = \Omega(n^{\log_b a + \epsilon})$，其中 $\epsilon > 0$，且对某个常数 $c < 1$ 和所有充分大的 $n$ 有 $af\left(\frac{n}{b}\right) \leq cf(n)$，则
   $$
   T(n) = \Theta(f(n))
   $$

> [!warning] 
> 主定理不适用于 $f(n)$ 的增长速度在情况1和情况3之间的"中间地带"。

### 8.2 典型递推式分析

> [!example] 
> **例1：归并排序**

递推方程：$T(n) = 2T\left(\frac{n}{2}\right) + n$

- $a = 2$，$b = 2$，$f(n) = n$
- $\log_b a = \log_2 2 = 1$
- $f(n) = n = \Theta(n^1)$，属于情况2

因此：
$$
T(n) = \Theta(n \log n)
$$

> [!example] 
> **例2：二分查找**

递推方程：$T(n) = T\left(\frac{n}{2}\right) + 1$

- $a = 1$，$b = 2$，$f(n) = 1$
- $\log_b a = \log_2 1 = 0$
- $f(n) = 1 = \Theta(n^0)$，属于情况2

因此：
$$
T(n) = \Theta(\log n)
$$

> [!example] 
> **例3：快速排序平均情况**

递推方程：$T(n) = \frac{1}{n} \sum_{i=1}^{n-1} [T(i) + T(n-i)] + O(n)$

化简后：
$$
T(n) = \frac{2}{n} \sum_{i=1}^{n-1} T(i) + O(n)
$$

使用主定理（情况2）：
$$
T(n) = \Theta(n \log n)
$$

> [!tip] 
> 平均情况下，快速排序的最坏时间复杂度是 $\Theta(n^2)$，但期望时间是 $\Theta(n \log n)$。

## 10 核心思想总结

### 算法的本质特征

1. **有穷性**：算法必须在有限步骤内终止，这是算法与程序的根本区别。
2. **确定性**：每一步都有明确的定义，没有歧义。
3. **可行性**：每一步都可以在有限时间内完成。
4. **输入输出**：有明确的输入和对应的输出。

### 分析的核心思想

1. **渐近分析**：关注问题规模增大时的增长趋势，忽略常数因子和低阶项。
2. **最坏情况分析**：提供性能保证，是算法分析的标准方法。
3. **独立于机器**：关注算法本身的特性，而非具体实现环境。

### 算法设计方法

1. **分治法**：分解-解决-合并，适用于可分解的问题。
2. **动态规划**：存储子问题解，避免重复计算，适用于最优子结构问题。
3. **贪心法**：每步选择局部最优，希望得到全局最优，需要证明贪心选择性质。

### 数学工具的应用

1. **渐近表示**：用O、Ω、Θ等记号描述算法性能。
2. **求和技巧**：计算循环和递归的复杂度。
3. **主定理**：快速求解特定形式的递推方程。

### 问题求解的思维模式

1. **模型抽象**：将实际问题抽象为数学模型。
2. **算法设计**：选择合适的算法设计方法。
3. **复杂度分析**：评估算法的时空效率。
4. **实现验证**：编写代码并测试正确性。

> [!tip] 
> 学习算法不仅是为了编程，更重要的是培养系统化思考和问题求解的能力。算法思维将伴随你终身，让你能够更高效地分析和解决各种复杂问题。
