## 1. 可满足性与有效性

对应课件第 3 页。设命题公式 $\varphi$ 的命题变量集为 $V$，真值赋值 $\tau:V\to\{0,1\}$ 按联结词的语义扩展到公式。写 $\tau\models\varphi$ 表示 $\varphi$ 在 $\tau$ 下为真。

**定义**：若存在 $\tau$ 使 $\tau\models\varphi$，则称 $\varphi$ **可满足**；若任意 $\tau$ 都满足 $\varphi$，则称其**有效**，记作 $\models\varphi$。不存在成真赋值时称其**不可满足**。

**命题**：$\varphi$ 可满足，当且仅当 $\neg\varphi$ 不是有效的。

**证明**：$\varphi$ 可满足意味着存在 $\tau$ 使 $\tau(\varphi)=1$，由否定的语义，此时 $\tau(\neg\varphi)=0$，故 $\neg\varphi$ 不是有效式。反之，$\neg\varphi$ 不是有效式，意味着存在使它为假的赋值；同一赋值就使 $\varphi$ 为真。这里“不是有效”是对元语言中全称断言的否定，不能读成“任意赋值都不满足”。

同理，$\varphi$ 有效当且仅当 $\neg\varphi$ 不可满足。因此，SAT 判定也能用于有效性判定：检查否定式是否不可满足即可。

可满足性的用途是检验一组规范是否能够同时成立。例如将规范表示为 $C_1\land\cdots\land C_m$，可满足表示存在至少一种符合全部条件的方案；求得满足赋值后还可还原具体方案。后文的 N 皇后编码就是这一思路。

本文用 $\varphi\equiv\psi$ 表示在所有共同变量的赋值下两式真值相同；用 $\Gamma\models\varphi$ 表示语义后承。两者都不同于证明系统中的 $\Gamma\vdash\varphi$。本章的范式转换首先是语义等值问题，求解器的“完备”则指判定程序能覆盖所有情况。

## 2. 文字、子句与三种范式

### 2.1 基本定义与边界约定

对应课件第 4 页。**文字**是命题变量 $p$ 或其否定 $\neg p$，前者称正文字，后者称负文字。$p$ 与 $\neg p$ 互为**互补文字**。

**子句**是有限个文字的析取
**项**是有限个文字的合取
**合取范式**（CNF）是有限个子句的合取
**析取范式**（DNF）是有限个项的析取
例如 $(\neg q\lor p\lor r)\land(\neg p\lor r)\land q$ 是 CNF，而 $(p\land r)\lor(\neg p\land r)\lor(p\land\neg r)$ 是 DNF。单个文字可以看作只有一个文字的子句或项，因此 $q$ 也是合法的子句。

**补充约定**：为统一算法的终止情况，空析取记为 $\bot$，空合取记为 $\top$。于是空子句为假，空子句集所表示的合取为真；空项为真，零个项构成的 DNF 为假。$\{\varnothing\}$ 与 $\varnothing$ 表示不同的子句集：前者含一个空子句，后者根本没有子句。

重复文字可用幂等律删除。包含互补文字的子句永真，可以从 CNF 中删除；包含互补文字的项永假，可以从 DNF 中删除。这些语义化简不会改变公式的模型集。

### 2.2 NNF、CNF 与 DNF 的关系

对应课件第 5 页。**否定范式**（NNF）只使用 $\land,\lor,\neg$，且 $\neg$ 只直接作用于命题变量。等价地，NNF 从文字出发，仅通过合取与析取构成。

每个 CNF、DNF 都是 NNF，反向不成立。课件例子 $(r\lor(p\land\neg q))\land(\neg r\lor(p\land q))$ 的否定都只作用于变量，所以是 NNF；但其外层合取的分量并非全是子句，外层也不是若干项的析取，因而按当前语法形式既不是 CNF，也不是 DNF。

“是某种范式”描述当前公式的语法结构，“等值于某种范式”描述存在另一个同真值公式。不能因为能够转换，就把原式直接称为 CNF。

### 2.3 范式直接给出的判定性质

对应课件第 6 页。

**命题 1**：CNF 有效，当且仅当其中每个子句都有效。

**证明**：若合取在所有赋值下为真，则每个合取分量在所有赋值下为真。反之，每个子句都有效，则任意赋值都使全部子句为真，从而使它们的合取为真。

**命题 2**：子句有效，当且仅当其中存在一对互补文字。

**证明**：若含 $p\lor\neg p$，任意赋值至少使二者之一为真。反之，若没有互补文字，就可以把每个正文字的变量赋为 $0$，把每个负文字的变量赋为 $1$；无互补文字保证这些要求不冲突。这样全部文字同时为假，子句并非有效。空子句也符合此结论。

**命题 3**：DNF 可满足，当且仅当其中至少一个项可满足；一个项可满足，当且仅当其中不存在互补文字。

**证明**：析取为真恰好要求至少一个分量为真。若项中包含 $p\land\neg p$，不可能满足；若不含互补文字，把正文字变量赋为 $1$、负文字变量赋为 $0$，即可同时满足全部文字。

这说明 **CNF 的有效性**与 **DNF 的可满足性**可以直接局部检查；并不说明 CNF 的可满足性也能逐子句检查。各子句可能分别可满足，却没有共同模型，例如 $p\land\neg p$。

## 3. 范式转换及其存在性证明

### 3.1 等值转换步骤

对应课件第 7 页。将任意公式转为等值 CNF，可以依次执行：消去蕴涵与双蕴涵，将否定内移得到 NNF，再把析取分配到合取上。

第一步使用 $\alpha\to\beta\equiv\neg\alpha\lor\beta$，以及 $\alpha\leftrightarrow\beta\equiv(\neg\alpha\lor\beta)\land(\neg\beta\lor\alpha)$。第二步使用双重否定律 $\neg\neg\alpha\equiv\alpha$，以及德摩根律 $\neg(\alpha\land\beta)\equiv\neg\alpha\lor\neg\beta$、$\neg(\alpha\lor\beta)\equiv\neg\alpha\land\neg\beta$。第三步使用 $\alpha\lor(\beta\land\gamma)\equiv(\alpha\lor\beta)\land(\alpha\lor\gamma)$，必要时借助交换律、结合律调整位置。

转换为 DNF 时，前两步相同，最后改用合取对析取的分配律 $\alpha\land(\beta\lor\gamma)\equiv(\alpha\land\beta)\lor(\alpha\land\gamma)$。

**课件例子的展开**：令 $\varphi=(r\lor(p\land\neg q))\land(r\to(p\land q))$。消去蕴涵后得到 $(r\lor(p\land\neg q))\land(\neg r\lor(p\land q))$，它已是 NNF。分别分配两个析取分量，得到 CNF $\varphi\equiv(r\lor p)\land(r\lor\neg q)\land(\neg r\lor p)\land(\neg r\lor q)$。

进一步可选地化简：前后含 $p$ 的两个子句合取等值于 $p$；另外两个子句分别是 $q\to r$ 和 $r\to q$，故原式还等值于 $p\land(r\leftrightarrow q)$。后一表达式便于理解语义，但其书写形式含有 $\leftrightarrow$，不能直接称为 CNF。

### 3.2 NNF 存在性：按公式长度归纳

对应课件第 9—13 页。**定理**：每个命题逻辑公式都等值于某个 NNF。

**证明**：先消去 $\to,\leftrightarrow$，只需考虑由 $\neg,\land,\lor$ 构成的公式。按公式长度 $|\varphi|$ 作强归纳，假设任意严格更短的公式都等值于某个 NNF。分以下情况。

1. $\varphi$ 为 $p$ 或 $\neg p$ 时，本身已是 NNF。
2. $\varphi=\neg\neg\alpha$ 时，$\alpha$ 更短，由归纳假设存在 NNF $\alpha'$ 与之等值，再由双重否定律得到 $\varphi\equiv\alpha'$。
3. $\varphi=\alpha\lor\beta$ 时，由归纳假设分别取等值 NNF $\alpha',\beta'$，则 $\varphi\equiv\alpha'\lor\beta'$；后者仍为 NNF。$\alpha\land\beta$ 的情形同理。
4. $\varphi=\neg(\alpha\lor\beta)$ 时，德摩根律给出 $\varphi\equiv\neg\alpha\land\neg\beta$。$\neg\alpha$ 与 $\neg\beta$ 均比 $\varphi$ 严格更短，因此分别有等值 NNF $\alpha',\beta'$，于是 $\varphi\equiv\alpha'\land\beta'$。
5. $\varphi=\neg(\alpha\land\beta)$ 时，同理对更短的 $\neg\alpha,\neg\beta$ 使用归纳假设，再以析取连接其 NNF。

这些情形穷尽了公式的构造方式，故定理成立。关键在于否定复合公式时，归纳假设应用于 $\neg\alpha$ 和 $\neg\beta$，而不只是应用于 $\alpha$ 和 $\beta$；按长度强归纳保证这种用法合法。

### 3.3 CNF 与 DNF 存在性

对应课件第 14—15 页。**定理**：每个命题逻辑公式都等值于某个 CNF，也都等值于某个 DNF。

**CNF 的证明**：由上一节，只需对 NNF 作结构归纳。文字自身就是单子句 CNF。若 $\alpha,\beta$ 分别等值于 CNF，则两者的合取仍为 CNF。剩下的是 $\alpha\lor\beta$：设 $\alpha\equiv\bigwedge_{i=1}^{m}C_i$，$\beta\equiv\bigwedge_{j=1}^{n}D_j$，其中 $C_i,D_j$ 均为子句。反复使用分配律得到核心转换式：

$$
\left(\bigwedge_{i=1}^{m}C_i\right)\lor\left(\bigwedge_{j=1}^{n}D_j\right)
\equiv\bigwedge_{i=1}^{m}\bigwedge_{j=1}^{n}(C_i\lor D_j).
$$

每个 $C_i\lor D_j$ 仍是文字的析取，因而右侧为 CNF。其语义也可直接检验：若左式为真，至少一侧的全部子句为真，于是所有配对子句都为真；若左式为假，两侧各有一个假子句 $C_i,D_j$，对应配对子句就为假。

**课件笔误说明**：第 15 页第三种情况再次写成了 $\varphi=(\varphi_1\land\varphi_2)$，但其后采用的是析取分配律；此处应为 $\varphi=(\varphi_1\lor\varphi_2)$。

**DNF 的证明**：仍对 NNF 作结构归纳。文字是 DNF；两个 DNF 的析取仍为 DNF；两个 DNF 的合取通过分配律转为所有项的两两合取之析取。每个新分量仍是项，归纳完成。这个存在性结论不保证转换结果规模较小。

### 3.4 等值转换的规模代价

对应课件第 8 页。考虑 $F_n=(p_1\land q_1)\lor\cdots\lor(p_n\land q_n)$，其中 $2n$ 个变量互不相同，原式长度为 $\Theta(n)$。用分配律生成的 CNF 中，每个子句对每个 $i$ 恰好选取 $p_i$ 或 $q_i$，所以子句共 $2^n$ 个，每个含 $n$ 个文字，总文字出现次数为 $n2^n$。

例如 $F_2$ 的 CNF 是 $(p_1\lor p_2)\land(p_1\lor q_2)\land(q_1\lor p_2)\land(q_1\lor q_2)$。从第 $n-1$ 组扩展到第 $n$ 组时，每个已有选择都分成选择 $p_n$ 或 $q_n$ 两种，因此子句数满足 $c_n=2c_{n-1}$、$c_1=2$，解为 $c_n=2^n$。

课件以“输入长度为 $n$，结果为 $2^n$”描述指数膨胀；严格说，本例中的 $n$ 是变量对数，而非精确符号总数。该例说明按此等值分配过程可产生指数大小的输出，不能把它当作高效的通用预处理。

**补充：等值与等可满足**。SAT 建模通常只要求保存是否有解。可以为子公式引入新变量，并添加局部定义约束，避免复制展开。例如用 $x$ 表示 $\alpha\land\beta$ 时，可用 $(\neg x\lor\alpha)\land(\neg x\lor\beta)\land(x\lor\neg\alpha\lor\neg\beta)$ 表达 $x\leftrightarrow(\alpha\land\beta)$，逐层编码并要求根变量为真。这里 $\alpha,\beta$ 可由对应的子公式变量代表，使每个节点只增加常数个文字。

所得扩展公式与原公式的关系是：原变量赋值满足原式，当且仅当它能扩展为新公式的满足赋值，即 $\varphi\equiv\exists\boldsymbol{x}\,T_\varphi$。存在量词在此说明对辅助变量的投影关系，并非把课件语言改成一阶逻辑。不要把增加变量后的 $T_\varphi$ 无条件写成与 $\varphi$ 在扩展变量集上逻辑等值。

## 4. 主析取范式与主合取范式

### 4.1 极小项与极大项的编码

对应课件第 16—17 页。固定且有序的变量表为 $(p_1,\ldots,p_n)$。**极小项**是恰好包含每个变量的一种文字的合取；**极大项**是恰好包含每个变量的一种文字的析取。要求每个变量出现一次，而不只是笼统地要求有 $n$ 个文字。

对二进制串 $b_1\cdots b_n$，按通常二进制位权解释为整数 $k$。极小项 $m_k$ 在 $b_i=1$ 时使用 $p_i$，在 $b_i=0$ 时使用 $\neg p_i$；它恰好在编码赋值处为真。极大项 $M_k$ 在 $b_i=0$ 时使用 $p_i$，在 $b_i=1$ 时使用 $\neg p_i$；它恰好在编码赋值处为假。

例如按 $(p,q,r)$ 排列，$m_5=p\land\neg q\land r$，其唯一成真赋值为 $101$；$M_2=p\lor\neg q\lor r$，其唯一成假赋值为 $010$。二者编码规则相反，是因为一个记录成真行，另一个记录成假行。

由德摩根律可得 $M_k\equiv\neg m_k$。这里下标相同指相同的真值表行，并不表示两者使用相同符号的文字。

### 4.2 从真值表构造主范式

对应课件第 18—19 页。**主析取范式**是若干不同极小项的析取，**主合取范式**是若干不同极大项的合取。设 $T=\{k:\tau_k\models\varphi\}$，$Z=\{k:\tau_k\not\models\varphi\}$，则：

$$
\varphi\equiv\bigvee_{k\in T}m_k
\equiv\bigwedge_{k\in Z}M_k.
$$

**证明**：对任意赋值 $\tau_j$，析取中的 $m_k$ 为真恰好要求 $j=k\in T$，所以左侧主范式与 $\varphi$ 有相同成真赋值。合取中的 $M_k$ 为假恰好要求 $j=k\in Z$，所以右侧主范式与 $\varphi$ 有相同成假赋值。两者均与原式等值。

固定变量表后，成真行与成假行由公式语义唯一确定，故主范式的项集合或子句集合唯一；书写顺序不影响公式。若改变变量表或变量顺序，编码与主范式的书写也会改变。

若 $\varphi$ 为永真式，主合取范式是空合取 $\top$，主析取范式含全部 $2^n$ 个极小项；若为永假式，主析取范式是空析取 $\bot$，主合取范式含全部极大项。课件第 18 页的“求真式/矛盾式的主范式记为 1 或 0”需结合这些空运算约定理解。

### 4.3 课件真值表的完整推导

第 18 页真值表以图片给出。令 $B=r\lor(p\land\neg q)$，$C=r\to(p\land q)$，$A=B\land C$，变量顺序为 $(p,q,r)$。逐行计算如下。

| 编码 | $p$ | $q$ | $r$ | $p\land\neg q$ | $B$ | $p\land q$ | $C$ | $A$ |
|---|---|---|---|---|---|---|---|---|
| $000$ | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 0 |
| $001$ | 0 | 0 | 1 | 0 | 1 | 0 | 0 | 0 |
| $010$ | 0 | 1 | 0 | 0 | 0 | 0 | 1 | 0 |
| $011$ | 0 | 1 | 1 | 0 | 1 | 0 | 0 | 0 |
| $100$ | 1 | 0 | 0 | 1 | 1 | 0 | 1 | 1 |
| $101$ | 1 | 0 | 1 | 1 | 1 | 0 | 0 | 0 |
| $110$ | 1 | 1 | 0 | 0 | 0 | 1 | 1 | 0 |
| $111$ | 1 | 1 | 1 | 0 | 1 | 1 | 1 | 1 |

只有 $100$ 与 $111$ 两行为真，故主析取范式是 $m_4\lor m_7=(p\land\neg q\land\neg r)\lor(p\land q\land r)$。它与第 3.1 节的 $p\land(r\leftrightarrow q)$ 一致。

其余六行给出主合取范式 $M_0\land M_1\land M_2\land M_3\land M_5\land M_6$。具体地，$M_0=p\lor q\lor r$，$M_1=p\lor q\lor\neg r$，$M_2=p\lor\neg q\lor r$，$M_3=p\lor\neg q\lor\neg r$，$M_5=\neg p\lor q\lor\neg r$，$M_6=\neg p\lor\neg q\lor r$。

一般 CNF 只要求由子句合取而成，不要求每个子句包含全部变量。因此，第 3.1 节四个二文字子句构成的 CNF，与此处六个三文字子句构成的主 CNF 可以等值而形式不同。

## 5. Horn 子句与可满足性算法

### 5.1 定义、规则与约束

对应课件第 21 页。**Horn 子句**是至多含一个正文字的子句；**Horn 公式**是 Horn 子句的合取。

恰有一个正文字的子句 $\neg p_1\lor\cdots\lor\neg p_k\lor q$ 等值于规则 $(p_1\land\cdots\land p_k)\to q$。正文字 $q$ 是规则的结论；负文字对应前提。当 $k=0$ 时，规则为 $\top\to q$，即事实 $q$。

没有正文字的子句 $\neg p_1\lor\cdots\lor\neg p_k$ 等值于 $(p_1\land\cdots\land p_k)\to\bot$，表示禁止这些变量同时为真，称为纯负约束。空子句也是这种情形，且立即不可满足。

课件的两个例子 $(\neg p\lor\neg q\lor\neg s)\land(\neg q\lor\neg r\lor p)\land s$ 与 $(\neg p_2\lor\neg p_3\lor\neg p_5\lor p_1)\land(\neg p_5\lor\neg p_1)$ 都是 Horn 公式。例如前者包含约束 $p\land q\land s\to\bot$、规则 $q\land r\to p$ 与事实 $s$。

Horn 结构使正信息的推导具有单一结论，因而适合前向推理，是逻辑编程、Datalog、知识表示和自动推理的重要基础。课件将其称为可高效自动推理的“最大实用片段”；这属于用途概括，不应据此推断所有其他多项式可判定片段都包含于 Horn 逻辑。

### 5.2 标记算法与课件实例

对应课件第 22 页。设 $S$ 为已标记原子的集合，初始 $S=\varnothing$。反复寻找规则 $p_1\land\cdots\land p_k\to q$，若全部前提都属于 $S$ 而 $q\notin S$，就将 $q$ 加入 $S$；事实的前提为空，因而可以立即触发。直到不存在可触发的新结论。

最后检查所有纯负约束 $p_1\land\cdots\land p_k\to\bot$：若某个约束的全部前提均已标记，则返回不可满足；否则返回可满足，并令 $S$ 中原子为真，其余原子为假。

课件实例含六个子句：$p$、$q$、$\neg p\lor\neg q\lor r$、$\neg r\lor\neg s\lor t$、$\neg r\lor s$、$\neg t\lor\neg u$。前五个依次对应事实和规则 $p$、$q$、$p\land q\to r$、$r\land s\to t$、$r\to s$；最后一个是约束 $t\land u\to\bot$。

先标记 $p,q$，由此标记 $r$，继而标记 $s$，最后标记 $t$，得到闭包 $S=\{p,q,r,s,t\}$。没有规则要求 $u$ 为真，故 $u$ 不被标记。约束的前提尚未全部进入 $S$，算法返回可满足；模型为 $p=q=r=s=t=1,u=0$。

未标记不意味着原子在所有模型中都为假。它只表示尚未被正规则强制为真，算法在构造模型时选择把它赋为假。本例中 $u$ 确实在所有模型中为假，是因为 $t$ 必真且有约束 $\neg t\lor\neg u$，这个结论需要额外使用约束。

### 5.3 正确性与最小模型

对应课件第 24—25 页。先证明算法维护的语义不变式。

**引理**：对于任意已标记的原子 $p$，Horn 公式 $\varphi$ 的每个模型都使 $p$ 为真，即 $\varphi\models p$。

**证明**：按标记发生的先后顺序作归纳。设第 $i$ 次标记 $q$，由某个规则 $p_1\land\cdots\land p_k\to q$ 触发，且全部前提此前已标记。任取模型 $\tau\models\varphi$，由归纳假设，$\tau$ 使全部 $p_j$ 为真。它也满足该规则，因此必须使 $q$ 为真。$k=0$ 时，规则就是事实 $q$，结论直接成立，覆盖了归纳起点。

**定理**：标记算法正确判定 Horn 公式的可满足性。

**证明，不可满足分支**：若纯负约束的全部前提都被标记，则由引理，任意假定的模型都必须使全部前提为真；但该约束又禁止这种情况。因此不存在模型，返回不可满足正确。

**证明，可满足分支**：若没有约束被触发，定义 $\tau_S(p)=1$ 当且仅当 $p\in S$。对于含正结论 $q$ 的规则，若 $q\in S$，则该子句由正文字满足；若 $q\notin S$，由于算法已停止，至少一个前提 $p_j\notin S$，否则应继续标记 $q$。此时 $\neg p_j$ 为真，规则仍满足。对于纯负约束，未触发意味着至少一个前提不在 $S$，相应负文字使约束成立。因此 $\tau_S$ 满足全部子句，是 $\varphi$ 的模型。

**补充结论：最小模型**。把模型表示为其中取真原子的集合，由引理可知，任意模型的真原子集合都包含 $S$；又因为可满足分支中 $S$ 自身就是模型，所以它是按集合包含关系的最小模型。这里最小模型是唯一的，但公式可以有多个模型。

算法终止也清楚：每次循环只标记一个尚未标记的原子；若共有 $v$ 个不同原子，则标记事件至多 $v$ 次。不同的合法触发顺序最终都生成由事实与正规则决定的同一最小闭包。

### 5.4 复杂度中的输入规模

对应课件第 23 页。课件由“每轮标记一个新原子”给出 $O(n)$，并将 $n$ 描述为原子数量。这个论证直接保证的是**至多线性次数的标记**，尚未计算每轮寻找可触发规则的代价。

设 $v$ 为不同原子数，$L$ 为输入表示长度，包括子句与文字出现次数。若每轮都扫描整个公式，最多 $v$ 轮扫描只能给出 $O(vL)$ 量级的上界；仅凭标记次数不能断言总时间为 $O(v)$，因为读取含大量重复出现的输入本身就需要时间。

**补充：线性实现的依据**。为每条规则记录尚未被标记的前提数，并为每个原子记录它作为前提出现在哪些规则中。将事实放入队列，每个原子首次被标记时只遍历它的前提出现位置，递减相应计数；计数归零就触发结论或约束。预处理、传播与检查合计为 $O(L)$，因为每个文字出现位置只处理常数次。结论是 Horn-SAT 可以在输入长度的线性时间内求解，而非任意朴素扫描实现都自动线性。

## 6. SAT 与计算复杂性

对应课件第 27—29 页。**CNF-SAT** 的输入是 CNF 公式，问题是是否存在满足全部子句的赋值。课件简称 SAT；一般公式的可满足性也常用这一名称。

课件第 27 页使用公式 $\varphi=(a\lor b\lor c)\land(\neg a\lor b\lor\neg c)\land(a\lor\neg b\lor\neg c)\land(\neg a\lor\neg b\lor\neg c)\land(\neg a\lor\neg b\lor c)\land(a\lor b\lor\neg c)$。对给定候选 $a=0,b=0,c=1$，第三个子句为真，但第六个子句 $a\lor b\lor\neg c$ 为假，因此该候选不满足公式。检验一个候选只需依次计算各文字与子句；寻找满足候选则面对更多可能性。

**P** 是能够由确定性算法在输入长度的多项式时间内判定的问题类。**NP** 是“是”实例具有多项式长度的证书，而且证书能在多项式时间内验证的问题类。SAT 的证书是各变量的真值；给定赋值后，计算公式真值的时间与公式长度成线性关系，故 SAT 属于 NP。

注意 NP 的定义并不是“必须穷举”或“已证明不能高效求解”。显然 $\mathrm{P}\subseteq\mathrm{NP}$，而 $\mathrm{P}=\mathrm{NP}$ 是课件讨论的开放问题。课件同时介绍其为克雷数学研究所七个千禧年难题之一，设有一百万美元奖金，并提到普遍猜想 $\mathrm{P}\ne\mathrm{NP}$；这里记录的是课件背景，不以猜想作为定理依据。

**多项式时间归约**：若能在多项式时间内把问题 $A$ 的实例 $x$ 转换为问题 $B$ 的实例 $f(x)$，且 $x$ 为“是”实例当且仅当 $f(x)$ 为“是”实例，则记 $A\leq_p B$。归约方向表示可以借助 $B$ 的求解算法解决 $A$。

**NP 完全**要求两个条件：问题属于 NP，且 NP 中每个问题都能多项式归约到它。SAT 是经典的 NP 完全问题，这是本节采用的定理；课件没有展开 Cook–Levin 定理的证明。若某个 NP 完全问题属于 P，则任意 NP 问题都可先归约再调用其多项式算法，故 NP 包含于 P，与反向包含合起来得到 P=NP。课件还提到 Stephen Cook 因 NP 完全性方面的工作获得 1982 年图灵奖。

不要把前面的范式存在性证明直接当成“任意公式都能通过等值分配多项式归约为 CNF”的证明：分配过程可能指数膨胀。使用辅助变量保存可满足性的编码才可以避开这一规模问题。

## 7. DPLL：传播、分支与回溯

### 7.1 子句集化简与终止条件

对应课件第 30 页。DPLL 得名于 Davis、Putnam、Logemann、Loveland。把 CNF 看作子句集合 $F$，一个子句又看作文字集合，因而子句内部和子句之间的重复可略去。

给定文字 $\ell$，要求它为真时，记化简结果为 $F\!\upharpoonright_\ell$：删除所有包含 $\ell$ 的子句，因为它们已满足；从其余子句中删除 $\ell$ 的互补文字，因为该文字必假；其他文字保持。化简必须同时保留此前的部分赋值，便于返回完整模型。

若 $F=\varnothing$，全部约束已满足，返回可满足；若 $\varnothing\in F$，至少一个子句全部文字已假，返回不可满足。**单位子句**只有一个文字 $\{\ell\}$，任何模型都必须使 $\ell$ 为真，所以可以直接传播，无须尝试其相反赋值。

### 7.2 DPLL 过程及其正确性

将课件的 $\operatorname{dp1}(\ell,F)$ 统一理解为“令 $\ell$ 为真、化简公式，再递归调用 DPLL”。下列伪代码明确其含义，不额外加入课件未使用的优化。

```text
DPLL(F):
    若 F 为空子句集，返回 SAT
    若 F 包含空子句，返回 UNSAT
    若 F 含单位子句 {ℓ}，返回 DPLL(F 限制于 ℓ 为真)
    选择 F 中一个尚未赋值的原子 A
    若 DPLL(F 限制于 A 为真) 返回 SAT，返回 SAT
    返回 DPLL(F 限制于 ¬A 为真)
```

**化简性质**：对使 $\ell$ 为真的赋值，原公式与化简结果的真假一致。删除的是已经为真的子句，以及在剩余子句中已经为假的文字，不会改变这些赋值下的满足情况。

**单位传播正确性**：若存在单位子句 $\{\ell\}$，所有模型都必须令 $\ell$ 为真。因此 $F$ 可满足当且仅当 $F\!\upharpoonright_\ell$ 可满足；从后者模型补回该单位赋值就得到原公式模型。

**分支正确性**：若无单位子句，对选定原子 $A$，任意总赋值必且仅可能满足 $A=1$ 或 $A=0$。于是 $F$ 可满足当且仅当 $F\!\upharpoonright_A$ 或 $F\!\upharpoonright_{\neg A}$ 可满足。第一支失败后检验第二支，便不会遗漏模型。

**终止与完备性**：每次传播或分支都固定一个仍出现在公式中的未赋值变量，变量数严格减少。终止叶由空子句集或空子句判定，因此搜索树有限；按剩余变量数归纳，上述等价关系保证有模型时能找到模型、无模型时能确认不可满足。最坏情况下仍可能出现指数规模的搜索树，完备不等于多项式时间。

### 7.3 两个课件公式的求解

**第 30 页例子**：$F=(b\lor c)\land(\neg a\lor\neg d)\land(\neg b\lor d)$。先取 $b=1$，第一个子句删除，第三个子句化为单位子句 $d$，因此传播 $d=1$。第二个子句随即化为 $\neg a$，传播 $a=0$ 后子句集为空，得到 SAT。剩余变量 $c$ 未受约束，可以任取，例如得到模型 $(a,b,c,d)=(0,1,0,1)$。

这条成功路径并未经历回溯，但算法必须具备失败后回到另一分支的能力。满足部分赋值后任取其余变量，只适用于所有子句都已满足的情况；不能在仍有非空约束时任意补值。

**第 31 页例子**：令 $\varphi_2=(a\lor\neg b\lor d)\land(a\lor\neg b\lor e)\land(\neg b\lor\neg d\lor\neg e)\land(a\lor b\lor c\lor d)\land(a\lor b\lor c\lor\neg d)\land(a\lor b\lor\neg c\lor e)\land(a\lor b\lor\neg c\lor\neg e)$。

课件给出部分赋值 $a=1,b=0,c=0,d=1$。令 $a=1$ 后，除第三个子句外均已满足；令 $b=0$ 后，第三个子句也由 $\neg b$ 满足。因此实际只需 $a=1,b=0$ 就足以保证全部子句成立，$c,d,e$ 均可任取。课件未给出 $e$ 并不造成缺解，而是给出了可扩展的部分赋值。

## 8. GSAT 与求解器发展

对应课件第 32—33 页。GSAT 从所有变量的一个随机总赋值出发，反复改变部分变量的值，直至找到满足赋值，或在达到限制后放弃当前尝试并重新随机开始；总尝试次数也可以设上限。

**补充其常见局部选择方式**：以满足的子句数为目标，每次考虑翻转一个变量，选择能使目标改进最多的翻转，平局时可随机选择。局部极值、平台和循环会妨碍搜索，因此需要步数限制、随机性或重启。课件没有规定具体平局策略与参数，不将某一实现视为唯一 GSAT。

GSAT 找到并检验了满足赋值，就足以证明 SAT；但有限次尝试都失败，只能表示“本次未找到解”，不能据此宣布 UNSAT。因此课件称其为**不完备**求解器。这里的不完备指判定算法的保证，与证明系统的语义完备性不是同一命题。

| 方面 | DPLL | GSAT |
|---|---|---|
| 搜索状态 | 部分赋值与剩余子句集 | 所有变量的总赋值 |
| 核心操作 | 单位传播、分支、回溯 | 变量翻转、局部搜索、随机重启 |
| 找到模型 | 可确认 SAT | 可确认 SAT |
| 未找到模型 | 完整搜索终止后可确认 UNSAT | 达到搜索限制时不能确认 UNSAT |
| 完备保证 | 有限穷尽搜索具有保证 | 有限随机局部搜索无此保证 |

课件给出“GSAT 的性能通常优于 DPLL”的经验描述。应结合实例族、算法版本、启发式与预算理解，不把它写成一般性能定理，更不能据此推断 GSAT 优于所有现代 SAT 求解器。

课件的历史概览列出：1960 年 DPLL 算法，1995—2010 年求解器显著发展，处理变量规模从约 $10$ 到 $10^6$，以及 GRASP（1996）、CHAFF（2001）、MiniSat（2003）、CADICAL（2019）。这些是课件采用的时间与规模概览，不是严格的最早发表年份考据或当前性能上限；其要点是实际需求推动求解技术发展，而非所有含百万变量的实例都容易求解。

## 9. N 皇后问题的 SAT 编码

### 9.1 变量与全部约束

对应课件第 34—35 页。给定 $n\geq1$ 个皇后与 $n\times n$ 棋盘，需要放置全部皇后，使任意两枚不同皇后不同行、不同列，也不在同一条斜对角线上。

引入 $n^2$ 个命题变量 $p_{ij}$，其中 $1\leq i,j\leq n$；$p_{ij}=1$ 表示第 $i$ 行第 $j$ 列放置皇后。下面把课件列出的六类约束写全，所有下标都受此范围约束。

**每行至少一枚**：对每个 $i$，加入子句 $\bigvee_{j=1}^{n}p_{ij}$，全部行的约束合取为 $R_{\geq1}=\bigwedge_{i=1}^{n}(\bigvee_{j=1}^{n}p_{ij})$。

**每行至多一枚**：同一行任意两个不同列位置不能同时为真，故加入 $R_{\leq1}=\bigwedge_{i=1}^{n}\bigwedge_{1\leq j<k\leq n}(\neg p_{ij}\lor\neg p_{ik})$。与“至少一枚”结合后，每行恰好一枚。

**每列至少一枚**：$C_{\geq1}=\bigwedge_{j=1}^{n}(\bigvee_{i=1}^{n}p_{ij})$。**每列至多一枚**：$C_{\leq1}=\bigwedge_{j=1}^{n}\bigwedge_{1\leq i<k\leq n}(\neg p_{ij}\lor\neg p_{kj})$。

**两类斜对角线至多一枚**：规定一族由 $i-j$ 的值确定，另一族由 $i+j$ 的值确定。对任意 $i<k$，若 $i-j=k-\ell$，就在第一类加入 $\neg p_{ij}\lor\neg p_{k\ell}$；若 $i+j=k+\ell$，就在第二类加入同样形式的禁止子句。记这两组子句的合取分别为 $D_-$ 与 $D_+$。使用坐标等式可以避免因棋盘画法而混淆“左斜”“右斜”。

全部约束的核心表达为：

$$
F_n=R_{\geq1}\land R_{\leq1}\land C_{\geq1}\land C_{\leq1}\land D_-\land D_+.
$$

斜对角线上只要求至多一枚，不能要求每条至少一枚，否则会排除合法解。行列至少一枚子句一般含多个正文字，所以这个编码整体不是 Horn 公式；大量禁止子句则都是纯负 Horn 子句。

### 9.2 编码正确性、规模与结果还原

**正确性，摆放到模型**：给定合法摆放，把皇后所在位置赋为真，其余位置赋为假。每行、每列恰好有一枚，故四类行列约束成立；任意两个皇后不共斜线，故全部斜线禁止子句成立。于是得到 $F_n$ 的模型。

**正确性，模型到摆放**：给定 $F_n$ 的模型，在所有真变量对应格子放皇后。每行至少且至多一个真变量，故总共恰好放置 $n$ 枚；列至多约束排除同列攻击，两族对角线约束排除斜线攻击。于是得到合法的 N 皇后摆放。两个方向共同证明“棋盘有合法摆放”当且仅当“$F_n$ 可满足”。

**补充：冗余约束**。已有每行恰好一枚与每列至多一枚时，恰好 $n$ 枚皇后分布于 $n$ 列，每列至多一枚，因此每列必恰好一枚。故列至少一枚可以省略而不改变模型集；本笔记为对应课件保留六类约束。单独使用每行至少一枚或每列至多一枚都不能得到这个结论。

**规模**：变量数为 $n^2$。行列至少约束各 $n$ 个子句；行列至多约束各 $n\binom n2$ 个二文字子句。一族斜线的长度为 $1,2,\ldots,n-1,n,n-1,\ldots,1$，产生 $\binom n2+2\sum_{k=1}^{n-1}\binom k2$ 个禁止子句，两族合计是其两倍。因此这种成对禁止编码共有 $2n+2n\binom n2+2\binom n2+4\binom n3$ 个子句，为 $O(n^3)$，构造和读取解都可在多项式时间完成。对 $n=8$，共有 $64$ 个变量、$744$ 个子句。

第 36 页给出的模型中，真原子为 $p_{11},p_{25},p_{38},p_{46},p_{53},p_{67},p_{72},p_{84}$，其余 $56$ 个变量为假。按行列出皇后列号为 $(1,5,8,6,3,7,2,4)$。这些列号互不相同；行号减列号为 $(0,-3,-5,-2,2,-1,5,4)$，行号加列号为 $(2,7,11,10,8,13,9,12)$，两列也各无重复，因此它确实是合法摆放。

完整工作流是：读取输入 $n$，构造 CNF $F_n$，调用 SAT 求解器，再把真变量还原为皇后位置。除求解器步骤外，其余步骤应保持多项式时间。多项式规模的归约不保证目标 SAT 实例能在多项式时间内求解。

课件还指出，在其使用的求解程序中，规模超过约 $20$ 或 $30$ 时 DPLL 类程序遇到困难，而 GSAT 能处理数千皇后的实例；第 36 页原文使用了 `dpss`。此处保留为课件特定实验背景，不视为一般算法界限，也不据该拼写推断另一个算法定义。

## 10. 例题

本节第 10.1—10.6 题为围绕课件知识点补充的例题；第 10.7 题展开第 27 页的问题。正文已完整展开课件的范式、Horn、DPLL 与 N 皇后实例。

### 10.1 不同范式对应哪些容易检查的问题

判断 $F=(p\lor q)\land(\neg p\lor q)\land\neg q$ 是否可满足；判断 $G=(p\land\neg p)\lor(q\land\neg r)$ 是否可满足。

> [!example]- 解析
> $F$ 的前两个子句合起来要求 $q$ 为真：若 $q=0$，它们分别要求 $p=1$ 与 $p=0$，冲突。但第三个子句又要求 $q=0$，故 $F$ 不可满足。虽然三个子句分别可满足，但没有共同模型。
>
> $G$ 是 DNF，第一项含互补文字，永假；第二项不含互补文字，令 $q=1,r=0$ 即可满足。因此 $G$ 可满足，$p$ 可以任取。关键差别是 DNF 只需一个可满足项，而 CNF 要求同一赋值满足所有子句。

### 10.2 从否定复合式到 CNF

将 $\neg(p\to(q\lor r))\lor s$ 转为 CNF，并说明每步依据。

> [!example]- 解析
> 先用蕴涵等值式得到 $\neg(\neg p\lor q\lor r)\lor s$，再由德摩根律与双重否定律得到 $(p\land\neg q\land\neg r)\lor s$。此时已是 NNF。
>
> 用析取对合取的分配律，得到 $(p\lor s)\land(\neg q\lor s)\land(\neg r\lor s)$，它是 CNF。其语义是：若 $s=1$，原式与新式都为真；若 $s=0$，两者都恰好要求 $p=1,q=r=0$。

### 10.3 主范式中的变量顺序

按变量顺序 $(p,q)$，求 $p\to q$ 的主 DNF 与主 CNF。若改按 $(q,p)$ 排序，编码是否改变？

> [!example]- 解析
> 按 $(p,q)$ 排序，只有 $10$ 行为假，因此主 CNF 是 $M_2=\neg p\lor q$。成真行是 $00,01,11$，故主 DNF 为 $m_0\lor m_1\lor m_3=(\neg p\land\neg q)\lor(\neg p\land q)\lor(p\land q)$。
>
> 改按 $(q,p)$ 排序后，同一个假赋值变成 $01$，故主 CNF 的编码变为 $M_1=q\lor\neg p$。公式语义未变，改变的是二进制位与变量之间的对应关系。

### 10.4 Horn 的闭包、冲突与非唯一模型

考虑 $H=p\land(\neg p\lor q)\land(\neg q\lor r)\land(\neg r\lor\neg s)$。求最小模型，并判断加入事实 $s$ 后是否可满足。

> [!example]- 解析
> 从事实 $p$ 出发，经 $p\to q$ 与 $q\to r$ 得闭包 $\{p,q,r\}$。约束 $r\land s\to\bot$ 未触发，因此最小模型为 $p=q=r=1,s=0$。
>
> 加入事实 $s$ 后，闭包含 $p,q,r,s$，约束被触发，所以新公式不可满足。这个例子中原来的四个变量取值其实都被迫固定，故原公式恰有一个模型。
>
> 若在原公式的变量表中再加入不出现在约束中的变量 $u$，最小模型令 $u=0$，但 $u=1$ 也给出模型。由此看出“最小模型唯一”与“只有一个模型”是不同结论。

### 10.5 DPLL 必须回溯的情况

对 $K=(\neg p\lor q)\land(\neg p\lor\neg q)\land(p\lor r)$，先尝试 $p=1$，展示求解过程。

> [!example]- 解析
> 令 $p=1$ 后，前两个子句分别化为单位子句 $q$ 与 $\neg q$，第三个子句已经满足。传播 $q=1$ 后，$\neg q$ 化为空子句，说明 $p=1$ 分支失败。
>
> 回溯并尝试 $p=0$，前两个子句都由 $\neg p$ 满足而删除，第三个子句化为单位子句 $r$。传播 $r=1$ 后得到空子句集，所以 SAT，模型可取 $p=0,q=0,r=1$，也可令 $q=1$。
>
> 一支遇到空子句只能否定该分支；只有全部必要分支均失败，才能判定原公式 UNSAT。

### 10.6 N 皇后编码的必要条件

若仅要求每行恰好一个皇后、每列至多一个皇后，但删去全部对角线约束，编码是否仍正确？每列至少一个是否还需要单独加入？

> [!example]- 解析
> 删去对角线约束后编码不再充分。例如 $n=4$，把皇后放在 $(1,1),(2,2),(3,3),(4,4)$，每行每列恰好一个，却都在同一条对角线上，彼此攻击。这给出满足删减公式、但不对应合法解的反例。
>
> 在仍保留每行恰好一个与每列至多一个时，已经有恰好 $n$ 枚皇后，而且占据互不相同的列。$n$ 枚分布于 $n$ 列即迫使每列恰好一个，故列至少约束可以省略。这一冗余性并不能补偿对角线条件的缺失。

### 10.7 检验候选与寻找全部模型

求第 6 节课件公式 $\varphi$ 的全部成真赋值。

> [!example]- 解析
> 三变量子句包含每个变量一次，因此各自恰好排除一个赋值。依照课件六个子句的顺序，它们分别排除 $000,101,011,111,110,001$。
>
> 全部八个赋值中只剩 $010$ 与 $100$。逐一代入，两者都使六个子句成立，故完整模型集为 $(a,b,c)=(0,1,0)$ 与 $(1,0,0)$。因此主 DNF 是 $(\neg a\land b\land\neg c)\lor(a\land\neg b\land\neg c)$。
>
> 第 27 页给出的候选 $001$ 恰好被第六个子句排除。候选失败只否定这个候选，不表示公式不可满足。

## 11. 易错点速查

| 易错点 | 正确结论与依据 |
|---|---|
| 把可满足当作有效 | 可满足要求存在模型，有效要求所有赋值均为模型 |
| “$\neg\varphi$ 不是有效”读成“$\neg\varphi$ 永假” | 前者只需一个反例赋值，恰等价于 $\varphi$ 可满足 |
| 只看式中含哪些联结词判断 CNF | 还须检查层次：外层合取，内部子句为文字析取 |
| 把等值于 CNF 的公式都称为 CNF | 当前语法形式与等值转换结果需分开 |
| CNF 每个子句可满足就推出整体可满足 | 所有子句必须共享同一个满足赋值 |
| DNF 每个项都要可满足 | 只需至少一个项可满足 |
| 合取与析取分配方向混淆 | CNF 用析取对合取分配，DNF 用合取对析取分配 |
| 范式存在就意味着高效转换 | 等值分配最坏可能指数膨胀 |
| 归纳证明默认可对任何公式使用归纳假设 | 必须说明公式更短或确为归纳允许的子结构 |
| 极小项与极大项按同样符号编码 | 极小项编码是唯一真行，极大项编码是唯一假行 |
| 主范式不说明变量表与顺序 | 必须固定变量集合与顺序，编码才有确定含义 |
| 把空子句集与含空子句混为一谈 | 空合取为真；含空析取的合取为假 |
| Horn 子句必须恰好一个正文字 | 是至多一个，允许纯负约束与空子句 |
| Horn 算法忽略事实 | 事实前提为空，初始化时即可触发 |
| 只处理规则而不检查纯负约束 | 正规则闭包仍可能违反禁止条件 |
| 未标记原子在每个模型中均为假 | 未标记只表示闭包未强制其为真；构造最小模型时赋假 |
| 最小模型唯一就等于模型唯一 | 最小模型包含于其他模型，其他模型仍可能存在 |
| 标记次数线性就认定总运行时间线性 | 还须计算规则定位代价；线性实现按文字出现次数计费 |
| NP 表示已证明不在 P 中 | NP 是可高效验证证书的问题类，P 包含于 NP |
| 归约方向写反 | 证明 $A\leq_p B$ 表示可用 $B$ 求解 $A$ |
| DPLL 一支失败就判 UNSAT | 必须检查剩余必要分支 |
| GSAT 超时即判 UNSAT | 只能表示预算内未找到模型 |
| 求解器完备性等于逻辑证明系统完备性 | 两者研究对象与保证不同，应分别陈述 |
| N 皇后只限制行列 | 还要排除两类斜线冲突 |
| 每条斜线都必须有皇后 | 只需至多一个，不要求至少一个 |
| 把辅助变量编码写成原变量上的直接等值 | 应说明可扩展性与投影关系，而非混同等值和等可满足 |

## 12. 知识点速查

### 12.1 结构与判定总表

| 对象 | 结构或条件 | 可直接使用的结论 |
|---|---|---|
| 文字 | $p$ 或 $\neg p$ | 互补文字不可能同真同假 |
| 子句 | 文字的析取 | 有效当且仅当含互补文字 |
| 项 | 文字的合取 | 可满足当且仅当不含互补文字 |
| NNF | 文字经合取、析取构成 | 任意公式都有等值 NNF |
| CNF | 子句的合取 | 有效性可逐子句检查；SAT 一般需全局搜索 |
| DNF | 项的析取 | 可满足性可逐项检查 |
| 主 DNF | 真行对应极小项的析取 | 恰保留所有成真赋值 |
| 主 CNF | 假行对应极大项的合取 | 恰排除所有成假赋值 |
| Horn 公式 | 每个子句至多一个正文字 | 正规则闭包加纯负约束检查，线性输入时间可判定 |
| DPLL | 单位传播加两值分支 | 完备，最坏搜索规模仍可指数增长 |
| GSAT | 总赋值上的随机局部搜索 | 找到模型可确认 SAT，失败不能确认 UNSAT |
| SAT 编码 | 规范转换为 CNF | 需证明模型与合法解的双向对应，并控制构造规模 |

### 12.2 五条核心思想

1. 范式将公式限制为固定语法结构，使某些语义性质可以通过局部检查判定；要始终分清检查的是有效性还是可满足性。
2. 等值范式的存在由归纳与分配律保证，转换规模却可能指数增长；语义正确与计算高效是两个要求。
3. 主范式以固定变量表为前提，用极小项精确记录真行，用极大项精确记录假行，因此直接刻画公式的全部语义。
4. Horn 标记算法不是猜测真值，而是累积任何模型都必须包含的真原子；闭包若不违反纯负约束，自身就给出最小模型。
5. 一般 SAT 的难点在寻找共同模型。DPLL 通过传播与穷尽分支保证判定，GSAT 通过局部搜索寻找模型；建模时还必须证明求解器输出确实对应原问题的解。

本章依赖命题逻辑的真值语义、等值关系和公式归纳，也与前一讲的可靠性和完备性相衔接：语义可满足性可用于反模型构造，但算法的完备保证需独立论证。后续学习更强的逻辑语言时，应继续区分公式变换、语义模型与证明系统。本项目目前无其他章节笔记，因此此处不建立尚不存在的章节链接，也不预设下一章具体主题。
