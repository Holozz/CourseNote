> [!info] 本章定位
> 本章把命题逻辑的语义扩展到有内部结构的原子公式与量词. 主线是：① 项表示对象，公式表达可判真假的断言，语言与解释分别决定符号的类型和指称；② 公式真值只依赖自由变量的赋值，量词通过修改对象赋值解释；③ 量词等值律与等值置换必须对所有解释、所有赋值成立；④ 项代入对应赋值更新，但只有避免变量捕获时，公式代入才保持这种对应. 约束变量改名的正确性由代入定理与等值置换共同保证.

## 1. 逻辑符号、语言与元数

对应课件第 4—5 页. 命题逻辑把原子整体赋为真或假；一阶逻辑进一步区分对象、对象之间的关系，以及对对象的量化. 例如 $\forall x(P(x)\lor Q(x))$ 不能只靠给 $P,Q$ 各指定一个真假值来解释，还要知道对象的范围和两个谓词各自表示哪些对象的性质.

### 1.1 逻辑符号与非逻辑符号

**逻辑符号**包括联结词 $\neg,\land,\lor,\to,\leftrightarrow$，量词 $\forall,\exists$，变量 $x,y,z,\ldots$，括号与逗号，以及等号 $=$. 本章使用带等号的一阶逻辑，等号必须解释成对象之间的恒等关系.

**常元符号** $a,b,c,\ldots$ 表示指定的个体；**函数符号** $f,g,h,\ldots$ 表示由若干对象得到一个对象的运算；**谓词符号** $P,Q,R,\ldots$ 表示对象的性质或关系. 这些都是非逻辑符号，具体含义由解释指定.

函数或谓词符号的**元数**是它接受的参数个数，属于语法规定. 固定语言中，同一个符号不能一会儿是一元、一会儿是二元. 若 $f$ 是二元函数符号，则 $f(x,y)$ 是合法的函数项，$f(x)$ 不是；函数符号 $f$ 不能直接充当谓词符号来形成原子公式.

常元可以统一看作零元函数符号. 零元谓词没有个体参数，其解释只有真、假两种可能，因而起命题原子的作用. **变量仍然只取论域中的个体**，本章不量化谓词或函数，这是一阶量化的范围.

### 1.2 算术语言与标准记法

**定义（语言）**：在固定逻辑符号后，一个一阶语言 $L$ 由非逻辑符号及各函数、谓词符号的元数确定. 指定语言只规定能够写哪些表达式，不规定它们是否为真.

课件给出的算术语言是 $L^*=[0,\prime,+,\cdot\,; <]$.

| 符号 | 语法类型 | 元数 |
|---|---|---|
| $0$ | 常元符号 | $0$ |
| $\prime$ | 函数符号 | $1$ |
| $+,\cdot$ | 函数符号 | $2$ |
| $<$ | 谓词符号 | $2$ |

$x+y$ 是 $+(x,y)$ 的中缀写法，$0''$ 表示将一元函数符号 $\prime$ 连续作用两次，$x<y$ 是 $<(x,y)$ 的中缀写法. 在标准算术解释中它们分别表示加法、后继和小于关系；在尚未指定解释时，这些只是带元数的符号.

等号虽然参与该语言的公式构造，却不列在非逻辑符号表中. 课件第 16 页的 $L=\{R,=\}$ 可理解为强调该语言带等号；按这里的分类，唯一列出的非逻辑符号是二元谓词 $R$.

## 2. 项、公式与变量作用域

对应课件第 6—8 页. 项和公式是两类不同的语法对象：项在解释与赋值下得到一个对象，公式在解释与赋值下得到真假判定.

### 2.1 项的递归定义

> [!note] 定义：项
> 1. 每个变量和每个常元都是项，称为原子项.
> 2. 若 $f$ 是 $n$ 元函数符号，$t_1,\ldots,t_n$ 都是项，则 $f(t_1,\ldots,t_n)$ 是项.
> 3. 只有有限次使用以上规则得到的表达式才是项.

课件例子包括 $0''$、$x+y$、$f(g(a),x)$、$f(x,y)$ 和 $g(f(a,g(a)))$. 后三个例子可统一取 $f$ 为二元函数符号、$g$ 为一元函数符号、$a$ 为常元. $f(g(a),x)$ 的最外层运算是 $f$，两个直接子项是 $g(a)$ 与 $x$.

**补充记号**：$\operatorname{Var}(t)$ 表示项 $t$ 中出现的变量集合. 递归地，$\operatorname{Var}(x)=\{x\}$，$\operatorname{Var}(a)=\varnothing$，而 $\operatorname{Var}(f(t_1,\ldots,t_n))=\bigcup_{i=1}^n\operatorname{Var}(t_i)$. 项中没有量词，因而项内的变量出现都是自由的.

**闭项**是不含变量的项，即 $\operatorname{Var}(t)=\varnothing$. $0''$ 和 $g(f(a,g(a)))$ 是闭项；$x+y$ 不是. 如果语言既无常元，也无零元函数符号，那么可以没有闭项，这不妨碍含变量项的构造.

### 2.2 原子公式与复合公式

**定义（原子公式）**：若 $P$ 是 $n$ 元谓词符号，$t_1,\ldots,t_n$ 是项，则 $P(t_1,\ldots,t_n)$ 是原子公式；若 $s,t$ 是项，则 $s=t$ 是原子公式.

**定义（公式）**：原子公式是公式；若 $A,B$ 是公式，则 $\neg A$、$(A\land B)$、$(A\lor B)$、$(A\to B)$、$(A\leftrightarrow B)$ 是公式；若 $A$ 是公式、$x$ 是变量，则 $\forall xA$ 和 $\exists xA$ 是公式. 公式集合取满足这些构造规则的最小集合，故每个公式都由有限次构造得到.

例如 $(\neg\forall xP(x)\lor\exists x\neg P(x))$ 和 $(\forall x\neg Q(x,y)\land\neg\forall zQ(f(y),z))$ 都是公式. 其中 $f$ 为一元、$Q$ 为二元，属于这两个表达式所用语言的元数约定，不能与另一个语言中的 $f$ 自动混同.

$f(x,y)$ 是项，$P(f(x,y))$ 是公式，$f(x,y)=a$ 也是公式. 原子公式可以包含复杂项；“原子”指它没有由联结词或量词构成的公式结构，并不要求其项没有内部结构.

### 2.3 自由出现、约束出现与语句

**定义（作用域）**：在 $\forall xB$ 或 $\exists xB$ 中，量词所管辖的公式 $B$ 是其作用域. 只有位于该作用域内的 $x$ 的出现，才可能由这一量词约束；另一个变量 $y$ 不会因为处于 $\forall x$ 的作用域而被约束.

**定义（变量的自由与约束出现）**：考察公式中项内某一次变量 $x$ 的出现. 若沿语法树向上能遇到一个以 $x$ 为约束名的量词 $\forall x$ 或 $\exists x$，则该次出现是约束出现，由最近的同名量词约束；否则为自由出现. 量词后的 $x$ 是约束名，分析自由出现时不把它当作可代入的位置.

例如 $F(x)\to\forall xF(x)$ 中，前件的 $x$ 是自由出现，后件 $F(x)$ 中的 $x$ 是约束出现. 因此，**同一个变量名可以在同一公式中兼有自由出现与约束出现**，不能只看变量名就给所有出现统一分类.

在 $x<y\land\neg\exists z(x<z\land z<y)$ 中，$x,y$ 的各次出现均自由，两个原子中的 $z$ 均由 $\exists z$ 约束. 公式断言 $x<y$，且二者之间不存在满足给定关系的 $z$；它的真值仍可能随 $x,y$ 的赋值改变.

> [!warning] 课件定义的表述澄清
> 第 8 页将“$x$ 不存在自由出现”简称为“$x$ 是约束变量”. 严格区分出现时，$x$ 根本没有出现也会满足前一句，不能据此断定存在约束出现. 本文用“$x$ 不自由出现”表达该条件；判断具体约束关系时始终检查出现位置与量词作用域.

**定义（语句）**：不含自由变量的公式称为闭公式或语句，英文为 sentence. $\forall xP(x)$ 是语句，$\forall xQ(x,y)$ 通常不是，因为 $y$ 仍自由. 公式含有量词，并不保证公式是闭的；没有自由变量，也不要求每个量词都实际约束某次出现，例如 $\forall x(a=a)$ 仍是语句.

### 2.4 自由变量集合的递归计算

以下是对课件定义的递归展开，记 $\operatorname{FV}(A)$ 为公式 $A$ 的自由变量集合.

| 公式结构 | 自由变量集合 |
|---|---|
| $P(t_1,\ldots,t_n)$ | $\bigcup_i\operatorname{Var}(t_i)$ |
| $s=t$ | $\operatorname{Var}(s)\cup\operatorname{Var}(t)$ |
| $\neg B$ | $\operatorname{FV}(B)$ |
| $(BcC)$ | $\operatorname{FV}(B)\cup\operatorname{FV}(C)$ |
| $\forall xB$ 或 $\exists xB$ | $\operatorname{FV}(B)\setminus\{x\}$ |

量词这一行只删除所绑定的那个变量名. 对 $A=\forall x\neg Q(x,y)\land\neg\forall zQ(f(y),z)$，左侧自由变量集是 $\{y\}$，右侧也是 $\{y\}$，故 $\operatorname{FV}(A)=\{y\}$. 对 $F(x)\to\forall xF(x)$，两边分别贡献 $\{x\}$ 与 $\varnothing$，故整个公式仍有自由变量 $x$.

## 3. 解释、对象赋值与项的指称

对应课件第 10—14 页. 对同一公式，改变解释会改变论域及符号含义，改变对象赋值则在同一个解释中改变自由变量的取值. 这两层必须分开.

### 3.1 一阶语言的解释

> [!note] 定义：解释
> 语言 $L$ 的解释 $\mathcal M$ 包括一个非空论域 $D=|\mathcal M|$，以及对每个非逻辑符号的指称：常元 $a$ 指定为 $a^{\mathcal M}\in D$；$n$ 元函数符号 $f$ 指定为函数 $f^{\mathcal M}:D^n\to D$；$n$ 元谓词符号 $P$ 指定为关系 $P^{\mathcal M}\subseteq D^n$. 等号解释为 $D$ 上的恒等关系.

函数解释是对每个参数组都有唯一输出的**全函数**. 不同常元不必指向不同个体；不同函数或谓词符号也可以有相同指称，除非额外的公式排除了这些情况. 例如语言含 $a,b$ 本身不能推出 $a\ne b$.

非空性是本章的基本条件. 它保证任意对象赋值有取值对象，也支持 $\forall xA\models\exists xA$ 这类推论. 若讨论允许空论域的另一套语义，必须重新检查相关结论，不能直接沿用.

对零元谓词，$D^0$ 只有空元组，故 $P^{\mathcal M}$ 可以为空，或包含该空元组，恰好对应假或真.

**算术标准解释**记为 $\mathcal N^*$：论域取 $\mathbb N=\{0,1,2,\ldots\}$，$0$ 指向自然数 $0$，$\prime$ 解释为 $n\mapsto n+1$，$+,\cdot,<$ 取通常含义. “标准”指定了这一特定解释，并不意味着一阶语义强迫每个算术语言解释都如此.

### 3.2 对象赋值及其更新

**定义（对象赋值）**：解释 $\mathcal M$ 的一个对象赋值 $l$ 是从全部变量组成的集合到 $D$ 的映射. 变量的取值属于赋值，常元的指称属于解释，不能用更新 $l$ 来改变 $a^{\mathcal M}$.

记 $l[x\mapsto d]$ 为只把 $x$ 的值改为 $d\in D$ 的赋值：它在 $x$ 上取值 $d$，在任意 $z\ne x$ 上仍取 $l(z)$. 更新不是对公式做字符串替换，而是构造一个新的语义参数.

后文反复使用以下直接由定义得到的事实.

- 连续更新同一变量时，后一次覆盖前一次：$l[x\mapsto d][x\mapsto e]=l[x\mapsto e]$.
- 若 $x\ne y$，且 $d,e$ 已是固定的论域元素，则不同变量的更新可交换：$l[x\mapsto d][y\mapsto e]=l[y\mapsto e][x\mapsto d]$.
- “更新可交换”不允许忽略项取值的时机. 例如 $t[l[y\mapsto e]]$ 未必等于 $t[l]$；只有 $y$ 不在 $t$ 中出现等条件，才能保证这一等式.

### 3.3 项的递归求值

**定义（项的指称）**：给定 $\mathcal M,l$，项 $t$ 的指称 $t^{\mathcal M}[l]\in D$ 按项结构递归定义.

| 项结构 | 指称 |
|---|---|
| 变量 $x$ | $x^{\mathcal M}[l]=l(x)$ |
| 常元 $a$ | $a^{\mathcal M}[l]=a^{\mathcal M}$ |
| $f(t_1,\ldots,t_n)$ | $f^{\mathcal M}(t_1^{\mathcal M}[l],\ldots,t_n^{\mathcal M}[l])$ |

课件将常元统一为零元函数，因而其第二条递归规则已经包含常元；这里单列是为了区分常元指称与变量赋值. 当解释清楚时简记为 $t[l]$.

例如在 $\mathcal N^*$ 中，若 $l(x)=1$，则 $(0''')^{\mathcal N^*}[l]=3$，且 $(x+0'')^{\mathcal N^*}[l]=1+2=3$. 第一式不需要读取任何变量赋值，第二式需要读取 $l(x)$；它们是两个不同的项，只是在这个解释与赋值下指向同一个数.

## 4. 满足关系与量词的语义

对应课件第 15—16 页. 项先得到对象，原子公式再根据关系或对象相等判真，复合公式最后根据联结词和量词递归判真.

### 4.1 原子公式与联结词

**定义（满足关系）**：$\mathcal M\models_l A$ 表示公式 $A$ 在解释 $\mathcal M$ 和赋值 $l$ 下为真. 原子情形如下.

- $\mathcal M\models_l P(t_1,\ldots,t_n)$，当且仅当 $(t_1^{\mathcal M}[l],\ldots,t_n^{\mathcal M}[l])\in P^{\mathcal M}$.
- $\mathcal M\models_l s=t$，当且仅当 $s^{\mathcal M}[l]=t^{\mathcal M}[l]$.

第一条右侧是论域中的元组与关系之间的成员关系；第二条右侧是元语言中对象的相等. 左侧的 $s=t$ 才是对象语言的公式.

否定满足 $\mathcal M\models_l\neg B$ 当且仅当 $\mathcal M\not\models_l B$. 析取满足 $\mathcal M\models_l B\lor C$ 当且仅当两个分量至少一个为真. 合取要求二者都真，蕴含只在前件真而后件假时为假，双条件要求二者真值相同. 课件第 15 页只显式列出 $\neg,\lor$；这里补齐其他联结词，与命题逻辑真值函数约定一致.

### 4.2 全称量词与存在量词

量词的核心语义是对**更新后的赋值**判定作用域公式.

$$
\mathcal M\models_l\forall xB
\quad\Longleftrightarrow\quad
\text{对每个 }d\in D,\ \mathcal M\models_{l[x\mapsto d]}B.
$$

$$
\mathcal M\models_l\exists xB
\quad\Longleftrightarrow\quad
\text{存在 }d\in D,\ \mathcal M\models_{l[x\mapsto d]}B.
$$

判定 $\forall xB$ 时，原赋值 $l(x)$ 被依次覆盖；其他自由变量仍沿用 $l$ 的值. 例如在标准算术中，$\forall x(x<y)$ 为真要求每个自然数都小于固定的 $l(y)$，而不是允许 $y$ 随每次选择的 $x$ 自由变化.

对嵌套量词必须保留选择次序. $\forall x\exists yR(x,y)$ 要求每个 $d$ 都有相应的见证 $e$，允许 $e$ 依赖 $d$；$\exists y\forall xR(x,y)$ 要求先固定一个 $e$，它对每个 $d$ 都适用. 第 7.3 节将给出严格的蕴含方向与反模型.

### 4.3 课件中的自然数解释实例

设 $D=\mathbb N$，二元关系 $R^{\mathcal M}(m,n)$ 表示 $m\le n$. 语句 $\exists x\forall yR(x,y)$ 为真，因为可选 $x=0$，对每个 $y\in\mathbb N$ 都有 $0\le y$.

$\exists y\forall xR(x,y)$ 为假. 对任何候选 $y=n$，都可以选 $x=n+1$，使 $x\le y$ 为假；因此没有一个候选 $y$ 能使内层全称公式成立. 这两个语句分别表达存在最小元素与存在最大元素，不是同一断言的变量改名.

在 $\mathcal N^*$ 中，$\forall x\forall y\exists z(x+z=y\lor y+z=x)$ 为真. 任取 $m,n$，若 $m\le n$，取 $z=n-m$ 使第一支为真；若 $n\le m$，取 $z=m-n$ 使第二支为真. 两种情况下见证都属于 $\mathbb N$.

$\forall x\exists y(y+y=x)$ 为假，因为取 $x=1$，任何自然数 $y$ 的两倍均不为 $1$. 这里否定全称语句只需提供一个失败的 $x$；但对该 $x$，必须说明不存在任何合适的 $y$.

## 5. 指称与真值只依赖有关变量

对应课件第 18—20 页. 本节要证明的是语义事实，并不涉及形式推导是否存在. 两条引理分别按项与公式的构造结构归纳；第二条量词情形需要说明更新后的两个赋值仍满足归纳假设.

### 5.1 项的指称只依赖项中的变量

> [!abstract] 项的赋值一致性引理
> 固定解释 $\mathcal M$. 若 $l,l'$ 对 $\operatorname{Var}(t)$ 中每个变量取值相同，则 $t^{\mathcal M}[l]=t^{\mathcal M}[l']$.

**证明思路**：项的求值只读取叶节点上的变量，并使用同一解释中的函数. 归纳命题是：对当前项 $t$ 的任意两个有关变量取值一致的赋值，其求值结果相同.

**变量与常元**：若 $t=x$，假设直接给出 $l(x)=l'(x)$，故两次指称相同. 若 $t=a$ 是常元，两次求值都等于解释固定的 $a^{\mathcal M}$，不依赖赋值.

**函数项**：设 $t=f(t_1,\ldots,t_n)$. 归纳假设具体是：对每个直接子项 $t_i$，任何在 $\operatorname{Var}(t_i)$ 上一致的两个赋值，给出的 $t_i$ 指称相同. 因为 $\operatorname{Var}(t_i)\subseteq\operatorname{Var}(t)$，当前的 $l,l'$ 满足每个子项的这一条件，所以对全部 $i$ 有 $t_i^{\mathcal M}[l]=t_i^{\mathcal M}[l']$.

两组相同的参数输入同一个函数 $f^{\mathcal M}$，结果也相同，故 $t^{\mathcal M}[l]=t^{\mathcal M}[l']$. 结构归纳完成.

**推论**：闭项的指称与对象赋值无关，因为需要一致的变量集合为空；但其指称仍可能随解释变化.

### 5.2 公式的真值只依赖自由变量

> [!important] 自由变量赋值一致性引理
> 固定解释 $\mathcal M$. 若 $l,l'$ 对 $\operatorname{FV}(A)$ 中每个变量取值相同，则 $\mathcal M\models_l A$ 当且仅当 $\mathcal M\models_{l'}A$.

**归纳命题**：对任意公式 $A$ 和任意两个在 $\operatorname{FV}(A)$ 上一致的赋值，$A$ 的真值相同. 归纳假设必须对所有满足条件的赋值成立，而不只是最初选定的 $l,l'$；量词步骤会把它应用于新的赋值.

**谓词原子**：若 $A=P(t_1,\ldots,t_n)$，则各项的变量都在 $\operatorname{FV}(A)$ 中. 由第 5.1 节，两次求值得到同一个参数元组，故该元组是否属于固定关系 $P^{\mathcal M}$ 的判断相同.

**等式原子**：若 $A=s=t$，同理有 $s[l]=s[l']$、$t[l]=t[l']$. 因此 $s[l]=t[l]$ 当且仅当 $s[l']=t[l']$，两次等式判定相同. 这补齐课件第 20 页只列出而未展开的情形.

**否定与二元联结词**：若 $A=\neg B$，自由变量集合不变，归纳假设给出 $B$ 在两赋值下真值相同，取否定仍相同. 若 $A=BcC$，则 $l,l'$ 分别在 $\operatorname{FV}(B)$、$\operatorname{FV}(C)$ 上一致，归纳假设保证两个直接子公式各自真值相同；同一个联结词的真值函数作用于相同输入，结果仍相同. 此论证覆盖全部二元联结词.

**全称量词**：设 $A=\forall xB$. 已知 $l,l'$ 在 $\operatorname{FV}(B)\setminus\{x\}$ 上一致，未必在 $x$ 上一致. 任取 $d\in D$，比较 $l[x\mapsto d]$ 与 $l'[x\mapsto d]$.

对 $\operatorname{FV}(B)$ 中任一变量 $v$，若 $v=x$，两赋值都取 $d$；若 $v\ne x$，则 $v\in\operatorname{FV}(A)$，两者保留相同的原值. 因此这两个更新赋值在 $B$ 的全部自由变量上确实一致.

现在才能对直接子公式 $B$ 应用归纳假设，得到 $\mathcal M\models_{l[x\mapsto d]}B$ 当且仅当 $\mathcal M\models_{l'[x\mapsto d]}B$. 该等价对每个 $d$ 成立，所以“所有 $d$ 都使 $B$ 为真”的条件在两边一致，即 $\forall xB$ 真值相同.

**存在量词**：设 $A=\exists xB$. 对每个候选 $d$，上述更新赋值仍在 $\operatorname{FV}(B)$ 上一致，故 $B$ 在它们下真值相同. 如果一边存在一个成功见证 $d$，同一个 $d$ 也使另一边成立；反方向相同. 因而两边的存在条件等价. 结构归纳完成.

### 5.3 语句的真值与对象赋值无关

**推论**：若 $A$ 是语句，则对固定解释 $\mathcal M$ 和任意 $l,l'$，有 $\mathcal M\models_l A$ 当且仅当 $\mathcal M\models_{l'}A$.

**证明**：语句满足 $\operatorname{FV}(A)=\varnothing$，任意两个赋值在空集上的一致性条件自动满足，直接应用上一引理.

因此对语句可以写 $\mathcal M\models A$，省略 $l$. 对含自由变量的公式，本笔记保留 $\mathcal M\models_l A$；若另外采用“$\mathcal M\models A$ 表示所有赋值都满足 $A$”的扩展约定，必须先明确，不能将它理解成“某个赋值满足”.

“与约束变量的赋值无关”应理解为：保持所有自由变量的取值不变时，改变其余变量的原赋值不改变真值. 对 $F(x)\to\forall xF(x)$，$x$ 虽有约束出现，也有自由出现，不能任意改变 $l(x)$ 后声称公式真值不变.

## 6. 可满足性、有效性、等值与后承

对应课件第 21 页. 以下定义都针对同一语言的解释；讨论不同公式时可放在包含全部相关符号的共同语言中. 解释仍取非空论域.

### 6.1 公式与公式集的可满足性

**定义（公式可满足）**：若存在解释 $\mathcal M$ 和对象赋值 $l$，使 $\mathcal M\models_l A$，则称 $A$ 可满足. 若不存在这样的二元组，则称 $A$ 不可满足.

**定义（公式集可满足）**：若存在同一个 $\mathcal M$ 和同一个 $l$，使每个 $\varphi\in\Phi$ 都满足 $\mathcal M\models_l\varphi$，则称 $\Phi$ 可满足. 记 $\mathcal M\models_l\Phi$ 为这一共同满足条件.

这里“同一个”不能省略. 在各不相同的赋值或解释下分别满足每个成员，不能证明整组可满足. 例如 $\{P(x),\neg P(x)\}$ 的两个成员各自可满足，但没有同一 $\mathcal M,l$ 同时满足二者.

对语句集，无须记录 $l$，满足它的解释称为该语句集的模型. 对开放公式，应保留赋值信息，避免把一种解释中的成真情况混为一谈.

### 6.2 有效性、逻辑等值与语义后承

**定义（有效）**：若对每个解释 $\mathcal M$ 和每个对象赋值 $l$ 都有 $\mathcal M\models_l A$，则称 $A$ 有效，记为 $\models A$.

**定义（逻辑等值）**：若对所有 $\mathcal M,l$，$\mathcal M\models_l A$ 当且仅当 $\mathcal M\models_l B$，则称 $A,B$ 逻辑等值，记为 $A\equiv B$.

**定义（语义后承）**：若对所有 $\mathcal M,l$，只要 $\mathcal M\models_l\Phi$ 就有 $\mathcal M\models_l A$，则记 $\Phi\models A$，称 $A$ 是 $\Phi$ 的逻辑推论. 单前提时简写为 $B\models A$.

**反模型的核对标准**：否定 $\Phi\models A$，必须提供一个共同的 $\mathcal M,l$，使 $\Phi$ 的每个前提都真，而结论 $A$ 假. 若前提和结论都是语句，则只需给出解释并逐项验证.

### 6.3 与命题逻辑的承接及基本关系

[[Chapter 2 命题逻辑的语法与语义]] 中，真值赋值是语义的主要参数；本章的参数变成解释与对象赋值二元组. 联结词的真值规则保持不变，因此 $A\equiv B$ 当且仅当 $\models A\leftrightarrow B$，也当且仅当 $A\models B$ 且 $B\models A$.

同理，$\Phi\models A$ 当且仅当 $\Phi\cup\{\neg A\}$ 不可满足：若存在共同满足后者的 $\mathcal M,l$，它恰好是前者的反模型；若前者有反模型，同一二元组就满足后者. $A$ 有效当且仅当 $\neg A$ 不可满足.

在某个固定解释中为真的语句不一定有效. 例如 $\exists x\forall yR(x,y)$ 在第 4.3 节的自然数次序解释中为真，却在 $D=\mathbb Z$、$R$ 解释为 $\le$ 时为假，因为整数没有最小元素.

本章建立的是 $\models$ 的语义性质，不建立新的一阶自然演绎规则. [[Chapter 3 命题逻辑自然演绎系统]] 和 [[Chapter 4 命题逻辑自然演绎系统的可靠性和完备性]] 中的命题逻辑结果不能未经扩展就当作一阶证明系统的规则或元定理.

## 7. 量词等值律、有效推论与反模型

对应课件第 22—26 页. 以下 $A,B$ 可以含其他自由变量；证明中固定任意解释 $\mathcal M$ 与原赋值 $l$，这些自由变量的值在更新量化变量时保持不变. 涉及 $x,y$ 交换时假定它们是不同变量.

### 7.1 全称量词与蕴含

**命题**：$\forall x(P(x)\to Q(x))\models(\forall xP(x)\to\forall xQ(x))$.

**证明**：任取满足前提的 $\mathcal M,l$. 为证明结论中的蕴含，若 $\forall xP(x)$ 为假，则蕴含已为真；若它为真，则任取 $d\in D$，在 $l[x\mapsto d]$ 下 $P(x)$ 为真，同时由全局前提知 $P(x)\to Q(x)$ 为真，所以 $Q(x)$ 为真. 因 $d$ 任意，得 $\mathcal M\models_l\forall xQ(x)$，结论成立.

**逆方向不成立（补充反模型）**：取 $D=\{0,1\}$，$P^{\mathcal M}=\{0\}$，$Q^{\mathcal M}=\varnothing$. $\forall xP(x)$ 为假，故 $\forall xP(x)\to\forall xQ(x)$ 为真；但在 $x=0$ 时 $P(x)$ 真而 $Q(x)$ 假，故 $\forall x(P(x)\to Q(x))$ 为假.

前一个公式逐对象约束 $P,Q$，后一个公式只比较两个整体的全称断言. 当后者的前件为假时，它不给出逐点约束.

### 7.2 否定与量词分配

**量词否定律**：$\neg\forall xA\equiv\exists x\neg A$，$\neg\exists xA\equiv\forall x\neg A$.

**证明**：在固定 $\mathcal M,l$ 下，$\neg\forall xA$ 真意味着并非每个 $d\in D$ 都使 $A$ 在 $l[x\mapsto d]$ 下为真，等价于存在一个 $d$ 使 $A$ 假，即使 $\neg A$ 真. 第二式中，不存在使 $A$ 真的见证，等价于每个 $d$ 都使 $A$ 假，即每个 $d$ 都使 $\neg A$ 真. 这使用经典二值语义下元语言中的量词否定.

**全称对合取分配**：$(\forall xA\land\forall xB)\equiv\forall x(A\land B)$.

**证明**：左式真意味着对每个 $d$，$A$ 真，且对每个 $d$，$B$ 真，所以对每个同一 $d$，$A\land B$ 真，右式真. 反向由右式对每个 $d$ 分别得到 $A$ 真与 $B$ 真，故两个全称断言都真.

**存在对析取分配**：$\exists x(A\lor B)\equiv(\exists xA\lor\exists xB)$.

**证明**：若左式真，取一个成功见证 $d$，在对应更新赋值下 $A$ 或 $B$ 至少一者为真；据该分支可得 $\exists xA$ 或 $\exists xB$. 反向若存在使某一分量真的见证，同一见证也使析取为真，故左式真.

**全称对析取只保证一个方向**：$(\forall xA\lor\forall xB)\models\forall x(A\lor B)$.

若前提第一支为真，则每个 $d$ 都使 $A$ 真，因此都使 $A\lor B$ 真；若第二支为真，改用 $B$ 完成同样论证. 这里先从前提中选定一个全局成立的分支，再对所有对象使用它.

**逆方向反模型**：取 $D=\{0,1\}$，$A=P(x)$，$B=Q(x)$，$P^{\mathcal M}=\{0\}$，$Q^{\mathcal M}=\{1\}$. 每个对象至少属于一类，所以 $\forall x(P(x)\lor Q(x))$ 真；但没有一个谓词在全部对象上真，故 $\forall xP(x)\lor\forall xQ(x)$ 假. “对每个对象可选不同分支”不能推出“有一个分支对所有对象成立”.

**存在对合取也只保证一个方向**：$\exists x(A\land B)\models(\exists xA\land\exists xB)$.

若存在一个同时使 $A,B$ 成立的见证，该见证分别证明两个存在公式. 逆方向不成立：仍用上面的两元素解释，$\exists xP(x)$ 与 $\exists xQ(x)$ 各自为真，见证分别是 $0,1$；但没有共同见证，所以 $\exists x(P(x)\land Q(x))$ 为假.

### 7.3 同类量词交换与异类量词次序

**同类交换律**：$\forall x\forall yA\equiv\forall y\forall xA$，$\exists x\exists yA\equiv\exists y\exists xA$.

**证明**：对不同变量 $x,y$，固定 $d,e\in D$ 后，$l[x\mapsto d][y\mapsto e]=l[y\mapsto e][x\mapsto d]$. 两个全称公式都要求对 $D^2$ 中每个有序对 $(d,e)$，$A$ 在该更新赋值下为真. 两个存在公式都只要求至少一个这样的有序对，因此相应条件分别相同.

**异类量词的单向推论**：$\exists y\forall xA\models\forall x\exists yA$.

**证明**：设 $\mathcal M\models_l\exists y\forall xA$. 取使内层全称公式成立的见证 $e_0\in D$，即对每个 $d\in D$，$\mathcal M\models_{l[y\mapsto e_0][x\mapsto d]}A$. 因 $x\ne y$，可交换这两个固定值的更新，得到 $\mathcal M\models_{l[x\mapsto d][y\mapsto e_0]}A$.

于是对每个 $d$，$e_0$ 都可作为 $\exists yA$ 的见证，故 $\mathcal M\models_l\forall x\exists yA$. 关键是把前提给出的同一个见证用于每个 $d$，不是在证明中擅自选择依赖 $d$ 的新见证.

**课件勘误**：第 26 页取存在见证的一行误写成 $l[x\mapsto b]$，应为 $l[y\mapsto b]$；交换赋值更新还必须说明 $x\ne y$.

**逆方向反模型**：取 $D=\{0,1\}$，令 $A$ 为 $x=y$. 对任意 $x=d$，取 $y=d$ 即可，故 $\forall x\exists y(x=y)$ 真. 但任何预先固定的 $y=e$ 都不等于另一个元素，故 $\exists y\forall x(x=y)$ 假. 在单元素论域上二者都真，因此要否定后承需允许至少两个元素的解释.

### 7.4 非空论域与函数等号性质

**命题**：$\forall xA\models\exists xA$.

**证明**：任取使前提真的 $\mathcal M,l$. 由 $D\ne\varnothing$ 可选 $d_0\in D$，全称语义给出 $\mathcal M\models_{l[x\mapsto d_0]}A$，所以 $d_0$ 是存在公式的见证. 非空性正用在选择 $d_0$ 这一步.

**函数保持相等是有效的**：$\models\forall x\forall y(x=y\to f(x)=f(y))$，其中 $f$ 为一元函数符号.

任取解释与赋值，再任取参数 $d,e$. 若 $d=e$，全函数 $f^{\mathcal M}$ 对同一个输入只有同一个输出，故 $f^{\mathcal M}(d)=f^{\mathcal M}(e)$；若 $d\ne e$，蕴含的前件为假. 因此每个参数对都使蕴含为真，公式有效.

**逆断言不是有效式**：$\forall x\forall y(f(x)=f(y)\to x=y)$ 要求 $f^{\mathcal M}$ 是单射. 取 $D=\{0,1\}$，令 $f^{\mathcal M}(0)=f^{\mathcal M}(1)=0$；在 $x=0,y=1$ 时前件真而后件假，故公式在这个解释中为假. 一阶函数解释保证单值性与全定义，不保证单射性.

## 8. 等值置换定理

对应课件第 27 页. 这里替换的是公式的指定子公式出现，与后文“用项代入变量”是两种操作. 第 27 页定理中的“命题逻辑公式 $B$”是沿用前章的表述；结合 $QxA_1$ 的证明分支，本章结论针对一阶公式.

### 8.1 定理及结构归纳证明

> [!important] 等值置换定理
> 设 $B\equiv B'$. 将一阶公式 $A$ 中一处或多处指定的子公式 $B$ 替换为 $B'$，得到 $A'$. 则 $A\equiv A'$.

**归纳命题**：固定一对对所有解释、赋值都等值的 $B,B'$. 对任意公式 $A$，按任意指定的出现位置执行上述置换后所得的 $A'$，都与 $A$ 等值. 对其直接子公式的归纳假设也允许任意指定其中的置换位置，因此能覆盖只替换部分出现的情况.

**根节点被选中**：此时 $A=B$，$A'=B'$，结论就是已知的 $B\equiv B'$. 若当前公式内没有选中的出现，得到的公式完全相同，等值也成立. 特别地，未被替换的原子公式属于后一情况.

**否定**：若 $A=\neg C$，且根节点未替换，所有指定位置都在 $C$ 内，设其置换结果为 $C'$. 归纳假设保证对每个 $\mathcal M,l$，$C,C'$ 真值相同，故其否定真值相同，即 $\neg C\equiv\neg C'$.

**二元联结词**：若 $A=CcE$，两个直接子公式分别变成 $C',E'$. 对没有置换的位置也取原公式本身. 归纳假设给出 $C\equiv C'$、$E\equiv E'$，同一个二元真值函数作用于两组相同的真值，所以 $CcE\equiv C'cE'$.

**全称量词**：若 $A=\forall xC$，其置换结果为 $A'=\forall xC'$. 归纳假设不是只说 $C,C'$ 在当前 $l$ 下真值相同，而是说它们对每个解释与每个赋值都等值. 因而对任意 $d\in D$，可以应用于更新后的 $l[x\mapsto d]$，得到 $\mathcal M\models_{l[x\mapsto d]}C$ 当且仅当 $\mathcal M\models_{l[x\mapsto d]}C'$.

对每个 $d$ 的判定相同，故两边全称条件相同，$\forall xC\equiv\forall xC'$.

**存在量词**：同样，对每个候选 $d$，$C,C'$ 在更新赋值下真值相同. 任一侧的成功见证也是另一侧的成功见证，所以 $\exists xC\equiv\exists xC'$. 结构归纳完成.

### 8.2 为什么必须是全局等值

等值置换不要求 $B,B'$ 具有完全相同的自由变量集合. 例如 $P(x)\lor\neg P(x)\equiv y=y$，两边都在每个解释、赋值下为真，即使外层量词约束其中某个自由变量，等值仍成立.

但若只知道 $B,B'$ 在某一个赋值下同真，或者只知道某一特定解释中的局部性质，就不能直接使用本定理得到全局等值. 量词会访问更新后的赋值，原先的一点相同不能保证更新后仍相同. 第 12.6 节给出一个两元素反例.

因此，“外层量词可能约束新子公式中的变量”并不推翻这里的定理：前提已经要求等值对全部赋值成立. 后文变量捕获的危险发生在另一种操作中，即将项中的自由变量带入新的量词作用域，而该操作原本未必满足任何全局等值前提.

## 9. 项代入、公式代入与变量捕获

对应课件第 29—31 页. 代入是语法操作，而赋值更新是语义操作；代入引理和代入定理将二者联系起来.

### 9.1 代入的定义与一次性原则

**定义（项代入）**：给定变量 $x$ 和项 $s,t$，$s[t/x]$ 表示将项 $s$ 中 $x$ 的每次出现都替换成项 $t$ 的结果. 变量 $x$ 变成 $t$，其他变量和常元保持不变，函数项在各直接子项中递归代入.

**定义（公式代入）**：$A[t/x]$ 表示将公式 $A$ 中 $x$ 的每次自由出现都替换成项 $t$ 的结果，原有的约束出现不变. 此处先按课件定义进行直接代入，尚不默认先改名避开捕获；能否保证预期语义，要另外检查可自由代入条件.

这两种操作都是**针对原表达式出现位置的一次代入**. 新放入的 $t$ 不再被同一次操作继续代入. 例如 $x[f(x,y)/x]=f(x,y)$，不会递归膨胀成 $f(f(x,y),y)$ 等表达式.

对量词的递归规则具体如下.

- 若量词约束名就是 $x$，则 $(QxB)[t/x]=QxB$，因为其中没有相对于整个 $QxB$ 自由的 $x$.
- 若 $y\ne x$，则 $(QyB)[t/x]=Qy(B[t/x])$. 这一语法式即使导致捕获也可以写出；第 10 节的条件决定能否应用代入定理.
- 若 $x\notin\operatorname{FV}(A)$，则 $A[t/x]=A$，不发生任何替换.

**课件第 29 页例子**：设 $\varphi=\forall x(P(x)\land Q(x))\to(\neg P(x)\lor Q(y))$，代入 $f(x,y)$ 后得到

$$
\varphi[f(x,y)/x]
=\forall x(P(x)\land Q(x))\to(\neg P(f(x,y))\lor Q(y)).
$$

前件中的 $x$ 已被前件量词约束，不能改动；后件 $P(x)$ 中的 $x$ 自由，所以被替换；新项中的 $x,y$ 位于后件，不在前件 $\forall x$ 的作用域内，仍自由.

### 9.2 项代入引理及其证明

> [!abstract] 项代入引理
> 对任意解释 $\mathcal M$、对象赋值 $l$、项 $s,t$ 与变量 $x$，令 $d=t^{\mathcal M}[l]$，则 $(s[t/x])^{\mathcal M}[l]=s^{\mathcal M}[l[x\mapsto d]]$.

**含义**：先把项 $t$ 写入语法中的 $x$ 位置再求值，与先计算 $t$ 在原赋值下的值、再把该对象赋给 $x$ 后求原项，结果一致. 项内没有量词，因此不需要防捕获条件.

**归纳命题**：固定 $t,x$，对每个项 $s$，上述等式在任意解释和任意赋值下成立. 对 $s$ 作结构归纳.

**变量**：若 $s=x$，左边是 $t[l]=d$，右边是 $l[x\mapsto d](x)=d$. 若 $s=v\ne x$，左边是 $l(v)$，右边的更新不改变 $v$，也为 $l(v)$.

**常元**：若 $s=a$，代入不改变常元，更新也不改变其解释，两边都是 $a^{\mathcal M}$.

**函数项**：若 $s=f(s_1,\ldots,s_n)$，归纳假设对每个直接子项 $s_i$ 给出 $(s_i[t/x])[l]=s_i[l[x\mapsto d]]$，其中 $d=t[l]$ 对所有子项相同. 根据代入的递归定义，左边是把这些代入子项的值输入 $f^{\mathcal M}$；右边是把原子项在更新赋值下的值输入同一函数. 每个对应参数相等，故函数值相等. 结构归纳完成.

**课件第 30 页计算**：在 $\mathcal N^*$ 中，取 $l(x)=5,l(y)=7$，原项 $s=x+y$，代入项 $t=0''$. 因 $t[l]=2$，左边 $(0''+y)[l]=2+7=9$；右边 $(x+y)[l[x\mapsto2]]=2+7=9$. 课件原例将原项记为 $t$、代入项记为 $s$，本文只统一了字母角色.

### 9.3 捕获为何破坏公式代入的语义

不能不加条件地断言 $\mathcal M\models_l A[t/x]$ 当且仅当 $\mathcal M\models_{l[x\mapsto t[l]]}A$. 问题不在项的求值，而在于代入可能把项中的自由变量放到同名量词的作用域内.

课件第 31 页取 $A=\forall y\neg(x=y+y)$，在 $\mathcal N^*$ 中表示 $x$ 不是任何自然数的两倍，即 $x$ 为奇数. 直接代入 $t=x+y$，得到 $A[x+y/x]=\forall y\neg(x+y=y+y)$.

这个结果在标准算术中对每个原赋值都假：令内层量化的 $y$ 取 $l(x)$，就有 $l(x)+l(x)=l(x)+l(x)$，否定式为假，故全称式为假. 它并未表达“原赋值下 $x+y$ 为奇数”. 原本应保持固定的 $l(y)$，被外层的 $\forall y$ 覆盖了.

**补充：直接核对代入等式失败**. 取 $l(x)=1,l(y)=0$，则 $t[l]=1$. 右侧在 $l[x\mapsto1]$ 下判定 $\forall y\neg(x=y+y)$，因 $1$ 不是自然数的两倍而真；左侧直接代入后的公式则如上所证为假. 同一个 $\mathcal M,l$ 给出不同真值，已足以否定无条件代入规律.

这里“恒为假”仅指在课件采用的自然数标准解释中、对每个赋值都假，不能忽略解释后声称这个公式在所有一阶解释中都不可满足.

## 10. 可自由代入与代入定理

对应课件第 32—33 页. 防止捕获的条件，是保证语法代入与语义更新一致的关键.

### 10.1 可自由代入的精确条件

> [!note] 定义：可自由代入
> 项 $t$ 在公式 $A$ 中对变量 $x$ 可自由代入，是指对每个 $y\in\operatorname{Var}(t)$，$A$ 中 $x$ 的任何自由出现，都不处于以 $y$ 为约束名的量词 $\forall y$ 或 $\exists y$ 的作用域中.

实际检查时，应先找出**要被替换的自由出现**，再沿其到根节点的路径检查量词约束名，判断是否与 $\operatorname{Var}(t)$ 相交. 无须禁止公式其他无关分支使用相同变量名，也无须禁止代入项本身含有 $x$.

- 闭项不含变量，故在任意公式中对任意 $x$ 都可自由代入.
- 若 $x\notin\operatorname{FV}(A)$，没有需要检查的替换位置，任何项都可自由代入，且 $A[t/x]=A$.
- 在 $\forall yP(x,y)$ 中代入 $t=f(z)$ 替换 $x$ 是安全的，前提是 $z\ne y$；代入 $t=f(y)$ 则会让新项中的 $y$ 被捕获.
- 在 $\forall xP(x,y)$ 中对 $x$ 代入 $f(y)$ 是空操作，不能因公式含 $\forall x$ 就把它误判为捕获.

这个条件是适用于所有公式的语法性保证. 不满足条件时，表示不能直接引用代入定理；并不意味着某个特殊公式代入后一定改变真值，例如恒真的上下文可能掩盖捕获带来的语义差别.

### 10.2 代入定理的命题与原子情形

> [!important] 代入定理
> 若项 $t$ 在公式 $A$ 中对 $x$ 可自由代入，则对任意解释 $\mathcal M$ 和对象赋值 $l$，令 $d=t^{\mathcal M}[l]$，有
>
> $$\mathcal M\models_l A[t/x]\quad\Longleftrightarrow\quad\mathcal M\models_{l[x\mapsto d]}A.$$

**归纳命题**：对每个公式 $A$，对所有满足可自由代入条件的 $t,x$，以及所有解释与赋值，上式成立. 证明对 $A$ 作结构归纳. 固定某个 $t,x,\mathcal M,l$ 后，归纳假设可用于直接子公式及任意新的赋值，但必须重新检查自由代入条件及代入项在该赋值下的值.

**谓词原子**：设 $A=P(s_1,\ldots,s_n)$. 代入作用于每个参数项，项代入引理给出 $(s_i[t/x])[l]=s_i[l[x\mapsto d]]$. 因此两边用于判定关系 $P^{\mathcal M}$ 的参数元组相同，满足条件等价.

**等式原子**：设 $A=s_1=s_2$. 项代入引理分别保证代入前后两端的对应指称相同，故 $(s_1[t/x])[l]=(s_2[t/x])[l]$ 当且仅当 $s_1[l[x\mapsto d]]=s_2[l[x\mapsto d]]$. 这正是等式公式所需的结论.

### 10.3 联结词情形

若 $A=\neg B$，可自由代入条件对 $B$ 仍成立，因为否定不引入量词. 归纳假设给出 $B[t/x]$ 在 $l$ 下的真值等于 $B$ 在 $l[x\mapsto d]$ 下的真值，取否定后仍相同.

若 $A=BcC$，$B,C$ 中自由的 $x$ 也正是各分支对整个 $A$ 贡献的自由出现. 因此 $t$ 在两子公式中分别对 $x$ 可自由代入，可以分别应用归纳假设. 两个分量的对应真值相同，同一个二元联结词的结果也相同，结论成立.

### 10.4 全称量词情形的完整证明

设 $A=\forall yB$，目标是比较 $(\forall yB)[t/x]$ 在 $l$ 下的真值，与 $\forall yB$ 在 $l[x\mapsto d]$ 下的真值，其中 $d=t[l]$.

**第一种情况：$x\notin\operatorname{FV}(\forall yB)$**. 此时代入不改变公式. 原赋值 $l$ 与 $l[x\mapsto d]$ 只可能在 $x$ 上不同，而 $x$ 不自由出现，故第 5.2 节的赋值一致性引理直接给出两边真值相同. 特别地，$x=y$ 时一定属于这种情况；不能错误地进入作用域代入那些已被该量词约束的 $x$.

**第二种情况：$x\in\operatorname{FV}(\forall yB)$**. 此时 $x\ne y$，且 $x$ 在 $B$ 中自由出现. 因为这些替换位置都位于外层 $\forall y$ 的作用域内，可自由代入条件强迫 $y\notin\operatorname{Var}(t)$. 同时，它也保证 $t$ 在子公式 $B$ 中对 $x$ 可自由代入.

任取 $e\in D$，令 $r=l[y\mapsto e]$. 由于 $y$ 不出现在 $t$ 中，项的赋值一致性引理给出 $t[r]=t[l]=d$. 这是证明中保证代入项的值不随内层量化对象改变的步骤.

对直接子公式 $B$，在赋值 $r$ 下使用归纳假设，得到 $\mathcal M\models_{l[y\mapsto e]}B[t/x]$ 当且仅当 $\mathcal M\models_{l[y\mapsto e][x\mapsto d]}B$. 因 $x\ne y$，固定对象的更新可交换，所以右边又等价于 $\mathcal M\models_{l[x\mapsto d][y\mapsto e]}B$.

因此，对每个候选 $e$，代入公式的作用域与原公式在更新赋值下的作用域真值相同. 对所有 $e$ 同时要求成立，就分别得到 $\mathcal M\models_l\forall y(B[t/x])$ 与 $\mathcal M\models_{l[x\mapsto d]}\forall yB$. 又因 $x\ne y$，左侧公式正是 $(\forall yB)[t/x]$，目标得证.

这一步实际使用了三个不同依据：可自由代入排除 $y\in\operatorname{Var}(t)$；项的赋值一致性保证 $t[l[y\mapsto e]]=t[l]$；不同变量的赋值更新可交换. 只写“由归纳假设”不足以完成量词步骤.

### 10.5 存在量词情形与定理的边界

设 $A=\exists yB$. 若 $x\notin\operatorname{FV}(A)$，仍由空代入与赋值一致性引理完成证明.

若 $x$ 自由出现，则同样有 $x\ne y$、$y\notin\operatorname{Var}(t)$，并且 $t$ 在 $B$ 中对 $x$ 可自由代入. 对每个 $e\in D$，按上一节相同的计算，$\mathcal M\models_{l[y\mapsto e]}B[t/x]$ 当且仅当 $\mathcal M\models_{l[x\mapsto d][y\mapsto e]}B$. 因此任一侧使作用域为真的见证 $e$，也使另一侧作用域为真；对 $e$ 取存在条件后，得到目标等价. 全部构造情形已经覆盖，结构归纳完成.

代入定理**没有**断言 $A[t/x]\equiv A$. 它比较的是两个不同语义参数下的满足关系. 例如 $A=P(x)$、$t=a$ 时，$P(a)$ 的真值对应 $P(x)$ 在 $x$ 被赋为 $a^{\mathcal M}$ 后的真值；它不必等于 $P(x)$ 在原赋值下的真值.

## 11. 约束变量改名与公式变体

对应课件第 34—36 页，其中第 34、35 页重复. 改名的目标是改变约束变量的名称而保留原有约束关系；它既不能把原自由出现一起改掉，也不能把其他自由变量捕获.

### 11.1 改名的定义及新变量条件

**定义（约束变量改名）**：对量词公式 $\forall yB$，取一个与 $y$ 不同、且不在 $B$ 中出现的新变量 $z$，将它改成 $\forall z(B[z/y])$；存在量词相应改成 $\exists z(B[z/y])$. 这里 $B[z/y]$ 只替换相对于作用域公式 $B$ 自由的 $y$，即原来由选中的外层量词约束的那些出现.

课件使用“$z$ 不出现在 $B$ 中”的新鲜性条件. 这是便于检查的充分条件；本文沿用它，不擅自放宽为仅检查某些位置. 选择时还明确要求 $z\ne y$，避免空约束等退化情形使“新变量”的含义不清.

例如 $\forall y(R(y)\land\exists yS(y))$ 改外层约束名为 $z$，结果是 $\forall z(R(z)\land\exists yS(y))$. 内层 $\exists y$ 自己约束的出现不是外层约束的，故不随这次操作改变. 若要把内层也改名，须另选一次量词出现单独处理.

### 11.2 改名保持等值的引理

> [!abstract] 约束变量改名引理
> 若 $z\ne y$，且 $z$ 不在 $B$ 中出现，则 $\forall z(B[z/y])\equiv\forall yB$，且 $\exists z(B[z/y])\equiv\exists yB$.

**证明思路**：先用代入定理解释 $B[z/y]$，再用自由变量赋值一致性消去对新变量 $z$ 的额外更新. 第二步不能无故省略.

固定任意 $\mathcal M,l$，对任意 $d\in D$，设 $r=l[z\mapsto d]$. 因为 $z$ 不在 $B$ 中出现，特别是 $B$ 中没有 $\forall z$ 或 $\exists z$ 会捕获代入的 $z$，所以项 $z$ 在 $B$ 中对 $y$ 可自由代入.

由代入定理，$\mathcal M\models_r B[z/y]$ 当且仅当 $\mathcal M\models_{r[y\mapsto z[r]]}B$. 由于 $z[r]=d$，右侧赋值是 $l[z\mapsto d][y\mapsto d]$.

这个赋值与 $l[y\mapsto d]$ 在 $B$ 的全部自由变量上相同：二者都把 $y$ 赋为 $d$；$z$ 不在 $B$ 中出现，无需比较其值；其余变量都保持原赋值. 由第 5.2 节，两赋值下 $B$ 真值相同.

于是对每个 $d$，$\mathcal M\models_{l[z\mapsto d]}B[z/y]$ 当且仅当 $\mathcal M\models_{l[y\mapsto d]}B$. 对所有 $d$ 取全称条件，得到 $\forall z(B[z/y])$ 与 $\forall yB$ 真值相同；取存在条件，得到 $\exists z(B[z/y])$ 与 $\exists yB$ 真值相同. 因 $\mathcal M,l$ 任意，两条逻辑等值成立.

**课件证明补全**：第 34、35 页的证明从代入定理跳到只更新 $y$ 的赋值，省略了先更新 $z$ 的影响. 严格写法应先得到 $l[z\mapsto d][y\mapsto d]$，再用 $z\notin\operatorname{FV}(B)$ 和赋值一致性引理消去额外更新；两个赋值未必作为全域映射完全相等，但在 $B$ 的真值上等效.

### 11.3 公式变体与安全代入

**定义（变体）**：若 $A'$ 由 $A$ 的指定子公式经过有限次符合新变量条件的约束变量改名得到，则称 $A'$ 是 $A$ 的一个变体.

**定理**：若 $A'$ 是 $A$ 的变体，则 $A\equiv A'$.

**证明**：每一步改名在被选中的量词子公式处，由上一引理保持逻辑等值；将该等值子公式放回整个公式，由第 8 节等值置换定理，整式仍等值. 对有限次步骤逐次使用等值的传递性，得到初末公式等值. 若没有改名，初末公式相同，也满足结论.

课件例子为 $\forall y(\neg\forall xP(x,y)\to Q(y))\equiv\forall y(\neg\forall zP(z,y)\to Q(y))$. 改动发生在内层 $\forall xP(x,y)$；外层的 $y$ 及其原有约束关系均不变，新名 $z$ 不出现在原内层作用域中.

**补充方法：先改名，再代入**. 若项 $t$ 在 $A$ 中对 $x$ 不可自由代入，就逐个处理那些会捕获 $\operatorname{Var}(t)$ 中变量的量词：取不出现在当前公式及 $t$ 中的新变量，按上述定义改名. 公式有限而变量储备无限，因此可以在有限次后得到等值变体 $\widetilde A$，使 $t$ 在其中对 $x$ 可自由代入.

正确的安全代入结果是 $\widetilde A[t/x]$. 对任意 $\mathcal M,l$，先由代入定理知它在 $l$ 下为真，当且仅当 $\widetilde A$ 在 $l[x\mapsto t[l]]$ 下为真；再由 $\widetilde A\equiv A$，等价于原公式 $A$ 在该更新赋值下为真. 这就恢复了预期的代入语义，不需要假定原来会捕获的直接代入也正确.

对第 9.3 节的 $A=\forall y\neg(x=y+y)$，先取新变量 $z$ 改成 $\widetilde A=\forall z\neg(x=z+z)$，再代入 $x+y$，得到 $\forall z\neg(x+y=z+z)$. 其中 $x,y$ 保持自由，才表达原赋值下“$x+y$ 为奇数”.

### 12.1 同名变量在不同作用域中的出现

**补充例题**：设 $R$ 为二元谓词，$S$ 为三元谓词，$x,y,z$ 两两不同. 对公式 $A=(\forall xR(x,y))\land\exists y(R(x,y)\land\forall xS(x,y,z))$，求自由变量集，并判断它是不是语句.

**解析**：左分量 $\forall xR(x,y)$ 删除原子中自由的 $x$，故自由变量集为 $\{y\}$；这个 $y$ 不在右分量的 $\exists y$ 作用域内，不能由右侧量词约束.

右侧存在量词的作用域中，$R(x,y)$ 的自由变量集是 $\{x,y\}$，$\forall xS(x,y,z)$ 的自由变量集是 $\{y,z\}$. 合取后为 $\{x,y,z\}$，再由外层 $\exists y$ 删除 $y$，得到右分量自由变量集 $\{x,z\}$.

所以 $\operatorname{FV}(A)=\{x,y,z\}$，不是语句. $x$ 在左分量及右侧 $S$ 中约束，但在右侧 $R$ 中自由；$y$ 在左分量自由，在右分量受 $\exists y$ 约束；$z$ 在它唯一的出现处自由. 判断依据是每次出现到根节点的量词路径，不能跨过合取分支寻找量词.

### 12.2 用纯等号语句刻画模型大小

**课件第 17 页题目**：设 $n$ 为正整数，只使用等号、不使用非逻辑符号，构造语句 $I_n,J_n,K_n$，分别表示论域至少有 $n$ 个、至多有 $n$ 个、恰有 $n$ 个个体.

**至少有 $n$ 个**：取两两不同的变量 $x_1,\ldots,x_n$，令

$$
I_n:=\exists x_1\cdots\exists x_n\bigwedge_{1\le i<j\le n}\neg(x_i=x_j).
$$

这里的大合取是有限次二元合取的缩写. 对 $n=1$，没有需要比较的变量对，空合取按真处理；若不引入真常量，可直接写 $I_1=\exists x_1(x_1=x_1)$.

若 $I_n$ 为真，存在见证 $d_1,\ldots,d_n$，每对都不相等，故论域至少有 $n$ 个不同对象. 反之，若论域至少有 $n$ 个对象，从中选出 $n$ 个不同对象分别赋给这些变量，即满足每个不等式，故语句真.

**至多有 $n$ 个**：令 $y$ 与所有 $x_i$ 不同，取

$$
J_n:=\exists x_1\cdots\exists x_n\forall y\bigvee_{i=1}^n(y=x_i).
$$

若 $J_n$ 真，则每个论域对象都等于某个已选见证，所以 $D\subseteq\{d_1,\ldots,d_n\}$，至多有 $n$ 个对象. 注意公式不要求这些见证彼此不同.

反之，若 $1\le|D|=k\le n$，先用前 $k$ 个见证枚举全部对象，余下的见证重复任意已有对象. 对每个 $y$，至少一个等式 $y=x_i$ 为真，故 $J_n$ 真. 允许重复是“至多”正确的必要之处；若额外强迫见证不同，就排除了小于 $n$ 的论域.

另一种等价写法是 $J_n'=\forall x_1\cdots\forall x_{n+1}\bigvee_{1\le i<j\le n+1}(x_i=x_j)$. 若论域至多有 $n$ 个对象，任取 $n+1$ 个取值必有重复；若论域至少有 $n+1$ 个对象，选取两两不同的值就使该公式为假. 因而 $J_n'\equiv J_n$.

**恰有 $n$ 个**：取 $K_n:=I_n\land J_n$. 上述两个方向的证明分别给出 $|D|\ge n$ 与 $|D|\le n$，共同成立恰好等价于 $|D|=n$.

例如 $K_2$ 可直接写成 $\exists x\exists y(\neg(x=y)\land\forall z(z=x\lor z=y))$. 两个见证保证下界，覆盖所有对象的全称条件保证上界. 这些语句不需要给每个对象命名的常元，变量与量词已经足以表达有限大小约束.

### 12.3 自由变量与实际真值依赖并不等同

**补充例题**：是否所有含自由变量的公式，在固定解释中都会随该变量的赋值改变真值？固定解释下的一个满足赋值，是否足以证明公式有效？

**解析**：第一问不成立. 公式 $x=x$ 的自由变量集为 $\{x\}$，语法上不是语句，但在任意解释与任意赋值下，等号恒等语义都使它为真. 第 5.2 节给出“对自由变量赋值相同，则真值相同”的充分保证，没有反向断言每个自由变量都对真值有实质影响.

第二问也不成立. 取公式 $x=y$ 与两元素论域 $D=\{0,1\}$. 在 $l(x)=l(y)=0$ 时公式真，因此它可满足；改成 $l'(x)=0,l'(y)=1$ 后公式假，因此它不有效. 即使解释没有改变，也已经出现反例赋值.

判断时应分别写出三个量化层次：“在这个 $\mathcal M,l$ 下真”“存在某个 $\mathcal M,l$ 使它真”“所有 $\mathcal M,l$ 都使它真”. 它们依次对应一次满足、可满足、有效，不是同一命题的不同简称.

### 12.4 可自由代入条件的逐项检查

**补充例题**：设 $x,y,z$ 两两不同，$f$ 为一元函数符号，$a$ 为常元，判断下列项是否在给定公式中对 $x$ 可自由代入.

| 公式 $A$ | 项 $t$ | 判断与依据 |
|---|---|---|
| $\forall yR(x,y)$ | $y$ | 否，自由 $x$ 所在路径经过 $\forall y$，会捕获新项中的 $y$ |
| $\forall yR(x,y)$ | $f(z)$ | 是，路径只绑定 $y$，而项中只有变量 $z$ |
| $\forall xR(x,y)$ | $f(y)$ | 是，整个公式无自由 $x$，代入为空操作 |
| $P(x)\land\forall yQ(y)$ | $f(y)$ | 是，待替换位置在左分支，不在右侧量词作用域内 |
| $\forall yR(x,y)$ | $a$ | 是，闭项不含可被捕获的变量 |
| $\exists yR(x,y)$ | $f(x)$ | 是，新项含 $x$ 没有问题，沿路径绑定的是 $y$ |

例如最后一项的直接代入结果是 $\exists yR(f(x),y)$，其中新项的 $x$ 仍自由，并不会因替换对象也是 $x$ 而被再次代入. 第三项则仍是 $\forall xR(x,y)$，不能把它错改成 $\forall xR(f(y),y)$.

### 12.5 综合完成一次防捕获代入

**补充例题**：对第 12.1 节的公式 $A$，用 $f(y)$ 代入自由变量 $x$，其中 $f$ 为一元函数符号. 给出直接代入的风险及一个满足预期语义的结果.

**解析**：原公式自由的 $x$ 只出现在右侧 $R(x,y)$ 中，它位于 $\exists y$ 作用域内. 因 $y\in\operatorname{Var}(f(y))$，直接代入得到 $\exists y(R(f(y),y)\land\forall xS(x,y,z))$ 这一右分量时，新项中的 $y$ 被捕获，故不能引用代入定理.

先取不在原式与代入项中出现的新变量 $u$，将右侧 $\exists y$ 改名. 其作用域中自由的 $y$ 包括 $R(x,y)$ 中的 $y$，也包括内层 $\forall xS(x,y,z)$ 中的 $y$；后者只受 $\forall x$ 约束变量 $x$，并未另行绑定 $y$. 因而等值变体是 $\widetilde A=(\forall xR(x,y))\land\exists u(R(x,u)\land\forall xS(x,u,z))$.

此时原自由 $x$ 的路径只经过 $\exists u$，而 $u$ 不在 $f(y)$ 中出现，可以安全代入，得到

$$
C=(\forall xR(x,y))\land\exists u(R(f(y),u)\land\forall xS(x,u,z)).
$$

两个 $\forall x$ 内原有的 $x$ 都保持不变. $C$ 的自由变量集为 $\{y,z\}$，其中新项的 $y$ 仍自由，符合预期.

严格验证应写为：对任意 $\mathcal M,l$，令 $d=f(y)^{\mathcal M}[l]$，由代入定理有 $\mathcal M\models_l C$ 当且仅当 $\mathcal M\models_{l[x\mapsto d]}\widetilde A$；再由 $\widetilde A\equiv A$ 得到 $\mathcal M\models_{l[x\mapsto d]}A$. 这才是安全代入的语义目标，不能改写成无条件的 $C\equiv A$.

### 12.6 局部同真不能代替等值置换的前提

**补充例题**：若在某个固定 $\mathcal M,l$ 下 $B,B'$ 同真，能否将它们放入 $\forall x$ 中后仍断言同真？

**解析**：取 $D=\{0,1\}$，$P^{\mathcal M}=\{0\}$，$Q^{\mathcal M}=\{0,1\}$，并取 $l(x)=0$. 令 $B=P(x)$，$B'=Q(x)$. 在当前赋值下二者都真.

但 $\forall xP(x)$ 为假，因为在更新赋值 $l[x\mapsto1]$ 下 $P(x)$ 为假；$\forall xQ(x)$ 为真，因为两个候选值都属于 $Q^{\mathcal M}$. 外层量词迫使我们检查新的赋值，原来 $x=0$ 时的一点同真不足以支持这一步.

第 8 节要求的 $B\equiv B'$ 对所有解释、所有赋值成立，故在 $l[x\mapsto1]$ 这样的更新赋值下也能使用. 这说明归纳证明中的全称量化是定理可应用的实质条件.

## 13. 易错点速查

| 常见的错误说法 | 应当如何判断 |
|---|---|
| 项与公式都是符号串，可以混用 | 先检查语法类型：项指向对象，谓词作用于项或项间等式才构成原子公式 |
| 固定语言中的 $f$ 可随例子改变参数数目 | 先固定元数，逐节点核对；另一个例子使用另一个语言时才可重新约定 |
| 算术语言的 $+$ 必然是自然数加法 | 语言只给符号与元数；指定 $\mathcal N^*$ 后才取标准含义 |
| 不同常元一定表示不同对象 | 查看是否有不等式等额外条件；解释可以使不同常元同指 |
| 函数符号天然表示单射 | 解释只要求全函数；用两元素常值函数即可否定单射有效性 |
| 一个变量名只能自由或约束二选一 | 检查每次出现及最近同名量词；同名变量可在不同位置承担不同角色 |
| $x$ 不自由出现，就一定有约束出现 | 检查 $x$ 是否实际出现；完全不出现也满足“不自由出现” |
| 有量词的公式就是语句 | 递归计算 $\operatorname{FV}(A)$，只有空集才是语句 |
| 公式有自由变量，真值就一定随它变化 | 自由变量是语法概念；$x=x$ 虽开放，却在所有赋值下真 |
| 修改 $l(x)$ 可以改变常元的值 | 常元由解释固定，赋值更新只改变变量值 |
| $\mathcal M\models_l A$ 就是 $A$ 有效 | 有效性要量化所有解释和赋值；一次满足只给出一个语义实例 |
| 每个前提分别可满足，前提集就可满足 | 必须找到同一个 $\mathcal M,l$ 同时满足全部前提 |
| 否定后承只要让结论假 | 同一反模型还须使每个前提都真 |
| $\forall x$ 对析取、$\exists x$ 对合取均可双向分配 | 一般只有第 7.2 节列出的单向关系；逆方向用两元素不相交的谓词解释检查 |
| $\forall x\exists y$ 与 $\exists y\forall x$ 可以交换 | 比较见证是否允许依赖 $x$；两元素论域上的 $x=y$ 是逆方向反例 |
| $\forall xA\models\exists xA$ 不需要任何背景条件 | 本章依赖非空论域，证明中必须能选出一个对象 |
| $A[t/x]$ 把所有同名 $x$ 一起替换 | 只替换原式中自由的 $x$；在 $Qx$ 下停止，不替换新放入项中的 $x$ |
| 出现同名量词就一定不可代入 | 只检查待替换的自由出现到根节点的路径，无关分支不构成捕获 |
| 代入项含 $x$ 就会无限代入 | 代入是一次性操作，$x[f(x)/x]=f(x)$ |
| 代入定理给出 $A[t/x]\equiv A$ | 它比较 $l$ 下的代入式与 $l[x\mapsto t[l]]$ 下的原式，赋值不同 |
| 不可自由代入就一定使某公式真值改变 | 这只表示一般定理的条件失败；特殊公式可能偶然同真，需另行验证 |
| 改名可将公式中所有 $y$ 全局替换 | 只改选定量词的约束名及由它约束的出现，保留其他分支及内层同名量词的约束关系 |
| 改名引理可直接删去更新 $z$ 的步骤 | 先写出两个更新，再以 $z$ 不自由出现为条件，调用赋值一致性引理 |
| 一个赋值下同真即可等值置换 | 必须满足定理要求的全局逻辑等值，量词步骤会检查更新后的赋值 |

### 14.2 量词规律与适用条件

| 关系 | 条件或关键思想 |
|---|---|
| $\neg\forall xA\equiv\exists x\neg A$；$\neg\exists xA\equiv\forall x\neg A$ | 经典二值语义下否定全称、存在条件 |
| $\forall x(A\land B)\equiv\forall xA\land\forall xB$ | 同一个对象上分别检查两个分量 |
| $\exists x(A\lor B)\equiv\exists xA\lor\exists xB$ | 一次成功见证落入至少一个分支 |
| $\forall xA\lor\forall xB\models\forall x(A\lor B)$ | 全局成立的一个分支足够；逆向一般失败 |
| $\exists x(A\land B)\models\exists xA\land\exists xB$ | 一个共同见证足够；分别有见证不保证共用 |
| $\forall x\forall yA\equiv\forall y\forall xA$ | 不同变量，遍历相同的全部参数对 |
| $\exists x\exists yA\equiv\exists y\exists xA$ | 不同变量，寻找同一个参数对 |
| $\exists y\forall xA\models\forall x\exists yA$ | 不同变量，固定的共同见证可重复使用；逆向一般失败 |
| $\forall xA\models\exists xA$ | 本章非空论域条件 |

### 14.3 代入与改名的核对顺序

遇到 $A[t/x]$，先计算待替换的自由出现，再检查 $\operatorname{Var}(t)$ 与这些出现路径上的量词约束名是否冲突. 没有冲突时，令 $d=t[l]$，用代入定理把目标转成原式在 $l[x\mapsto d]$ 下的判定. 有冲突时，先用足够新鲜的变量改名，得到等值变体后重新检查，不直接套定理.

证明量词归纳步骤时，依次核对：当前公式与作用域的自由变量差在哪里；更新赋值是否在作用域自由变量上相同；项的值是否因更新而改变；两个更新对应的变量是否不同；最后再按全称或存在条件合并逐个对象的结论.

与前章的联系是语义后承、等值与可满足性的定义框架保持一致，但本章多了内部项结构与量词依赖. [[Chapter 5 命题逻辑范式和 SAT 求解器]] 中直接基于有限命题变量赋值的真值表或 SAT 搜索，不能直接替代本章对任意论域、函数和量词的语义论证.
