## 一、基本概念

**通俗一句话：** 图就是一堆点（顶点）和点之间的连线（边），用来建模关系。
**严谨定义：** 图 $G = (V, E)$，$V$ 为顶点集，$E \subseteq \binom{V}{2}$ 为边集（允许重边/自环时称**伪图**）

| 术语                    | 定义                                                               |
| --------------------- | ---------------------------------------------------------------- |
| **阶 (order)**         | $n = \|V\|$，顶点数                                                  |
| **边数 (size)**         | $m = \|E\|$                                                      |
| **度 (degree)**        | $\deg(v)$ = 与 $v$ 关联的边数；$\delta(G)$ 最小度，$\Delta(G)$ 最大度          |
| **简单图**               | 无重边、无自环                                                          |
| **完全图 $K_n$**         | 任意两点间恰有一条边，$m = n(n-1)/2$                                        |
| **二分图 $K_{a,b}$**     | 顶点分两部，边只跨部存在                                                     |
| **补图 $\overline{G}$** | 顶点集同 $V$，边集为完全图减 $E$                                             |
| **子图 / 导出子图**         | $H \subseteq G$ 顶点边均为子集；$G[S]$ 由 $S \subseteq V$ 及两端均在 $S$ 中的边构成 |

**握手引理 (Handshaking Lemma):** $\sum_{v \in V} \deg(v) = 2|E|$ → 推论：**奇数度顶点必为偶数个**
**可图化 / 可简单图化：** 非增序列 $d_1 \ge d_2 \ge \cdots \ge d_n$，满足 $\sum d_i$ 为偶数时可图化。满足 Erdős–Gallai 定理时可简单图化
**连通性：** 图中任意两点有路径。**连通分支数** $c(G)$。**割点 / 割边**：移除后增加分支数
**路 / 圈：** 路 $P_n$ 含 $n$ 顶点 $n-1$ 边；圈 $C_n$ 含 $n$ 顶点 $n$ 边。**Girth** 为最短圈长
> [!warning] ⚠️ 握手引理 $\sum \deg(v) = 2m$ 用于判断度序列是否可能，但注意区分"可图化"（允许重边）和"可简单图化"（用 Erdős–Gallai）。
## 二、树 (Tree)
**通俗一句话：** 树是最小连通图——边数刚好多到恰好连通，少一条就不连通
**严谨定义：** 连通无圈的图。**等价条件：** ① 连通且 $m = n-1$；② 无圈且 $m = n-1$；③ 任意两点间有唯一路径

| 概念 | 内容 |
|---|---|
| **生成树 (Spanning Tree)** | 包含所有顶点的树 |
| **最小生成树 (MST)** | 边权总和最小的生成树，**Kruskal** (贪心+并查集) / **Prim** (加点法) |
| **Cayley 公式** | $K_n$ 的生成树个数为 $\tau(K_n) = n^{n-2}$ |
| **Matrix-Tree 定理** | 图的生成树数 = Laplacian 矩阵任一 $n-1$ 阶主子式的行列式 |
| **Steiner 树** | 给定顶点子集 $S$，允许增加额外点使连通，求最小总边权（NP-hard） |

> [!tip] 树的**悬垂点 (leaf)** 至少 2 个（$n \ge 2$）。
## 三、匹配 (Matching)
**通俗一句话：** 匹配是图里选一组边，两两不共享顶点。目标是选最多的边
**严谨定义：** $M \subseteq E$，任意两条边在 $M$ 中无公共端点

| 概念 | 定义 |
|---|---|
| **最大匹配 (Maximum Matching)** | 边数最多的匹配 |
| **完美匹配 (Perfect Matching)** | 覆盖所有顶点的匹配，$n$ 为偶数 |
| **饱和/未饱和点** | $M$ 覆盖/未覆盖的顶点 |
| **可扩路 (Augmenting Path)** | 两端为未饱和点的交错路（边交替在/不在 $M$ 中） |
| **最大匹配算法** | 反复找可扩路 → 翻转（增广），直到无可扩路 → **最大匹配** |

### Hall 婚姻定理 (Hall 1935)
**二分图 $G = (X, Y)$**，存在饱和 $X$ 的匹配 $\iff$ $\forall S \subseteq X$, $|N(S)| \ge |S|$。（$N(S)$ 是 $S$ 的邻居集）
> ⚠️ 条件也叫"相异代表系存在定理"。检查时先验证是否 $\exists S$ 使 $|N(S)| < |S|$
### König 定理
在二分图中：**最大匹配数 = 最小顶点覆盖数**（NP-hard 问题在二分图变多项式）。
> 推论：$\alpha'(G) = \beta(G)$（二分图），其中 $\alpha'$ 为边独立数，$\beta$ 为点覆盖数。
### 匈牙利算法 (Kuhn-Munkres, 1955/1957)
用于求解**赋权二分图最大权匹配**（指派问题）。
1. 构造等值子图 $G_{l}$（满足 $l(x_i)+l(y_j)=w_{ij}$ 的边构成）
2. 在 $G_{l}$ 中找完美匹配，找到则最优
3. 否则调整标号 $l$：$\theta = \min\{l(x_i)+l(y_j)-w_{ij}\} ，x \in S$ 减 $\theta$，$y \in T$ 加 $\theta$，回到 2
> [!example] 例：邻接矩阵 [[3,5,5,4,1],[2,2,0,2,2],[2,4,4,1,0],[0,1,1,0,0],[1,2,1,3,3]]，用匈牙利算法求最大权匹配
> **关键步骤：** 每行/列减最小元 → 覆盖零 → 调整标号 → 直到 5 个零在不同行不同列
> **答案：** 最优匹配值 14
## 四、平面图 (Planar Graph)
**通俗一句话：** 能画在纸上边不交叉的图
**严谨定义：** 可嵌入平面的图，即存在无交叉边的平面画法。**平面嵌入**把平面分成若干**面 (face)**。外部无限面称**外部面**
### Euler 公式 (Euler 1758)
**连通平面图：** $v - e + f = 2$（$v$ 顶点数、$e$ 边数、$f$ 面数）
$k$ 个连通分支：$v - e + f = 1 + k$（计入外部面）
> [!important] **推论（平面图必要条件）：**
> - 简单连通平面图：$e \le 3v - 6$（$v \ge 3$），无三角形时 $e \le 2v - 4$
> - 平面图最小度 $\delta \le 5$
### Kuratowski 定理 (Kuratowski 1930)
**图 $G$ 可平面化 $\iff$ $G$ 不含 $K_5$ 或 $K_{3,3}$ 的细分 (subdivision)**。
> $K_5$ 和 $K_{3,3}$ 是两个**极小非平面图**。任何非平面图必以二者之一为"骨架"
> **Wagner 定理 (1937)：** 图可平面化 $\iff$ 不含 $K_5$ 或 $K_{3,3}$ 为 **minors**

| 判断方法           | 要点      |
| -------------- | ------- |
| $e > 3v - 6$   | 直接排除平面性 |
| 含 $K_5$ 细分     | 必非平面    |
| 含 $K_{3,3}$ 细分 | 必非平面    |

## 五、图着色 (Coloring)
### 顶点着色 (Vertex Coloring)
**$k$-着色：** 用 $k$ 种颜色给顶点染色，相邻点不同色。**色数 $\chi(G)$** = 所需最小颜色数。

| 结果 | 内容 |
|---|---|
| **下界** | $\chi(G) \ge \omega(G)$（团数），$\chi(G) \ge \left\lceil\frac{n}{\alpha(G)}\right\rceil$（$\alpha$ 为独立数） |
| **上界** | $\chi(G) \le \Delta(G) + 1$（平凡上界） |
| **Brooks 定理 (1941)** | 若 $G$ 非奇圈、非完全图，则 $\chi(G) \le \Delta(G)$ |
| **Welsh-Powell 算法** | 按度降序 → 依次尝试最小可用颜色（贪心） |
| **四色定理** | 平面图 $\chi(G) \le 4$（Appel–Haken 1976，计算机辅助证明） |
| **Heawood 五色定理** | 平面图 $\chi(G) \le 5$（更早、更简的结论） |

> [!warning] ⚠️ $\chi(G) \ge \omega(G)$，但反之不成立——存在 $\omega=2$, $\chi=3$ 的图（如 $C_5$）。**色数与团数无直接等价关系**
### 边着色 (Edge Coloring)
**$k$-边着色：** 给边染色，有公共端点的边不同色。**边色数 $\chi'(G)$**。

| 结果                   | 内容                                         |
| -------------------- | ------------------------------------------ |
| **平凡下界**             | $\chi'(G) \ge \Delta(G)$                   |
| **Vizing 定理 (1964)** | $\Delta(G) \le \chi'(G) \le \Delta(G) + 1$ |
| **二分图边着色**           | $\chi'(G) = \Delta(G)$（König 线图定理）         |
| **奇圈**               | $\chi'(C_{2k+1}) = 3 = \Delta + 1$         |

Vizing 定理将图分为两类：**Class 1** ($\chi' = \Delta$) 和 **Class 2** ($\chi' = \Delta+1$)
> ⚠️ 判定一个图属于 Class 1 还是 Class 2 是 NP-complete 问题
## 六、谱图论 (Spectral Graph Theory)
**通俗一句话：** 把图写成矩阵，通过特征值看图的连通性、分割性质
### 图矩阵

| 矩阵                | 定义                               | 性质                                          |
| ----------------- | -------------------------------- | ------------------------------------------- |
| **邻接矩阵 $A$**      | $A_{ij} = 1$ 若 $ij \in E$，否则 $0$ | $A$ 对称，特征值全实数                               |
| **度矩阵 $D$**       | $D_{ii} = \deg(v_i)$，非对角元均为 $0$  | 对角阵                                         |
| **Laplacian $L$** | $L = D - A$                      | 半正定，$L\mathbf{1} = 0$，最小特征值 $\lambda_1 = 0$ |

### Laplacian 的关键性质
- $x^\top L x = \sum_{(i,j) \in E} w_{ij}(x_i - x_j)^2 \ge 0$，故 $L$ 半正定
- 特征值 $0 = \lambda_1 \le \lambda_2 \le \cdots \le \lambda_n$
- $\lambda_2 > 0 \iff$ 图连通；$\lambda_2 = 0$ 的重数 = 连通分支数
- $\lambda_2$ 称为**代数连通度 (Algebraic Connectivity / Fiedler 值)**
- 对应特征向量 $v_2$ 称 **Fiedler 向量**，用于谱聚类/图划分
> **Cheeger 不等式：** $\frac{\lambda_2}{2} \le h(G) \le \sqrt{2\lambda_2}$，其中 $h(G)$ 为 Cheeger 常数（等周数）。将谱间隙和图的割结构联系起来
### 谱聚类算法
1. 构造 $L = D - A$
2. 计算 $\lambda_2$ 及 Fiedler 向量 $v_2$
3. 按 $v_2$ 分量符号（$>0$ / $<0$）二分顶点
4. 可递归进行多层次划分
> ⚠️ **归一化 Laplacian**（用于谱聚类）：$L_{sym} = D^{-1/2}LD^{-1/2}$ 或 $L_{rw} = D^{-1}L$。特征值范围 $[0, 2]$，取值更具可比性
### 图割 (Graph Cut)

| 类型 | 定义 | 问题 |
|---|---|---|
| **Min Cut** | $\min_{A,B} \text{cut}(A,B) = \sum_{i\in A,j\in B} w_{ij}$ | 倾向切孤立点 |
| **Ratio Cut** | $\min \frac{\text{cut}(A,B)}{\|A\|} + \frac{\text{cut}(A,B)}{\|B\|}$ | 平衡划分大小 |
| **Normalized Cut** | $\min \frac{\text{cut}(A,B)}{\text{vol}(A)} + \frac{\text{cut}(A,B)}{\text{vol}(B)}$，$\text{vol}(A) = \sum_{i\in A} d_i$ | 谱聚类目标 |

> [!tip] Normalized Cut 的连续松弛就是归一化 Laplacian 的 $\lambda_2$ 特征向量
## 七、图的连通性 (Connectivity)
### 顶点连通度 / 边连通度

| 概念 | 定义 |
|---|---|
| **点连通度 $\kappa(G)$** | 最小移除顶点数使图不连通或为平凡图 |
| **边连通度 $\lambda(G)$** | 最小移除边数使图不连通 |
| **Whitney 不等式** | $\kappa(G) \le \lambda(G) \le \delta(G)$ |
| **$k$-连通** | $\kappa(G) \ge k$，移除 $<k$ 个顶点仍连通 |
| **$k$-边连通** | $\lambda(G) \ge k$ |

> 直觉：破坏图连通性，最省力的是删顶点（≤ 删边 ≤ 最小度）
### Menger 定理 (Menger 1927)
**核心结论：** 图 $G$ 是 $k$-连通的 $\iff$ 任意两不同顶点间存在 $k$ 条**内部不交**的路
边版本：$k$-边连通 $\iff$ 任意两顶点间存在 $k$ 条**边不交**的路
> [!important] **Menger ⇒ Hall ⇒ König ⇒ 最大流最小割。** 这四个定理在理论上是等价的系列
### Whitney 定理 (1932)
$\kappa(G) \ge 2$（$G$ 是 2-连通图）$\iff$ $G$ 可被**圈覆盖**（任意两顶点在同一圈上）$\iff$ 无割点且 $n \ge 3$
> 2-连通图：连通、无割点、$n \ge 3$。等价于任意两顶点在同一圈上
## 知识点速查

| 主题 | 核心公式/结论 | 关键细节 |
|---|---|---|
| 握手引理 | $\sum \deg(v) = 2m$ | 奇度顶点偶数个 |
| 欧拉公式 | $v - e + f = 2$ | 连通平面图；$k$ 分支时 $v - e + f = 1 + k$ |
| 平面图边数上界 | $e \le 3v - 6$ | $v \ge 3$；无三角形时 $e \le 2v - 4$ |
| 树 | $m = n - 1$ | 连通无圈；Cayley: $\tau(K_n) = n^{n-2}$ |
| 匹配 | $\alpha'(G) = \beta(G)$ | König 定理（二分图） |
| Hall 定理 | $\|N(S)\| \ge \|S\|$ | 二分图完美匹配存在条件 |
| 色数下界 | $\chi \ge \omega$，$\chi \ge \lceil n/\alpha \rceil$ | 仅下界，非等式 |
| Brooks 定理 | $\chi \le \Delta$ | 排除奇圈和完全图 |
| Vizing 定理 | $\Delta \le \chi' \le \Delta + 1$ | 二分图 $\chi' = \Delta$ |
| Laplacian | $L = D - A$ | $\lambda_1=0$，$\lambda_2>0 \iff$ 连通 |
| 代数连通度 | $\lambda_2$ 为 Fiedler 值 | Cheeger: $\frac{\lambda_2}{2} \le h \le \sqrt{2\lambda_2}$ |
| Whitney | $\kappa \le \lambda \le \delta$ | 连通度三件套 |
| Menger | $k$-连通 $\iff$ $k$ 条内点不交路 | 图论核心定理之一 |

**核心思想总结：** 图论研究离散结构中"连接"性质的数学分支。四种基本对象——**树**（最小连通）、**匹配**（最大独立边集）、**平面嵌入**（无交叉画法）、**着色**（冲突避免）——通过**特征值/谱**（Laplacian）、**割/连通度**（Menger–Whitney）、**对偶性**（König, Kuratowski）
