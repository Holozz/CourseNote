## 一、问题描述

### 1.1 问题背景

航空公司需要为不同机型的飞机安排航班调度计划。给定一组航班数据（包含出发/到达机场、出发/到达时间、飞机型号），要求将相同机型的航班连接成航班环或航班串，使得全局总得分最大化。
### 1.2 计分规则
- 航班环（Ring）：起点机场与终点机场相同的闭合回路，长度 $L \ge 2$
	- 得分公式：$\text{score} = \min(L - 0.5,\ 5.5)$
- 航班串（String）：起点机场与终点机场不同的开放路径，长度 $L \ge 2$
	- 得分公式：$\text{score} = \min(L - 1.5,\ 4.5)$
- 单个航班（$L=1$）不计分；长度超过 6 的序列得分封顶
### 1.3 约束条件

1. 机型一致性：同一序列中所有航班必须为相同飞机型号
2. 时空连续性：后序航班的出发机场须等于前序航班的到达机场，且出发时间严格晚于到达时间
3. 航班唯一性：每个航班最多出现在一个序列中
4. 同日期：序列内的航班须在同一日历日内
## 二、算法设计

### 2.1 整体思路
问题可建模为有向无环图（DAG）上的最大权重路径覆盖问题：
- 顶点：每个航班
- 有向边 $i \to j$：航班 $j$ 可以接在航班 $i$ 之后（满足机型相同、机场衔接、时间先后）
- 目标：将顶点集划分为若干条点不相交的路径（航班串）和闭合路径（航班环），最大化总得分
由于评分函数对环有利（相同长度下环比串多 1 分），算法采用**环优先贪心**策略
### 2.2 图构建与存储
采用邻接表存储稀疏 DAG。对于每个机型分组：
1. 将航班按出发时间升序排列
2. 对每个航班 $i$，在到达机场相同的航班列表中二分查找出发时间晚于 $i$ 到达时间的航班
3. 将这些航班加入 `succ[i]`
```
空间复杂度：O(V + E)，适合稀疏图
时间复杂度：O(V log V + E)，其中 E 为有效衔接边数
```
### 2.3 环枚举（剪枝 DFS）
对每条航班边出发，用深度优先搜索（DFS）枚举所有长度 $2 \sim 6$ 的环。
剪枝策略：
1. 长度限制：深度不超过 6，避免在超长路径上浪费计算
2. 路径去重：使用 `set` 存储当前路径上的顶点，O(1) 判重（避免 `nxt in path` 的 O(L) 开销）
3. frozenset 去重：相同航班集合的环只保留一个
$$
\text{最坏时间复杂度：} O(V \cdot d^5)
$$

其中 $d$ 为平均出度。在本数据中 $d \approx 3\sim8$，按机型分组后 $V \approx 30\sim110$
### 2.4 环选择（多策略贪心 + 局部搜索）

枚举得到候选环集合 $\mathcal{R}$ 后，需选择一个互不相交的子集最大化总环得分。这是经典的最大权重独立集（MWIS）问题，在冲突图上为 NP-hard。
贪心近似：按不同排序规则贪心选取不冲突的环。

| 策略              | 排序规则        | 特点       |
| --------------- | ----------- | -------- |
| `longest`       | 长度降序 → 得分降序 | 优先长环     |
| `efficient`     | 得分/长度降序     | 优先单位航班收益 |
| `hybrid`        | 效率 − 冲突惩罚   | 平衡收益与冲突  |
| `random_greedy` | 随机打乱后按长度贪心  | 探索多样性    |

对每种机型尝试不同随机策略，保留得分最高的环集合
并且从最优环集合中随机移除 1-3 个环，释放其航班，从完整环枚举中重新贪心选择，若得分提高则接受。共 500 次迭代。
### 2.5 串提取（最长路径 DP + 最优切割）

环选择后，在剩余航班构成的 DAG 上运行最长路径 DP（无长度上限）：

```python
dp[i] = 1 + max{dp[j] : j ∈ succ[i], used[j] = False}
```

选择全局最长路径后，使用DP 最优切割将其切分为长度 $2 \sim 8$ 的段，每段自动判别为环（起点=终点）或串。重复提取直到无剩余。

切割 DP：令 `dp[i]` 表示前 $i$ 个航班的最优切割得分，枚举最后一段长度 $k \in [2, \min(8,i)]$：

$$
dp[i] = \max_{k}\{dp[i-k] + \text{score}(\text{seg}[i-k:i])\}
$$

### 2.6 后处理
1. 剩余配对：未使用航班尝试两两组队（L2 环优先，其次 L2 串）
2. 序列合并：若序列 A 的终点 = 序列 B 的起点且时间相容，合并为更长序列
3. 环转换：合并后若串的起点 = 终点，自动转换为环
4. 航班插入：将未使用航班尝试插入已有序列（前插、后插、内插）
5. 重复 2-4 直至稳定
### 2.7 算法流程图

```
输入：同机型航班列表（按出发时间排序）
  │
  ├─ 1. 建图：邻接表 succ[i] = {后续航班}
  │
  ├─ 2. 环枚举：DFS + 剪枝 → 所有 L2-L6 环
  │
  ├─ 3. 环选择：2000+ 随机贪心策略 → 最优环子集
  │         └─ 局部搜索 ×500：移除→重新枚举→贪心
  │
  ├─ 4. 串提取：最长路径 DP → DP 最优切割 → 重复
  │
  ├─ 5. 剩余配对 → 合并 → 环转换 → 插入（迭代至稳定）
  │
  └─ 输出：航班环/航班串列表
```

## 四、算法性能分析

### 4.1 时间复杂度

| 阶段    | 复杂度                            | 说明            |
| ----- | ------------------------------ | ------------- |
| 建图    | $O(V \log V)$                  | 二分查找后继        |
| 环枚举   | $O(V \cdot d^5)$               | DFS 深度 ≤ 6    |
| 环选择   | $O(S \cdot\mathcal{R}\cdot L)$ | S=策略数, L=平均环长 |
| 串提取   | $O(V + E)$                     | 最长路径 DP       |
| 切割 DP | $O(L \cdot K)$                 | K=最大段长(8)     |
| 后处理   | $O(N^2)$                       | N=序列数, 合并+插入  |

对于 8553 航班分 51 机型的情况，每个机型 $\approx 57$ 航班，整体运行时间约 **3 秒**，满足实时性要求

### 4.2 空间复杂度

- 邻接表：$O(V + E)$，实际 $E \approx 3 \sim 8 \times V$
- 环存储：$O(|\mathcal{R}|)$，每机型 $|\mathcal{R}| \approx 500 \sim 2000$
### 4.3 剪枝效果

在环枚举中，通过长度限制（深 ≤ 6）和 set 去重（O(1) 判重），将 DFS 的搜索空间从理论上 $O(d^{V-1})$ 限制到 $O(d^5)$。对于出度 5 的最坏情况，从指数级降至 $\sim 5^5 = 3125$ 路径/起始航班。

## 五、算法优化

### 5.1 环 vs 串

理论分析：环在相同长度下比串高 1.0 分。对于 L2 序列，环的单位航班收益（0.75/航班）是串（0.25/航班）的 3 倍。因此算法采用先环后串的贪心顺序。
实验验证：若去掉环优先（纯最长路径提取），Day 1 得分仅 1997.5（环优先为 2036.5），验证了环优先的正确性

### 5.2 多策略 vs 单策略

单策略（最长环优先）得分约 6057.5；多策略（2000 次随机 + 局部搜索）得分 6120.5，提升 +63 分（+1.0%）。多策略通过探索不同排序顺序下的贪心选择，避免了"最长环阻碍更优环组合"的陷阱

## 六、改进尝试与结论

### 6.1 尝试过的改进方向

| 改进方向     | 方法            | 效果                |
| -------- | ------------- | ----------------- |
| Swap ILS | 允许环替换冲突的保留序列  | 无提升（贪心已达最优）       |
| 可达性剪枝    | 预计算机场级可达性     | 无提升（DFS 本身已可控）    |
| 策略数翻倍    | 800→2000 随机策略 | 无提升               |
| 局部搜索增强   | 完整环枚举替代 DP 重建 | 无提升               |
| 航班插入     | 将剩余航班插入已有序列   | +0.5 分            |

### 6.2 结论

1. 环优先贪心 + 多策略 + 局部搜索 对于本数据规模已达近似最优。2000 策略和 500 次局部搜索均无法进一步显著提升，表明贪心策略在本题 DAG 结构上具有良好的近似比

2. 算法满足要求：邻接表存储（空间 O(V+E)）、DFS 剪枝，先环后串（充分利用环 3 倍于串的权重优势）

3. 最终得分 6120.5 在 8553 个航班上取得了 74.4% 环比例 和 92.5% 利用率，结构尚可
