## 二、简答题
### 1.请比较首次适应（First Fit）、最佳适应（Best Fit）和最差适应（Worst Fit）三种连续内存分配算法，并说明外部碎片与内存紧缩（Compaction）的关系
- 首次适应：从头开始寻找可以容纳的连续内存，一旦找到就立即分配之
- 最佳适应：从头到尾全部遍历一次，把符合条件的最小的连续内存分配之
- 最差适应：同上，但是是分配最大的
- 关系：当空闲内存总量足以满足请求，但不连续时，就无法分配，此时可以利用压缩，直接移动进程合并空闲区，或允许逻辑地址不连续

### 2. 请解释分页系统中的页（page）、页框（frame）、页表（page table）和页表项（PTE）。一次普通内存访问在没有 TLB 和有 TLB 的情况下分别需要哪些步骤？
- 页：把逻辑内存划分为一块块的区域，每一块就是页
- 页框：同上，但是是物理内存
- 页表：指示页的位置和大小的表
- 页表项：页表中的条目，具体给出了某一页的位置和大小信息
- 步骤
	- 没有TLB：
		1. CPU生成逻辑地址
		2. 访问内存中的页表
		3. 将页框号和页内偏移结合形成物理地址
		4.  根据物理地址读写目标
	- 有TLB：
		1. CPU生成逻辑地址
		2. 查找TLB
			1. 命中：直接获得物理页框号，得到物理地址，访问之
			2. 去访问内存中的页表，也就是从没有TLB情况的步骤2继续

###  3.  什么是请求分页？请描述从 CPU 访问一个不在内存中的页面开始，到该指令重新执行为止，操作系统处理缺页异常的大致流程。
- 请求分页：不在进程加载时就将其全放入内存，而是实际需要访问的时候才调入
- 流程：
	1. 查页表，发现有效位为i
	2. 检查访问是否合法，没有无效地址或者越界
	3. 触发缺页中断，操作系统接管
	4. 找到一个空闲帧
	5. 将目标页读入
	6. 将帧号填入页表
	7. 重启指令
	8. 正常访问
## 三、分析题
### 1. 某分页系统页面大小为 1KB，页表如下。页号为逻辑地址除以页面大小的商，页内偏移为余数。

| **页号** | **有效位** | **页框号** |
| ------ | ------- | ------- |
| **0**  | 1       | 5       |
| **1**  | 1       | 9       |
| **2**  | 0       | -       |
| **3**  | 1       | 2       |
| **4**  | 1       | 11      |
| **5**  | 0       | -       |
1. 分别将逻辑地址 100、1350、3220、5200 转换为物理地址；若发生缺页异常，请指出
	由于偏移是余数，所以页面大小应该是除数，也就是1KB
	- 100：页号为100/1KB = 0 余 100，页框为5，物理地址：5\*1KB + 100 = 5100
	- 1350：页号为1350/1KB = 1 余 350，页框9，物理地址：9\*1K + 250 =9350
	- 3220：页号3，页框就是2，物理地址：2\*1K + 220 = 2220
	- 5200：页号5，有效位为0，发生缺页异常
2. 若访问内存一次需要 100ns，TLB 查询需要 10ns，TLB 命中率为 80%，忽略缺页异常开销，计算有效访问时间（Effective Access Time）
	由$$EAT = \alpha \cdot (m + \tau) + (1 - \alpha) \cdot (2m + \tau)$$得$EAT=80\%(10ms+100ms)+(1-80\%)(2*100ms+10ms)=290ms$
3. 如果页表项中增加保护位和修改位，它们分别可以用于什么目的？
	- 保护位：
		作为读写权限位，区分只读数据和可写数据；或者作为有效位，区分是否在进程地址空间内
	- 修改位：区分内容是否被修改过
