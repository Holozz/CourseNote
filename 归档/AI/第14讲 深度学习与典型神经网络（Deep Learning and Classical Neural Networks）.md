## 一、前情回顾：神经网络基础

### 1.1 神经元与神经网络结构

一个神经元的数学表达：

$$y = \sigma(z) = \sigma(W \cdot x + b)$$

其中 $W$ 是权重矩阵，$b$ 是偏置，$\sigma$ 是激活函数（如 Sigmoid）。

**神经网络参数 = 权重（weights）$W$ + 偏置（biases）$b$**

### 1.2 神经网络的整体矩阵表达

对于 $L$ 层的神经网络，各层逐层计算：

$$\mathbf{a}^1 = \sigma(\mathbf{W}^1 \mathbf{x} + \mathbf{b}^1)$$ $$\mathbf{a}^2 = \sigma(\mathbf{W}^2 \mathbf{a}^1 + \mathbf{b}^2)$$ $$\vdots$$ $$\mathbf{y} = \sigma(\mathbf{W}^L \mathbf{a}^{L-1} + \mathbf{b}^L)$$

整体写成复合函数形式：

$$\mathbf{y} = f(\mathbf{x}) = \sigma\bigl(\mathbf{W}^L \cdots \sigma\bigl(\mathbf{W}^2 \sigma(\mathbf{W}^1 \mathbf{x} + \mathbf{b}^1) + \mathbf{b}^2\bigr) \cdots + \mathbf{b}^L\bigr)$$

> [!tip] 计算加速 实际训练时使用**并行计算技术（GPU）**来加速上述矩阵运算，这是深度学习能够处理大规模数据的关键基础设施。
### 1.3 神经网络的两种理解视角

**函数视角**：神经网络就是一个函数，输入一个向量，输出另一个向量。**网络结构（层数、节点数、激活函数）相当于定义了函数的搜索空间**，训练就是在这个空间里找最优函数。

**功能视角**：从功能角度来看，神经网络 = **多层特征提取（隐藏层）+ 线性分类器（输出层 + Softmax）**。隐藏层自动完成了传统机器学习中需要手工设计的特征工程，这是深度学习强大的根本原因之一。

## 二、深度学习概念与分类

### 2.1 "深度"的含义

**深度 = 非常多的隐藏层**。不是简单堆叠，而是需要**特殊结构**来使训练有效。

|模型|年份|层数|ImageNet 错误率|
|---|---|---|---|
|AlexNet|2012|8层|16.4%|
|VGG|2014|19层|7.3%|
|GoogleNet|2014|22层|6.7%|
|ResNet|2015|152层|**3.57%**|

> [!warning] 深度学习 ≠ 单纯堆叠层数 层数增加会加剧**梯度消失问题**（每层梯度 ≤ 0.25 倍衰减）。ResNet 提出**残差连接（跨层直连）**才使得 152 层的超深网络得以有效训练。
> 
> 结论：**深度学习 = 深层网络 + 特殊结构设计**

### 2.2 深度学习按数据类型分类

**视觉数据**：CNN（卷积神经网络）、ResNet、DenseNet……

**文本/序列数据**：RNN、LSTM、Transformer、BERT、ChatGPT……

**其他数据**：AlphaFold（蛋白质结构预测，2024 年诺贝尔化学奖）……

### 2.3 深度学习奠基人（2018 图灵奖）

- **Yann LeCun**：独立发现并改进反向传播算法，提出卷积神经网络（CNN）
- **Geoffrey Hinton**：反向传播算法和玻尔兹曼机提出者，**2024 年诺贝尔物理学奖**获得者
- **Yoshua Bengio**：自然语言处理、注意力机制、生成式模型的先驱

## 三、卷积神经网络（CNN）

### 3.1 为什么需要 CNN？
用 MLP 直接处理图像存在两个致命问题：
**问题一：参数量庞大**。一张 224×224×3 的彩色图片展开成向量就有 150528 维，全连接层参数量爆炸
**问题二：忽略图片的结构特性**。像素间存在空间相关性（相邻像素更相关），MLP 把所有像素一视同仁，破坏了这种结构
**解决方案**：卷积神经网络（CNN），基于**人类视觉机理**来设计
### 3.2 人类视觉机理的三个关键性质

> [!important] CNN 设计的生物学依据

**① 局部特征影响大（Local Receptive Field）**
人识别鸟，看到鸟嘴、羽毛等局部区域即可判断，不需要看完整张图。**一些关键特征只占图片的很小一块区域**
→ CNN 的卷积核只覆盖一个小的局部区域（如 $3\times3$），而非全图

**② 重要位置常变化（Spatial Invariance）**
同一张图里，鸟嘴可能在左上角，也可能在中间，是**相同特征出现在不同位置**。应该用相同的检测器来检测，而不是为每个位置训练独立的权重
→ CNN 使用**权重共享（Weight Sharing）**：同一卷积核在图上滑动，同一组权重检测所有位置

**③ 采样压缩也没差（Subsampling）**
对图片进行下采样（降低分辨率）不会改变识别对象的关键信息。
→ CNN 使用**池化（Pooling）** 操作压缩特征图

### 3.3 卷积核运算（重点、难点）
#### 卷积核是什么？
卷积核（Filter/Kernel）是一个**小的权重矩阵**，尺寸通常为 $f \times f$（如 $3\times3$），它的参数是**需要学习的网络参数**
它对输入图像的**局部区域**做加权求和，得到一个标量输出，表示该区域对这个卷积核所代表特征的"匹配程度"
#### 卷积操作的计算方式
将卷积核逐步滑动过输入图像，每次计算**对应位置元素乘积之和**（即内积）：
**示例**（输入 $3\times3$，卷积核 $2\times2$，步长 $s=1$）：
```
输入:           卷积核:
1  2  3         0  1
4  5  6    *    2  3
7  8  9

第(1,1)位置: 0×1 + 1×2 + 2×4 + 3×5 = 25
第(1,2)位置: 0×2 + 1×3 + 2×5 + 3×6 = 31
第(2,1)位置: 0×4 + 1×5 + 2×7 + 3×8 = 43
第(2,2)位置: 0×5 + 1×6 + 2×8 + 3×9 = 49

输出特征图:
25  31
43  49
```
#### 特征图维度公式（重要！）
> [!note] 必须掌握的公式

设输入图片尺寸为 $n_h \times n_w$（高×宽），卷积核尺寸为 $f \times f$，步长为 $s$，填充（Padding）为 $p$，则输出**特征图**尺寸为：
$$h = \left\lfloor \frac{n_h - f + 2p}{s} + 1 \right\rfloor, \quad w = \left\lfloor \frac{n_w - f + 2p}{s} + 1 \right\rfloor$$
**参数说明：**
- $f$（Filter Size）：卷积核大小，越大感受野越大
- $s$（Stride）：步长，越大特征图越小
- $p$（Padding）：在输入边缘填充 0，可控制输出尺寸
**例子验证**：$6\times6$ 输入，$3\times3$ 卷积核，$s=1$，$p=0$： $$h = \frac{6 - 3 + 0}{1} + 1 = 4 \quad \Rightarrow \text{输出为 } 4\times4$$
**步长 $s=2$ 时**：$h = \frac{6 - 3}{2} + 1 = 2.5 \to \lfloor 2.5 \rfloor = 2$，输出为 $2\times2$
> [!warning] 易错点 步长不能整除时要**向下取整**，而不是四舍五入！

#### 彩色图像（多通道）的卷积
彩色 RGB 图片有 3 个通道，卷积核的深度必须与输入通道数匹配：

|参数|说明|
|---|---|
|输入|$n_h \times n_w \times n_c$（高×宽×通道数）|
|卷积核|$f \times f \times n_c$（必须与输入通道数相同）|
|输出（1个核）|$h \times w \times 1$（单层特征图）|
|输出（$K$个核）|$h \times w \times K$（$K$ 层特征图，深度 = 卷积核数量）|

**记忆关键**：$K$ 个卷积核 → 输出深度为 $K$，每个核负责检测一种局部特征模式
### 3.4 完整卷积层的结构
一个完整卷积层 = **卷积操作 + 偏置 + 激活函数（ReLU）**：
```
输入 → [卷积核1, 卷积核2, ...] → 特征图堆叠 → ReLU → + 偏置 → 输出特征图
```

>[!IMPORTANT] 参数量的计算
> - 卷积层：
>	- 参数量=$(K_{h}​K​_{w}C_{in}​+Bias)C_{out}​$
>	-  **Kh,Kw​**：卷积核的高和宽（比如 3x3）。
>	- **Cin​**：输入通道数（上一层输出的深度）
>	- **Cout​**：输出通道数，也就是本层的卷积核个数
>	- Bias:1 or 0
> - 全连接层（Linear / Dense）
> 	- 参数量=$(输入特征数+1)×输出特征数参数量$
> - 池化和激活层不算参数量
### 3.5 池化（Pooling）
池化是对特征图进行**下采样**，压缩尺寸、减少参数
**最大池化（Max Pooling）**：对每个区域取**最大值**。
```
特征图（4×4）经 2×2 Max Pooling（步长2）→ 2×2

3  -1 | -3  -1          3    0
-3   1 |  0  -3   →    -3    1
--------+--------
-3  -3 |  0   1
 3  -2 | -2  -1
```
**池化的好处**：
- 减少特征图尺寸，减少后续层的参数量
- 对小幅平移具有一定的**位置不变性**（平移几个像素，最大值不变）
- 降低过拟合风险

### 3.6 CNN 完整架构

```
原始图像
    ↓
[卷积层 → ReLU → 最大池化] × 多次   ← 特征提取
    ↓
展开（Flatten）为向量
    ↓
全连接层（MLP）+ Softmax             ← 分类器
    ↓
类别概率输出
```

层数越深，能提取的特征越抽象：浅层学边缘/纹理，深层学形状/语义。

### 3.7 CNN vs ANN（全连接网络）的参数量对比
**以 ANN 的视角理解 CNN 的好处**：
CNN 等价于一个对权重做了两种约束的特殊 ANN：
- **稀疏连接（Sparse Connectivity）**：每个神经元只连接输入的一小块（$f\times f$）区域，而不是全部输入
- **权重共享（Weight Sharing）**：同一个卷积核在不同位置使用**同一组权重**
这两点使得 CNN 的参数量**远少于**同等规模的全连接网络，同时利用了图像的空间结构特性
> [!example] 数量级对比 一张 $224\times224\times3$ 图片，第一个全连接层设 1000 个神经元：
> 
> - ANN 参数量：$224\times224\times3\times1000 \approx 1.5 \times 10^8$
> - CNN（64个 $3\times3\times3$ 卷积核）参数量：$3\times3\times3\times64 = 1728$
> 
> 参数量相差约 **8 万倍**！


## 四、循环神经网络（RNN）

### 4.1 为什么需要 RNN？
处理**序列数据**（文本、语音、时间序列）时，MLP 存在根本缺陷：它**没有记忆功能**，每次输入被独立处理，无法考虑上下文

例子——订票系统槽位填充：
```
"I would like to arrive Guangzhou on May 31th."
```
想把 "Guangzhou" 填入「目的地」槽，把 "May 31th" 填入「到达时间」槽
问题：同样是 "Guangzhou"，在以下两句话中含义不同：
- "arrive Guangzhou" → Guangzhou 是**目的地**
- "leave Guangzhou" → Guangzhou 是**出发地**
MLP 只看单词本身，**看不到 "arrive" 或 "leave"** 这个上文，所以无法正确分类。

**结论：需要网络具备"记忆"功能，能利用历史上下文。**
### 4.2 词的向量表示：One-hot Encoding
在将文本输入神经网络前，需要将单词转为向量
**One-hot 编码**：给定词典大小为 $N$，每个单词用一个长度为 $N$ 的向量表示，该单词对应位置为 1，其余为 0
```
词典 = {apple, bag, cat, dog, elephant}

apple    = [1, 0, 0, 0, 0]
bag      = [0, 1, 0, 0, 0]
cat      = [0, 0, 1, 0, 0]
dog      = [0, 0, 0, 1, 0]
elephant = [0, 0, 0, 0, 1]
```

> [!warning] One-hot 的局限性 向量维度 = 词典大小（实际可达数万到数十万），且任意两个词向量的余弦相似度均为 0，**无法表示词义的相似性**（如 "cat" 和 "dog" 语义相近，但向量正交）。 改进方案：词嵌入（Word Embedding），如 Word2Vec、GloVe。

### 4.3 RNN 的核心思想：记忆机制
RNN 在普通神经网络的基础上增加了一个**记忆单元（Memory）**，存储隐藏层的输出，并将其作为下一时间步的**额外输入**

**核心机制**：
- **Store（存储）**：当前时间步的隐藏层输出 $a^t$ 存入记忆
- **Remember（调取）**：下一时间步处理时，将记忆中的 $a^t$ 作为额外输入
```
             y¹          y²          y³
              ↑            ↑            ↑
 x¹ → [RNN] → a¹ → [RNN] → a² → [RNN] → a³ → ...
        ↓store   ↑remember  ↓store  ↑remember
       [a¹]  ——→              [a²] ——→
```
**相同的网络结构（同一组权重 $W, U, V$）在每个时间步重复使用**，这就是"循环"的含义

### 4.4 RNN 的前向传播公式
$$s_t = \tanh(U x_t + W s_{t-1})$$ $$\hat{y}_t = \text{softmax}(V s_t)$$
其中：
- $x_t$：$t$ 时刻的输入
- $s_t$：$t$ 时刻的隐藏状态（"记忆"）
- $s_{t-1}$：上一时刻的隐藏状态
- $\hat{y}_t$：$t$ 时刻的输出（如各类别的概率分布）
- $U, W, V$：**所有时间步共享的权重矩阵**（这是参数量小的关键）

**损失函数**（所有时间步的误差之和）：

$$E(y, \hat{y}) = -\sum_t E_t(y_t, \hat{y}_t)$$

> [!tip] 输入顺序很重要！ 改变输入序列的顺序会对 RNN 的输出产生影响——这正是 RNN 的设计目标，利用时序关系。

### 4.5 RNN 的训练：BPTT 算法

RNN 使用**随时间反向传播（Backpropagation Through Time，BPTT）** 算法

由于 $s_3$ 依赖 $s_2$，$s_2$ 依赖 $s_1$，……，链式法则需要**跨越多个时间步**反向传播梯度：

$$\frac{\partial E_3}{\partial W} = \sum_{k=0}^{3} \frac{\partial E_3}{\partial \hat{y}_3} \cdot \frac{\partial \hat{y}_3}{\partial s_3} \cdot \left(\prod_{j=k+1}^{3} \frac{\partial s_j}{\partial s_{j-1}}\right) \cdot \frac{\partial s_k}{\partial W}$$

### 4.6 RNN 的梯度消失问题

> [!warning] RNN 的致命弱点：无法学习长距离依赖

**问题原因**（数学推导）：

每次相邻隐藏状态之间的偏导 $\frac{\partial s_j}{\partial s_{j-1}}$ 是一个**雅可比矩阵（Jacobian Matrix）**。

由于 tanh 的导数最大值为 1，该雅可比矩阵的 2-范数上界 $\leq 1$

连乘多个 $\leq 1$ 的矩阵 → 梯度**指数级缩小** → **远处时间步的梯度变成 0**，网络学不到长距离依赖。

**另一面**：如果权重矩阵的范数 $> 1$，则梯度会**指数级爆炸（Gradient Explosion）**，训练发散。

**解决梯度爆炸的技巧：梯度裁剪（Gradient Clipping）** — 当梯度超过阈值时，将其截断。

**根本解决方案：LSTM（长短期记忆网络）**，通过门控机制缓解梯度消失。

### 4.7 RNN 的误差表面

RNN 的误差表面**极不规则**（非凸），通常**相当平坦（梯度消失区域）或相当陡峭（梯度爆炸悬崖）**。这导致训练不稳定，损失曲线可能剧烈震荡。

## 五、长短期记忆网络（LSTM）

### 5.1 RNN vs LSTM 的直觉理解

|      | 经典 RNN       | LSTM                              |
| ---- | ------------ | --------------------------------- |
| 记忆类型 | 只有"工作记忆"（短期） | 工作记忆 + **长期记忆（Long-term Memory）** |
| 类比   | 忘不了却学不会新的    | 可以主动遗忘旧信息、记住新信息                   |

### 5.2 LSTM 的结构：三个门 + 一个记忆单元

LSTM 是一种**特殊神经元**，有 **4 个输入，1 个输出**。

核心组件：

|组件|符号|作用|
|---|---|---|
|**记忆单元（Memory Cell）**|$c$|存储长期记忆（cell state）|
|**输入门（Input Gate）**|$z_i$|控制有多少新信息写入记忆|
|**遗忘门（Forget Gate）**|$z_f$|控制保留多少旧记忆|
|**输出门（Output Gate）**|$z_o$|控制从记忆中读出多少信息作为输出|

> [!note] 门控机制的原理 所有门都使用 **Sigmoid 激活函数**，输出值在 $[0, 1]$ 之间，用于**模拟开关**：
> 
> - 接近 0 → 门关闭（阻断信息）
> - 接近 1 → 门打开（允许信息通过）
> 
> 通过乘法（multiply）实现软性的"开/关"控制。

### 5.3 LSTM 的计算公式

**记忆单元更新（核心公式）**：
$$c' = g(z) \cdot f(z_i) + c \cdot f(z_f)$$

- $g(z)$：新的候选值（当前输入经过 tanh）
- $f(z_i)$：输入门权重（决定写多少新值进来）
- $c$：旧的记忆单元值
- $f(z_f)$：遗忘门权重（决定保留多少旧记忆）

**输出计算**：

$$a = h(c') \cdot f(z_o)$$
- $h(c')$：对更新后记忆施加 tanh 激活
- $f(z_o)$：输出门权重（决定输出多少）

**LSTM 为何能缓解梯度消失**：记忆单元 $c$ 通过**加法**更新（而非 RNN 的乘法），梯度可以通过加法路径直接流动，不必经过多次矩阵乘法 —— 这类似 ResNet 的残差连接思路。

### 5.4 LSTM 示例演算

**任务规则**：

- 当 $x_2 = 1$：把 $x_1$ 的值**累加**到记忆中
- 当 $x_2 = -1$：**重置**记忆（遗忘）
- 当 $x_3 = 1$：**输出**记忆的值

**输入序列**：

|时间步|$x_1$|$x_2$|$x_3$|记忆 $c$|输出 $y$|
|---|---|---|---|---|---|
|1|1|0|0|0|0|
|2|3|1|0|0+3=3|0|
|3|4|1|0|3+4=7|0|
|4|2|0|0|7|0|
|5|1|0|1|7|**7** ← 输出！|
|6|3|-1|0|0|0|
|7|6|1|0|0+6=6|0|
|8|1|0|1|6|**6** ← 输出！|

### 5.5 LSTM 的参数量

LSTM 用原来的神经元**替换**标准 RNN 中的隐藏层，每个 LSTM 单元需要 4 组权重（对应 $z, z_i, z_f, z_o$ 四个向量），因此**参数量是普通 RNN 的 4 倍**。

### 5.6 LSTM 的训练：BPTT

LSTM 同样使用 BPTT 算法：

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

由于记忆单元通过加法更新，梯度能更好地在时间方向流动，从而能学习更长距离的依赖关系。但训练仍然不总是容易，误差表面依然粗糙。

## 六、深度学习的可解释性

### 6.1 为什么需要可解释性？

深度神经网络是"黑盒"——能给出结果，但无法解释原因。这在以下场景中是重大问题：

- **招聘简历审核**：机器根据能力判断？还是无意中学到了性别偏见？
- **司法假释判断**：基于具体犯罪证据？还是学到了肤色偏见？
- **金融贷款决策**：法律要求提供拒贷理由
- **模型诊断**：不能只看准确率，需要确认模型学到了正确的模式（"神马汉斯"的故事）

> [!info] 神马汉斯（Clever Hans）的启示 19世纪末，一匹马"汉斯"被认为会做算术，但实验发现它其实是在观察训练师无意识的身体语言来猜答案。深度模型也可能学到"捷径"而非真正的规律。

### 6.2 可解释性的目标

> [!important] 正确理解可解释性
> 
> 可解释性的目标 **≠** 完全搞清楚模型的工作原理（人脑也是黑盒！）
> 
> 真正的目标：
> 
> - **让人觉得"舒坦"**（Make people comfortable）：用户、老板、监管者都能接受
> - **让机器变得"可控"**（Make machine controllable）：知道哪里出错，才能改进

**可解释性 vs 功能强大的权衡**：

|模型类型|可解释性|功能|
|---|---|---|
|线性模型|✅ 高（权重即重要性）|❌ 弱|
|决策树|✅ 较高|❌ 中等|
|深度神经网络|❌ 低（黑盒）|✅ 强大|

正确做法：**不是因为深度网络是黑盒就放弃它**（削足适履），而是研究如何让深度网络变得可解释。

### 6.3 局部解释（Local Explanation）

**问题：为什么你认为这张图片是猫？**

**基本思路**：将输入 $x$ 分解为若干部分 ${x_1, \ldots, x_n, \ldots, x_N}$（图像：像素/区域；文本：单词），逐一移除或修改某部分，观察模型决策是否变化：

- **变化大** → 该部分对决策**很重要**
- **变化小** → 该部分对决策不重要

**数学化**：计算输出类别概率 $y_k$ 对输入第 $n$ 个分量的偏导数：

$$\left|\frac{\partial y_k}{\partial x_n}\right|$$

绝对值越大，说明该位置的像素对分类结果的影响越大，将其可视化为**显著性图（Saliency Map / 特征图）**，高亮区域就是"模型看到的关键区域"。

### 6.4 全局解释（Global Explanation）

**问题：你认为"猫"应该是什么样子？**

思路：找出让模型对某个类别给出最高置信度的**理想输入**：

$$x^* = \arg\max_x y_i$$

但直接在像素空间优化会产生人眼看不懂的噪声图像（"对抗样本"问题）。

**改进方案（Generator 约束）**：先用 GAN 或 VAE 训练一个图像生成器 $G$，再在**低维隐变量空间** $z$ 中优化：

$$z^* = \arg\max_z y_i, \quad x^* = G(z^*)$$

由于 $z$ 被约束在"合理图像"的流形上，生成的 $x^*$ 更接近人类可识别的图像。

## 七、例题精讲

### 例题 1：卷积核计算（基础）⭐

**题目**：输入图像为 $3\times3$，卷积核 $2\times2$，步长 $s=1$，无填充，计算完整特征图。

$$\text{输入} = \begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}, \quad \text{卷积核} = \begin{pmatrix}0&1\\2&3\end{pmatrix}$$

**解答**：

输出特征图尺寸：$h = \frac{3-2}{1}+1 = 2$，即 $2\times2$。

$(1,1)$：$0\cdot1+1\cdot2+2\cdot4+3\cdot5 = 0+2+8+15 = 25$

$(1,2)$：$0\cdot2+1\cdot3+2\cdot5+3\cdot6 = 0+3+10+18 = 31$

$(2,1)$：$0\cdot4+1\cdot5+2\cdot7+3\cdot8 = 0+5+14+24 = 43$

$(2,2)$：$0\cdot5+1\cdot6+2\cdot8+3\cdot9 = 0+6+16+27 = 49$

$$\text{特征图} = \begin{pmatrix}25&31\\43&49\end{pmatrix}$$
### 例题 2：特征图维度计算 ⭐⭐

**题目**：输入图像为 $8\times8\times3$（RGB 彩色图），使用 **4 个** $3\times3\times3$ 卷积核，步长 $s=1$，无填充（$p=0$）。求输出特征图的维度。

**解答**：

$$h = \frac{8-3+0}{1}+1 = 6$$ $$w = \frac{8-3+0}{1}+1 = 6$$ $$\text{深度} = K = 4$$

**输出特征图维度：$6\times6\times4$**

参数量计算：每个卷积核有 $3\times3\times3=27$ 个权重，4 个核共 $27\times4=108$ 个权重参数（远少于全连接的 $8\times8\times3\times6\times6\times4=27648$）。

---

### 例题 3：加 Padding 的特征图尺寸 ⭐⭐

**题目**：输入 $6\times6$，卷积核 $3\times3$，步长 $s=2$，填充 $p=1$，求输出尺寸。

**解答**：

$$h = \left\lfloor \frac{6-3+2\times1}{2}+1 \right\rfloor = \left\lfloor \frac{5}{2}+1 \right\rfloor = \left\lfloor 3.5 \right\rfloor = 3$$

**输出尺寸：$3\times3$**

> [!warning] 易错点 步长为 2 时 $\frac{5}{2}=2.5$，需**向下取整**为 2，再加 1 得 3。

---

### 例题 4：Max Pooling 计算 ⭐

**题目**：对如下 $4\times4$ 特征图做 $2\times2$ Max Pooling（步长 2）：

$$\begin{pmatrix}3&-1&-3&-1\-3&1&0&-3\-3&-3&0&1\3&-2&-2&-1\end{pmatrix}$$

**解答**：

将特征图分成 4 个 $2\times2$ 区域，各取最大值：

- 左上 ${3,-1,-3,1}$ → **3**
- 右上 ${-3,-1,0,-3}$ → **0**
- 左下 ${-3,-3,3,-2}$ → **3**
- 右下 ${0,1,-2,-1}$ → **1**

$$\text{池化输出} = \begin{pmatrix}3&0\3&1\end{pmatrix}$$

### 例题 5：RNN 前向传播数值计算 ⭐⭐
**题目**：RNN 只有一个隐藏节点，所有权重为 1，无偏置，激活函数为线性（$f(x)=x$），初始记忆 $s_0=0$
输入序列：$x_1=\binom{1}{1}, x_2=\binom{1}{1}, x_3=\binom{2}{2}$
求每步的输出 $y_1, y_2, y_3$（设 $y_t = s_t$，权重 $V=1$）。

**解答**：
公式：$s_t = U x_t + W s_{t-1}$（权重均为 1 的简化版）
每个节点接受 $x_t$ 的两个分量和前一步两个记忆分量：
**$t=1$**：$s_1 = 1\cdot x_{1,1} + 1\cdot x_{1,2} + 1\cdot s_{0,1} + 1\cdot s_{0,2} = 1+1+0+0 = 2$，$y_1 = \binom{4}{4}$（两节点对称，$4$）
**$t=2$**：每节点 $= 1+1+2+2 = 6$，$y_2 = \binom{12}{12}$
**$t=3$**：每节点 $= 2+2+6+6 = 16$，$y_3 = \binom{32}{32}$
> [!note] 关键结论 改变输入序列的顺序会产生不同的输出 —— RNN 对时序信息是敏感的。

### 例题 6：LSTM 门控行为分析 ⭐⭐⭐

**题目**：按照课件中的 LSTM 示例，给定如下某时刻输入 $(x_1, x_2, x_3) = (3, 1, 0)$，当前记忆 $c=0$，LSTM 的权重设置使得：当 $x_2=1$ 时输入门 $f(z_i)\approx 1$，遗忘门 $f(z_f)\approx 1$，输出门 $f(z_o)\approx 0$
请分析该时刻的记忆更新过程和输出。
**解答**：
**记忆更新**：
$$c' = g(z) \cdot f(z_i) + c \cdot f(z_f)$$ $$= 3 \times 1 + 0 \times 1 = 3$$
记忆从 0 更新为 3（$x_1=3$ 被写入记忆）。
**输出**：

$$a = h(c') \cdot f(z_o) = h(3) \times 0 \approx 0$$

输出为 0（输出门关闭，虽然记忆已更新，但不对外输出）。

**总结**：该时刻完成了"写入记忆但不输出"的操作，体现了 LSTM 可以独立控制"学习"和"输出"的灵活性。

### 例题 7：卷积 vs 全连接的参数量对比 ⭐⭐

**题目**：一张 $32\times32$ 灰度图（1通道），分别用：

- 方案 A：展开成 1024 维向量，全连接到 64 个神经元
- 方案 B：用 64 个 $5\times5\times1$ 卷积核，步长 $s=1$，无填充

分别计算两方案的参数量，并说明哪种更适合图像处理。

**解答**：

**方案 A（全连接）**：

参数量 = $1024 \times 64 = 65536$

**方案 B（卷积）**：

每个卷积核参数量 = $5\times5\times1 = 25$，64 个核共 $25 \times 64 = 1600$（不含偏置）

输出特征图：$h = \frac{32-5}{1}+1 = 28$，即 $28\times28\times64$

**比较**：卷积层参数量（1600）**仅为全连接（65536）的 $\approx 2.4\%$**，节省了约 40 倍。

**优势**：

- 参数量大幅减少，减轻过拟合风险
- 权重共享使卷积核可以检测图片**任意位置**的相同特征
- 保留了空间结构信息

**结论**：卷积层更适合图像处理。

### 例题 8：可解释性方法分析 ⭐⭐

**题目**：某 CNN 模型将一张图片分类为"猫"。现在想了解模型主要关注图片的哪个区域做出了这个决定，描述一种可行的局部解释方法，并写出其数学表达。

**解答**：

使用**梯度显著性图（Gradient Saliency Map）** 方法：

**步骤**：

1. 前向传播，计算模型对"猫"类别的输出概率 $y_{\text{cat}}$
2. 对每个像素 $x_n$ 计算偏导数：$\left|\frac{\partial y_{\text{cat}}}{\partial x_n}\right|$
3. 将所有像素的偏导绝对值可视化为热力图

**含义**：偏导越大，说明该像素的微小变化对"猫"这个分类的影响越大，即该像素**对分类贡献越重要**。

**热力图中亮区（高梯度区）** = 模型认为对判断是猫最关键的区域（如猫的耳朵、鼻子区域）。

若热力图高亮的是背景（草地、树等），而非猫本身，说明模型学到的是背景特征的"捷径"，存在泛化风险——这正是可解释性的价值所在。

## 📌 本讲重点总结

> [!summary] 核心知识点速览
> 
> **CNN**：为图像设计的网络，核心是卷积（局部连接+权重共享）+池化（下采样）；特征图尺寸公式 $h = \lfloor(n_h-f+2p)/s+1\rfloor$；比 ANN 参数更少且利用空间结构
> 
> **RNN**：为序列设计，通过记忆隐藏状态实现"上下文记忆"；用 BPTT 训练；核心缺陷是梯度消失，无法学习长距离依赖
> 
> **LSTM**：用三个门（输入/遗忘/输出）+记忆单元解决 RNN 的梯度消失问题；记忆单元通过加法更新，梯度畅通；参数量是 RNN 的 4 倍
> 
> **可解释性**：Local Explanation（用梯度显著性图解释单次决策）；Global Explanation（用 $\arg\max_x y_i$ 可视化模型"心目中"的类别原型）；目标是让模型可控、让人放心

## ❗ 易错点与难点提示

> [!warning] 常见错误
> 
> 1. **特征图尺寸计算忘记 Padding**：加了 padding 后公式变为 $(n-f+2p)/s+1$，忘记 $2p$ 是常见错误
> 2. **步长不整除时忘记取整**：结果要**向下取整**（floor），不是四舍五入
> 3. **多通道卷积**：卷积核深度必须等于**输入通道数** $n_c$，不是卷积核数量 $K$；输出深度才等于 $K$
> 4. **RNN 权重共享**：$U, W, V$ 在所有时间步**共享**，不是每步独立的权重
> 5. **LSTM 遗忘门为 1 时**：$f(z_f)\approx1$ 意味着**完全保留**旧记忆（不遗忘），为 0 才是遗忘——名字容易引发反直觉
> 6. **RNN 的梯度消失方向**：梯度在**时间方向**消失（沿序列向早期时间步传播时衰减），不是空间方向
> 7. **深度学习 ≠ 堆叠层数**：层数多不代表效果好，需要特殊结构（残差连接等）才能训练超深网络
