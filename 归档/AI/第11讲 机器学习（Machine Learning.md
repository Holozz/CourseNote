# 一、为什么需要机器学习

## 1.1 传统符号主义 AI 的局限

传统 AI：
- 人工编写规则
- 基于逻辑推理
- 适合规则明确的问题

例如：
- “刘备的义弟是关羽”
- “关羽的义弟是张飞”

可以推理：
- “刘备和张飞是义兄弟”
这种方式本质是：

```text
知识库 + 推理规则
```

问题在于：
现实世界通常：
- 数据量巨大
- 规则不完整
- 情况动态变化
- 人类自己都说不清规则
例如：
- 图像识别
- 自动驾驶
- 语音生成
- 推荐系统
人根本无法穷举规则。
因此：
> 不能再“人工写规则”，而是让机器“从数据中自动学习规则”。
# 二、机器学习的本质

## 2.1 机器学习定义

Arthur Samuel（1959）：

> 机器学习是让计算机在不显式编程的情况下获得学习能力。

Tom Mitchell 定义：

> 如果一个程序在任务 T 上，  
> 随着经验 E 增加，  
> 性能 P 提高，  
> 则认为该程序具有学习能力。
# 三、机器学习核心思想

## 3.1 本质：寻找函数映射

机器学习本质：
> 从数据中自动寻找一个函数：
```text
y = f(x)
```
其中：

|符号|含义|
|---|---|
|x|输入|
|y|输出|
|f|模型（函数）|

## 3.2 举例理解

### 例1：垃圾邮件识别

输入：
```text
"恭喜中奖，请点击链接"
```
输出：
```text
spam
```
即：
```text
f(email) = spam
```
### 例2：房价预测
输入：
- 面积
- 地段
- 楼层
输出：
- 房价
即：
```text
f(房屋特征)=价格
```
### 例3：AI绘图
输入：
```text
“一只宇航员猫”
```
输出：
- 图像
即：
```text
f(文本)=图像
```
# 四、机器学习三大任务
## 4.1 回归（Regression）
输出是：
```text
连续数值
```
例如：
- 房价预测
- 温度预测
- 股票预测
## 4.2 分类（Classification）

输出是：
```text
离散类别
```
例如：
- 垃圾邮件识别
- 肿瘤良恶性判断
- 猫狗分类
## 4.3 生成（Generation）
输出是：
```text
数据本身
```
例如：
- ChatGPT 生成文本
- MidJourney 生成图像
- TTS 生成语音

# 五、机器学习核心流程（三大步骤）

机器学习本质流程：
```text
1. 确定模型
2. 确定评价标准
3. 找到最优模型
```
即：
```text
Model + Loss + Optimization
```
# 六、第一步：确定候选函数集合（Model）

## 6.1 什么是模型
模型：
> 用于表示函数 f 的结构。
例如：
- 线性函数
- 决策树
- 神经网络
- Transformer
## 6.2 候选函数集合

记作：

```text
H（Hypothesis Space）
```

表示：

```text
所有可能函数的集合
```

---

## 6.3 为什么模型重要

不同模型擅长不同任务：

|模型|擅长|
|---|---|
|CNN|图像|
|RNN|序列|
|Transformer|NLP/大模型|
|决策树|结构化数据|

---

# 七、第二步：确定损失函数（Loss Function）

## 7.1 为什么需要 Loss

机器学习必须知道：

```text
模型好不好
```

Loss：

> 衡量预测误差大小。

---

## 7.2 回归中的损失

课件中使用：

```text
L(f)=Σ|f(xi)-yi|
```

含义：

- 预测值和真实值差距越小
    
- Loss 越小
    
- 模型越好
    

---

## 7.3 易错点：Loss 小 ≠ 真正优秀

很多人误以为：

```text
训练集Loss小 → 模型强
```

错误。

因为：

模型可能：

```text
死记硬背训练数据
```

即：

# 过拟合（Overfitting）

---

# 八、泛化能力（Generalization）

## 8.1 什么是泛化

泛化：

> 模型对“新数据”的表现能力。

真正目标：

```text
训练好 + 测试也好
```

不是：

```text
只会背答案
```

---

## 8.2 训练集 vs 测试集

|数据|用途|
|---|---|
|Training Data|训练|
|Test Data|测试泛化|

---

## 8.3 i.i.d 假设（重点）

机器学习通常假设：

```text
训练集与测试集独立同分布
```

即：

```text
i.i.d
```

含义：

- Independent
    
- Identically Distributed
    

---

## 8.4 易错点

### 错误：

训练集和测试集重复。

这样：

```text
测试毫无意义
```

因为模型已经见过答案。

---

# 九、正则化（Regularization）

## 9.1 为什么需要正则化

目的：

```text
防止过拟合
```

本质：

```text
限制模型复杂度
```

---

## 9.2 理解

如果模型太复杂：

它甚至能：

```text
把噪声也记住
```

结果：

训练很好。

测试崩溃。

---

# 十、第三步：优化（Optimization）

## 10.1 优化目标

目标：

```text
找到Loss最小的函数
```

数学形式：

f^*=\arg\min_{f\in H} L(f)

---

## 10.2 常见优化算法

|方法|用途|
|---|---|
|Gradient Descent|最常见|
|Adam|深度学习核心|
|Genetic Algorithm|遗传优化|

---

# 十一、监督学习（Supervised Learning）

## 11.1 定义
训练数据：
```text
(x,y)
```
即：
```text
输入 + 标签
```
模型学习：
```text
x → y
```
## 11.2 分类任务
例如：
眼部肿瘤：
- 良性
- 恶性
输入特征：
- 肿瘤大小
- 年龄
- 颜色
- 神经距离
输出：
```text
恶性/良性
```
## 11.3 回归任务
输出：
```text
连续数值
```
例如：
- 房价
- 温度
- 收入
# 十二、半监督学习（Semi-Supervised Learning）

## 12.1 核心思想
只有部分数据有标签。
例如：
```text
10000张图片
只有100张标注
```
机器利用：
- 少量标签
- 大量无标签数据
共同学习
## 12.2 难点
核心思想：
```text
相似样本 → 输出应相似
```
因此：
Loss 中会加入：
```text
相似性约束
```
# 十三、无监督学习（Unsupervised Learning）

## 13.1 定义

数据：

```text
只有x
没有y
```

机器自己发现：

```text
数据内部结构
```

---

## 13.2 聚类（Clustering）

例如：

把用户自动分群：

- 游戏用户
    
- 购物用户
    
- 金融用户
    

---

## 13.3 本质

机器回答：

```text
哪些样本彼此相似？
```

---

# 十四、强化学习（Reinforcement Learning）

## 14.1 核心概念

强化学习四要素：

|名称|含义|
|---|---|
|Agent|智能体|
|Environment|环境|
|State|状态|
|Reward|奖励|
## 14.2 核心目标
学习：
```text
策略 Policy
```
即：
```text
状态 → 动作
```
## 14.3 强化学习特点
不是直接告诉答案。
而是：
```text
做对给奖励
做错给惩罚
```
## 14.4 典型应用
- 自动驾驶
- 游戏AI
- 机器人控制
- 无人机导航

# 十六、评价指标（重点）
## 16.1 Accuracy
准确率：
```text
预测正确比例
```
## 16.2 Precision
查准率：
```text
预测为正中真正为正
```

## 16.3 Recall

召回率：

```text
真正为正中被找出多少
```

---

## 16.4 F1-score

Precision 与 Recall 的调和平均。

---

## 16.5 易错点

很多人误认为：

```text
Accuracy高 → 模型一定强
```

错误。

例如：

```text
99%正常
1%癌症
```

模型全预测正常：

```text
Accuracy = 99%
```

但毫无意义。

# 十八、感知机（Perceptron）

## 18.1 神经网络起点

本质：
```text
线性分类器
```
结构：
```text
输入 → 加权求和 → 激活
```
## 18.2 数学表达
$y=f\left(\sum_i w_i x_i+b\right)$
## 18.3 局限
单层感知机：
```text
不能解决 XOR
```
这是第一次神经网络寒冬的重要原因。

# 二十一、重点易错总结

---

## 易错1

### “机器学习就是神经网络”

错误。

神经网络只是机器学习一种。

还有：

- 决策树
    
- SVM
    
- 贝叶斯
    
- KNN
    

---

## 易错2

### “训练准确率高就行”

错误。

核心：

```text
泛化能力
```

---

## 易错3

### “无监督学习没有目标”

错误。

它目标是：

```text
发现结构
```

不是没有目标。

---

## 易错4

### “强化学习就是监督学习”

错误。

监督学习：

```text
直接给标准答案
```

强化学习：

```text
只给奖励
```

A. 欠拟合

答案：

```text
C
```

# 例题3（难）

下列关于 i.i.d 假设正确的是：

A. 样本必须相同  
B. 样本必须线性相关  
C. 训练测试来自相同分布  
D. 数据必须服从正态分布

答案：

```text
C
```

# 例题4（综合）

为什么 Accuracy 不适合医疗诊断？

答案：

因为：

```text
类别极不平衡
```

例如：

99%正常。

模型全预测正常也能达到99%。

但：

```text
Recall 极低
```

无法发现病人。

---

# 例题5（高难）

为什么深度学习通常需要更多数据？

答案：

因为：

```text
模型参数量巨大
```

复杂模型若数据不足：

```text
容易过拟合
```

因此：

需要大量样本支撑泛化。
