## 1. 搜索问题概述
人工智能中的"搜索"本质上回答的是同一类问题：**一个能够自主决策的智能体（Agent），如何从当前所在的状态，通过一系列动作，抵达一个令人满意的目标状态？**
这背后有三个朴素的问题：
- 我现在在哪？（what state am I?）
- 我能做什么？（what actions can I take?）
- 我想去哪？（what state should I achieve?）
只要能把这三个问题回答清楚，就可以把"如何解决问题"转化为"如何在一个抽象的状态图上找路径"，这就是**搜索（Search）** 能派上用场的地方。
需要特别注意的是**搜索的局限性**：搜索只能告诉我们"问题被正确形式化之后该怎么解决"，如果问题形式化本身就是错的（比如状态空间、动作定义不对），那么再好的搜索算法也无济于事。这提醒我们，**建模比算法更重要**——很多实际问题最难的部分恰恰是"如何把它变成一个搜索问题"，而不是"用哪个算法去搜"
搜索技术不仅用于经典的路径规划问题（如导航），也广泛用于游戏 AI、自然语言处理（词图搜索、机器翻译）、机器人运动规划、资源分配等场景——只要能定义出"状态"和"从一个状态到另一个状态的动作"，几乎都可以套用搜索的框架

## 2. 搜索问题的形式化定义
### 2.1 六大要素
要把一个现实问题变成计算机能求解的搜索问题，需要明确定义以下**六个组成部分**：

|要素|英文|含义|
|---|---|---|
|状态空间|state space|所有可能状态构成的集合，是对问题的形式化抽象|
|动作|action|从一个状态转移到另一个状态的操作，是对真实动作的形式化|
|初始状态|initial state|智能体一开始所处的状态|
|目标|goal|需要达到的目标状态（或满足目标条件的状态集合）|
|启发式方法|heuristics|用于指导搜索方向的额外信息（在启发式搜索中才会用到）|
|解|solution|由"动作"构成的序列，能把初始状态转化为目标状态|

> **通俗理解**：状态空间就像一张地图上所有可能的"位置"，动作就是"从一个位置到另一个位置的移动方式"，初始状态是"你现在站的地方"，目标是"你要去的地方"，解就是"一条具体的路线"。

**严谨定义**：一个搜索问题可以被形式化为一个五元组 $(S, s_0, \text{Actions}, \text{Succ}, \text{Goal})$，其中 $S$ 是状态集合，$s_0 \in S$ 是初始状态，$\text{Actions}(s)$ 返回状态 $s$ 下可执行的动作集合，$\text{Succ}(s, a)$ 返回执行动作 $a$ 后到达的后继状态，$\text{Goal}(s)$ 是一个布尔函数，当 $s$ 满足目标条件时返回真

**算法的输入输出**可以进一步细化为：
- **输入**：初始状态（可以是具体的物理状态，也可以是表示"认知状态"的一个状态集合）；后继函数 $S(x)$（$x$ 经过一个动作后能到达的状态集合）；目标测试函数；前进成本函数 $C(x, a, y)$（从状态 $x$ 经动作 $a$ 到达状态 $y$ 所需要的成本，若 $x$ 无法通过任何动作到达 $y$，则约定其值为 $\infty$）
- **输出**：一条从初始状态到某个满足目标测试的状态的**状态序列**（或等价地，一条动作序列）

### 2.2 例题一：Romania Travel
**问题**：目前在 Arad 城，需要尽快到达 Bucharest 城，请形式化这个搜索问题。

|要素|具体内容|
|---|---|
|状态空间|所有可以到达的城市|
|动作|在相邻城市之间移动|
|初始状态|位于 Arad|
|目标条件|位于 Bucharest|
|解|一条从 Arad 到 Bucharest 途经城市组成的旅行路线|

这个例子直观地展示了形式化的四个基本步骤——它是本讲后面几乎所有例题的"母题"

### 2.3 例题二：Water Jugs 水罐问题
**问题**：有一个 3 加仑的量杯和一个 4 加仑的量杯，可以：把某个量杯从水龙头接满、把某个量杯倒空、把一个量杯的水倒入另一个（倒到另一个满为止）

| 要素   | 具体内容                                                                                  |
| ---- | ------------------------------------------------------------------------------------- |
| 状态空间 | 数对 $(gal_3, gal_4)$，表示 3 加仑杯和 4 加仑杯中当前的水量                                             |
| 动作   | Empty-3-Gallon、Empty-4-Gallon、Fill-3-Gallon、Fill-4-Gallon、Pour-3-into-4、Pour-4-into-3 |
| 初始状态 | 例如 $(0,0)$                                                                            |
| 目标条件 | 例如 $(0,2)$ 或 $(1,3)$                                                                  |

**易错点提醒**：
- 如果一开始 $gal_3, gal_4$ 都是整数，那么整个搜索过程中只能到达整数状态（比如永远不会出现 $1.5$ 加仑）
- 有些状态**不可达**：比如从 $(0,0)$ 出发，无法到达 $(1,2)$（需要验证具体的动作规则）
- 有些动作是"空动作"：不改变状态，比如 $(0,0) \xrightarrow{\text{Empty-3-Gallon}} (0,0)$，这种自环在搜索时要小心处理，否则会带来无意义的循环扩展
### 2.4 例题三：8-Puzzle 八数码问题
**问题**：3×3 的方格中有 8 个数字方块和一个空格，每次可以把空格移动到相邻位置（等价于把相邻数字移入空格）

|要素|具体内容|
|---|---|
|状态空间|各种不同的方格摆放方式|
|初始状态|给定的初始方格排布|
|目标|给定的目标方格排布|
|动作|空格向上/下/左/右移动|

八数码问题属于**滑块难题（sliding puzzle）** 的一种，滑块难题又是**二维组合谜题**的一个子类（类比：华容道也是二维组合谜题；魔方则是**三维组合谜题**）。这个分类思想有助于理解"同一类抽象问题可能有很多现实原型"
### 2.5 例题四：吸尘器世界（认知状态空间）
前面的例子中，一个"状态"直接对应现实世界的一种真实状态（比如城市、方格排布）。但**状态也可以表示智能体对世界的认知情况**，即"智能体的认知状态"（knowledge state）——这是一个非常重要的建模思路拓展

**物理问题描述**：两个房间，每个房间"干净/不干净"两种物理状态；吸尘器可以 left/right 移动（如果对应方向没有房间则动作无效），也可以 suck（把当前房间变干净，即使已经是干净的）

**认知层面的状态空间**：一个"认知状态"是**物理状态空间的一个子集**——也就是说，智能体只知道自己"处于这几个物理状态之一"，但不知道具体是哪一个

举例：如果智能体完全不清楚物理世界的初始状况，那么初始认知状态就是全部 8 种物理状态的集合 ${1,2,\dots,8}$。此时，即使不知道具体在哪个物理状态，动作序列 $\langle \text{right, suck, left, suck} \rangle$ 依然能保证到达"所有房间都干净"的目标：

$${1,\dots,8} \xrightarrow{right} {2,4,6,8} \xrightarrow{suck} {4,8} \xrightarrow{left} {3,7} \xrightarrow{suck} {7}$$

> **直觉理解**：这就好比你在完全没有地图、看不到周围的情况下（对应认知状态是一个很大的集合），依然可能找到一套"保证有效"的操作序列，让你无论一开始具体处在哪个位置，最终都能确保达成目标。这也是后续机器人学、部分可观测环境（POMDP）等问题的雏形。

## 3. 搜索算法的通用框架
### 3.1 后继函数与边界（Frontier）
状态 $x$ 可能通过**不同动作**到达不同后继状态，比如 $x \xrightarrow{a} y$、$x \xrightarrow{b} z$。为了区分"通过哪个动作到达哪个后继状态"，后继函数 $S(x)$ 的返回值不仅包含后继状态本身，还要记录到达它所经过的动作：

$$S(x) = {\langle y, a\rangle, \langle z, b\rangle, \dots}$$

**算法框架的核心概念——边界（Frontier，也称 Open 表）**：
- 边界中存放"已经被发现、但还没有被探索/扩展"的状态（或路径）
- 初始时，边界中只有初始状态
- 每一次迭代：从边界中取出一个节点，对其调用后继函数 $S(x)$，把新得到的子节点重新插入边界
**关键洞察**：所有的盲目搜索算法，其实都只是"以怎样的顺序从边界中取出下一个待扩展节点"这一规则的不同实现——只要规定了边界上元素的排序方式，就相当于确定了一种搜索策略

```mermaid
flowchart TD
    A[初始化 Frontier = 初始状态] --> B{Frontier 是否为空?}
    B -- 是 --> C[搜索失败 FAIL]
    B -- 否 --> D[按选择规则取出一个节点 n]
    D --> E{n 是否满足目标测试?}
    E -- 是 --> F[返回对应的动作/状态序列]
    E -- 否 --> G[用后继函数 S(n) 生成子节点]
    G --> H[将子节点按规则插入 Frontier]
    H --> B
```

### 3.2 树搜索 vs 图搜索
**树搜索**：用一棵搜索树来寻找从起点到终点的路径
- 根节点为起点，叶节点为终点（或待扩展节点）；
- 粗实线表示"已生成"的节点，虚线表示"尚未生成"的节点；
- 加阴影的节点表示"已扩展"过的节点
**重要提醒**：边界中保存的通常不只是"状态"，而是**路径**（从根到当前节点的完整路径）。这是初学者最容易忽略的一点——因为如果边界只存状态，就无法回溯得到完整的解路径，也无法正确处理"同一个状态、不同路径成本不同"的情况
### 3.3 示例：罗马尼亚旅行问题的搜索
以宽度优先的扩展顺序为例（数字为路径累积成本）：
1. 边界初始：${Arad}$
2. 扩展 Arad：${Z\langle A\rangle, T\langle A\rangle, S\langle A\rangle}$
3. 扩展 Sibiu：${Z\langle A\rangle, T\langle A\rangle, A\langle S,A\rangle, O\langle S,A\rangle, F\langle S,A\rangle, R\langle S,A\rangle}$
4. 扩展 Fagaras：得到 $B\langle F,S,A\rangle$，此时边界上已经出现目标节点 Bucharest，**该解的成本为** $140+99+211=450$
但如果换一条扩展顺序（先扩展 R.V. 再扩展 Pitesti），可以找到成本更低的解：$140+80+97+101=418$
> **核心结论**：**"从边界中选择哪个状态优先扩展"这件事，直接决定了（1）能否找到解、（2）找到的解的成本高低、（3）搜索所耗费的时间和空间资源。** 这是理解后续所有盲目搜索算法差异的总纲

**循环问题**：由于边界中存放的是路径而非状态，只要路径不同就会不断往边界里添加新元素——如果状态空间中存在环路，同一个状态可能被反复地"沿着不同路径"重复扩展，从而导致搜索永不终止或效率极低。这就引出了后面的"路径检测"和"环检测"机制

### 3.4 搜索算法的四大评价指标

|指标|中文|含义|
|---|---|---|
|Completeness|完备性|只要问题存在解，算法是否**保证**能找到解|
|Optimality|最优性|当动作有成本时，算法是否**保证**能找到成本最小的解|
|Time complexity|时间复杂度|为了找到解，最多需要探索/生成多少个节点|
|Space complexity|空间复杂度|搜索过程中最多需要在内存里同时保存多少个节点|

这四个指标贯穿本讲的所有算法对比表，请务必牢记其定义，因为几乎所有考试题都会围绕"某算法是否具备某个性质，为什么"来出题。

## 4. 盲目（无信息）搜索

**盲目搜索策略的三个共同特征**：
1. 采用固定规则来选择下一个待扩展状态；
2. 规则不随具体问题变化而变化；
3. 完全不使用与问题领域相关的任何额外信息
常用盲目搜索方法共 5 种：**宽度优先（BFS）、深度优先（DFS）、一致代价（UCS）、深度受限（DLS）、迭代加深（IDS）**，此外还有双向搜索
一个重要的统一视角：**边界的选择规则总可以等价地表示为"对边界集合排序，然后总是取第一个元素"**——这解释了为什么 BFS 用队列（FIFO）、DFS 用栈（LIFO）、UCS 用按成本排序的优先队列，本质上都是"排序规则不同"而已
### 4.1 宽度优先搜索 BFS
**规则**：把当前扩展节点的后继状态放在边界的**最后面**（即用队列 FIFO 实现），总是优先扩展"最先加入边界"的节点
**逐层扩展的直觉**：BFS 会先探索完所有第 1 步能到达的状态，再探索所有第 2 步能到达的状态，以此类推，是名副其实的"层层递进"
**性质**：
- **完备性：是**。因为短路径一定会在比它长的路径之前被遍历，给定长度的路径数量是有限的，因此迟早能遍历完所有长度为 $d$ 的路径，从而找到最短解
- **最优性：是**（前提是每步动作成本相同，此时"最短路径" = "最小成本路径"）
- **时间复杂度**：$1+b+b^2+\dots+b^d+b(b^d-1) = O(b^{d+1})$
- **空间复杂度**：$O(b^{d+1})$
其中 $b$ 为一个状态的最大后继状态个数（分支因子），$d$ 为最短解的动作个数（深度）

> **BFS 的致命弱点：空间复杂度**。举例：若 $b=10$，每秒能扩展 1000 个节点，每个节点占用 100 字节，则深度为 6 时需要 111MB 内存、耗时 18 分钟；深度为 8 时需要 11GB 内存、耗时 31 小时。**在实际应用中，往往是内存先于时间耗尽而使算法无法继续运行**——这是 BFS 最大的实践瓶颈。

### 4.2 深度优先搜索 DFS
**规则**：把当前扩展节点的后继状态放在边界的**最前面**（即用栈 LIFO 实现），总是优先扩展"最深"的节点
**与 BFS 对比**（同样的后继函数 $S(n)={n+1, n+2}$，初始 0，目标 5）：

|步骤|深度优先 Frontier|宽度优先 Frontier|
|---|---|---|
|0|${0}$|${0}$|
|1|${1,2}$|${1,2}$|
|2|${2,3,2}$|${2,2,3}$|
|3|${3,4,3,2}$|${2,3,3,4}$|
|...|沿一条路径持续深挖|逐层扩展|

**性质**：
- **完备性**：
    - 状态空间无限：**否**（可能沿着一条无限长的路径永远深挖下去，永远碰不到解）
    - 状态空间有限但存在环路（无限路径）：**否**
    - 状态空间有限，且对重复路径进行了剪枝：**是**
- **最优性：否**（先找到的解不一定是成本最小的解）
- **时间复杂度**：$O(b^m)$，其中 $m$ 是遍历过程中**最长路径的长度**。当 $m$ 远大于 $d$ 时，效率会很差；但如果存在多条解路径，DFS 有时能"运气好"先碰到某条通往解的路径，从而比 BFS 更快找到（某一个）解。
- **空间复杂度**：$O(bm)$——这是 DFS 最大的优点，空间复杂度是**线性**的。因为 DFS 一次只考虑一条路径，边界中只保存当前最深节点及其"回溯点"（当前路径上尚未被扩展过的兄弟节点）。

> **易混淆点**：DFS 的空间优势（线性）和 BFS 的空间劣势（指数）形成鲜明对比，这也是后续"深度受限搜索"和"迭代加深搜索"试图融合两者优点的动机所在。

### 4.3 一致代价搜索 UCS
**规则**：边界中的路径按**累积成本从小到大**排序，总是扩展当前成本最低的那条路径。当所有动作成本相同时，UCS 退化为 BFS
**性质**（假设每个动作成本 $\geq s > 0$）：
- 所有成本较低的路径一定会在成本更高的路径之前被扩展；
- 给定成本上限，该成本范围内的路径数量是有限的；
- 因此成本小于最优解的路径数量有限，最终一定能找到最短（最小成本）路径。
- **完备性、最优性：是**
- **时间/空间复杂度**：$O(b^{C_s + 1})$，其中 $C^{\_}$ 为最优解的成本。

> **对比 BFS**：BFS 的复杂度是 $O(b^{d+1})$（关注深度），UCS 的复杂度是 $O(b^{C^*/s+1})$（关注成本）。可以理解为 UCS 是"用成本代替深度"的 BFS。

### 4.4 深度受限搜索 DLS
**动机**：BFS 空间复杂度太大；DFS 可能在存在无限路径时永远运行不下去。**深度受限搜索 = 深度优先搜索 + 预先设定的深度上限 $L$**，超过 $L$ 就不再扩展，从而保证一定会终止。但代价是：**只有当解路径长度 $\leq L$ 时，才能找到解**
**伪代码**：

```text
DLS(Frontier, Successors, Goal?, D):
    # 初始调用时 Frontier = {<START>}
    while Frontier not EMPTY:
        n = 从 Frontier 中取出第一个节点
        Curr = n 的终止状态
        if Goal?(Curr):
            return n
        if Depth(n) < D:                     # 注意：深度等于 D 时不再扩展！
            Frontier = (Frontier - {n}) ∪ Successors(Curr)
        else:
            Frontier = Frontier - {n}
            CutOffOccurred = True
    return FAIL
```
**性质**：
- 完备性：**否**（若最优解深度 $>L$ 则找不到）
- 最优性：**否**
- 时间复杂度：$O(b^L)$
- 空间复杂度：$O(b^L)$
### 4.5 迭代加深搜索 IDS
**核心思想**：为了同时规避 DFS（可能无限运行）和 BFS（空间爆炸）的问题，从深度限制 $L=0$ 开始，**反复进行深度受限搜索，每次迭代把深度限制加一**。若某次迭代找到解或者该深度限制下已无节点可扩展，就结束当前迭代并提高深度限制；若深度限制已经无法再提高、仍未找到解，则说明整个状态空间已被搜索完毕，问题无解
**性质**：
- 完备性：**是**
- 最优性：**是**（前提：所有动作成本相同）。若动作成本不一致，可以用"成本边界（cost bound）"代替深度限制：每轮只扩展成本低于当前成本边界的路径，并记录未扩展路径中的最小成本，作为下一轮的新边界——但此时迭代次数可能等于所有不同成本取值构成集合的大小，开销会显著增大。
- 时间复杂度：$(d+1)b^0 + db + (d-1)b^2 + \dots + b^d = O(b^d)$
- 空间复杂度：$O(b^d)$
**为什么 IDS 比 BFS 更高效**？直觉上重复搜索浅层节点似乎很浪费，但实际上：**IDS 不需要扩展"深度限制层"上的所有节点**（只要找到目标就停止），而 BFS 需要把目标节点所在层**全部**扩展完才能确认找到的是最优解。数学上也验证了 IDS 的时间复杂度 $O(b^d)$ 优于 BFS 的 $O(b^{d+1})$（相差一个 $b$ 的因子），同时空间复杂度从 BFS 的 $O(b^{d+1})$ 大幅降到 IDS 的 $O(b^d)$（严格来说是线性 $O(bd)$，因为本质上每一轮都是一次 DFS）
### 4.6 双向搜索
**思路**：同时从初始状态向前搜索、从目标状态向后搜索，当两个方向的搜索"相遇"时停止
**性质**（假设两个方向都用 BFS）：
- 完备性：**是**
- 最优性：**是**（前提：每条边/每个动作成本相同）
- 时间和空间复杂度：$O(b^{d/2})$——这是双向搜索最大的优势，因为指数的底数不变、但指数减半，能带来巨大的效率提升
**难点**：如何"向后搜索"往往并不容易。有些问题的后继函数是可逆的，容易定义"逆向动作"；但很多现实问题（比如某些不可逆操作）向后搜索非常困难甚至无法定义
### 4.7 盲目搜索总结对比表

|算法|边界排序规则|完备性|最优性|时间复杂度|空间复杂度|
|---|---|---|---|---|---|
|BFS 宽度优先|先进先出（按深度）|是|是（等成本时）|$O(b^{d+1})$|$O(b^{d+1})$|
|DFS 深度优先|后进先出（按深度）|有限状态空间+剪枝时是|否|$O(b^m)$|$O(bm)$|
|UCS 一致代价|按路径累积成本排序|是|是|$O(b^{C^*/s+1})$|$O(b^{C^*/s+1})$|
|DLS 深度受限|后进先出+深度上限 $L$|否|否|$O(b^L)$|$O(bL)$|
|IDS 迭代加深|反复做 DLS，逐步增大 $L$|是|是（等成本时）|$O(b^d)$|$O(bd)$|
|双向搜索|正向+逆向同时 BFS|是|是（等成本时）|$O(b^{d/2})$|$O(b^{d/2})$|

> 表中：$b$ = 分支因子（一个状态最大后继数），$d$ = 最短解的动作个数，$m$ = 遍历中最长路径的长度，$L$ = 深度限制，$C^*$ = 最优解成本，$s$ = 动作成本下界。

### 4.8 路径检测与环检测
在讨论重复节点（循环）问题时，有两种常见的去重策略：
**路径检测（Path Checking）**：扩展节点 $n_k$ 得到子节点 $c$ 时，只需确保 $c$ 不等于**到达 $c$ 的这条路径上的任何祖先节点**（即单独检查每条路径内部是否有重复）
**环检测（Cycle Checking）**：额外维护一个"已扩展过的全部节点"集合。扩展节点 $n_k$ 得到子节点 $c$ 时，确保 $c$ 不等于**之前任何被扩展过的节点**（无论它在哪条路径上）

|比较维度|路径检测|环检测|
|---|---|---|
|检测范围|仅当前路径上的祖先节点|历史上所有被扩展过的节点|
|空间开销|较低|较高（等同于 BFS 的空间复杂度）|
|去重能力|弱（同一状态仍可能通过不同路径被多次扩展）|强|

**环检测对最优性的影响（重要考点）**：
- 对 **UCS**：使用环检测后仍能保持最优性。因为 UCS 第一次扩展到某个节点时，其实已经找到了到达该节点**成本最低**的路径，被剔除的节点不可能存在更优路径
- 对**启发式搜索（如 A*）**：这个结论**不一定成立**！只有当启发式函数满足"单调性/一致性"时，环检测才能保持最优性（详见 [[#5.6 一致性/单调性 Consistency]]）。如果只是"可采纳"但不满足单调性，环检测可能会破坏最优性——除非额外记录被剪枝节点的路径成本，一旦发现更低成本的路径就重新扩展

## 5. 启发式（有信息）搜索

### 5.1 为什么需要启发式信息
盲目搜索方法虽然分类繁多，但本质上有一个共同的局限：**它们都只依据某种固定的评价指标（深度或路径长度）来决定搜索方向，而这个指标和"搜索对象本身距离目标有多近"完全无关**。例如 UCS 总是扩展"从初始状态到当前状态成本最小"的路径，却从来没有考虑过"从当前状态到目标状态还需要多少成本"
而人类解决问题时天然带有"启发性（heuristic）"——比如在地图上凭直觉判断"哪个方向更靠近目的地"。**启发式搜索的核心动机，就是把这种"距离目标的估计"引入搜索过程，让搜索变得更"聪明"**
### 5.2 启发式函数 h(n) 的定义
**通俗理解**：$h(n)$ 就是"从 $n$ 走到目标节点，需要花多少代价"的一个**估计值**，不需要精确，但需要有指导意义
**严谨定义**：对于一个具体问题，构造一个专用于该领域的启发式函数 $h(n)$，用于估计从节点 $n$ 到达目标节点的成本。要求：**对所有满足目标条件的节点 $n$，$h(n) = 0$**（因为已经到达目标，不需要再花费任何成本）。
$h(n)$ 因问题领域不同而有不同的构造方式，常见的思路包括：
- 当前节点到目标节点的某种"距离"或"差异"度量
- 当前节点处于最优路径上的（主观估计）概率
- 某种领域相关的 if-then 经验规则
**案例：8-Puzzle 的启发式函数演化**（这是理解"如何设计启发式函数"的经典教学案例）：

|方法|思路|缺陷|
|---|---|---|
|Method A|当前棋局与目标棋局"错位牌的数量"（Misplaced Tiles）|没考虑距离因素，比如把"1、2"颠倒 vs 把"1、5"颠倒，移动难度显然不同，但错位牌数目可能一样|
|Method B|错位牌"距离目标位置的距离和"（曼哈顿距离和）|没考虑"移动难度"——即使只差一格（如"1、2"颠倒），移动起来依然可能不容易，因为移动一张牌可能需要先挪开别的牌|
|Method C|遇到需要"颠倒两张相邻牌"的情形，认为需要固定步数|只处理了一种特殊情形，覆盖面窄|
|Method D|综合 B 和 C：既考虑距离，也加上需要颠倒的数量修正|是对前几种方法的组合优化|

这个演化过程揭示了设计启发式函数的一般规律：**越精细地刻画"实际还需要花费的成本"，启发式函数就越"聪明"（信息量越大），但计算开销通常也会相应增加**，需要在信息量和计算代价之间权衡

另一个经典例子是**直线距离（欧氏距离）启发式**，比如罗马尼亚问题中，$h(n)$ = 当前城市到 Bucharest 的直线距离。但需要注意：**仅依靠启发式函数本身是有问题的**——例如 Arad→Sibiu→Fagaras→Bucharest 按直线距离启发选出的路径成本是 450，而真正最短路径 Arad→Sibiu→RV→Pitesti→Bucharest 的成本只有 418。这说明**单纯依赖 $h(n)$ 可能"舍近求远"**，这正是下一节要讲的"贪心最佳优先搜索"的固有缺陷。

### 5.3 贪心最佳优先搜索 Greedy Best-First Search
**定义**：只用启发式函数 $h(n)$ 对边界节点排序，评价函数 $f(n) = h(n)$

**存在的问题**：贪心地只看"离目标还有多远"，完全忽略了"从初始状态走到当前节点已经花了多少成本" $g(n)$。这可能导致算法"误入歧途"——选中一个虽然按 $h(n)$ 看起来离目标很近，但实际上离初始状态已经非常远（路径成本很高）的节点

**结论：贪心最佳优先搜索既不是完备的，也不是最优的**
	一个直观例子：设 $S$ 到 $n_1$ 步成本 10，$h(n_1)=10$；$S$ 到 $n_3$ 步成本 100，$h(n_3)=100$；但 $n_1$ 通往目标还需绕远路，而 $n_3$ 直接毗邻目标。贪心算法会一直优先扩展 $h$ 值小的 $n_1$ 方向，即便实际总成本更高

>[!INFO] **辅助信息与评价函数的关系**（重要概念辨析）：
> - **辅助信息**：与所求解问题相关但问题本身之外的额外知识/信息；
> - **启发式函数 $h(n)$**：利用辅助信息，估计从当前节点 $n$ 到目标节点还需要多少成本；
> - **评价函数 $f(n)$**：根据 $h(n)$（以及可能的 $g(n)$），选择"下一个该扩展哪个节点"的最终依据。

### 5.4 ⭐⭐⭐ A 算法与 A* 算法
- 盲目搜索（如 UCS）只精确计算了"前半段"：从初始节点到当前节点的实际成本；
- 贪心搜索只"估计"了"后半段"：从当前节点到目标节点的成本。
A 算法的思想就是把两者结合起来：
$$\boxed{f(n) = g(n) + h(n)}$$
其中：
- $g(n)$：从初始状态到节点 $n$ 的**已知**路径成本（真实值，随搜索推进逐渐精确）
- $h(n)$：从节点 $n$ 到目标节点的**启发式估计**成本
- $f(n)$：经过节点 $n$ 到达目标的总路径成本的估计值
**算法规则**：用 $f(n)$ 对边界上的节点排序，**总是扩展 $f$ 值最小的节点**

UCS vs Greedy vs A* ：

|算法|评价函数|关注点|
|---|---|---|
|UCS|$f(n) = g(n)$|只看"已经走了多远（成本）"|
|Greedy Best-First|$f(n) = h(n)$|只看"离目标还有多近（估计）"|
|A（A*）|$f(n) = g(n) + h(n)$|两者兼顾|

当启发式函数满足特定条件（下一节的可采纳性）时，A 算法就被称为 **A* 算法**
### 5.5 可采纳性 Admissibility
**动机推导——启发函数为什么需要有"上限"**：设 $g(n)$ 为从起点 $S$ 到 $n$ 的所有路径中成本最小的那条（真实最优代价），$h(n)$ 为从 $n$ 到目标 $E$ 的所有路径中成本最小的那条（真实最优代价），则真正的最优路径成本为 $f(n) = g(n) + h(n)$

由于 $f(n)$ 无法直接计算（否则问题已经解决了），我们只能用近似值。搜索过程中，$g(n)$ 是随着搜索逐步精确化得到的，通常可以认为 $g^*(n) \approx g(n)$ 是合理的近似。为了保证"$n$ 点仍然有被扩展、进而找到最优解的可能性"，需要满足：
$$f(n) \leq f^{*}(n) \implies h(n) \leq h^{*}(n)$$
这就是启发式函数的**上限要求**——如果 $h(n)$ 超过了这个上限（高估了真实剩余代价），搜索算法可能会"发散"（错误地跳过真正的最优节点），从而不能保证找到最优解

**严谨定义**：设 $c(n_1 \to n_2) \geq s > 0$（每个状态转移成本非负且有下界），$h(n)$ 是从节点 $n$ 到目标节点的最优路径成本（若 $n$ 与目标不连通，则 $h(n) = \infty$）
$$\boxed{\text{若对所有节点 } n, \ h(n) \leq h^*(n), \text{ 则称 } h(n) \text{ 是可采纳的（admissible）}}$$
**通俗理解**：可采纳的启发式函数**永远不会高估**从当前节点到目标的真实剩余代价，它只能"低估"或"恰好估对"。这样一来，实际成本最小的最优路径才不会因为估计过高而被算法过早排除。此外，对任意目标节点 $g$，必有 $h(g) = 0$
### 5.6 一致性/单调性 Consistency
**定义**：对任意节点 $n_1, n_2$（$n_2$ 是 $n_1$ 的后继节点），若满足
$$\boxed{h(n_1) \leq c(n_1 \to n_2) + h(n_2)}$$
则称 $h(n)$ 具有**一致性（consistency）**，也称**单调性（monotonicity）**
**直觉理解**：这其实是启发式函数版本的"三角不等式"——从 $n_1$ 直接估计到目标的代价，不应该比"先走到 $n_2$ 花费真实成本 $c(n_1\to n_2)$，再从 $n_2$ 估计到目标"更大

**重要定理：一致性 ⟹ 可采纳性**（证明如下，是必考的经典证明）：
- **Case 1**：若从 $n$ 没有路径能到达目标，可采纳性自动成立。
- **Case 2**：设 $n=n_1\to n_2\to \dots \to n_k$（$n_k$ 为目标）是从 $n$ 到目标的一条**最优路径**。用数学归纳法证明对所有 $i$，$h(n_i) \leq h^*(n_i)$：
    - **基例（Base）**：$h(n_k) = 0 = h^*(n_k)$（目标节点的 $h$ 值恒为 0）。
    - **归纳步（Induction）**：假设 $h(n_i) \leq h^_(n_i)$ 成立，那么 $$h(n_{i-1}) \leq c(n_{i-1}\to n_i) + h(n_i) \leq c(n_{i-1}\to n_i) + h^_(n_i) = h^_(n_{i-1})$$ （最后一步是因为路径 $n_{i-1}\to n_i \to \dots \to n_k$ 是最优路径的一段，所以 $c(n_{i-1}\to n_i)+h^_(n_i)$ 恰好等于 $h^*(n_{i-1})$。）

**结论**：大部分实践中构造出的可采纳启发式函数，同时也满足一致性——但**并非所有可采纳的启发式函数都满足一致性**（见下面的反例）

**反例：可采纳但不满足单调性的启发式函数**

设某图中，$h(n_2) > c(n_2 \to n_4) + h(n_4)$，此时 $h$ 不满足单调性但仍可采纳。搜索过程会出现"错误地忽略了 $n_2$ 而去扩展 $n_1$"的现象——虽然最终依然能找到最优路径 $S\to n_2 \to n_4 \to Goal$，但中间会多走一些"冤枉路"（多扩展一些无用节点）

**环检测对不满足单调性的启发式函数的影响**：若只有可采纳性而没有单调性，一旦对已扩展节点做环检测（直接剪枝），**有可能破坏最优性**——因为不能保证"第一次到达某节点时走的就是最优路径"。解决方法：对每个已遍历节点记录其路径成本，若发现到达该节点的更低成本路径，则需要重新扩展（而不是直接剪枝）。而**只要启发式函数具备单调性**，就可以保证"进行环检测之后仍然保持最优性"，因为单调性恰好保证了"第一次遍历到某个节点时，走的必然是到该节点的最优路径"（详见 Proposition 4）。

### 5.7 单调性的四条重要推论

这四条命题环环相扣，是理解 A* 为什么正确、以及为什么可以安全地做环检测的理论基础：

**Proposition 1：一条路径上的节点，其 $f$ 值应该是非递减的**（注意：仅有可采纳性时，这个结论不成立！）

_证明_：设路径上相邻两点 $n_1, n_2$： $$f(n_1) = g(n_1) + h(n_1) \leq g(n_1) + c(n_1\to n_2) + h(n_2) = g(n_2) + h(n_2) = f(n_2)$$ （不等号成立正是因为单调性 $h(n_1) \leq c(n_1\to n_2) + h(n_2)$。）

**Proposition 2：若节点 $n_2$ 在节点 $n_1$ 之后被扩展，则 $f(n_1) \leq f(n_2)$**

_证明_：分两种情况——若 $n_1$ 被扩展时 $n_2$ 已在边界上，则由于算法总是优先扩展 $f$ 值小的节点，$n_2$ 没被优先选中说明 $f(n_1)\leq f(n_2)$；若 $n_1$ 被扩展时 $n_2$ 的祖先 $n_3$ 在边界上，则同理 $f(n_1)\leq f(n_3)$，再结合 Proposition 1（$f(n_3)\leq f(n_2)$，因为 $n_3$ 是 $n_2$ 路径上的祖先）得到 $f(n_1)\leq f(n_2)$

**Proposition 3：在遍历节点 $n$ 时，所有 $f$ 值小于 $f(n)$ 的节点都已经被遍历过了**

_证明_（反证法）：假设存在路径 $p=n_1\to n_2\to\dots\to n_k$ 尚未被遍历，但 $f(n_k) < f(n)$，其中 $n_k$ 是路径 $p$ 上最后被遍历的节点。路径上的节点 $n_{i+1}$（$n_k$ 的后继）应该已经在 $n$ 被探索时处于边界上，因此 $f(n) \leq f(n_{i+1})$；再由 Proposition 1，$f(n_{i+1}) \leq f(n_k)$。于是 $f(n) \leq f(n_k)$，与假设 $f(n_k) < f(n)$ 矛盾

**Proposition 4：A* 搜索第一次扩展到某个状态时，就已经找到了到达该状态的最小成本路径**

_证明_：设路径 $p=\dots\to n$ 是第一条被发现的到达 $n$ 的路径，$p'=\dots\to m\to n$ 是第二条到达 $n$ 的路径。由 Proposition 2，$f(n)\ \text{via}\ p = g(p)+h(n) \leq f(m)$；再由 Proposition 1，$f(m) \leq f(n)\ \text{via}\ p' = g(p')+h(n)$。两式结合得 $g(p) \leq g(p')$，即 $c(p) \leq c(p')$——**第一次找到的路径不会比之后找到的更差**。这正是"单调性下环检测仍保持最优性"的理论依据

### 5.8 IDA*：迭代加深的 A*
**动机**：A* 和 BFS/UCS 一样存在潜在的**空间复杂度过大**的问题（所有边界节点都要保存在内存中）。
**做法**：类似迭代加深搜索，但**用 $f$ 值（而非深度）作为每轮迭代的界限**。每次迭代把界限提高到"上一轮迭代中超出界限的最小 $f$ 值"
**最优性保证**：当启发式函数 $h$ 可采纳时，IDA* 是最优的——设 $C^_$ 为最优解成本，界限最终会被逐步提升到 $C^_$，从而找到最优解
### 5.9 构造启发式函数：松弛问题
**核心思路**：通过把原问题"放松/简化"成一个更容易求解的简单问题，并令 $h(n)$ 等于**在这个简化问题中，从 $n$ 到目标的最优成本**
以 8 数码问题为例，原始规则是"把方块 A 移动到位置 B"需要满足两个条件：
1. A 与 B 位置相邻（上/下/左/右）；
2. B 位置为空。
**逐步放松这两个条件**，可以得到不同层次的启发式函数：

|放松方式|得到的启发式函数|说明|
|---|---|---|
|③ 忽略两个条件（A 可以直接移到任意 B）|**Misplaced Tiles**（错位方块数）：$h(n)$ = 当前状态与目标状态位置不同的方块数|最粗糙的松弛，$h$ 值最小（信息量最少）|
|① 只忽略"B 必须为空"|**Manhattan Distance**（曼哈顿距离）：$h(n)$ = 所有方块到达其目标位置的曼哈顿距离之和|更精细的松弛，$h$ 值更大（信息量更多）|

**可采纳性证明（Misplaced Tiles）**：对每个不在目标位置的方块，至少需要 1 次动作才能归位，这个动作成本 $\geq 1$，因此 $h(n) \leq h^*(n)$

**单调性证明（Misplaced Tiles）**：任何一次动作最多只能消除一个"不在目标位置"的方块（即最多让一个方块归位），因此对相邻状态 $n_1, n_2$：$h(n_1) - h(n_2) \leq 1 \leq c(n_1\to n_2)$，满足单调性定义

**可采纳性证明（Manhattan Distance）**：每个不在目标位置的方块，都至少需要 $d$ 个动作才能到达目标位置（$d$ 为该方块的曼哈顿距离），不同方块的这些动作互不相同（不存在一步动作同时让两个方块都归位），因此累加仍满足 $h(n) \leq h^*(n)$。

**单调性证明（Manhattan Distance）**：任何一次动作最多能让一个方块的曼哈顿距离减少 1，因此 $h(n_1)-h(n_2) \leq 1 \leq c(n_1\to n_2)$。

**松弛问题的一般性定理**：在松弛问题中，到达某个节点的最优成本，就是原始问题中一个可采纳的启发式函数值。

_证明思路_：设 $P$ 是原问题，$P_j$ 是 $P$ 的松弛版本。由于松弛意味着"约束更少、可行动作更多"，因此 $P$ 的解集合是 $P_j$ 解集合的子集：$Sol(P) \subseteq Sol(P_j)$。子集的最小成本不会小于母集合的最小成本，因此 $mincost(Sol(P_j)) \leq mincost(Sol(P))$，即松弛问题的最优成本 $h(n) \leq h^*(n)$（原问题真实最优成本）——这正是可采纳性的定义

> **构造启发式函数的心法**：想要一个"稳妥"（可采纳）的启发式函数，最简单可靠的方法就是"删掉几条约束条件，做一个更容易求解的松弛问题，然后用这个松弛问题的最优解作为估计值"。这是设计启发式函数最常用、最系统化的通用技巧。

### 5.10 启发式函数的支配关系
**定义**：设 $h_1, h_2$ 都是可采纳的，如果对**除目标节点外的所有节点** $n$，都有 $h_1(n) \leq h_2(n)$，则称 **$h_2$ 支配（dominates）$h_1$**，或者说 $h_2$ 比 $h_1$ 蕴含更多信息

> 保证可采纳的情况下，更大就更接近真实值，更准确，更高效

**定理**：如果 $h_2$ 支配 $h_1$，那么在 A* 算法中，使用 $h_2$ 所扩展到的节点，使用 $h_1$ 也一定会扩展到（即 $h_2$ 扩展的节点数不会比 $h_1$ 更多）

**实验数据对比**（8 数码问题，IDS vs A*(Misplaced) $h_1$ vs A*(Manhattan) $h_2$，展示了启发式函数信息量对搜索效率的巨大影响）：

|深度|IDS|A*(Misplaced) $h_1$|A*(Manhattan) $h_2$|
|---|---|---|---|
|10|47,127|93|39|
|14|3,473,941|539|113|
|24|---|39,135|1,641|

> **结论**：**曼哈顿距离启发式（$h_2$）比错位方块数启发式（$h_1$）扩展的节点数少一到两个数量级**，验证了"信息量更大的启发式函数（支配关系中更大的那个）能显著提升搜索效率"这一核心思想。这也是本讲最重要的实践启示：设计启发式函数时，在保证可采纳性的前提下，**应尽量选择估计值更大（更接近真实值）的那一个**

## 6. A* 的典型应用

A* 搜索因其"完备+最优+相对高效"的良好性质，在众多领域都有广泛应用：

- **游戏 AI**：如怪物追逐路径规划——用怪物坐标作为状态，坐标间的直线转移作为动作，用怪物当前坐标与目标坐标的**直线距离**作为启发函数（满足 $h(n) \leq h^*(n)$，因为两点之间直线最短）。
- **导航路径规划**：如地图寻路、避障路径规划。
- **资源分配**。
- **机器人运动规划**。
- **语言分析**：
    - **语音识别中的词图搜索**：把用户发音转化为若干可能的词，构成词图，搜索任务是在词图中找到最有可能组成合理句子的词语组合。
    - **机器翻译中的启发式搜索**：源语言的每个词有多种译法，所有可能的译文拼接方式构成一个状态空间，最佳译文就是这个状态空间中的一条最优搜索路径。

### 例题 1（基础）：一致代价搜索求解
**题目**：初始状态为 $S$，目标状态为 $G$，各边路径成本已知。用 UCS 求解，按扩展顺序列出节点，记录每一步 Open 表和 Closed 表状态

|步骤|扩展节点|Open 表（括号内为总成本）|Closed 表|说明|
|---|---|---|---|---|
|0|-|$S(0)$|空|初始状态|
|1|$S$|$A(1), B(5), C(15)$|$S(0)$|扩展 $S$，生成子节点|
|2|$A$|$B(5), G(11), C(15)$|$S(0), A(1)$|扩展 $A$，生成 $G$（成本 $1+10=11$）|
|3|$B$|$G(10), C(15)$|$S(0), A(1), B(5)$|扩展 $B$，生成 $G$（成本 $5+5=10$，更优）|
|4|$G$|$C(15)$|$S(0), A(1), B(5), G(10)$|找到目标 $G$，终止|

**最终路径**：$S \to B \to G$，总成本 $10$

**思考题**：当节点 $A$ 生成目标 $G$（路径成本 11）时，为什么算法不立即终止？

**解答**：UCS **只在节点被扩展时才检查是否为目标**，而不是在生成（加入 Open 表）时检查。此时 Open 表中仍有 $B(5)$，其通往 $G$ 的潜在总成本可能更低（实际为 $5+5=10$）。UCS 始终优先扩展"累积成本最小"的节点，这保证了**第一次真正扩展到目标节点时，路径成本一定是最小的**。若提前在生成时就终止，则可能错过更优路径（本例中的 $B\to G$）

### 例题 2（中等）：8-Puzzle 的 A* 启发式求解过程
用 $h(n)$ = "错位牌数量"（Misplaced Tiles），$g(n)$ = "已移动步数"，从初始状态开始搜索，$f = g+h$：

|步骤|操作|Open 表|Closed 表|
|---|---|---|---|
|1|初始节点 $g=0, h=4$，记为 $a_4$|$[a_4]$|$[\ ]$|
|2|扩展 $a_4$ 得三个子节点，计算各自 $f$ 值，选最优继续|$[c_4, b_6, d_6]$|$[a_4]$|
|3|继续扩展 $f$ 值最小的节点|$[e_5, f_5, b_6, d_6, g_6]$|$[a_4, c_4]$|
|4|$e$ 的两个孩子均未优于 $f_5$，回溯扩展 $f_5$|$[f_5, h_6, b_6, d_6, g_6, i_7]$|$[a_4, c_4, e_5]$|
|5|继续|$[j_5, h_6, b_6, d_6, g_6, k_7, i_7]$|$[a_4, c_4, e_5, f_5]$|
|6|$j$ 只有一个孩子 $L$|$[L_5, h_6, b_6, d_6, g_6, k_7, i_7]$|$[a_4, c_4, e_5, f_5, j_5]$|
|7|找到目标 $m$|$[m_5, h_6, b_6, d_6, g_6, n_7, k_7, i_7]$|$[a_4, c_4, e_5, f_5, j_5, L_5]$|

**关键教学点**：每一步都是从 Open 表中挑选 $f$ 值最小的节点扩展；一旦遇到 $f$ 值更大的分支，暂不扩展、先记录在 Open 表中"排队"，这正体现了 A* "始终优先扩展最有希望节点"的核心策略，也直观展示了 Proposition 3（遍历 $n$ 时，$f$ 值小于 $f(n)$ 的节点都已被遍历）。

### 例题 3（中高难度）：为传教士与野蛮人问题构造启发式函数并证明其可采纳性
**问题**：$N$ 个传教士和 $N$ 个野蛮人在河左岸，一艘船最多载 $K$ 人，要求任何时刻（两岸或船上）传教士人数 $\geq$ 野蛮人人数，或传教士人数 $=0$。求把所有人渡到右岸的方法。

**状态形式化**：状态 $(M, C, B)$ 表示：$M$ = 左岸传教士数，$C$ = 左岸野蛮人数，$B=1$ 表示船在左岸。动作 $(m,c)$ 表示船上传教士数 $m$、野蛮人数 $c$，需满足约束条件。动作效果： $$ (M,C,1) \xrightarrow{(m,c)} (M-m, C-c, 0), \qquad (M,C,0) \xrightarrow{(m,c)} (M+m, C+c, 1) $$

**尝试 1**：$h_1(n) = M+C$ 是否可采纳？

**验证**：考察状态 $(1,1,1)$，此时 $h_1(n) = 2$，但真实最优成本 $h^_(n) = 1$（一次动作即可把两人渡到对岸），出现 $h_1(n) > h^_(n)$，**不可采纳**！

**改进**：设 $h(n) = M + C - 2B$

**单调性验证**（分两种转移方向）：

- 当 $B=1 \to 0$（即 $(M,C,1)\xrightarrow{(m,c)}(M-m,C-m,0)$）： $$h(n_1)-h(n_2) = (M+C-2) - (M-m+C-c-0) = m+c-2 \leq K-2 \leq 1$$ （因为船容量 $m+c \leq K$，且题目常见设定 $K \leq 3$ 使得 $K-2 \leq 1$。）
- 当 $B=0\to 1$： $$h(n_1)-h(n_2) = (M+C) - (M+m+C+c-2) = 2-(m+c) \leq 1 \quad (\text{因为 } m+c\geq 1)$$
两种情况都满足 $h(n_1)-h(n_2) \leq c(n_1\to n_2)$（每次渡船动作成本为 1），说明 **$h(n)=M+C-2B$ 具有单调性**，从而也具有可采纳性，是一个合法的 A* 启发式函数
**直接证明可采纳性（另一视角）**：
- 当 $B=1$（船在左岸）时，最好的情形是最后一步把剩余人渡完，之前每次往返最多送 2 人过河（3 人过去，1 人把船划回来），因此至少需要 $\left\lceil \frac{M+C-3}{2} \right\rceil + 1 \geq M+C-2$ 次动作
- 当 $B=0$（船在右岸）时，需要先有一人把船划回左岸（形成 $B=1$ 的情形），此时共需渡 $M+C+1$ 人，因此至少需要 $M+C+1-2+1 = M+C$ 次动作
综合两种情况： $$h(n) = \begin{cases} M+C-2, & B=1 \ M+C, & B=0\end{cases} = M+C-2B$$
这与前面单调性推导得到的启发式函数完全一致，说明它满足 A* 条件
### 例题 4（较高难度）：带对角线移动的 A* 网格寻路
**题目**：探险队需绕过湖到达露营地，地图为方格网格，湖面为障碍区。探险队可向上下左右或对角线移动（水平/垂直成本 10，对角线成本 15）。用 A* 算出最近路径
**启发式函数设计**：因为可以斜着走且斜线代价比"两次直走"更低，直接用曼哈顿距离会**高估**真实代价（不可采纳）。正确做法：注意到若忽略湖面障碍，从当前位置到目标的最优路径必然由"一段对角线 + 一段直线"组成。设

$$a = \max(|x_g-x_{curr}|, |y_g-y_{curr}|), \qquad b=\min(|x_g-x_{curr}|,|y_g-y_{curr}|)$$

$$\boxed{h(n) = h(x_{curr}, y_{curr}) = 10\times(a-b) + 15\times b}$$
**可采纳性**：$h(n) \leq h^*(n)$（因为忽略障碍求得的路径成本，一定不高于绕开障碍后的真实最优成本）。 **一致性**：满足 $h(n_1) \leq c(n_1,n_2) + h(n_2)$

**搜索过程**（起点 $(1,2)$，湖面覆盖 $(3,2)$ 和 $(3,3)$，露营地 $(5,3)$；花括号第一项为坐标，第二项为 $f=g+h$）：

|步骤|当前坐标|Open 表（部分）|移动方向|
|---|---|---|---|
|0|-|$[(1,2), f=0+45]$|-|
|1|$(1,2), f=45$|$(2,1),f=55$; $(2,2),f=45$; $(2,3),f=45$; $(1,3),f=50$; $(1,1),f=60$|右上|
|2|$(2,3), f=45$|$(2,2),f=60$; $(2,4),f=60$; $(3,4),f=55$|右上|
|3|$(3,4), f=55$|$(3,5),f=70$; $(4,5),f=70$; $(4,4),f=55$; $(4,3),f=55$|右下|
|4|$(4,3), f=55$|$(5,3),f=55$; $(4,4),f=70$; $(4,2),f=70$; ...|右|
|5|$(5,3), f=55$|到达露营地，算法结束|-|

**最终路径**：$(1,2)\to(2,3)\to(3,4)\to(4,3)\to(5,3)$，总成本 $55$。

> **易错提醒**：题目特别指出，当同时存在多个相同最小 $f$ 值的节点时，选择不同的移动方向可能得到成本相同但路径不同的解——这说明 **A* 保证找到最优成本，但不一定保证路径唯一**。

### 例题 5（拓展练习，留作思考）：怪物追逐问题

游戏中怪物要以最快路径接近静止不动的小孩，可沿 8 个方向移动。设计思路（三步法，供参照 8-Puzzle/网格寻路的建模模式自行完整求解）：

1. **状态与转移**：直接用怪物坐标作为状态，坐标点之间的移动作为转移动作。
2. **启发函数设计**：目标是步数最短，两点间直线最短，所以设 $h(n)$ = 怪物当前坐标与目标坐标的**直线（欧氏）距离**，满足 $h(n)\leq h^*(n)$。
3. **搜索过程**：在 $t=0$ 时向 8 个方向各走一步（$g=1$），计算每个方向的 $h$ 值，选 $f=g+h$ 最优的方向前进，如此反复直至到达目标。

## 8. 常见误区与易错点

| 误区                                                       | 正确理解                                                                                                     |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 认为"边界"里只存状态                                              | 边界中通常存的是**路径**（否则无法回溯出完整解，也无法正确处理不同路径成本）                                                                 |
| 认为 UCS 在生成目标节点时就应该终止                                     | UCS **只在扩展（弹出）节点时**才检查是否为目标，生成时不检查，因为可能存在总成本更低但尚未被扩展的路径                                                  |
| 认为可采纳的启发式函数一定满足单调性                                       | **单调性 ⟹ 可采纳性，但反过来不成立**！存在可采纳但不单调的反例（如 5.6 节示例），此时环检测可能破坏最优性                                              |
| 认为环检测对所有搜索都能保持最优性                                        | 对 UCS 恒成立；对 A* 只有当 $h$ **满足单调性**时才成立，否则需要额外记录路径成本以支持"重新扩展"                                               |
| 认为 $h(n)$ 越大越好                                           | $h(n)$ 必须满足**可采纳性**（$h(n)\leq h^_(n)$）这个硬约束，超过上限会导致搜索发散、失去最优性保证；在满足可采纳性的前提下，才是"$h$ 值越大（越接近 $h^_$）搜索效率越高" |
| 混淆"错位牌数" (Misplaced) 与"曼哈顿距离" (Manhattan) 两种启发式的可采纳性证明角度 | 前者证明基于"每个错位方块至少需要 1 步"；后者基于"每个方块至少需要其曼哈顿距离步"，是完全不同层次的松弛（分别对应放松不同的约束条件）                                   |
| 在含对角线移动、非均匀代价的网格中直接套用曼哈顿距离                               | 曼哈顿距离在这种场景下会**高估**真实成本，破坏可采纳性，必须按实际代价结构重新设计启发式函数（如例题 4 的"对角线+直线"组合公式）                                    |
| 认为深度优先搜索一定比宽度优先搜索差                                       | 当存在多条解路径时，DFS 有"运气好"先碰到某条通往解的路径、从而更快找到（某个，不一定最优的）解的可能；DFS 的空间复杂度优势（线性 $O(bm)$）也是其重要优点                    |
| 认为迭代加深搜索(IDS)因为重复搜索浅层节点而效率低于BFS                          | IDS 的渐进时间复杂度 $O(b^d)$ 实际上优于 BFS 的 $O(b^{d+1})$，因为 IDS 不需要像 BFS 一样扩展完目标所在层的**全部**节点才能确认最优解                |

## 9. 公式速查表

**通用评价函数**： $$f(n) = g(n) + h(n)$$

**可采纳性（Admissibility）**： $$h(n) \leq h^*(n) \quad \text{对所有节点 } n \text{ 成立}$$

**一致性/单调性（Consistency）**： $$h(n_1) \leq c(n_1\to n_2) + h(n_2)$$

**关系**：一致性 $\Rightarrow$ 可采纳性（反之不一定成立）

**支配关系**：若 $h_1(n)\leq h_2(n)$（对所有非目标节点 $n$）且二者均可采纳，则称 $h_2$ 支配 $h_1$，A* 用 $h_2$ 扩展的节点数不多于用 $h_1$。

**盲目搜索复杂度总表**：

|算法|时间复杂度|空间复杂度|
|---|---|---|
|BFS|$O(b^{d+1})$|$O(b^{d+1})$|
|DFS|$O(b^m)$|$O(bm)$|
|UCS|$O(b^{C^*/s+1})$|$O(b^{C^*/s+1})$|
|DLS|$O(b^L)$|$O(bL)$|
|IDS|$O(b^d)$|$O(bd)$|
|双向搜索（BFS+BFS）|$O(b^{d/2})$|$O(b^{d/2})$|

**A* 的时间/空间复杂度下界**：当 $h(n)=0$ 时退化为 UCS，因此 UCS 的复杂度下界同样适用于 A*——除非找到足够好的启发式函数，否则 A* 仍可能是指数复杂度。

**8-数码常用启发式函数**：

- Misplaced Tiles：$h(n) = $ 与目标不同位置的方块数
- Manhattan Distance：$h(n) = \sum$（各方块到目标位置的曼哈顿距离）

**对角线移动网格启发式**（水平/垂直代价 $D$，对角线代价 $D_2$）： $$h(n) = D\cdot(a-b) + D_2\cdot b, \quad a=\max(\Delta x,\Delta y),\ b=\min(\Delta x,\Delta y)$$
