## 第8讲 搜索算法

### 爬山法 (Hill-Climbing)

- 局部搜索，每次选邻域最优后继
- ⚠️ **缺陷**：陷入局部最优，无法保证全局最优

### 模拟退火 (Simulated Annealing)

> 核心：Metropolis 准则——以一定概率接受恶化解，温度高时概率大，温度低时趋于贪心。

$$\boxed{P(\text{接受恶化解}) = e^{-(E_{\text{new}} - E_{\text{old}}) / T}}$$

**降温调度**：$t_{k+1} = \alpha \cdot t_k$，$\alpha \in (0.8, 0.999)$

**特点**：算法通用性强，适用于 0-1 背包、TSP 等 NP-hard 问题；需多次运行取最优。

### 遗传算法 (GA)

> 模拟自然选择：种群 → 选择 → 交叉 → 变异 → 新种群

| 步骤 | 要点 |
|------|------|
| **编码** | 二进制 / 格雷码 / 实数 / 排列编码（TSP） |
| **选择** | 轮盘赌：$P_{si} = f_i / \sum f_j$；锦标赛选择 |
| **交叉** | 单点/两点交叉；TSP 专用：PMX、OX、CX |
| **变异** | 小概率翻转基因；TSP：交换/倒位/插入变异 |

**适应度函数**：
- 最大化：$Fit(f) = f(x)$
- 最小化：$Fit(f) = 1/f(x)$ 或 $C_{max} - f(x)$

**模式定理**：群体规模 M 可生成和检测 $O(M^3)$ 个模式。

**欺骗问题**：
- 过早收敛 → 降低超级个体竞争力（适应度缩放）
- 停滞现象 → 改变原始适应值比例关系

**适应度尺度变换**：
- 线性：$f' = af + b$
- 幂函数：$f' = f^K$
- 指数：$f' = e^{-af}$

### TSP 数学建模

$$\min \sum_{i=1}^{n} \sum_{j=1}^{n} d_{ij}x_{ij}, \quad x_{ij} \in \{0,1\}$$

约束：每城市出度=1, 入度=1, 无子回路。

> 💡 **GA vs 传统方法**：GA 是种群→种群的多方向搜索，基于概率转移，不易陷入局部最优。

## 第9讲 朴素贝叶斯

### 概率基础

| 公式 | 表达式 |
|------|--------|
| 条件概率 | $P(B\|A) = \frac{P(A \cap B)}{P(A)}$ |
| 全概率 | $P(A) = \sum_i P(A\|B_i)P(B_i)$ |
| 链式规则 | $P(A_1...A_n) = P(A_1\|A_2...A_n)...P(A_n)$ |
| 独立性 | $P(A \cap B) = P(A)P(B)$ |
| 条件独立 | $P(B \cap C\|A) = P(B\|A)P(C\|A)$ |

### 贝叶斯定理

$$\boxed{P(Y|X) = \frac{P(X|Y) \cdot P(Y)}{P(X)}}$$

- $P(Y)$：先验 | $P(Y|X)$：后验 | $\frac{P(X|Y)}{P(X)}$：似然比
- 将"因果方向"反转为"诊断方向"

### 朴素贝叶斯分类器

$$\boxed{\hat{C} = \arg\max_C P(C) \prod_{i=1}^{n} P(A_i|C)}$$

**朴素假设**：给定类别，各属性条件独立。

**参数估计**：
- 离散属性：$P(A_i|C_k) = n_{ik} / n_k$（频率计数）
- 连续属性：高斯分布 $P(A_i|C_k) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-(x-\mu)^2/2\sigma^2}$

**平滑处理**：
- Laplace：$P(A_i|C_k) = \frac{n_{ik}+1}{n_k+|Dom[A_i]|}$
- m-估计：$P(A_i|C_k) = \frac{n_{ik}+mp}{n_k+m}$

### 贝叶斯网络 (BBN)

利用条件独立性做概率推理，信念传播 (BP) 算法。每个节点给定父节点后，条件独立于非后代节点。

## 第10讲 决策树

### 核心算法演进

| 算法 | 年份 | 准则 | 树结构 | 连续属性 |
|------|------|------|--------|----------|
| CLS | 1966 | 无规定 | 多叉 | ✗ |
| ID3 | 1979 | **信息增益** ↑ | 多叉 | ✗ |
| C4.5 | 1993 | **增益率** ↑ | 多叉 | ✓ |
| CART | 1984 | **基尼指数** ↓ | **二叉树** | ✓ |

### 关键公式

$$\boxed{\text{熵：} H(D) = -\sum_{c} p_c \log_2 p_c}$$

$$\boxed{\text{条件熵：} H(D|A) = \sum_{v} \frac{|D_v|}{|D|} H(D_v)}$$

$$\boxed{\text{信息增益 (ID3)：} g(D,A) = H(D) - H(D|A)}$$

$$\boxed{\text{增益率 (C4.5)：} \text{GainRatio} = \frac{g(D,A)}{\text{SplitInfo}_A(D)}}$$

$$\text{其中 } \text{SplitInfo}_A(D) = -\sum_{j=1}^{v} \frac{|D_j|}{|D|} \log_2\frac{|D_j|}{|D|}$$

$$\boxed{\text{基尼指数 (CART)：} \text{gini}(D) = 1 - \sum_{c} p_c^2}$$

$$\boxed{\text{分裂基尼：} \text{gini}_{\text{split}} = \frac{N_1}{N}\text{gini}(D_1) + \frac{N_2}{N}\text{gini}(D_2)}$$

> ⚠️ **ID3 偏向多值属性** → C4.5 用增益率（除以 SplitInfo）修正。
> ⚠️ **CART 必做二元划分**，多值属性需枚举所有二元分割方案。

### 连续属性离散化

排序后取相邻值中点作为候选分裂点：$\frac{a_i + a_{i+1}}{2}$

## 第11讲 机器学习总论

### ML 三要素

$$\boxed{\text{Model} + \text{Loss} + \text{Optimization}}$$

> 本质：从数据中自动寻找函数映射 $y = f(x)$

### 三大任务

| 类型 | 输出 | 举例 |
|------|------|------|
| 回归 | 连续数值 | 房价预测 |
| 分类 | 离散类别 | 垃圾邮件 |
| 生成 | 数据本身 | ChatGPT |

### 四大范式

| 范式 | 数据标签 | 特点 |
|------|----------|------|
| 监督学习 | 全有 $(x,y)$ | 分类/回归 |
| 半监督学习 | 部分有 | 利用无标签数据 |
| 无监督学习 | 无 | 聚类/降维 |
| 强化学习 | 奖励信号 | 序列决策 |

### 核心概念
- **泛化**：模型在未见数据上的表现 → 真正目标
- **过拟合**：训练好但测试差 → 用正则化限制模型复杂度
- **i.i.d**：训练集和测试集独立同分布
- **深度学习 ⊂ 机器学习 ⊂ AI**
### 评价指标

| 指标 | 含义 |
|------|------|
| Accuracy | 预测正确比例 |
| Precision | 预测为正中真正正的占比 |
| Recall | 真正正中被找出的占比 |
| F1 | Precision 和 Recall 调和平均 |

> ⚠️ 类别不均衡时 Accuracy 无效（如 99% 正常，全预测正常 → Accuracy = 99% 但无意义）。

## 第12讲 聚类算法

### 两种范式

| 范式 | 特点 | 代表算法 |
|------|------|----------|
| 分割式 | 非重叠子集，需指定 K | K-means |
| 层次聚类 | 嵌套树状结构，不指定 K | AGNES (凝聚), DIANA (分裂) |

### 距离度量

$$\boxed{L_p(x_i, x_j) = \left( \sum_{l=1}^n |x_i^{(l)} - x_j^{(l)}|^p \right)^{1/p}}$$

| p | 名称 | 特点 |
|---|------|------|
| 1 | 曼哈顿 (L1) | 对异常值较稳健 |
| 2 | 欧氏 (L2) | 最常用，对尺度敏感 |
| ∞ | 切比雪夫 | 取最大维度差 |

**余弦距离**（高维文本）：$\cos Dist = 1 - \frac{x_1 \cdot x_2}{\|x_1\| \|x_2\|}$

### K-means

$$\boxed{SSE = \sum_{i=1}^{K} \sum_{x \in C_i} \|x - m_i\|^2}$$

- 复杂度：$O(n \cdot K \cdot I \cdot d)$
- ⚠️ 易陷入局部最优（取决于初始质心）
- **改进**：K-means++（概率选远点）、K-means||（大规模优化）
- **选 K**：肘部法则（SSE-K 曲线拐点）、轮廓系数

**K-means 局限**：不同大小/密度/非球形数据失效、需预设 K、对离群点敏感。

### DBSCAN

> 基于密度的聚类，两个参数：$\varepsilon$（邻域半径）、MinPts

| 点类型 | 定义 |
|--------|------|
| 核心点 | $\varepsilon$ 邻域内 ≥ MinPts 个点 |
| 边界点 | < MinPts，但在某核心点邻域内 |
| 噪声点 | 既非核心也非边界 |

- ✅ 可发现任意形状簇，自动识别噪声
- ❌ 对 $\varepsilon$ / MinPts 敏感，高维失效

### K-means vs DBSCAN

| | K-means | DBSCAN |
|---|---|---|
| 簇形状 | 球形 | 任意形状 |
| 需预设 K | ✅ | ❌ |
| 噪声 | 敏感 | 自动剔除 |

### 评估指标

- **外部**：RI, NMI（需真实标签）
- **内部**：SSE（越小越好）、轮廓系数（[-1,1]，越大越好）
- $SST = SSE + SSB$（总离差 = 簇内 + 簇间）

## 第13讲 人工神经网络

### MP 神经元

$$\boxed{z = g\left(\sum_{i=1}^{n} w_i a_i\right)}, \quad g = \text{sgn}$$

> ⚠️ MP 模型：权重人工预设，不可学习。

### 感知机 (Perceptron)

$$\boxed{\hat{y} = \text{sgn}(\mathbf{w} \cdot \mathbf{a})}$$

$$\boxed{\Delta W = \eta (y - \hat{y}) \cdot \mathbf{a}}$$

> ⚠️ **致命缺陷**：单层感知机无法解决 XOR（线性不可分）。

### 多层感知机 (MLP)

$$\boxed{\mathbf{a} = g_1(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1)}$$
$$\boxed{\mathbf{z} = g_2(\mathbf{W}_2 \mathbf{a} + \mathbf{b}_2)}$$

**通用近似定理**：单隐藏层 + 足够多节点 → 可逼近任意连续函数。

> 🔑 非线性激活函数是 MLP 能力的核心来源——否则多层 = 单层。

### 激活函数对比

| 函数 | 公式 | 导数 | 梯度消失 |
|------|------|------|----------|
| sgn | $\pm 1$ | 不可微 | — |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | $\sigma(x)(1-\sigma(x))$ ≤ 0.25 | ⚠️ 高 |
| tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | ≤ 1 | 中等 |
| **ReLU** | $\max(0,x)$ | 0 或 1 | ✅ 无 |

### 训练 = 前向传播 + 反向传播

**损失（MSE）**：
$$\boxed{\mathcal{L} = \frac{1}{2}(y - \hat{y})^2}$$

**参数更新（梯度下降）**：
$$\boxed{\mathbf{w} \leftarrow \mathbf{w} - \alpha \frac{\partial \mathcal{L}}{\partial \mathbf{w}}}$$

**反向传播** = 链式法则从输出层到输入层逐层计算梯度：
$$\frac{\partial \mathcal{L}}{\partial w_5} = \frac{\partial \mathcal{L}}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial net} \cdot \frac{\partial net}{\partial w_5}$$

> ⚠️ **隐藏层多路径梯度要相加**：$\frac{\partial E_{total}}{\partial h_1} = \frac{\partial E_{o1}}{\partial h_1} + \frac{\partial E_{o2}}{\partial h_1}$

### 梯度消失

Sigmoid 导数 ≤ 0.25 → L 层网络第 1 层梯度 ≈ $(0.25)^{L-1}$ 倍 → 指数衰减。

**解决方案**：ReLU（正区间梯度恒为 1）、BatchNorm、残差连接。

## 第14讲 CNN & RNN & LSTM

### CNN

> 三大设计依据：局部感受野 + 空间不变性 + 下采样不丢信息

**特征图维度公式**：
$$\boxed{h = \left\lfloor \frac{n_h - f + 2p}{s} + 1 \right\rfloor}$$

- $f$：卷积核大小 | $s$：步长 | $p$：填充（Padding）

**多通道**：卷积核深度 = 输入通道数；$K$ 个核 → 输出深度 = $K$。

**池化 (Max Pooling)**：下采样，减少参数，增加平移不变性。

**CNN 的两大约束**：
- 稀疏连接（局部感受野）
- 权重共享（同一卷积核滑动）

> ✅ CNN 参数量远少于全连接（如 $224^2 \times 3 \times 1000 \approx 1.5 \times 10^8$ vs $3^2 \times 3 \times 64 = 1728$）

### RNN

$$\boxed{s_t = \tanh(U x_t + W s_{t-1})}$$
$$\boxed{\hat{y}_t = \text{softmax}(V s_t)}$$

- $U, W, V$：所有时间步**共享**的权重矩阵
- 训练：BPTT（随时间反向传播）
- ⚠️ **梯度消失**：$\frac{\partial s_j}{\partial s_{j-1}}$ 连乘导致指数衰减 → 无法学长距离依赖
- 梯度爆炸 → 梯度裁剪

### LSTM

> 通过三个**门** + 记忆单元解决 RNN 的梯度消失

**核心公式**：
$$\boxed{c' = g(z) \cdot f(z_i) + c \cdot f(z_f)}$$
$$\boxed{a = h(c') \cdot f(z_o)}$$

| 门 | 符号 | 作用 |
|----|------|------|
| 输入门 | $z_i$ | 写入多少新信息 |
| 遗忘门 | $z_f$ | 保留多少旧记忆（=1 全保留） |
| 输出门 | $z_o$ | 输出多少 |

> 🔑 LSTM 记忆单元通过**加法**更新 → 梯度可直接流动，不衰减。参数量是 RNN 的 4 倍。

### 深度学习可解释性

- **局部解释**：梯度显著性图 $\left|\frac{\partial y_k}{\partial x_n}\right|$，高亮关键区域
- **全局解释**：$x^* = \arg\max_x y_i$，找理想输入

## 第15讲 Transformer

### 词嵌入 (Word Embedding)

> One-Hot 向量正交（相似度恒为 0）→ 词向量：低维稠密，语义相近则距离近

**Word2Vec 预测函数**：
$$\boxed{P(o \mid c) = \frac{\exp(u_o^T v_c)}{\sum_{w \in V} \exp(u_w^T v_c)}}$$

| 变体 | 方向 | 特点 |
|------|------|------|
| Skip-Gram | 中心词 → 上下文 | 稀有词好，需更多数据 |
| CBOW | 上下文 → 中心词 | 训练快，高频词好 |

**词语类比**：$\text{king} - \text{man} + \text{woman} \approx \text{queen}$

**优化**：负采样（O(K) 替代 O(|V|)）、层次 Softmax

**GloVe**：全局共现矩阵 → 捕捉窗口外的关系  
**FastText**：子词嵌入 → 处理 OOV，捕捉形态信息

### Seq2Seq

编码器读取源序列 → 压缩为上下文向量 $c$ → 解码器逐词生成。

> ⚠️ **信息瓶颈**：所有信息压缩进一个固定向量 $c$，长句丢失严重。

### 注意力机制 (Attention)

$$\boxed{\alpha^t = \text{softmax}(e^t)}, \quad e_i = s_t^T h_i$$
$$\boxed{a^t = \sum_{i=1}^{N} \alpha_i^t h_i}$$

**通用定义**：
$$\boxed{\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V}$$

> 🔑 除以 $\sqrt{d_k}$：防止点积方差随维度增大导致 softmax 饱和。

### Transformer 核心组件

| 组件 | 作用 |
|------|------|
| **自注意力** | 序列内每对词直接交互，Q/K/V 同源 |
| **多头注意力** | $h$ 个头并行，每头维度 $d/h$，多视角 |
| **位置编码** | 注入顺序信息（自注意力无顺序感） |
| **残差连接** | $x_l = F(x_{l-1}) + x_{l-1}$，防梯度消失 |
| **层归一化** | 特征维度归一化，不依赖 batch |
| **掩码注意力** | 解码器防止看到未来词（下三角掩码） |

**编码器层**：多头自注意力 → Add&Norm → FFN → Add&Norm  
**解码器层**：掩码多头自注意力 → Add&Norm → Cross-Attention → Add&Norm → FFN → Add&Norm

> 💡 **Transformer 优势**：任意两词 O(1) 步直达，全并行计算，GPU 效率极高。

## 第16讲 强化学习

### MDP 五元组

$$\boxed{(\mathcal{S}, \mathcal{A}, p, R, \gamma)}$$

- $p(s'|s,a)$：状态转移概率
- $R(s,a,s')$：奖励函数
- $\gamma \in [0,1]$：折扣因子

**马尔可夫性质**：下一状态只取决于当前状态。

### 核心公式

$$\boxed{G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}} \quad \text{(回报)}$$

$$\boxed{V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]} \quad \text{(状态价值)}$$

$$\boxed{Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t=s, A_t=a]} \quad \text{(动作价值)}$$

$$V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)$$

### 贝尔曼方程

$$\boxed{V^\pi(s) = \sum_a \pi(a|s)\left[\mathcal{R}^a_s + \gamma \sum_{s'} \mathcal{P}^a_{ss'} V^\pi(s')\right]}$$

$$\boxed{Q^\pi(s,a) = \mathcal{R}^a_s + \gamma \sum_{s'} \mathcal{P}^a_{ss'} \sum_{a'} \pi(a'|s') Q^\pi(s',a')}$$

### 贝尔曼最优方程

$$\boxed{V^*(s) = \max_a\left(\mathcal{R}^a_s + \gamma \sum_{s'} \mathcal{P}^a_{ss'} V^*(s')\right)}$$

$$\boxed{Q^*(s,a) = \mathcal{R}^a_s + \gamma \sum_{s'} \mathcal{P}^a_{ss'} \max_{a'} Q^*(s',a')}$$

### 表格型 RL 方法

| 方法 | 类型 | 更新公式 |
|------|------|----------|
| 策略评估 | 有模型 | $v_{k+1}(s) = \sum_a \pi(a\|s)[\mathcal{R} + \gamma\sum_{s'}P v_k(s')]$ |
| 值迭代 | 有模型 | $v_{k+1}(s) = \max_a[\mathcal{R} + \gamma\sum_{s'}P v_k(s')]$ |
| **MC** | 无模型 | $V(s) \approx \frac{1}{N}\sum G(s)$，需完整 episode |
| **TD** | 无模型 | $V(S_t) \leftarrow V(S_t) + \alpha(R_{t+1}+\gamma V(S_{t+1}) - V(S_t))$ |

### MC vs TD vs DP

| | DP | MC | TD |
|---|---|---|---|
| 需要模型 | ✅ | ❌ | ❌ |
| 更新时机 | 基于模型 | Episode 结束 | **每步都可** |
| 偏差 | 无偏 | 无偏 | **有偏** |
| 方差 | 低 | 高 | **低** |

### SARSA vs Q-Learning

$$\boxed{\text{SARSA: } Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)]}$$

$$\boxed{\text{Q-Learning: } Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha[R_{t+1}+\gamma \max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)]}$$

| | SARSA | Q-Learning |
|---|---|---|
| 策略类型 | **同策略** (On-Policy) | **异策略** (Off-Policy) |
| 目标值 | 实际执行的动作 | **max** 最优动作 |
| 行为 | 保守（含探索代价） | 激进（假设最优） |

### ε-贪心策略

$$\pi'(a|s) = \begin{cases} 1-\epsilon + \epsilon/|\mathcal{A}| & a = \arg\max Q \\ \epsilon/|\mathcal{A}| & \text{otherwise} \end{cases}$$

### DQN 系列

| 改进 | 解决的问题 |
|------|-----------|
| **经验回放** | 打破样本时间相关性 |
| **目标网络** | 固定训练目标防震荡（周期复制参数） |
| **Double DQN** | Q 值高估（选动作与估值分离） |
| **Dueling DQN** | 分解 $Q(s,a) = V(s) + A(s,a) - \frac{1}{\|\mathcal{A}\|}\sum A$ |
| **优先经验回放** | TD 误差大的样本优先采样（需重要性采样修正） |

### 策略梯度

$$\boxed{\nabla_\theta J(\theta) = \mathbb{E}_\tau\left[\sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G(\tau)\right]}$$

- **基线减方差**：减去 $b = \frac{1}{N}\sum R(\tau_i)$，期望不变但方差减小

### Actor-Critic (A2C)

$$\boxed{\nabla_\theta J(\theta) \approx \frac{1}{N} \sum_i \sum_t \nabla_\theta \log \pi_\theta(a_t^i|s_t^i) \cdot \hat{A}^\pi(s_t^i, a_t^i)}$$

**优势函数**（TD 残差）：
$$\boxed{\hat{A}^\pi(s_t, a_t) \approx r + \gamma \hat{V}^\pi(s_{t+1}) - \hat{V}^\pi(s_t)}$$

> Actor（策略网络）负责决策，Critic（价值网络）负责评估。A2C = Actor-Critic + 优势函数。

### AlphaGo

| 阶段 | 方法 |
|------|------|
| 训练 1 | 行为克隆（监督学习模仿人类棋谱） |
| 训练 2 | 策略梯度 RL（自我对弈，REINFORCE） |
| 训练 3 | 训练价值网络 $v(s;w)$ |
| 执行 | **MCTS**（选择→扩展→评估→回传）× 数千次 |

**AlphaGo Zero**：纯自我对弈，不用人类数据，共享主干网络，100:0 击败 AlphaGo。

### RL 算法关系

```
DP (有模型) ──→ MC (采样完整轨迹) ──→ TD (自举+采样)
                                          │
                              ┌───────────┴───────────┐
                           SARSA (同策略)        Q-Learning (异策略)
                              │                       │
                              ▼                       ▼
                         表格型 RL ──────────→ DQN (深度+值函数)
                                                    │
                                           Actor-Critic (深度+值+策略)
                                                    │
                                               AlphaGo (MCTS)
```

### DQN 改进链

```
Classic DQN → Double DQN (解高估) → Dueling DQN (分解V+A)
    │              │                      │
    └── 经验回放 + 目标网络 ──────────────┘
                    │
              Rainbow DQN (整合全部改进)
```

> [!summary] 核心思想总结
> 1. **搜索**：启发式搜索用概率跳出局部最优（SA、GA）
> 2. **概率推理**：贝叶斯定理反转因果方向，朴素假设简化计算
> 3. **决策树**：从 CLS 到 C4.5/CART，本质是选最优属性递归划分
> 4. **机器学习**：$f(x)$ = Model + Loss + Optimizer，核心是泛化
> 5. **聚类**：K-means 简单高效但要预设 K；DBSCAN 发现任意形状
> 6. **神经网络**：MP → 感知机 → MLP + BP → 梯度消失 → ReLU 拯救
> 7. **CNN/RNN/LSTM**：卷积用权重共享降参；LSTM 用三门控解长程依赖
> 8. **Transformer**：自注意力 O(1) 交互 + 位置编码 + 多头 + 残差 + 并行
> 9. **强化学习**：MDP → Bellman → MC/TD → Q-Learning → DQN → Policy Gradient → AC/A2C
