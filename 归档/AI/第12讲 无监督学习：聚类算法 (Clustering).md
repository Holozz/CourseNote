> 对应课程：人工智能（专业必修）第六章 — 无监督（聚类）算法  
> 核心思想：在无标签数据中发现天然的分组结构，使得**组内相似，组间差异**。
## 📌 1. 什么是聚类分析？

> **定义**：寻找一组对象，使得同一组（簇）内的对象彼此相似/相关，而不同组的对象彼此不同/不相关。

- **无监督学习**：训练数据没有标签 \(y\)，只有特征 \(x\)。
- **目标**：挖掘数据内在的分布规律、隐藏结构。

### 典型应用

| 领域 | 应用举例 |
| :--- | :--- |
| 文本挖掘 | 将相关文档分组（新闻聚类） |
| 生物信息学 | 将具有相似功能的基因/蛋白质聚类 |
| 金融 | 将价格波动相似的股票分组 |
| 图像处理 | 图像分割（每个区域一个簇） |
| 社交网络 | 发现社区结构 |
| 市场营销 | 客户细分（市场划分） |

## 🧩 2. 什么不是聚类？

- **有监督分类**：有类别标签，属于监督学习。
- **简单的分段**：例如按姓氏字母顺序分组，不基于相似性。

## 🎯 3. 簇的概念：二义性与类型

### 3.1 簇的二义性

同一组数据，不同视角下可以有不同数量的簇（2个、4个、6个…）—— **没有绝对正确的答案，取决于分析目的**。

### 3.2 簇的主要类型

| 类型 | 定义 | 图示特征 |
| :--- | :--- | :--- |
| **Well‑separated (分离良好)** | 簇内任意点与同簇其他点的距离都小于到任何异簇点的距离 | 明显分离的团块 |
| **Center‑based (基于中心)** | 每个点更靠近本簇中心而非其他簇中心 | 球形/椭球形，有质心 |
| **Contiguous (基于邻近)** | 簇由邻近点连接形成（图连通分量） | 链状、不规则形状 |
| **Density‑based (基于密度)** | 簇是高密度区域，被低密度区域分隔 | 任意形状，可含噪声 |
| **Conceptual (概念)** | 共享某种属性或概念 | 可重叠，无几何约束 |
| **Objective function (目标函数)** | 通过优化目标函数（如最小化SSE）定义 | 数学形式，不依赖几何直观 |

> ⚠️ **易错点**：很多教材默认“簇”就是球形且分离的，但真实数据可能是任意形状（如月牙形、环形），此时K‑means会失效。

## 🔀 4. 聚类算法的两大范式

| 范式 | 特点 | 是否需要 K | 代表算法 |
| :--- | :--- | :--- | :--- |
| **分割式聚类 (Partitional)** | 将数据划分为**非重叠**子集，每个点属于一个簇 | 需要指定簇数量 K | K‑means, K‑medoids |
| **层次聚类 (Hierarchical)** | 生成嵌套的树状结构（树状图），不要求指定 K | 不需要 | 凝聚层次聚类（AGNES）、分裂层次聚类（DIANA） |

- **层次聚类流程**（凝聚式）：
  1. 每个点自成一簇
  2. 重复：找到距离最近的两个簇 → 合并
  3. 直到所有点合并成一个簇

## 📐 5. 距离/相似度度量

聚类的基础是度量样本间的**距离**（不相似度）或**相似度**。

### 常用距离公式
$L_p(x_i, x_j) = \left( \sum_{l=1}^n |x_i^{(l)} - x_j^{(l)}|^p \right)^{1/p}$

| p 值             | 名称         | 公式                                          | 特点           |
| :-------------- | :--------- | :------------------------------------------ | :----------- |
| \($p=1$\)       | 曼哈顿距离 (L1) | \($\sum x_i^{(l)} - x_j^{(l)}$              | 街区距离，对异常值较稳健 |
| \($p=2$\)       | 欧氏距离 (L2)  | \($\sqrt{\sum (x_i^{(l)} - x_j^{(l)})^2}$\) | 最常用，对尺度敏感    |
| \($p=\infty$\)  | 切比雪夫距离     | \($\max_lx_i^{(l)} - x_j^{(l)}$             | 国际象棋中王移动距离   |
| \($p=-\infty$\) | 极小值距离      | \($\min_lx_i^{(l)} - x_j^{(l)}$             | 罕见           |

### 余弦距离（用于高维稀疏向量，如文本）

$\cos \text{Distance} = 1 - \cos(\mathbf{x}_1, \mathbf{x}_2) = 1 - \frac{\mathbf{x}_1 \cdot \mathbf{x}_2}{\|\mathbf{x}_1\|_2 \|\mathbf{x}_2\|_2}$

> **注意**：余弦相似度看方向，不受向量模长影响；余弦距离取值 [0,2]。

## 🔵 6. K‑means 聚类算法（分割式，基于中心）

### 6.1 算法流程

```
输入：样本集 D，簇数 K，最大迭代次数
输出：K 个簇

1. 随机选择 K 个样本作为初始质心 (centroids)
2. 重复：
   2.1 将每个样本分配到最近的质心（距离度量通常为欧氏距离）
   2.2 更新每个簇的质心为簇内所有点的均值
3. 直到质心不再变化或达到迭代上限
```

### 6.2 关键细节

- **复杂度**：\($O(n \cdot K \cdot I \cdot d)$\)  
  \(n\): 样本数, \(K\): 簇数, \(I\): 迭代次数, \(d\): 特征维度
- **收敛性**：保证收敛，但可能收敛到**局部最优**（取决于初始质心）。
- **停止条件**：通常“质心变化很小”或“只有少量点改变归属”。

### 6.3 如何选择 K？—— 肘部法则 (Elbow Method)

- 计算不同 K 值下的 **SSE** (Sum of Squared Errors)：
	$SSE = \sum_{i=1}^K \sum_{x \in C_i} \|x - m_i\|^2$
- 绘制 K vs SSE 曲线，寻找“手肘”拐点 —— SSE 下降速度变缓的点。

> ⚠️ **注意**：肘部法则有时不够明显，可结合轮廓系数 (Silhouette) 等其他指标。

### 6.4 初始质心的重要性与改进方法

- **问题**：随机初始质心可能导致次优解，尤其当 K 较大时（例如 K=10，每个真簇选一个质心的概率仅约 0.00036）。
- **改进策略**：
  - **多次运行**：选择 SSE 最小的结果。
  - **二分 K‑means**：迭代地分裂簇，直到达到 K 个。
  - **K‑means++**：概率化选择相距较远的初始质心。
  - **K‑means||**（可伸缩）：每轮采样多个点，适合大规模数据。

#### 🔹 K‑means++ 初始化步骤
1. 随机选第一个质心 \(x_1\)。
2. 对 \(i = 2\) 到 \(K\)：
   - 对每个点 \(x\)，计算 \(D(x)\) = 到已选最近质心的距离。
   - 按概率 \($\frac{D(x)^2}{\sum_x D(x)^2}$\) 采样下一个质心。
   - **直观**：让质心尽可能分散，避免扎堆。

#### 🔹 K‑means||
- 每轮采样 **多个** 候选点（过采样因子），重复多次，然后对候选点再聚类得到 K 个质心。
- 减少迭代次数，适合大规模数据（K=50 时，迭代次数：随机 167 次 → K‑means++ 42 次 → K‑means|| 28 次）。

### 6.5 K‑means 的局限性（⚠️ 高频考点）

| 问题 | 原因 | 图示说明 |
| :--- | :--- | :--- |
| **不同大小** | 质心偏向大簇，小簇被吞并 | ❌ K‑means 失效 |
| **不同密度** | 基于欧氏距离，稀疏区域难形成簇 | ❌ K‑means 失效 |
| **非球形** | 算法假设球形/高斯分布 | ❌ 月牙形、环形数据无效 |
| **对离群点敏感** | 离群点会拉偏质心 | ❌ 需预处理 |
| **必须预设 K** | 实际不知道真实簇数 | ⚠️ 需肘部法或领域知识 |

> **解决思路**：使用 DBSCAN 等密度聚类，或对非球形数据先用核技巧映射。

### 6.6 K‑means 例题（手动计算）

**题目**：给定 8 个点：  
(1,2), (2,4), (1,9), (6,5), (4,2), (7,2), (8,2), (4,3)  
设 K=2，初始质心为 (1,2) 和 (8,2)，使用**曼哈顿距离**（L1）。  
求 **一次迭代后** 的簇划分及新质心坐标。

**解答**：

计算每个点到两个质心的 L1 距离：

| 点     | 到 (1,2) | 到 (8,2) | 归属  |
| :---- | ------- | ------- | --- |
| (1,2) |         |         | 簇1  |
| (2,4) | =1+2=3  | =6+2=8  | 簇1  |
| (1,9) | =0+7=7  | =7+7=14 | 簇1  |
| (6,5) | =5+3=8  | =2+3=5  | 簇2  |
| (4,2) | =3+0=3  | =4+0=4  | 簇1  |
| (7,2) | =6+0=6  | =1+0=1  | 簇2  |
| (8,2) | =7+0=7  | =0+0=0  | 簇2  |
| (4,3) | =3+1=4  | =4+1=5  | 簇1  |

- **簇1** 的点： (1,2), (2,4), (1,9), (4,2), (4,3) 共 5 个点
- **簇2** 的点： (6,5), (7,2), (8,2) 共 3 个点

**新质心**（取各簇点的均值，注意此处用 L1 距离但质心仍用算术平均）：
- 簇1 质心 = $\left( \frac{1+2+1+4+4}{5},\ \frac{2+4+9+2+3}{5} \right) = (12/5,\ 20/5) = (2.4, 4)$
- 簇2 质心 =  $\left( \frac{6+7+8}{3},\ \frac{5+2+2}{3} \right) = (21/3,\ 9/3) = (7, 3)$ 

> 📌 **注意**：虽然距离用 L1，但质心更新仍使用**坐标均值**（L2 意义下的几何中心）。若要求严格 L1 中心（中位数），则应使用 K‑medoids。

## 🔴 7. DBSCAN（基于密度的聚类）

### 7.1 核心概念

| 参数 | 含义 | 典型设置 |
| :--- | :--- | :--- |
| **Eps (ε)** | 邻域半径 | 由 k‑距离图的手肘点决定 |
| **MinPts** | 半径内最少点数 | 通常取 4 或 2×维度 |

**点类别**：

- **核心点 (Core point)**：在 ε 半径内包含 ≥ MinPts 个点（包括自身）。
- **边界点 (Border point)**：在 ε 半径内点数 < MinPts，但落在某个核心点的邻域内。
- **噪声点 (Noise point)**：既不是核心也不是边界。

### 7.2 DBSCAN 算法步骤

1. 标记所有点为核心点、边界点、噪声点。
2. 删除噪声点（不参与聚类）。
3. 在**核心点**之间，若距离 ≤ ε，则连接它们（形成连通图）。
4. 每个连通分量成为一个簇。
5. 将边界点分配到其关联的核心点所属的簇。

### 7.3 复杂度与理论澄清

- 原始论文声称平均复杂度 \(O(m \log m)\)（借助空间索引）。
- **2015 SIGMOD 最佳论文**（《DBSCAN Revisited》）指出：
  - 对于 \(d \ge 3\)，DBSCAN 无法达到 \(O(m \log m)\)，最坏情况需 \(\Omega(m^{4/3})\)。
  - 提出近似 DBSCAN 替代方案。

- 空间复杂度：\(O(m)\)，仅存储标签和点类型。

### 7.4 DBSCAN 优缺点

| 优点 | 缺点 |
| :--- | :--- |
| ✅ 不需要预先指定 K | ❌ 对参数 ε, MinPts 敏感 |
| ✅ 能发现任意形状的簇 | ❌ 密度差异大时效果差 |
| ✅ 能识别并剔除噪声点 | ❌ 高维数据失效（维度诅咒） |
| ✅ 对离群点鲁棒 | ❌ 计算复杂度较高（高维且无索引） |

### 7.5 参数选择 —— k‑距离图

- 对每个点，计算到其第 k 个最近邻的距离（k = MinPts）。
- 按距离从小到大排序绘图。
- 寻找“膝盖”位置的纵坐标作为 ε。

## ⚖️ 8. K‑means vs DBSCAN 对比总结

| 维度 | K‑means | DBSCAN |
| :--- | :--- | :--- |
| **簇形状** | 球形/高斯分布 | 任意形状 |
| **需要 K** | 是（需预设） | 否（由密度自动发现） |
| **对噪声处理** | 敏感，噪声影响质心 | 直接识别并剔除噪声 |
| **密度差异** | 效果差 | 密度差异大时效果差 |
| **高维数据** | 可处理（如文本） | 欧氏距离失效，表现差 |
| **参数** | K | ε, MinPts |
| **输出** | 每个点属于一个簇 | 簇 + 噪声点 |

## 📊 9. 簇有效性评估 (Cluster Validation)

### 9.1 为什么评估？
- 比较不同算法或同一算法不同参数的表现。
- 确定“正确”的簇数量。
- 但“簇”有一定主观性，需结合指标。
### 9.2 评估指标分类

| 类别       | 说明                    | 典型指标                       |
| :------- | :-------------------- | :------------------------- |
| **外部指标** | 与真实标签（ground truth）比较 | 熵 (Entropy)、纯度、RI、NMI      |
| **内部指标** | 仅使用数据本身，不依赖外部标签       | SSE、轮廓系数 (Silhouette)、DB指数 |
| **相对指标** | 比较两个聚类结果              | 通过内部/外部指标对比                |

### 9.3 内部指标详解：SSE 与 凝聚度/分离度

**总平方和分解**（对于 K‑means 目标函数）：

\[
SST = SSE + SSB
\]
- \($SST = \sum_{j=1}^K \sum_{x \in C_j} \|x - m\|^2$\) （总离差平方和，常数）
- \($SSE = \sum_{j=1}^K \sum_{x \in C_j} \|x - m_j\|^2$\) （簇内平方和 → 凝聚度）
- \($SSB = \sum_{j=1}^K n_j \|m_j - m\|^2$\) （簇间平方和 → 分离度）

**评价准则**：
- **凝聚度越高越好**（SSE 越小越好）
- **分离度越高越好**（SSB 越大越好）
- 常用 **轮廓系数** 同时考虑两者，取值 [-1,1]，越大越好。

### 9.4 相关性评估（内部）

- 构造 **邻近矩阵**（样本间距离）和 **关联矩阵**（是否同簇）。
- 计算两者相关系数（Mantel 检验）。相关系数高表示聚类与距离结构一致。

> 示例：对良好分离的数据，相关系数可达 0.92；对随机数据，仅约 0.58。

## 🧪 10. 例题（难度稍高，考察细节）

### 例题 1：K‑means 初始质心对结果的影响

**题目**：考虑一维点集：{1, 2, 4, 5, 10, 11, 12, 20}。使用 K=2 的 K‑means。  
(1) 若初始质心为 {4, 10}，最终划分和 SSE 是多少？  
(2) 若初始质心为 {1, 20}，最终划分和 SSE 会不同吗？为什么？  
(3) 请解释 K‑means++ 如何降低这种敏感性。

<details>
<summary>📝 答案</summary>

(1) 初始 {4,10}：  
- 第1轮：分配 → 簇1: {1,2,4,5}（到4近），簇2: {10,11,12,20}（到10近）。  
- 新质心：簇1=3，簇2=13.25。  
- 再分配：3 vs 13.25：{1,2,4,5} 仍属簇1，{10,11,12,20} 仍属簇2 → 收敛。  
  SSE = (1-3)²+(2-3)²+(4-3)²+(5-3)² + (10-13.25)²+(11-13.25)²+(12-13.25)²+(20-13.25)² = 10 + 48.75 = 58.75。

(2) 初始 {1,20}：  
- 第1轮：到1近 → {1,2,4,5,10,11,12}（质心≈6.43），到20近 → {20}（质心20）。  
- 新质心 (6.43, 20)。  
- 第2轮：到6.43近：{1,2,4,5,10,11,12}，到20近：{20} → 收敛。  
  SSE = (1-6.43)²+…+(12-6.43)² + (20-20)² ≈ 86.86。  
  → 结果不同，且 SSE 更大（更差）。

(3) K‑means++ 通过概率采样相距远的点，避免两个初始质心都落在同一高密度区，从而得到更接近全局最优的解。

</details>

### 例题 2：DBSCAN 参数影响

**题目**：二维数据分布如下：两个密度不同的簇，簇A（密集，半径2内有10个点），簇B（稀疏，半径2内仅有3个点），以及若干孤立噪声点。  
若设置 Eps=2, MinPts=5，请分析 DBSCAN 的输出结果。

<details>

<summary>📝 答案</summary>

- 簇A：半径2内点数 ≥ 5 → 核心点 → 形成一个簇。
- 簇B：半径2内点数 = 3 小于 5 → 所有点都不是核心点。但这些点之间的距离可能很小？但 MinPts=5 的要求导致整个簇B 不被认为是密度足够的区域 → 簇B 中的点若落在某个核心点（如簇A的核心）的邻域内，则成为边界点；否则成为噪声点。
- 实际上，由于簇B 与簇A 远离，簇B 的点既非核心也不在核心点邻域 → 全部被标记为 **噪声点**（丢失了簇B）。
- 结论：MinPts 设置过高会丢失低密度簇。需通过 k‑距离图选择合适 MinPts（例如 MinPts = 2×维度，或根据数据规模）。
</details>


### 例题 3：内部指标计算

**题目**：4 个点：A(0,0), B(1,1), C(5,5), D(6,6)。用 K‑means 聚类得到两个簇：簇1={A,B}，簇2={C,D}。  
(1) 计算 SSE 和 SSB。  
(2) 若将 C 误分到簇1，SSE 变化如何？  
(3) 解释为什么 SSE 单独使用不能评价不同 K 的聚类。

<details>
<summary>📝 答案</summary>

(1) 总体均值 m = ((0+1+5+6)/4, (0+1+5+6)/4) = (3,3)  
簇1 质心 m1 = (0.5,0.5)，簇2 质心 m2 = (5.5,5.5)  
SSE = Σ(x - m1)^2 + Σ(x - m2)^2 =  
  (0-0.5)²+(0-0.5)² + (1-0.5)²+(1-0.5)² = 0.5+0.5=1 ？逐点：  
  点A: (0-0.5)^2+(0-0.5)^2=0.5，点B: 同=0.5 → 簇1 SSE=1  
  点C: (5-5.5)^2+(5-5.5)^2=0.5，点D: 同=0.5 → 簇2 SSE=1  
  总 SSE = 2  
SSB = n1*(m1-m)^2 + n2*(m2-m)^2  
   (m1-m)=(-2.5,-2.5) → 平方和=12.5，乘以 n1=2 → 25  
   (m2-m)=(2.5,2.5) → 平方和=12.5，乘以 n2=2 → 25  
   SSB = 50  
SST = SSE+SSB = 52，也可直接计算各点到 (3,3) 平方和。

(2) 若 C 误分到簇1，新簇1={A,B,C}，簇2={D}。  
新 m1 = ((0+1+5)/3, (0+1+5)/3) = (2,2)  
新 m2 = (6,6)  
SSE_new = (A: (0-2)^2+(0-2)^2=8) + (B: (1-2)^2+(1-2)^2=2) + (C: (5-2)^2+(5-2)^2=18) + (D:0) = 28 → 远大于 2，说明错误分配导致凝聚度急剧下降。

(3) SSE 会随 K 增加而单调下降（直到每个点自成一簇，SSE=0），因此不能直接比较不同 K 的 SSE 绝对值。需用肘部法则或使用轮廓系数等归一化指标。

</details>

### 例题 4：层次聚类与分割式聚类的区别

**题目**：某数据集有三个自然簇：簇1 包含点 {A,B,C}，簇2 包含点 {D,E}，簇3 包含点 {F,G,H}。  
(1) 使用凝聚层次聚类（单链），画出可能的树状图（只需示意合并顺序）。  
(2) 若改为 K‑means（K=3）并且初始质心恰好选到不同簇，最终结果与层次聚类的差异主要在哪里？  
(3) 什么时候层次聚类优于分割式聚类？

<details>
<summary>📝 答案</summary>

(1) 单链（最小距离）通常会先合并最接近的两个点。假设簇内点都很接近，簇间距离较远。  
   - 簇1内：先合并 A 与 B（若它们最近）→ {A,B}，再与 C 合并。  
   - 簇2内：合并 D,E。  
   - 簇3内：合并 F,G → {F,G}，再与 H。  
   然后可能合并整个簇1和簇2（取决于距离），最后合并簇3。树状图反映了嵌套结构。

(2) K‑means 输出**平铺**的 K 个簇，没有层次信息；层次聚类输出树，可任意选择不同 K 的划分（通过切割树状图）。另外，K‑means 可能受初始质心影响，层次聚类确定性的（取决于距离度量）。

(3) 当不知道 K 且希望探索不同粒度的聚类结构时；或者数据具有自然的层次关系（如生物分类学）时。

</details>


### 例题 5：综合辨析题

**题目**：判断下列说法是否正确，并说明理由。  
① “聚类算法一定需要指定簇的数量 K。”  
② “K‑means 聚类总是能找到全局最优解。”  
③ “DBSCAN 不需要参数。”  
④ “轮廓系数越接近 1 表示聚类越好。”  
⑤ “高维数据下，欧氏距离仍然能很好地反映密度。”

<details>
<summary>📝 答案</summary>

① **错误**。层次聚类、DBSCAN 等不需要指定 K。  
② **错误**。K‑means 依赖于初始质心，容易陷入局部最优。  
③ **错误**。DBSCAN 需要两个参数 (Eps, MinPts)。  
④ **正确**。轮廓系数取值范围 [-1,1]，1 表示紧凑且分离好。  
⑤ **错误**。高维下距离趋于均匀，密度定义失效（维度灾难）。

</details>

## 📚 11. 本章小结

- 聚类是无监督学习的核心任务，目标：**组内相似，组间差异**。
- **K‑means**：简单高效，但限于球形簇，需预设 K，对初始值敏感。改进版 K‑means++、K‑means|| 缓解初始化问题。
- **DBSCAN**：能发现任意形状簇，自动识别噪声，但对密度差异敏感，高维数据表现差。
- **评估**：外部指标（需要真值）、内部指标（SSE、轮廓系数）、相对指标。
- **选择算法**：  
  - 数据为球形/高斯分布 → K‑means  
  - 数据含噪声、形状不规则 → DBSCAN  
  - 需要层次关系 → 层次聚类

> 🧠 **思考题**：如果数据具有多个密度层次（如中心密集、外围稀疏），你该如何改进 DBSCAN 或结合其他算法？
