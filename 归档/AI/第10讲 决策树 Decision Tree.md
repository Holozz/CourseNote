## 一、什么是决策树

决策树是一种**树状结构的分类模型**，其核心思想是通过一系列属性测试，将样本逐步划分到对应的类别。

### 结构组成

|结构成分|含义|
|---|---|
|**内部结点（Internal Node）**|对应某个属性上的"测试"（test）|
|**分支（Branch）**|对应该测试的一种可能结果，即该属性的某个取值|
|**叶结点（Leaf Node）**|对应最终的预测结果（类别）|

### 使用流程

- **学习过程**：通过分析训练样本，确定各内部结点对应的"划分属性"（即哪个属性作为节点）。
- **预测过程**：将测试样本从根结点出发，沿着划分属性构成的判定序列向下走，直到到达叶结点，输出该叶结点对应的预测类别。

### 直观示例：购买电脑预测

给定如下训练数据（14条），目标是预测用户是否购买电脑：

|年龄|收入|学生?|信用等级|是否买电脑|
|---|---|---|---|---|
|<=30|high|no|fair|**no**|
|<=30|high|no|excellent|**no**|
|31…40|high|no|fair|**yes**|
|>40|medium|no|fair|**yes**|
|>40|low|yes|fair|**yes**|
|>40|low|yes|excellent|**no**|
|31…40|low|yes|excellent|**yes**|
|<=30|medium|no|fair|**no**|
|<=30|low|yes|fair|**yes**|
|>40|medium|yes|fair|**yes**|
|<=30|medium|yes|excellent|**yes**|
|31…40|medium|no|excellent|**yes**|
|31…40|high|yes|fair|**yes**|
|>40|medium|no|excellent|**no**|

对应生成的决策树如下（以"年龄"为根节点）：

```
          年龄
        /  |  \
    <=30  31~40  >40
      |     |     |
   学生?   yes  信用等级?
   /  \        /      \
  no  yes  excellent  fair
   |   |       |        |
  no  yes     no       yes
```

> **解读**：若年龄在31~40，则无论其他属性，都买电脑（yes）；若年龄<=30，则看是否是学生；若年龄>40，则看信用等级。

## 二、决策树算法发展历程

```
1966  CLS   ← Hunt, Marin, Stone  （奠基性算法）
1979  ID3   ← Quinlan              （信息增益，最具影响力）
1983/1986   → ID3 总结简化
1986  ID4   ← Schlimmer & Fisher   （支持增量式生成）
1988  ID5   ← Utgoff               （效率进一步提升）
1984  CART  ← Breiman等            （二元划分，Gini指数）
1993  C4.5  ← Quinlan              （增益率，ID3的改进版）
```

## 三、CLS算法

### 算法定义

**CLS（Concept Learning System）** 是最早期的决策树学习算法，是众多决策树算法的基础。

### 核心思想

从一棵**空决策树**开始，选择某一属性作为测试属性，按该属性的取值将训练样本划分为若干子集：

- 若子集**为空**，或子集中**所有样本属于同一类**→ 该子集为**叶结点**（停止划分）
- 否则 → 该子集对应**内部结点**，需继续选择新的属性对其递归划分

### 算法步骤

1. 生成一棵空决策树和一个训练样本属性表
2. 若训练集 $T$ 中所有样本属于同一类，生成叶结点并终止
3. 根据**某种策略**从属性表中选择属性 $A$ 作为测试属性，生成测试结点
4. 若 $A$ 的取值为 $v_1, v_2, \ldots, v_m$，将 $T$ 划分成 $m$ 个子集 $T_1, T_2, \ldots, T_m$
5. 从属性表中删除属性 $A$
6. 对每个子集递归调用 CLS

### CLS示例：人种分类

|人员|眼睛颜色|头发颜色|所属人种|
|---|---|---|---|
|1|黑色|黑色|黄种人|
|2|蓝色|金色|白种人|
|3|灰色|金色|白种人|
|4|蓝色|红色|白种人|
|5|灰色|红色|白种人|
|6|黑色|金色|混血|
|7|灰色|黑色|混血|
|8|蓝色|黑色|混血|

**第一步**：选择"眼睛颜色"作为根节点 → 划分为三组 {1,6}、{2,4,8}、{3,5,7}，均不纯，继续划分  
**第二步**：对各子集选择"头发颜色"继续划分，最终每个叶结点只包含一种人种

**最终决策树**：

```
        眼睛颜色
      /    |    \
   黑色   蓝色   灰色
    |      |      |
  头发颜色 头发颜色 头发颜色
  /  \   / | \   / | \
黑 金 金 红 黑  金 红 黑
 |  |  |  |  |   |  |  |
黄种人 混血 白 白 混血 白 白 混血
```

### CLS 的问题

> ⚠️ **关键缺陷**：步骤3中"根据某种策略选择属性"**没有规定具体采用何种策略**。

实践表明，**测试属性的选择以及测试顺序对最终决策树的效果有决定性影响**。

**反例**：对于同一个学生膳食与缺钙数据集，若以"鸡肉→猪肉→牛肉..."顺序选属性，得到一棵很深的树；若直接选"牛奶"作为根节点，只需一层即可完美分类（有牛奶=不缺钙，无牛奶=缺钙）。

这说明：**不同的属性选择策略会产生复杂度差异极大的决策树**，因此需要一种客观的属性选择准则。

## 四、ID3算法

### 算法概述

**ID3（Iterative Dichotomiser 3）** 由 Quinlan 于1979年提出，是决策树学习中**最具影响力**的经典算法。

- 核心创新：使用**信息增益（Information Gain）** 来量化并选择最优测试属性
- 直觉依据：小概率事件包含的信息量更大（如"百年一遇"比"习以为常"信息量大）

---

### 4.1 信息论基础

#### 熵（Entropy）

熵衡量一个**离散随机变量的不确定性**：

$$H(X) = -\sum_{x \in X} p(x) \log_2 p(x) = \sum_{x \in X} p(x) \log_2 \frac{1}{p(x)}$$

- **熵越大** → 不确定性越高，信息量越大
- **熵越小** → 样本越"纯"，不确定性越低

**示例：掷8面骰子**
每面概率均为 $\frac{1}{8}$，需要 3 个比特编码：

$$H(X) = -\sum_{i=1}^{8} \frac{1}{8} \log_2 \frac{1}{8} = 3 \text{ bits}$$

**示例：抛硬币**
正面概率为 $p$，反面为 $1-p$：

$$H(X) = -p\log_2 p - (1-p)\log_2(1-p)$$

当 $p=0.5$ 时熵最大（= 1 bit），当 $p=0$ 或 $p=1$ 时熵为 0（完全确定，无信息量）。

#### 条件熵（Conditional Entropy）

在已知随机变量 $X$ 的取值后，$Y$ 仍然保留的不确定性：

$$H(Y|X) = \sum_{x \in X} p(x) H(Y|X=x) = -\sum_{x \in X}\sum_{y \in Y} p(x,y)\log_2 p(y|x)$$

#### 联合熵（Joint Entropy）

两个变量 $X$ 和 $Y$ 联合系统的总不确定性：

$$H(X,Y) = -\sum_{x \in X}\sum_{y \in Y} p(x,y)\log_2 p(x,y)$$

**重要关系**：

$$H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$$

> 联合熵 = X 的不确定性 + 已知 X 后 Y 的不确定性

#### 互信息（Mutual Information）

由联合熵的对称性推导：

$$I(X;Y) = H(Y) - H(Y|X) = H(X) - H(X|Y)$$

**含义**：衡量两个离散变量之间的**相关度**（类比连续变量中的协方差/相关系数）。

- $I(X;Y) = 0$：X 与 Y 完全无关（知道 X 对预测 Y 没有帮助）
- $I(X;Y)$ 越大：X 与 Y 越相关

|度量对象|连续变量|离散变量|
|---|---|---|
|单变量不确定性|方差 $\text{Var}(X)$|熵 $H(X)$|
|两变量相关度|协方差/相关系数|互信息 $I(X;Y)$|

---
### 4.2 基于信息增益的属性选择

#### 信息增益定义

$$g(D, A) = I(D; A) = H(D) - H(D|A)$$

- $D$：类标签（目标变量）
- $A$：候选属性
- **信息增益越大** = 该属性对分类的贡献越大 = 条件熵越小

> **ID3的选择准则**：每次选择信息增益**最大**的属性作为当前结点的划分属性。

#### 计算示例（购买电脑数据集）

**Step 1：计算类标签 $D$ 的熵**

14个样本中，9个买电脑（yes），5个不买（no）：

$$H(D) = -\frac{9}{14}\log_2\frac{9}{14} - \frac{5}{14}\log_2\frac{5}{14} \approx 0.940$$

**Step 2：计算属性"年龄"的条件熵**

年龄三种取值的样本分布：

- $\leq 30$：5个样本（2 yes, 3 no）
- $31\sim40$：4个样本（4 yes, 0 no）
- $>40$：5个样本（3 yes, 2 no）

$$H(D|A=\text{"年龄"}) = \frac{5}{14}\left(-\frac{2}{5}\log_2\frac{2}{5}-\frac{3}{5}\log_2\frac{3}{5}\right) + \frac{4}{14}\left(-\frac{4}{4}\log_2\frac{4}{4}-0\right) + \frac{5}{14}\left(-\frac{3}{5}\log_2\frac{3}{5}-\frac{2}{5}\log_2\frac{2}{5}\right) = 0.694$$

**Step 3：计算各属性信息增益**

|属性|信息增益 $g(D,A)$|
|---|---|
|年龄|$0.940 - 0.694 = \mathbf{0.246}$ ← 最大|
|收入|$0.029$|
|学生|$0.151$|
|信用等级|$0.048$|

**结论**："年龄"的信息增益最大，被选为根节点。然后对各子集递归执行同样操作，直至构建完整决策树。

## 五、C4.5算法

### ID3的局限性

信息增益存在**偏向取值数量多的属性**的问题。例如，若把"用户ID"作为属性，每个ID唯一，划分后每个子集只有1个样本，信息增益达到最大，但这样的划分毫无泛化意义。

### C4.5的改进：增益率（Gain Ratio）

**增益率**对信息增益进行正则化，惩罚取值数量过多的属性：

$$\text{GainRatio}_A(D) = \frac{\text{Gain}_A(D)}{\text{SplitInfo}_A(D)}$$

其中**分裂信息**（惩罚项）定义为：

$$\text{SplitInfo}_A(D) = -\sum_{j=1}^{v} \frac{|D_j|}{|D|} \times \log_2\left(\frac{|D_j|}{|D|}\right)$$

- $v$：属性 $A$ 的取值数量
- $|D_j|$：取第 $j$ 个值的子集大小
- SplitInfo 本质上是按属性值划分的**熵**，取值越多，SplitInfo 越大，从而压低增益率

**选择准则**：每次选取**增益率最大**的属性进行划分。

#### 计算示例

对属性"收入"（high/medium/low，各 4/6/4 条）：

$$\text{SplitInfo}_{A=\text{income}}(D) = -\frac{4}{14}\log_2\frac{4}{14} - \frac{6}{14}\log_2\frac{6}{14} - \frac{4}{14}\log_2\frac{4}{14} = 0.926$$

$$\text{GainRatio}_{A=\text{income}}(D) = \frac{0.029}{0.926} \approx 0.031$$

## 六、CART算法

### 算法概述

**CART（Classification And Regression Tree）** 于1984年提出，与 ID3/C4.5 的主要区别：

- 使用**基尼指数（Gini Index）** 而非信息熵
- 每个节点**只有两个分支**（二元划分），生成的是**二叉树**
- 同时支持**分类**和**回归**任务

### 基尼指数（Gini Index）

衡量数据集的**不纯度**：

$$\text{gini}(D) = \sum_{j=1}^{n} p_j(1-p_j) = 1 - \sum_{j=1}^{n} p_j^2$$

- $p_j$：类 $j$ 在数据集 $D$ 中的比例
- 基尼指数越小，数据集越纯
- 当只有两类（$n=2$）时：$\text{gini}(D) = 2p(1-p)$

### 分裂基尼指数

将数据集 $D$ 按某属性分为 $D_1$（大小 $N_1$）和 $D_2$（大小 $N_2$）后：

$$\text{gini}_{\text{split}}(D) = \frac{N_1}{N}\text{gini}(D_1) + \frac{N_2}{N}\text{gini}(D_2)$$

**选择准则**：选使 $\text{gini}_{\text{split}}(D)$ **最小**的属性及切分点。

### 计算示例

**数据集整体基尼指数**（9 yes，5 no）：

$$\text{gini}(D) = 1 - \left(\frac{9}{14}\right)^2 - \left(\frac{5}{14}\right)^2 \approx 0.459$$

**属性"收入"划分：{medium, high} vs {low}**

- $D_1$（medium+high，10条）：6 yes，4 no → $\text{gini}(D_1) = 1-(\frac{6}{10})^2-(\frac{4}{10})^2 = 0.48$
- $D_2$（low，4条）：1 yes，3 no → $\text{gini}(D_2) = 1-(\frac{1}{4})^2-(\frac{3}{4})^2 = 0.375$

$$\text{gini}_{\text{split}} = \frac{10}{14} \times 0.48 + \frac{4}{14} \times 0.375 \approx 0.450$$

**若收入分为三组（high / medium / low）的各组基尼指数**：

|子集|样本|yes|no|基尼|
|---|---|---|---|---|
|high|4|2|2|$1-(0.5)^2-(0.5)^2 = 0.5$|
|medium|6|4|2|$1-(\frac{4}{6})^2-(\frac{2}{6})^2 \approx 0.444$|
|low|4|1|3|$1-(\frac{1}{4})^2-(\frac{3}{4})^2 = 0.375$|

注意：CART 是二叉树，所以对三值属性需枚举所有二元分割方案（如 {high} vs {medium,low}，{medium} vs {high,low}，{low} vs {high,medium}），选择分裂基尼最小的方案。

### CART（分类树）生成算法

```
输入：训练集 D，停止条件
输出：CART 分类树

从根节点开始，递归操作每个结点：
1. 对每个特征 A 的每个取值 a：
   - 将 D 分为 D1（A=a）和 D2（A≠a）
   - 计算 gini_split(D)
2. 选择 gini_split 最小的 (A, a) 作为分裂点
3. 将数据分配到两个子结点
4. 对子结点递归调用 1~3
直到满足停止条件（结点纯度达标 或 样本数不足）
```

## 七、连续型属性的处理

对于连续值属性（如年龄取具体数值），无法直接枚举所有取值，需要**离散化**：

给定属性 $A$ 有 $v$ 个不同取值（排序后），则有 $v-1$ 个候选分裂点，相邻取值 $a_i$ 和 $a_{i+1}$ 的中点：

$$\text{分裂点} = \frac{a_i + a_{i+1}}{2}$$

对每个候选分裂点计算信息增益（或基尼指数），选择最优分裂点，将连续属性转为二值划分（$\leq$ 阈值 / $>$ 阈值）。

## 八、算法横向对比

|特性|CLS|ID3|C4.5|CART|
|---|---|---|---|---|
|属性选择准则|无规定|信息增益（最大）|增益率（最大）|基尼指数（最小）|
|树结构|多叉树|多叉树|多叉树|**二叉树**|
|连续属性|✗|✗|✓|✓|
|偏向多值属性|-|**有偏**|已修正|不敏感|
|适用任务|分类|分类|分类|**分类 + 回归**|
|提出年份|1966|1979|1993|1984|

## 关键公式速查

$$\text{熵：} H(X) = -\sum_{x} p(x)\log_2 p(x)$$

$$\text{条件熵：} H(Y|X) = \sum_x p(x) H(Y|X=x)$$

$$\text{信息增益（ID3）：} g(D,A) = H(D) - H(D|A)$$

$$\text{增益率（C4.5）：} \text{GainRatio}_A = \frac{g(D,A)}{\text{SplitInfo}_A(D)}$$

$$\text{基尼指数（CART）：} \text{gini}(D) = 1 - \sum_j p_j^2$$

$$\text{分裂基尼（CART）：} \text{gini}_\text{split}(D) = \frac{N_1}{N}\text{gini}(D_1) + \frac{N_2}{N}\text{gini}(D_2)$$
