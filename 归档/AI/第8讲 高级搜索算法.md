# 爬山算法 (Hill-Climbing)

- 一种局部搜索算法，总是移动到邻域中值最高的后继状态
- 伪代码：
```
function Hill-Climbing(problem)
  inputs: problem
  returns a state that is a local maximum
  1. current ← Make-Node(Initial-State[problem])
  2. loop do
  3.   neighbor ← a highest-valued successor of current
  4.   if Value[neighbor] < Value[current] then
         return State[current]
  5.   current ← neighbor
```
- 缺点：容易陷入局部最优，无法保证全局最优

# 模拟退火算法 (Simulated Annealing)

## 基本思想
- 由Metropolis (1953)提出，Kirkpatrick等人(1983)将退火思想引入组合优化领域
- 物理退火过程的数学表述：
  - Metropolis准则：以概率接受新状态
  - 温度T下：若 $E_{j}<E_{i}$，接受j为当前状态
  - 否则以概率 $p=e^{-(E_j-E_i)/k_B T}$ 接受新状态
  - 在高温下，可接受与当前状态能量差较大的新状态
  - 在低温下，只接受与当前状态能量差较小的新状态

## 算法流程
```python
procedure SA
  // 初始化
  Randomly generate a solution X0, calculate f(X0)
  Xbest ← X0; k ← 0; tk ← T;
  while not stop
    for i=1 to L    // 内循环（等温过程）
      Generate a new solution Xnew based on Xk
      if f(Xnew) < f(Xk)     // 改进则接受
        Xk ← Xnew
        if f(Xk) < f(Xbest) then Xbest ← Xk
        continue
      end if
      Calculate P(tk)=e^{-[(f(Xnew)-f(Xk))/tk]}  // Metropolis准则
      if random(0,1) < P then Xk ← Xnew
    end for
    tk+1 ← drop(tk); k ← k+1   // 降温
  end while
  print Xbest
end procedure
```
## 退火调度 (Annealing Schedule)
- $t_{k+1} = \alpha \cdot t_k$，其中 $\alpha \in (0.8, 0.999)$
- $t_{k+1} = t_k - \Delta t$
- 初始温度 $t_0$ 的确定：$t_0 = (f_{max} - f_{min}) / \ln P_r$，其中 $P_r \approx 1$（初始接受概率）

## 算法特点
- SA不是SA的1次，通常SA执行多次分别从不同初始解开始搜索
- SA依据Metropolis准则，既接受改进解也以一定概率接受恶化解，并随温度下降趋于确定性
- 通用性强；用于0-1背包、TSP等NP难问题

## 0/1背包问题SA示例
- 问题：n=5, 容量c=8, w=(2,3,5,1,4), v=(2,5,8,3,6)
- 编码：i=(1,1,0,0,1)，T=10，f(i)=2+5+6=13，s=i
- 迭代过程：
  - j=(1,1,1,0,0)，f(j)=2+5+8=15>13 → 接受j，更新解
  - (a) j=(1,1,0,1,0)，f(j)=2+5+3=10<15，P(T)=exp(-0.5)=0.607 > random → 接受
  - (b) j=(1,0,1,1,0)，f(j)=2+8+3=13<15，P(T)=exp(-0.3)=0.741 < random → 拒绝
- 退火公式：$P(T)=e^{-[f(j)-f(i)]/T}$

## TSP应用
- TSP (Traveling Salesman Problem): 给定n个城市，求最短哈密顿回路
- 数学建模：
  - $d_{ij}$: 城市i到j的距离
  - $x_{ij} \in \{0,1\}$: 是否选择边(i,j)
  - $\min \sum_{i=1}^{n} \sum_{j=1}^{n} d_{ij}x_{ij}$
  - s.t. $\sum_{j=1}^{n} x_{ij}=1$ (每城市出度1), $\sum_{i=1}^{n} x_{ij}=1$ (每城市入度1), 无子回路约束

# 遗传算法 (Genetic Algorithm)
## 概述
- **进化算法**（Evolutionary Algorithms, EA）：基于自然选择和自然遗传等生物机制的搜索算法
- 通过 **选择、重组、变异** 实现优化问题的求解
- 进化算法簇：遗传算法(GA)、遗传规划(GP)、进化策略(ES)、进化规划(EP)
- 基本对应关系：
```
目标函数 <---> 适应度函数
可行解   <---> 染色体 (chromosome)
一组解   <---> 种群 (population)
```
- 基因(gene)：染色体中的元素；位点(locus)：基因在染色体中的位置；等位基因(alleles)：基因的取值
## GA vs 传统方法
- 传统方法：点对点（point-to-point），基于梯度，沿最速下降方向迭代，易陷入局部最优
- GA：种群到种群（population-to-population），多方向搜索，概率转移规则，不易陷入局部最优
- 随机搜索 + 定向搜索 = GA
## 算法结构
```
procedure: GA
begin
  t ← 0;
  initialize P(t) by encoding;
  fitness eval(P) by decoding;
  while (not termination condition) do
    crossover P(t) to yield C(t);
    mutation P(t) to yield C(t);
    fitness eval(C) by decoding;
    select P(t+1) from P(t) and C(t);
    t ← t+1;
  end
  output best solution;
end
```

## 算法详细

### 1. 编码
1. 位串编码
	1. 二进制编码
		优点：交叉、变异操作容易实现；处理模式数最多
		缺点：相邻整数的二进制编码可能具有较大的Hamming距离（如15→01111, 16→10000）；串长较长，效率低
	2. 格雷码（Gray Code）：相邻整数之间只有一位不同
2. 实数编码
3. 多参数映射编码

### 2. 初始种群确定
1. 初始种群产生方式：
   - 随机产生群体规模数目的个体
   - 随机产生后挑选最好的个体加入，迭代至预定规模
   - 根据问题知识在最优解分布范围内设定
2. 种群规模：
   - 太小 → 易陷入局部最优
   - 太大 → 计算复杂
   - 模式定理(Schema Theorem)：群体规模M可从M个个体中生成和检测$O(M^3)$个模式

### 3. 适应度函数
- 最大化问题：$Fit(f(x))=f(x)$ 或 $f(x)-C_{min}$
- 最小化问题：$Fit(f(x))=\frac{1}{f(x)}$ 或 $C_{max}-f(x)$
- **欺骗问题**(deceptive problem)：妨碍高适应度个体产生的问题
	- **过早收敛**：通过降低超级个体竞争力来解决
	- **停滞现象**：改变原始适应值比例关系，提高个体间竞争力
	- **尺度变换**(fitness scaling)：
		  1. 线性变换：$f' = af + b$，其中 $a = \frac{(C_{mult}-1)f_{avg}}{f_{max}-f_{avg}}$, $b = \frac{f_{max}-C_{mult}f_{avg}}{f_{max}-f_{avg}}$
		  2. 幂函数变换：$f' = f^K$
		  3. 指数变换：$f' = e^{-af}$

### 4. 选择 (Selection/Reproduction)
1. 个体选择概率分配方法
   - 适应度比例方法（蒙特卡罗法/轮盘赌）：
     $P_{si} = \frac{f_i}{\sum f_i}$
   - 排序方法：
     1. 线性排序(Baker)：将个体从好到坏排序 $x_1,x_2,\dots$，$P_i = \frac{a - bi}{M(M+1)}$
     2. 非线性排序(Michalewicz)：$p_i = q(1-q)^{i-1} ~~where~i\neq M$

2. 选择实现方法
   - 轮盘赌选择（Roulette Wheel）：按概率分布构造轮盘，旋转选择
   - 锦标赛选择（Tournament Selection）：随机选若干个体，选最优者；可加入随机锦标赛变体

### 5. 交叉 (Crossover)
1. **单点交叉**（single-point crossover）：随机选择一个切点，交换右半部分
2. **两点交叉**（two-point crossover）：随机选择两个切点，交换中间部分
3. TSP交叉算子（排列编码专用）：
   - **PMX**(Partial-Mapped Crossover)：部分映射交叉，选两个切点交换子串，建立映射关系，合法化后代
   - **OX**(Order Crossover)：顺序交叉，复制一段子串到proto-child，从另一父代按顺序填充未固定位置
   - **PBX**(Position-based Crossover)：随机选位置集，从父代1复制，其余从父代2填充
   - **OBX**(Order-based Crossover)：随机选位置集，父代2非选中值先复制，再从父代1复制选中值
   - **CX**(Cycle Crossover)：循环交叉，找出两父代间的循环，从父代1复制循环值，其余从父代2填充
   - **Subtour Exchange Crossover**：选子路径交换，其余补全

### 6. 变异 (Mutation)
- 基本原理：以一定概率（变异率）改变基因值

1. TSP变异算子：
   - **Inversion Mutation**（倒位变异）：选子串将其反向排列
   - **Insertion Mutation**（插入变异）：选一个基因插入到随机位置
   - **Displacement Mutation**（移位变异）：选一段子串插入到随机位置
   - **Swap Mutation**（交换变异）：随机交换两个位置
   - **Heuristic Mutation**（启发式变异）：选多个基因，产生邻居染色体，选适应度最佳者

## 数值优化详细示例 (Michalewicz, 1996)
- 目标函数：$\max f(x_1, x_2) = 21.5 + x_1 \sin(4\pi x_1) + x_2 \sin(20\pi x_2)$
- 约束：$-3.0 \le x_1 \le 12.1$，$4.1 \le x_2 \le 5.8$

### 编码过程
- 精度要求：小数点后5位
- $x_1$: (12.1-(-3.0)) × 10^5 = 151,000，$2^{17}<151,000\le 2^{18}$，需18位
- $x_2$: (5.8-4.1) × 10^5 = 17,000，$2^{14}<17,000\le 2^{15}$，需15位
- 总染色体长度：18+15=33位

### 解码公式
- $x_j = a_j + \frac{decimal(substring_j)}{2^{m_j}-1}(b_j - a_j)$

### 演化过程
- 初始种群：随机生成10条染色体 → 计算适应度 → 轮盘赌选择 → 单点交叉 → 变异 → 新种群
- Rastrigin函数（可作测试）：$f(x_1,x_2)=20+x_1^2+x_2^2-10(\cos 2\pi x_1 + \cos 2\pi x_2)$

## GA求解TSP

### 编码表示
1. **排列编码**（Permutation Encoding）：城市访问顺序直接排列，如 3-2-5-4-7-1-6-9-8
2. **随机密钥编码**（Random Keys Encoding）：每个城市赋(0,1)随机数，按值排序得到访问顺序
   - 优点：交叉操作不产生非法解

### TSP GA算法流程
```
procedure: GA for TSP
begin
  t ← 0;
  initialize P(t) by permutation/random keys encoding;
  fitness eval(P);
  while (not termination condition) do
    crossover P(t) to yield C(t);   // PMX等
    mutation P(t) to yield C(t);    // swap mutation等
    fitness eval(C);
    select P(t+1) from P(t) and C(t);
    t ← t+1;
  end
  output best tour route;
end
```
- 30城市TSP基准测试参数：$t_f=0.01$, $\alpha=0.90$, $L=200 \times CityNum$
