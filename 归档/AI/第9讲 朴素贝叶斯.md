# 不确定性推理：概率方法

## 为什么需要概率推理？
- 现实世界充满**不确定性**：传感器噪声、知识不完整、环境多变
- 要在不确定性下理性行动，必须能够评估事物的可能性（概率）
- 通过权衡事件的似然度（概率），可以开发在不确定性下理性行动的机制

## 期望效用理论 (Expected Utility)
- 在不确定环境下做决策的框架：
  - 列出所有可能行动的**结果**
  - 为每个结果分配**概率**和**效用值**(utility)
  - 计算每个行动的**期望效用** = $\sum P(outcome) \times U(outcome)$
  - 选择期望效用最大的行动（Maximum Expected Utility, MEU）
- 联合分布(joint distribution) + 结果效用(utilities of outcomes) → 理性决策

# 概率论基础

## 有限集合上的概率
- 样本空间 $U$（universe）：所有可能事件的集合
- 概率函数 $Pr: U \to [0,1]$
- 基本公理：
  - $Pr(U) = 1$，$Pr(\emptyset) = 0$
  - $Pr(A \cup B) = Pr(A) + Pr(B) - Pr(A \cap B)$
- 集合运算性质：
  - $A \cap (B \cap C) = (A \cap B) \cap C$
  - $A \cup (B \cup C) = (A \cup B) \cup C$
  - $\bar{A} = U - A$（补集）

## 特征向量上的概率
- 特征变量 $V_1, V_2, \dots, V_n$，各自有定义域 $Dom[V_i]$
- 全联合分布包含所有变量的组合：$\{(d_1,d_2,\dots,d_n) | d_i \in Dom[V_i]\}$
- 若每个变量有 $|Dom[V_i]|=2$，则联合概率表大小为 $2^n$（指数级！）
- **边缘化(marginalization/Summing out)**：
  - $Pr(V_1=a) = \sum_{x_2 \in Dom[V_2]} \dots \sum_{x_n \in Dom[V_n]} Pr(V_1=a, V_2=x_2, \dots, V_n=x_n)$
- 问题与解法：
  - 问题：指定指数级的概率，求和指数级的项
  - 解法：利用概率独立性，特别是**条件独立性**

# 条件概率与独立性

## 条件概率
- 定义：$Pr(B|A) = \frac{Pr(B \cap A)}{Pr(A)}$，其中 $Pr(A) > 0$
- $Pr(B|A)$ 读作"在A发生的条件下B发生的概率"
- 例：P(头痛)=1/10, P(流感)=1/40, P(头痛|流感)=1/2
  - 问：P(流感|头痛) = ?

## 全概率公式 (Summing out)
- 若 $B_1, B_2, \dots, B_k$ 构成 $U$ 的一个划分（互斥且穷尽）：
  - $Pr(B_i \cap B_j) = 0$（互斥）
  - $Pr(B_1 \cup B_2 \cup \dots \cup B_k) = 1$（穷尽）
- 则 $Pr(A) = Pr(A|B_1)Pr(B_1) + \dots + Pr(A|B_k)Pr(B_k)$

## 独立性
- A与B独立：$Pr(B|A) = Pr(B)$，等价于 $Pr(A \cap B) = Pr(A) \cdot Pr(B)$
- 若独立，联合概率可分解为边际概率的乘积

## 条件独立性
- 给定A，B与C条件独立：$Pr(B|A \cap C) = Pr(B|A)$
- 含义：知道A后，C不提供关于B的额外信息
- 推论：若给定A时B与C条件独立，则 $Pr(B \cap C|A) = Pr(B|A) \cdot Pr(C|A)$
- 条件独立性大大减小了表示和推理的计算复杂度

## 链式规则 (Chain Rule)
- $Pr(A_1 \cap A_2 \cap \dots \cap A_n) =$
  $\quad Pr(A_1|A_2 \dots A_n) \cdot Pr(A_2|A_3 \dots A_n) \dots Pr(A_{n-1}|A_n) \cdot Pr(A_n)$

# 贝叶斯定理 (Bayes Rule)
## 公式
$$Pr(Y|X) = \frac{Pr(X|Y) \cdot Pr(Y)}{Pr(X)}$$

- $Pr(Y)$ 称为**先验概率**(prior)
- $Pr(Y|X)$ 称为**后验概率**(posterior)
- $\frac{Pr(X|Y)}{Pr(X)}$ 称为**似然度**(likelihood ratio)
	- 若 > 1：证据X支持假设Y
	- 若 = 1：证据X不改变对Y的信念
	- 若 < 1：证据X削弱对Y的信念

## 贝叶斯定理的意义
- 贝叶斯规则是一个简单的数学事实，但对概率推理有深远意义
- 它将"因果方向"反转为"诊断方向"：
  - 因果：$Pr(高胆固醇|心脏病)$ ← 容易从数据估计
  - 诊断：$Pr(心脏病|高胆固醇)$ ← 通过贝叶斯反转，可用于预测
- 因果概率更"稳定"：流行病不会改变 $Pr(发烧|疟疾)$，但会改变 $Pr(疟疾|发烧)$

## 贝叶斯定理示例
- 疾病诊断：疾病 ∈ {疟疾, 感冒, 流感}，症状 = 发烧
- $Pr(疟疾|发烧) = \frac{Pr(发烧|疟疾)Pr(疟疾)}{Pr(发烧)}$
- 其中 $Pr(发烧) = Pr(发烧 \cap 疟疾) + Pr(发烧 \cap 感冒) + Pr(发烧 \cap 流感)$
- $Pr(发烧 \cap 疟疾) = Pr(发烧|疟疾)Pr(疟疾)$

- 医学检验示例（经典）：
	- 疾病先验概率 = 0.001（千分之一）
	- 检验灵敏度 = 99%（患者阳性概率）
	- 检验假阳性率 = 5%
	- 若检验为阳性，真正患病的后验概率 ≈ 2%（而非直觉中的99%）

# 朴素贝叶斯分类器 (Naive Bayes)

## 原理
- 目标：给定属性 $A_1, A_2, \dots, A_n$，预测类别 $C$
- 贝叶斯公式：$P(C|A_1 \dots A_n) = \frac{P(A_1 \dots A_n|C)P(C)}{P(A_1 \dots A_n)}$
- 最大化后验概率等价于最大化 $P(A_1 \dots A_n|C)P(C)$
- **朴素假设**：给定类别C，各属性条件独立
  $$P(A_1, A_2, \dots, A_n | C) = P(A_1|C) P(A_2|C) \dots P(A_n|C)$$
- 分类决策：选择使 $\max_{C} P(C) \prod_i P(A_i|C)$ 最大的类别
## 参数估计
- $P(C_k) = N_k / N$（类别先验）
- 离散属性：$P(A_i|C_k) = |A_{ik}| / N_k$（频率计数）
- 连续属性：$P(A_i|C_k) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$（高斯分布）
## 零概率问题与平滑
- 问题：若某个 $P(A_i|C_k)=0$，则整个乘积为0
- Laplace平滑：$P(A_i|C_k) = \frac{n_{ik} + 1}{n_k + |Dom[A_i]|}$
- m-估计：$P(A_i|C_k) = \frac{n_{ik} + mp}{n_k + m}$，其中p为先验估计，m为等效样本量

## 朴素贝叶斯特点
- 优点：对孤立噪声点和无关属性鲁棒
- 缺点：
  - 对先验概率敏感（可用无信息先验缓解）
  - 属性独立假设可能不成立（可用贝叶斯信念网络BBN改进）
  - 属性间相关性被忽略

# 应用案例

## 垃圾邮件过滤 (Paul Graham, 2002)
- 问题：判断邮件是垃圾邮件(S)还是正常邮件(H)
- 先验：训练集中50%为Spam，50%为Healthy
- 给定词W="prince"，P(W|S)=5%, P(W|H)=0.05%
- 利用贝叶斯：$P(S|W) = \frac{5\% \times 50\%}{5\% \times 50\% + 0.05\% \times 50\%} = 99.01\%$
- 实际系统中组合多个词（如15个最显著特征词）
- 效果：Graham的方案正确率99.5%（1000封邮件中误判5封）

## 联邦党人文集作者归属
- 背景：《联邦党人文集》(1787-88)中12篇文章作者有争议（Hamilton vs Madison）
- Mosteller & Wallace (1955/1964)：首次使用贝叶斯统计方法
- 方法：
  - 分析功能词频率："in", "an", "of", "upon"等（这些词不受主题影响）
  - 发现关键词："while"(Hamilton常用) vs "whilst"(Madison常用)
  - 统计1255个不同词汇，2401种出现模式
- 结论：12篇争议文章均归为Madison所作（1968年统计概率>99%）

## 贝叶斯搜索理论 (Bayesian Search Theory)
- 应用：2009年法航447航班在大西洋失踪后的搜索
- 方法：将搜索区域网格化，根据漂移模型和搜索反馈不断更新概率分布
- 成功在先前搜索失败的区域找到了残骸

# 概率图模型与贝叶斯网络
## 动机
- 若n个布尔变量完全独立 → $O(n)$参数（线性）替代 $O(2^n)$（指数）
- 但完全独立很罕见；多数领域存在**条件独立性**
- **贝叶斯网络(Bayesian Networks/Belief Networks, BBN)** 正是利用条件独立性进行表示和推理
## 贝叶斯网络示例
- 医学诊断网络：
```
  Smoking → Lung Cancer
     ↓           ↓
  Bronchitis   X-ray
       ↓         ↓
       →→→ Dyspnoea ←←←
```
- 每个节点是一个随机变量，边表示直接依赖关系
- 给定父节点，每个节点条件独立于其非后代节点

# 概率推理的发展历史

## 关键人物与贡献
| 时间 | 人物 | 贡献 |
|------|------|------|
| 1965 | Lotfi Zadeh | 提出模糊逻辑(Fuzzy Logic)，处理不精确知识 |
| 1976 | Edward Shortliffe | 开发MYCIN专家系统，使用确定性因子处理不确定性 |
| 1980s | Judea Pearl | 创立贝叶斯网络和信念传播(Belief Propagation, BP)算法 |

- Judea Pearl因在概率和因果推理方面的贡献获得2011年ACM图灵奖
- Pearl于1988年发表信念传播(BP)算法论文
## 信念传播与神经网络
- BP算法在树结构网络中精确计算边缘概率
- BP与Hopfield网络有深刻的数学联系
- Ott & Stoop研究了二元马尔可夫随机场(MRF)上BP的神经动力学
- 相关模型：MRF(马尔可夫随机场), CRF(条件随机场), HMM(隐马尔可夫模型)

# 关键公式总结
| 名称 | 公式 |
|------|------|
| 条件概率 | $Pr(B\|A) = Pr(B \cap A)/Pr(A)$ |
| 全概率公式 | $Pr(A) = \sum_i Pr(A\|B_i)Pr(B_i)$ |
| 独立性 | $Pr(A \cap B) = Pr(A) \cdot Pr(B)$ |
| 条件独立性 | $Pr(B \cap C\|A) = Pr(B\|A) \cdot Pr(C\|A)$ |
| 贝叶斯定理 | $Pr(Y\|X) = \frac{Pr(X\|Y)Pr(Y)}{Pr(X)}$ |
| 链式规则 | $Pr(A_1 \dots A_n) = Pr(A_1\|A_2 \dots A_n) \dots Pr(A_{n-1}\|A_n)Pr(A_n)$ |
