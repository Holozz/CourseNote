# 布尔运算和表达式
### 二值逻辑
- 不同的数码可以表示不同的**事物**
- 用0和1表示一个事物的两种不同逻辑状态
- 这种**只有两种对立逻辑状态**的逻辑关系称为二值逻辑
### 逻辑运算
两个二进制数码表示不同的逻辑状态时，它们之间可以按照某种指定的因果关系进行推理运算
### 布尔代数
- 逻辑变量：逻辑代数中用字母表示的变量
- 逻辑运算是逻辑变量和常量之间逻辑状态的推理，==不是数量运算==
- 0和1元素的性质
	$X+0=X~~~X+1=1~~~X*0=0~~~X*1=X~~~\bar{0}=1~~~\bar{1}=0$
# 布尔代数的定律和法则
- 交换律 $A*B=B*A~~~A+B=B+A$
- 结合律$A(B*C)=(A*B)*C~~~A+(B+C)=(A+B)+C$
- 分配律$A*(B+C)=A*B+A*C$
- 还原律$\bar{\bar{A}}=A$
- 德摩根律$\overline{A*B}=\bar{A}+\bar{B}~~~\overline{A+B}=\bar{A}*\bar{B}$（可以推广到多个）
- 布尔代数法则：
  $\begin{gathered}A+A*B=A~~~A*B+A*\bar{B}=A\\A+\bar{A}*B=A+B~~~A*(A+B)=A\\A*B+\bar{A}*C+B*C=A*B+\bar{A}*C\end{gathered}$
- **布尔代数基本定理**：在任何一个包含变量A的逻辑等式中以另外一个逻辑式代换所有的A，等式仍然成立
- **反演定理**：对任一逻辑式，若将其中所有乘换成加，加换成乘，0换成1，1换成0，变量取反，则得到原式的反
> [!note]- 注意
>1) 遵守 **“括号，乘，加”** 的改变优先次序
>2) 不属于单个变量上的反号应该保留
- 对偶式： 将任一逻辑式中的乘换成加，加换成乘，0换成1，1换成0，则得到对偶式
- **对偶定理**：若两逻辑式相等，则它们的对偶式也相等

# 布尔代数的化简
### 目的
使用尽可能少的门电路实现给定功能
- 函数式中相加的乘积项不能再减少
- 每项中相乘的因子不能再减少
### 方法
1. 并项法$AB+A\bar{B}=A$
2. 吸收法$A+AB=A$
3. 消项法$AB+\bar{A}C+BC=AB+\bar{A}C$
4. 消因子法$A+\bar{A}B=A+B$
5. 配项法$A+A=A~~~AA=A~~~1=A+\bar{A}$
6. 综合法
### 布尔表达式的标准形式
#### 最小项
- 在n变量逻辑函数中，若m为包含n个因子的乘积项，而且这几个变量均以原变量或反变量的形式在m中出现一次，则称m为该组变量的最小项
- 输入变量的每一组取值，都使一个对应的最小项的值等于1
- n变量的最小项有$2^n$个
- ![[Pasted image 20260327210858.png|340]]
- 性质：
	- 在输入变量的任何取值下必有且仅有一个最小项的值为1
	- 全体最小项之和为1
	- 任意两个最小项之积为0
	- 相邻的两个最小项可以合并成一项并消去一对因子

# 卡诺图
- 一种简化布尔表达式的系统方法
- 生成最简单的SOP表达式
- 显示输入变量的所有可能值
- 一组单元格
- 每个单元格表示输入变量的二进制值
- 位置上的邻接等价于布尔代数中的相邻
