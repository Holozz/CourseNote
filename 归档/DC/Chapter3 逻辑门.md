# 基本逻辑门
- 门电路
	- 用以实现逻辑运算的单元电路，通称为**逻辑门电路**，简称**门电路**
	- 常用的门电路的逻辑功能：
		  ==与、或、非门、与非、或非门、同或、异或门==
- 逻辑电平：用来表示0和1的电压
- **反相器**(The Inverter)
	- 将一个逻辑电平更改为相反的电平：
									$\begin{align}1-\to{0} \\ 0-\to{1} \end{align}$
	- 逻辑表达式：$X = \bar{A}$
	- 真值表
	- 对于一个方波脉冲，反相器低电平有效是说由方波脉冲的**后沿触发**，如果说是高电平有效就是方波脉冲的**前沿触发**
	- ![[Pasted image 20260317235117.png|500]]
- 高低电平有效
	- **高电平有效**：当信号为高电平（逻辑1）时，功能被激活；低电平（逻辑0）时，功能无效
	- **低电平有效**：当信号为低电平（逻辑0）时，功能被激活；高电平（逻辑1）时，功能无效
- **与门**(TheAndGate)
	- 可组合成任何逻辑的==基本门==之一
	- 具有**两个或多个输出** 和 **一个输入**
	- 仅当*所有*输入均为**高电平**的时候才输出**高电平**
	- ![[Pasted image 20260317235159.png|250]]
	- **运算**：
		![[Pasted image 20260317235300.png|400]]
		逻辑表达：**布尔运算**  $X~=~ABCD$
- **或门**(The OR Gate)
	- 可组合成任何逻辑的==基本门==之一
	- 具有**两个或多个输入**和**一个输出**
	- *只要有一个*高电平输入，就输出高电平
	- *全部*都为低电平，才输出低电平
	- ![[Pasted image 20260317235715.png|250]]
	- **运算**
		![[Pasted image 20260317235737.png|400]]
		逻辑运算：**布尔运算** $X~=~A+B+C$
	- 可以由==反相器和与门==组合实现：
		![[Pasted image 20260318000017.png|350]]
- **与非门**(The NAND Gate)
	- 具有反码输出的与函数
	- *仅当所有*输入均为高电平时，才产生低电平输出
	- ![[Pasted image 20260318000221.png|380]]
	- **运算**：
		![[Pasted image 20260318000256.png|350]]
		逻辑表达：“先与后非”或“先非后或”     $X~=~\overline{AB}$
- **或非门**(The NOR Gate)
	- 具有反码输出的或函数
	- *只要有一个*输入为高电平，输出就为低电平
	- *仅当全部*输入为低电平，输出才是高电平
	- ![[Pasted image 20260318000617.png|400]]
	- **运算**：
		![[Pasted image 20260318000638.png|350]]
		逻辑表达：“先或后非”或”先非后与“ $X~=~ \overline{A+B}$
- **异或门和同或门**(The XOR Gate & XNOR Gate)
	- *只有*两个输入
	- 异或门：只有两个输入均为**相反**电平时，输出才为高电平
		- ![[Pasted image 20260318191125.png]]
		- **运算**：
				![[Pasted image 20260318191157.png|350]]
				$X~=~A \oplus B$
	- 同或门：只有两个输入均为**相同**电平时，输出才为高电平
		- ![[Pasted image 20260318191327.png]]
		- **运算**：
				![[Pasted image 20260318191351.png|350]]
				$X~=~A \odot B$
