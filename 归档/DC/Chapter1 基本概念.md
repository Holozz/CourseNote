# 数字量和模拟量
- **模拟量**：具有连续的数值，如电压、磁场强度
- **数字量**：具有离散的数值。如开关、0和1、高和低
	- 数字量的表达：按位计数制
# 基本逻辑运算系统
- 二进制数：
	- 二进制系统中0和1两个数称为位，1表示高电压（H），0表示低电压（L）
	- 一组位（0和1的组合）称为码（Codes）
- 逻辑电平：用来表示1和0的电压
	- 高电压：指定最大、最小值之间的任意值
	- 低电压：指定最大、最小值之间的任意值
	- ![[Pasted image 20260314143827.png|400]]
- 数字波形：由两种不同的电平值组成，它们在高低电平或状态之间不断地变化
- 波形特征：
	- 周期$T$：不断重复自身的时间间隔
	- 频率$f$：重复的速率，单位为$Hz$
	- $T = \frac{1}{f}$
	- 占空比：脉冲宽度$t_{w}$和周期$T$的百分比值$\frac{t_{w}}{T}*100\%$
		![[Pasted image 20260314151434.png|400]]
- 数字波形携带二进制信息：
	- 时钟：数字系统中，所有的波形都与一个基本时序波形同步，称之为时钟，其本身不携带任何信息
		![[Pasted image 20260314151500.png|400]]
	- 时序图：数字波形的图形，表示两个或两个以上波形的实际时间关系，还表示波形和波形之间的相互变化关系
		![[Pasted image 20260314151608.png|400]]
- 数据传输：
	- ==串行传输==：数据线少、传输时间长
	- ==并行传输==：数据线多、传输时间短
# 数字集成电路
- 集成电路（IC）
	- 完全由单个小型的硅芯片组成的电子电路
	- 元件：晶体管、二极管、电阻和电容
	- 分类
		- 固定功能集成电路
		- 可编程逻辑电路
# 可编程逻辑
- 可编程逻辑设备
	- PLD: Programmable Logic Device
	- FPGA: Filed Programmable GateArray
	- SPLD: Simple PLD
	- CPLD: Complex PLDs
