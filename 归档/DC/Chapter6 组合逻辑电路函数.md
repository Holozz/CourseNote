# 核心知识导图
本章主要研究五种核心的中规模组合逻辑器件（MSI）及其应用：
1.  **加法器**：算术运算基础。
2.  **比较器**：数值大小判断。
3.  **译码器**：代码转换与地址分配。
4.  **编码器**：请求信号优先级处理。
5.  **多路复用器/分配器**：数据选择与分发。

此外，还需掌握**代码转换电路**的设计方法以及组合逻辑中的**竞争-冒险**现象
# 1. 加法器 (Adders)
加法器是构成算术逻辑单元（ALU）的核心。
## 1.1 半加器 (Half Adder)
- **定义**：仅将两个1位二进制数相加，不考虑来自低位的进位。
- **输入**：A (加数)， B (被加数)
- **输出**：S (本位的和)， \(C_{out}\) (向高位的进位)
- **逻辑表达式**：
    - $S = A \oplus B$
    - $C_{out} = A \cdot B$
- **局限**：仅能处理最低位的加法。
## 1.2 全加器 (Full Adder)
- **定义**：将两个1位二进制数及来自低位的进位相加。
- **输入**：A， B， \(C_{in}\) (来自低位的进位)
- **输出**：$S， C_{out}$
- **逻辑表达式**：
    - \($S = A \oplus B \oplus C_{in}$\)
    - \($C_{out} = AB + (A \oplus B)C_{in}$\)
## 1.3 多位并行加法器 (Ripple Carry Adder)
- **结构**：将多个全加器级联，低位 \($C_{out}$\) 连接高位 \($C_{in}$\)
- **特点**：
    - **优点**：结构简单，扩展方便。
    - **缺点**：**异步进位（行波进位）**导致速度慢。高位必须等待低位进位计算完成，延迟随位数增加而线性增长（最坏情况延迟）**
## 1.4 超前进位加法器 (Carry Look-ahead Adder)
- **核心思想**：并行计算每一位的进位输入，消除级联等待。
- **关键函数**：
    - **进位生成** \($C_{gi} = A_i B_i$\)：若该位产生进位，则必有进位输出。
    - **进位传输** \($C_{pi} = A_i \oplus B_i$\)：若该位为1，则来自低位的进位可以穿过该位。
- **进位逻辑**：
    - \($C_{out,i} = C_{gi} + C_{pi} \cdot C_{in,i}$\)
    - 例如：\($C_4 = C_{g3} + C_{p3}C_{g2} + C_{p3}C_{p2}C_{g1} + C_{p3}C_{p2}C_{p1}C_{g0} + C_{p3}C_{p2}C_{p1}C_{p0}C_{in0}$\)
- **优缺点**：**速度极快**，但电路复杂，扇入系数随位数急剧增加。典型芯片 **74LS283** 即为4位超前进位加法器。
## 例题精讲 1：加法器级联与时序分析
**【题目】** 使用两个4位超前进位加法器74LS283级联构成一个8位加法器。已知输入数据稳定时间为 \(t_{data}=5ns\)，单个74LS283的进位延迟（输入到 \($C_{out}$\)）为 \($t_{p}=10ns$\)，求和延迟为 \($t_{sum}=15ns$\)。试计算该8位加法器在最坏情况下的总运算时间，并说明为什么超前进位芯片级联后仍存在异步延迟。
**【解析】**
1.  **结构分析**：级联时，低4位芯片的进位输出 \($C_4$\) 连接至高4位芯片的进位输入 \($C_{in}$\)。
2.  **延迟路径**：
    - 低4位芯片作为超前进位单元，其内部 \($C_4$\) 产生时间为 \($t_p = 10ns$\)。
    - 高4位芯片必须等待低4位的 \($C_4$\) 稳定后，才能开始内部超前进位计算。
    - 高4位芯片输出和与进位需要额外时间。
3.  **计算**：
    - 低4位产生 \($C_4$\) 的时间：\($t_p = 10ns$\)。
    - 高4位接收 \(C_4\) 后产生最终高位和 \($S_5-S_8$\) 的时间：\($t_{sum} = 15ns$\)。
    - **总时间** = \(10ns + 15ns = 25ns\)。
4.  **结论**：虽然在芯片**内部**是超前进位（并行），但在**芯片之间**由于物理连接和依赖关系，依然存在异步（行波）进位延迟。这是典型的“块内超前，块间行波”结构。

# 2. 比较器 (Comparators)

## 2.1 1位数值比较器
- **功能**：比较 \(A, B\) 的大小。
- **输出函数**：
    - \(F_{A>B} = A \overline{B}\)
    - \(F_{A<B} = \overline{A} B\)
    - \(F_{A=B} = \overline{A \oplus B}\)
## 2.2 多位数值比较器
- **比较规则**：**自高向低逐位比较**。高位能决定大小时，无需看低位；只有高位相等时，才需比较次高位。
- **级联扩展**：典型芯片 **74LS85**。
    - 它不仅比较本级的4位数据，还接收来自低位的比较结果输入（\(I_{A<B}, I_{A=B}, I_{A>B}\)），这种**级联输入**允许芯片扩展比较8位、16位等更宽的数据。
## 例题精讲 2：比较器级联与优先权设计
**【题目】** 使用两片74LS85设计一个8位数值比较器，比较 \(A[7:0]\) 和 \(B[7:0]\)。若将低4位芯片的级联输入强制接为 \(I_{A=B}=1\)，\(I_{A>B}=0\)，\(I_{A<B}=0\)。试分析：当 \(A=1100\ 0011\)，\(B=1100\ 0100\) 时，输出结果是什么？这种接法是否正确？

**【解析】**
1.  **数据分段**：高4位芯片比较 \(A[7:4]=1100\) 和 \(B[7:4]=1100\)；低4位芯片比较 \(A[3:0]=0011\) 和 \(B[3:0]=0100\)。
2.  **接法分析**：低4位芯片级联输入强制为相等（\(I_{A=B}=1\)）。
3.  **逻辑推导**：
    - **低4位芯片**：比较 \(0011 < 0100\)。但由于其级联输入强制为“相等”，低4位芯片无法将“小于”信号传递给高4位，它只能输出自己本级的比较结果，但该结果会被高4位忽略吗？
    - **高4位芯片**：比较 \(1100 = 1100\)，高4位数据相等。此时，高4位芯片的输出取决于其**级联输入引脚**（即低4位芯片的输出）。
    - **结果**：低4位实际输出为 \(A<B\)（真），故高4位接收到的级联输入为 \($I_{A<B}=1$\)，最终总输出为 **\(A<B\)**。
4.  **结论**：**正确**。对于最低位芯片（LSB），没有更低位的比较结果传入，因此必须将其级联输入固定为“相等状态”（\($I_{A=B}=1$\)），表示“假设更低且不存在的位是相等的”，这符合逻辑运算的初始条件。
# 3. 译码器 (Decoders)
译码器是**“多对一”**的输出选择逻辑，识别特定二进制代码。
### 3.1 二进制译码器 (N-to-\(2^N\) Line Decoder)
- **功能**：n条输入线，\(2^n\)条输出线。对于每一个输入组合，有且仅有一个对应输出有效（高/低电平）。
- **应用核心**：**产生最小项**。每个输出端对应一个输入变量的最小项 \($m_i$\)。
- **扩展**：利用使能端（Enable）进行级联，可将4-16译码器（如**74HC154**）扩展为5-32译码器。
## 3.2 显示译码器 (BCD-to-7-Segment Decoder)
- **常见芯片**：
    - **74LS47**：驱动**共阳极**数码管，输出低电平有效（开集电极输出，耐压高）。
    - **74LS48**：驱动**共阴极**数码管，输出高电平有效，内部带上拉电阻。
- **特殊控制端功能**：
    - **LT (Lamp Test)**：灯测试，强制所有段点亮，检查是否有坏点。
    - **RBI (Ripple Blanking Input)**：灭零输入。用于消除整数前导零（如显示“003”中的前两个零）。
    - **BI/RBO**：灭灯输入/灭零输出。双重功能引脚，既可作为输入强制灭灯，也可作为输出通知下一级本芯片已灭零
## 例题精讲 3：译码器实现逻辑函数
**【题目】** 使用一片74HC154（4-16译码器，低电平输出有效）和一个多输入与非门，实现逻辑函数 \($F(A,B,C,D) = \sum m(1, 4, 7, 9, 14, 15)$\)。

**【解析】**
1.  **理论依据**：任何组合逻辑函数均可表示为最小项之和（\(\sum m\)）。低电平有效的译码器输出为 \(\overline{m_i}\)。
2.  **表达式转换**：
   $$ [
    F = m_1 + m_4 + m_7 + m_9 + m_{14} + m_{15}
    ]$$
    利用摩根定理求反：
    $$
    \
    F = \overline{\overline{m_1 + m_4 + m_7 + m_9 + m_{14} + m_{15}}} = \overline{\overline{m_1} \cdot \overline{m_4} \cdot \overline{m_7} \cdot \overline{m_9} \cdot \overline{m_{14}} \cdot \overline{m_{15}}}
    \
    $$
3.  **电路连接**：
    - 将函数变量 \(A, B, C, D\) 分别接至译码器的地址输入端（A接高位）。
    - 将输出端 \($\overline{Y_1}, \overline{Y_4}, \overline{Y_7}, \overline{Y_9}, \overline{Y_{14}}, \overline{Y_{15}}$\) 引出，连接至一个**6输入与非门**的输入端。
    - 该与非门的输出即为函数 \(F\)。
# 4. 编码器 (Encoders)

## 4.1 普通编码器 vs 优先编码器
- **普通编码器**：要求**任何时刻只有一个输入有效**，否则输出混乱。
- **优先编码器**：允许多输入同时有效，电路按**优先级高低**输出编码值。输入下标越大，通常优先级越高（如74HC148）。
## 4.2 典型芯片：74HC148 (8线-3线优先编码器)
- **输入**：\($\overline{I_0} \sim \overline{I_7}$\) (低有效，7优先级最高)
- **输出**：\($\overline{A_2}, \overline{A_1}, \overline{A_0}$\) (反码输出)
- **级联控制端**：
    - **EI (Enable Input)**：使能，低有效。若EI=1，芯片不工作。
    - **EO (Enable Output)**：使能输出。当EI=0且**无任何有效输入**时，EO=0。
    - **GS (Group Signal)**：组信号。当EI=0且**有任意有效输入**时，GS=0。
## 例题精讲 4：编码器级联扩展与地址映射
**【题目】** 利用两片74HC148级联构成一个16线-4线优先编码器。要求：输入 \($\overline{A_{15}} \sim \overline{A_0}$\)（15优先级最高），输出为原码 \($Y_3 Y_2 Y_1 Y_0$\)。
1. 画出级联框图，标明高位片与低位片。
2. 当输入 \($\overline{A_{10}}$\) 有效（低电平），其余无效时，求输出 \($Y_3 Y_2 Y_1 Y_0$\) 的值。
**【解析】**
3.  **级联连接**：
    - **高位片**处理 \($A_{15} \sim A_8$\)，**低位片**处理 \($A_7 \sim A_0$\)。
    - **优先级传递**：高位片的**EO** 接 低位片的**EI**。若高位片无有效输入，EO=0 使能低位片工作。
    - **高位指示**：高位片的GS信号经反相后作为最高位输出 \($Y_3$\)。
    - **数据线合并**：两片芯片的低3位输出 \($\overline{A_2} \overline{A_1} \overline{A_0}$\) 分别通过与门（或线与）合并，再反相得到 \($Y_2 Y_1 Y_0$\)
4.  **计算 \(A_{10}\) 情况**：
    - \($A_{10}$\) 属于高位片（对应 \($I_2$\) 引脚，编码为 \(010\) 的反码即 \(101\)）。
    - 高位片有输入，故其 GS=0，经反相后 \(Y_3 = 1\)。
    - 高位片 EO=1，**封锁**低位片（低位片 EI=1），低位片输出全为1。
    - 高位片输出反码 \(101\)，反相后得 \($Y_2 Y_1 Y_0 = 010$\)。
    - **最终结果**：\($Y_3 Y_2 Y_1 Y_0 = 1\ 0\ 1\ 0$\)，即十进制 10。对应输入 \($A_{10}$\)，正确。
# 5. 多路复用器与分配器 (MUX & DEMUX)

## 5.1 多路复用器 (Data Selector)
- **核心公式**：n位地址选择线，对应 \(2^n\) 路数据输入。
- **通用逻辑函数发生器**：MUX是最灵活的器件之一。
    - **原理**：MUX的输出表达式为 \($Y = \sum_{i=0}^{2^n-1} (m_i \cdot D_i)$\)。通过设置数据输入端 \($D_i$\) 为0或1，可以方便地实现任何n变量逻辑函数。
- **降维实现**：使用 \($2^{n-1}$\) 选1 MUX实现n变量函数（将某一变量移入数据端）。
## 5.2 奇偶校验器 (74LS280)
- **功能**：检测输入包含“1”的个数是奇数还是偶数。
- **应用**：在数据传输中产生或校验奇偶校验位（Parity Bit）。
## 例题精讲 5：数据选择器实现复杂逻辑函数（降维法）
**【题目】** 仅使用一片8选1数据选择器（如74LS151）和少量门电路（非门），实现函数 \($F(A,B,C,D) = \sum m(0, 3, 5, 6, 9, 10, 12, 15)$\)。

**【解析】**
1.  **变量分配**：8选1有3根地址线。我们将 A, B, C 接至地址线 \($S_2, S_1, S_0$\)。剩下的 D 作为**数据输入变量**。
2.  **绘制卡诺图降维（确定 \($D_i$\) 逻辑）**：
    - 列出真值表或卡诺图（A为高位，D为低位）。
    - 观察每一组 \((A,B,C)\) 固定值时，输出F与变量D的关系。

| A B C |   D=0   |   D=1   |     对应MUX数据端 \(D_i\)     |        备注        |
| :---: | :-----: | :-----: | :----------------------: | :--------------: |
| 0 0 0 | 1 (m0)  |    0    | \($D_0 = \overline{D}$\) | D为0时输出1，D为1时输出0  |
| 0 0 1 |    0    | 1 (m3)  |      \($D_1 = D$\)       |                  |
| 0 1 0 |    0    | 1 (m6)  |      \($D_2 = D$\)       |                  |
| 0 1 1 | 1 (m5)  |    0    | \($D_3 = \overline{D}$\) |                  |
| 1 0 0 | 1 (m12) |    0    | \($D_4 = \overline{D}$\) |                  |
| 1 0 1 |    0    | 1 (m10) |      \($D_5 = D$\)       | (注：m9无效，但由m10确定) |
| 1 1 0 | 1 (m9)  |    0    | \($D_6 = \overline{D}$\) |                  |
| 1 1 1 |    0    | 1 (m15) |      \($D_7 = D$\)       |                  |

3.  **电路实现**：
    - 地址线：\(S_2=A, S_1=B, S_0=C\)。
    - 数据线：\($D_0, D_3, D_4, D_6$\) 接 \($\overline{D}$\) (需一个非门产生 \($\overline{D}$\))。
    - 数据线：\($D_1, D_2, D_5, D_7$\) 接 \(D\)。
    - 使能端接地（有效）。
    - 输出Y即为F


# 6. 组合逻辑电路中的竞争与冒险 (Hazards)

## 6.1 基本概念
- **竞争 (Race)**：门电路两个输入信号同时向相反逻辑电平跳变的现象。
- **冒险 (Hazard)**：由于竞争而在输出端产生**不应有的尖峰脉冲（Glitch）**。
- **判别方法**：
    1.  **逻辑代数法**：若在特定条件下（如 \(B=C=1\)），输出函数能化简为 \($Y = A + \overline{A}$\) 或 \($Y = A \cdot \overline{A}$\) 的形式，则存在竞争-冒险。
    2.  **卡诺图法**：卡诺图中，两个相邻的质蕴涵圈（Prime Implicant）相切，且切点处未被另一个圈覆盖，则存在冒险。
## 6.2 消除方法
1.  **接入滤波电容**：在输出端对地接小电容（几十~几百pF），吸收毛刺。*副作用：使输出波形边沿变缓，限制工作速度。*
2.  **引入选通脉冲**：在信号稳定后、跳变结束后再读取输出。*即同步逻辑思想。*
3.  **修改逻辑设计（增加冗余项）**：在卡诺图上将相切的两圈用**冗余圈**连接起来。这是最根本的解决方法。

## 例题精讲 6：竞争冒险分析与冗余项消除
**【题目】** 分析组合逻辑电路 \(F = AB + \overline{A}C\)。当 \(B=C=1\) 时，判断是否存在竞争冒险？若存在，如何通过增加冗余项消除？

**【解析】**
1.  **代数法分析**：
    当 \(B=1, C=1\) 时，原式变为：
    $F = A \cdot 1 + \overline{A} \cdot 1 = A + \overline{A}$
    理论上输出恒为1。但实际上，非门有延迟。当A从1跳变到0时，\($\overline{A}$\) 从0跳变到1会滞后。在滞后的 \(\Delta t\) 内，会出现 \($A=0, \overline{A}=0$\) 的瞬间，导致与门输出均为0，使得最后的或门输出产生一个**负向毛刺（0尖峰）**。**结论：存在1态冒险。**

2.  **卡诺图法分析**：
    - 画出函数 $F = AB + \overline{A}C$ 的卡诺图。
    - 圈出两个质蕴涵圈：一个圈覆盖 \(AB=11\)（即 \(A=1, B=1\)），另一个圈覆盖 \($\overline{A}C=11$\)（即 \(A=0, C=1\)）。
    - 当 \(B=1, C=1\) 时，这两个圈在 \(BC=11\) 的列上**相切**（从A=0切到A=1），且无第三个圈覆盖切点。这印证了冒险的存在。

3.  **消除方法**：
    增加一个**冗余项** \(BC\)，覆盖相切的边沿。
    修改后的逻辑式为：
    $$[
    F_{new} = AB + \overline{A}C + BC
    ]$$
    当 \($B=1, C=1$\) 时，冗余项 \($BC=1$\)，无论A如何跳变，输出都被强制钳位在1，彻底消除了毛刺
