
## 核心知识导图

本章系统讲解数字系统中实现**1位二进制信息存储**的基本单元电路，以及产生定时脉冲的相关电路。

1.  **锁存器 (Latch)**：电平触发，结构简单，但抗干扰能力弱。
2.  **边沿触发器 (Edge-Triggered Flip-Flop)**：仅在时钟边沿采样，抗干扰能力强，是同步时序电路的基础。
3.  **触发器的运算特性**：建立时间 $t_{su}$、保持时间 $t_h$、传输延迟 $t_{pd}$ 等关键时序参数。
4.  **触发器应用**：并行数据存储、分频器、计数器。
5.  **单稳态触发器与555定时器**：生成由 $RC$ 决定的单脉冲或矩形波。

---

## 1. 锁存器 (Latch)

锁存器是**电平敏感**的双稳态存储电路。其状态在使能信号有效期间随输入变化而改变。

### 1.1 基本SR锁存器

| 类型 | 构成 | 有效电平 | 特性方程 | 约束条件 |
| :--- | :--- | :--- | :--- | :--- |
| 高有效SR锁存器 | 或非门交叉耦合 | $S=1$置位，$R=1$复位 | $Q^* = S + \overline{R} Q$ | $S \cdot R = 0$ |
| 低有效SR锁存器 | 与非门交叉耦合 | $\overline{S}=0$置位，$\overline{R}=0$复位 | $Q^* = \overline{\overline{S}} + \overline{R} Q$ | $\overline{S} + \overline{R} = 1$ |

> **重点理解**：对于与非门构成的低有效SR锁存器，两个输入**同时为0**是非法的，撤除后状态不确定。同时为1则保持。

### 1.2 门控锁存器 (Gated Latch)

引入**使能端 (GATE 或 CLK)**，仅当 GATE 有效时，锁存器才对输入敏感。

- **门控SR锁存器**：在 $GATE=1$ 期间，功能同基本SR锁存器。若 $S$、$R$ 多次变化，输出**也随之多次翻转**。
- **门控D锁存器**：将 $S$ 接 $D$，$R$ 接 $\overline{D}$，可消除非法状态。$GATE=1$ 时透明（$Q = D$），$GATE=0$ 时锁存最后值。

### 1.3 电平触发方式的动作特点（重点缺陷）

> **核心缺陷**：在CLK有效电平（如高电平）的**整个期间**，输入信号的变化都会直接引起输出端状态的变化。若此期间输入端有**毛刺或多次跳变**，触发器的状态也会**发生多次翻转**，严重降低了电路的**抗干扰能力**。

## 2. 边沿触发器 (Edge-Triggered Flip-Flop)

### 2.1 边沿触发的核心优势
**次态仅取决于时钟脉冲有效边沿（上升沿或下降沿）到达时刻的输入状态**。在此之前和之后，输入信号的变化对输出无影响。这极大地提高了抗干扰能力和工作可靠性。

- **边沿触发指示**：逻辑符号中，时钟输入端有动态输入指示器（小三角 $\triangleright$）。

### 2.2 边沿触发的S-R触发器
- 在时钟边沿，$S$ 和 $R$ 决定输出状态，功能表类似基本SR锁存器，但受窄脉冲边沿约束。

### 2.3 边沿触发的D触发器（应用最广）
- **特性方程**：$Q^* = D$
- 在有效时钟边沿，输出 $Q$ 将跟随输入 $D$ 的值；其他时间保持不变。
- 典型芯片：74LS74（双上升沿D触发器）。

### 2.4 边沿触发的J-K触发器（功能最全）
- **特性方程**：$$Q^* = J\overline{Q} + \overline{K}Q$$
- **功能表**：

| $J$ | $K$ | 功能 | 次态 $Q^*$ |
| :--: | :--: | :---: | :---: |
| 0 | 0 | 保持 | $Q$ |
| 0 | 1 | 复位 | 0 |
| 1 | 0 | 置位 | 1 |
| 1 | 1 | **翻转** | $\overline{Q}$ |

> **T触发器**：将J-K触发器的 $J$ 和 $K$ 连接在一起，作为 $T$ 输入端，即构成T触发器。特性方程为 $Q^* = T \oplus Q$。当 $T=1$ 时，每个时钟边沿翻转一次，可用于分频。

### 2.5 异步预置位 (Preset) 与清零 (Clear)
- **异步输入**：不受时钟控制，直接迫使触发器输出为1（$\overline{PRE}$ 有效）或0（$\overline{CLR}$ 有效），通常低电平有效。
- **优先级最高**：一旦异步输入有效，触发器立即响应，同步输入端和时钟信号均被忽略。


### 例题精讲 1：带异步控制的边沿触发器波形分析
**【题目】** 图示为一负边沿触发的J-K触发器，带有低电平有效的异步清零端 $\overline{CLR}$ 和异步预置端 $\overline{PRE}$。输入波形如下图所示，设触发器初始状态 $Q=0$。请画出输出 $Q$ 的波形。

*(假设波形描述)*：
- 时钟CLK：周期波形。
- $\overline{PRE}$：初始高电平，在 $t_1$ 时刻产生一个负脉冲（低电平）后恢复高。
- $J$：在 $t_2$ 时刻由0变1。
- $K$：始终为0。
- $\overline{CLR}$：初始高电平，在 $t_3$ 时刻产生一个负脉冲后恢复高。
- $t_1, t_2, t_3$ 的时间顺序：$t_1$ < 时钟边沿A < $t_2$ < 时钟边沿B < $t_3$ < 时钟边沿C ...

**【解析】**
1.  **初始状态**：$Q=0$。
2.  **$t_1$ 时刻 ($\overline{PRE}$负脉冲)**：异步预置端有效（=0），输出 $Q$ **立即无条件置为1**，与时钟无关。这是异步行为。
3.  **时钟边沿A**：发生在 $\overline{PRE}$ 恢复高后，$J=0$，$K=0$。根据功能，$J=0,K=0$ 时**保持**，$Q$ 仍为1。
4.  **$t_2$ 时刻 ($J$ 变为1)**：此时不在时钟边沿，输入变化对 $Q$ 无影响，$Q=1$。
5.  **时钟边沿B (下降沿)**：此时 $J=1$，$K=0$，功能为**置位**。但 $Q$ 当前已是1，所以 $Q^*=1$，输出仍然保持1。
6.  **$t_3$ 时刻 ($\overline{CLR}$ 负脉冲)**：异步清零端有效（=0），输出 $Q$ **立即无条件被清零**，$Q$ 变为0。
7.  **时钟边沿C**：此时 $J=1$，$K=0$，$Q^*=1$。$Q$ 在边沿后变为1。

> **结论**：画波形时，必须首先处理**异步控制信号**，它们具有最高优先级。只有在异步信号无效时，时钟边沿和同步输入 $J/K$ 才按功能表决定次态。

## 3. 触发器的运算特性 (Timing Characteristics)

为保证触发器可靠锁存正确数据，必须满足以下时序约束：

| 参数 | 符号 | 定义 | 设计要求 |
| :--- | :--- | :--- | :--- |
| **建立时间** | $t_{su}$ | 数据输入在时钟有效边沿**之前**必须稳定存在的**最小时间**。 | 数据提前稳定时间 > $t_{su}$ |
| **保持时间** | $t_h$ | 数据输入在时钟有效边沿**之后**必须继续保持稳定的**最小时间**。 | 数据保持稳定时间 > $t_h$ |
| **传播延迟** | $t_{pd}$ | 从时钟边沿到输出 $Q$ 发生稳定变化所需的时间。 | 影响电路最高工作频率 |
| **最大时钟频率** | $f_{max}$ | 由厂商给定的触发器可可靠触发的最高时钟频率。 | 系统时钟 < $f_{max}$ |

> **关键警示**：违反 $t_{su}$ 或 $t_h$ 会导致触发器进入**亚稳态 (Metastability)**，输出为非“0”非“1”的中间电平且恢复时间不可预测，是同步系统设计中的首要隐患。


### 例题精讲 2：时序违规与亚稳态分析
**【题目】** 某上升沿触发的D触发器，$t_{su}=5\,\text{ns}$，$t_h=3\,\text{ns}$，$t_{pd}=8\,\text{ns}$。将其输出 $\overline{Q}$ 反馈接回 $D$ 输入端，构成二分频器。时钟频率为 $100\,\text{MHz}$ (周期 $10\,\text{ns}$)。试分析此电路能否可靠工作？若不能，指出问题并提出解决方案。

**【解析】**
1.  **电路分析**：$\overline{Q}$ 反馈到 $D$，即 $D = \overline{Q}$。每个时钟上升沿，输出翻转。
2.  **路径延迟计算**：从时钟上升沿触发，到 $\overline{Q}$ 稳定输出的延迟为 $t_{pd}=8\,\text{ns}$。这个新的 $\overline{Q}$ 值就是下一个时钟沿的 $D$ 输入。
3.  **建立时间检查**：新 $D$ 值在时钟沿后 $8\,\text{ns}$ 才稳定。而下一个时钟上升沿在 $10\,\text{ns}$ 后到来。因此，**数据在下一个时钟沿前稳定的时间**为 $10\,\text{ns} - 8\,\text{ns} = 2\,\text{ns}$。
4.  **违规判定**：建立时间要求数据提前 $t_{su}=5\,\text{ns}$ 稳定。实际只有 $2\,\text{ns}$，**远小于 $5\,\text{ns}$**，严重违反建立时间。此电路在 $100\,\text{MHz}$ 下**无法可靠工作**，会发生亚稳态。
5.  **解决方案**：降低时钟频率，使周期 $T > t_{pd} + t_{su} = 13\,\text{ns}$，即 $f_{max} < 77\,\text{MHz}$。或使用速度更快、$t_{pd}$ 更小的触发器。

## 4. 触发器应用

### 4.1 并行数据存储
多个D触发器的时钟端连在一起，同一时钟边沿将多位数据 $D$ 并行存入各自 $Q$ 端。这是寄存器（Register）的基础。

### 4.2 分频器
将D触发器的 $\overline{Q}$ 反馈回 $D$ 端（构成T触发器且 $T=1$），每个时钟边沿触发器翻转一次，输出频率为时钟频率的一半。
- **$N$ 个触发器级联**，可实现 $2^N$ 分频。

### 4.3 二进制计数器
- 触发器直接构成计数器的基础单元。每个触发器可表示二进制数的一位。
- **状态循环**：对于模 $2^N$ 计数器，每 $2^N$ 个时钟脉冲，输出状态循环一次。


### 例题精讲 3：分频器级联与波形分析
**【题目】** 一个 $8\,\text{kHz}$ 的方波信号加在两个级联的上升沿D触发器的时钟输入端。每个触发器的 $\overline{Q}$ 均反馈连接至自身的 $D$ 输入端，第一个触发器的 $Q$ 输出作为第二个触发器的时钟信号。画出触发器A和B的输出波形，并计算B输出的频率。

**【解析】**
1.  **触发器A**：接成二分频器，$\overline{Q_A}$ 接 $D_A$。输入时钟 $f_{clkA}=8\,\text{kHz}$。$Q_A$ 输出为输入时钟的二分频，即波形为 $4\,\text{kHz}$ 方波，且与时钟同步。
2.  **触发器B**：时钟端接 $Q_A$，同样接成二分频器，$\overline{Q_B}$ 接 $D_B$。注意，**级联是异步方式**。每当 $Q_A$ 产生一次上升沿，触发器B就翻转一次。
3.  **波形绘制**：
    - $Q_A$ 在CLK的每个上升沿（假设）翻转，频率为 $4\,\text{kHz}$。
    - $Q_B$ 在 $Q_A$ 的每个上升沿翻转，频率为 $2\,\text{kHz}$。
4.  **频率计算**：触发器A输出频率 $f_{QA} = 8\,\text{kHz} / 2 = 4\,\text{kHz}$。触发器B输出频率 $f_{QB} = 4\,\text{kHz} / 2 = 2\,\text{kHz}$。
5.  **总计分频**：两级级联实现了 **4分频** ($8\,\text{kHz} / 4 = 2\,\text{kHz}$)。如果用 $n$ 个触发器级联，可得到 $2^n$ 分频。

## 5. 单稳态触发器与555定时器

### 5.1 矩形脉冲参数
- **占空比 $D$**：$D = \frac{t_w}{T}$，其中 $t_w$ 是正脉冲宽度，$T$ 是周期。

### 5.2 单稳态触发器 (Monostable Multivibrator)
- **特点**：一个稳态 + 一个暂稳态。
- **工作过程**：窄触发脉冲 → 进入暂稳态（输出脉冲）→ $RC$ 延时后自动返回稳态。
- **脉冲宽度**：$t_w$ 仅由外接的 **$R$ 和 $C$ 时间常数**决定，与触发脉冲宽度无关。
- **分类**：
    1.  **不可重复触发型**：暂稳态期间，新触发脉冲**无效**。
    2.  **可重复触发型**：新触发脉冲会**重新开始定时**，延长暂稳态。

### 5.3 非稳态多谐振荡器 (Astable Multivibrator)
- **特点**：**无稳态**，两个暂稳态相互交替。
- **原理**：不需要触发信号，上电即通过正反馈和 $RC$ 充放电自由振荡，产生连续的矩形脉冲。

### 5.4 555定时器
一种多用途数模混合IC，可配置为两种主要模式：
- **单稳态模式**：产生单脉冲，脉宽 $t_w = 1.1 \, R \, C$。
- **非稳态模式**：产生连续方波，
  $$f \approx \frac{1.45}{(R_A + 2R_B)C}, \quad D = \frac{R_A+R_B}{R_A+2R_B}$$


### 例题精讲 4：555定时器非稳态电路设计
**【题目】** 利用555定时器设计一个非稳态多谐振荡器，要求产生频率为 $10\,\text{kHz}$、占空比为 $60\%$ 的矩形波。电源电压为 $+5\,\text{V}$。请画出电路图并确定外接元件 $R_A$、$R_B$ 和 $C$ 的一个合理取值组合。

**【解析】**
1.  **设计公式**：
    - 电容充电时间（输出高电平）：$t_1 = 0.693(R_A + R_B)C$
    - 电容放电时间（输出低电平）：$t_2 = 0.693(R_B)C$
    - 周期：$T = t_1 + t_2 = 0.693(R_A + 2R_B)C$
    - 频率：$f = 1/T = \frac{1.44}{(R_A + 2R_B)C}$
    - 占空比：$D = t_1/T = \frac{R_A+R_B}{R_A+2R_B}$

2.  **求解元件值**：
    - 已知 $D=0.6$，所以 $\frac{R_A+R_B}{R_A+2R_B} = 0.6 \Rightarrow R_A+R_B = 0.6R_A+1.2R_B \Rightarrow 0.4R_A = 0.2R_B \Rightarrow R_A = 0.5 R_B$。
    - 取 $R_B = 10\,\text{k}\Omega$，则 $R_A = 5\,\text{k}\Omega$。
    - 已知 $f=10\,\text{kHz}$，代入频率公式求 $C$：
      $$C = \frac{1.44}{f(R_A+2R_B)} = \frac{1.44}{10 \times 10^3 \times (5+20) \times 10^3} = \frac{1.44}{2.5 \times 10^8} = 5.76 \times 10^{-9}\,\text{F}$$
    - 取标称值电容 $C \approx 5600\,\text{pF}$ 或 $5.7\,\text{nF}$。

3.  **电路连接**：
    - 555芯片，$V_{CC}$ 和 RESET 接 $+5\,\text{V}$。
    - $R_A$ 一端接 $V_{CC}$，另一端接 DIS (7脚) 和 $R_B$ 一端。
    - $R_B$ 另一端接 THRES (6脚) 和 TRIG (2脚)，并通过电容 $C$ 接地。
    - CONT (5脚) 通过一个 $0.01\,\mu\text{F}$ 防噪电容接地。
    - OUT (3脚) 即输出 $10\,\text{kHz}$ 方波。

## 总结

-   **锁存器是电平敏感，边沿触发器是边沿敏感。** 后者抗干扰能力大幅提升，是同步时序电路首选。
-   **时序约束**是触发器应用核心。设计时必须计算路径延迟，确保满足所有触发器的 $t_{su}$、$t_h$，防止亚稳态。
-   **D触发器和JK触发器**是最常用的两个功能类型。JK功能全面，D使用方便。
-   **555定时器**是经典的模数混合电路，掌握其单稳（$t_w=1.1RC$）和非稳态（频率、占空比）的计算方法是应用关键。
