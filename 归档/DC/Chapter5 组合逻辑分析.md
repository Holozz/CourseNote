## 1. 组合逻辑电路概述

### 1.1 数字电路分类
- **组合逻辑电路**：输出仅取决于当前输入，**无记忆功能**。
- **时序逻辑电路**：输出不仅取决于当前输入，还与电路历史状态有关。
### 1.2 组合逻辑电路的特点
- 任何时刻输出状态 **只决定于该时刻的输入状态**。
- 电路 **不含存储单元**，输出与输入之间 **无反馈延迟通路**。
### 1.3 逻辑功能描述方法
| 方法         | 说明                           |
|--------------|--------------------------------|
| 真值表       | 列出所有输入组合与对应输出     |
| 卡诺图       | 用于化简逻辑函数               |
| 逻辑表达式   | SOP（与或式）或 POS（或与式）  |
| 时序图       | 描述信号随时间变化的关系       |

> 以上几种方法之间 **可以相互转换**。

### 1.4 基本逻辑形式
- **与-或逻辑（SOP）**：乘积项之和，由与门产生乘积项，或门求和。
- **与-或-非逻辑**：对 SOP 取反得到。
- **异或逻辑（XOR）**：两输入不同时输出 1。
- **同或逻辑（XNOR）**：异或门加反相器，输入相同时输出 1。

## 2. 组合逻辑电路的分析

### 2.1 分析步骤
1. 根据逻辑图写出输出函数表达式。
2. 利用公式法或卡诺图化简逻辑表达式。
3. 列出真值表。
4. 描述电路逻辑功能。

### 2.2 分析示例
- **全加器电路分析**：输入 A、B、CI，输出 S（和）、CO（进位）。
- 由真值表确认其为 **带低位进位的加法器**。

---

## 3. 组合逻辑电路的实现

### 3.1 从布尔表达式到逻辑电路
- 每个乘积项用与门实现，多项求和用或门实现。
- 示例：`X = AB + CDE` 需两个与门和一个或门。

### 3.2 从真值表到逻辑电路
- 写出输出的 SOP 表达式 → 化简 → 绘制逻辑图。

### 3.3 设计步骤（通用流程）
1. **逻辑抽象**：确定输入/输出变量，定义逻辑状态含义。
2. **列真值表**。
3. **写出逻辑函数式**。
4. **选择器件类型**（如小规模集成电路）。
5. **化简或变换表达式**（适应所选门类型）。
6. **画出逻辑电路图**。
7. **工艺设计**（实际布线等）。

## 4. 与非门和或非门的通用特性

### 4.1 与非门（NAND）的通用性
- **单个与非门** → 反相器（输入并接）。
- **两个与非门** → 与门。
- **三个与非门** → 或门。
- **四个与非门** → 或非门。
> 任何逻辑函数均可 **仅用与非门** 实现。
### 4.2 或非门（NOR）的通用性
- **单个或非门** → 反相器。
- **两个或非门** → 或门。
- **三个或非门** → 与门。
- **四个或非门** → 与非门。
> 任何逻辑函数均可 **仅用或非门** 实现。
### 4.3 双重符号表示法（便于阅读）
- **与非逻辑** 可视为 **非-或** 形式：输入端带圈，输出端无圈。
- **或非逻辑** 可视为 **非-与** 形式：输入端无圈，输出端带圈。
- **规则**：圈连圈、非圈连非圈，保证信号极性匹配。

## 5. 使用与非门和或非门实现组合逻辑

### 5.1 用与非门实现 SOP 表达式
- 例：`X = AB + CD`
- 方法：两次取反，利用 **与非-与非** 结构。
- 电路结构：两个与非门分别产生 `(AB)'` 和 `(CD)'`，再经一个与非门得到最终输出。
### 5.2 用或非门实现 POS 表达式
- 例：`X = (A+B)(C+D)`
- 方法：两次取反，转换为 **或非-或非** 结构。

## 6. 具有脉冲波形输入的逻辑电路运算

### 6.1 基本规则
- **与门**：所有输入同时为高时，输出才为高。
- **或门**：至少一个输入为高时，输出即为高。
- **与非门**：所有输入同时为高时，输出才为低。
- **或非门**：只要有一个输入为高，输出即为低。

### 6.2 波形分析示例
- 给定输入波形 A、B，逐段分析输出波形。
- 注意 **传播延迟** 忽略不计时，输出变化与输入同步。

## 7. 组合逻辑电路设计实例

### 7.1 交通信号灯故障监视电路
- **输入**：R（红）、A（黄）、G（绿），亮为 1。
- **输出**：Z（故障），正常为 0，故障为 1。
- **真值表异常情况**：三灯全灭或全亮，或任意两灯同时亮。
- **逻辑式**（化简后）：
  ```
  Z = R'A'G' + RAG + RA + RG + AG
  ```
- **实现**：用与非门构成两级与非结构。

### 7.2 病房优先呼唤电路
- **输入**：A、B、C、D（按钮，按下为 1），优先级 A > B > C > D。
- **输出**：L1～L4 对应病房灯亮。
- **逻辑关系**：
  - L1 = A
  - L2 = A'B
  - L3 = A'B'C
  - L4 = A'B'C'D
- **实现**：用与门和反相器组合，或转换为与非-与非形式。

## 8. 课程回顾与总结

- **组合逻辑核心**：输出仅由当前输入决定。
- **分析**：逻辑图 → 表达式 → 真值表 → 功能说明。
- **设计**：真值表 → 表达式 → 化简 → 电路图。
- **通用门**：与非门、或非门可单独实现任何逻辑函数。
- **脉冲波形分析**：依据门类型逐时刻判断输出。
- **双重符号法**：帮助理解与非/或非结构的等效变换。
