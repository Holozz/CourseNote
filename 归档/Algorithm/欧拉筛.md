## 基本想法
 给定范围n，从第一个数开始寻找质数，存入prime数组，同时，无论当前数字是否为质数，将其与prime数组里的质数相乘就一定得到合数，直接把得到的所有合数筛掉。
**重要一步：**
在遍历prime数组的元素以得到相乘后的合数的时候，如果当前数字能够被该元素整除，意味着该元素其实已经被这个元素也“筛”过了。
***比如*** 到数字8的时候，8早已被4 * 2标记为合数，不会添加进prime数组里，此时只会执行8 * 2把16也排除掉，而且，由于8 % 2 == 0所以不会再让8和更大的质数相乘。
==1.==早先到数字4的时候，4被2 * 2标记为合数不会存进prime，以及4 % 2 == 0所以只会有4 * 2 == 8 一个标记，**但是**，4的其他倍数也是合数，为什么不在这个时候标记呢？因为4是2的倍数，所以任何更大的4的其他倍数肯定也是2的倍数，而且在后面一定会被2继续标记（*比如* 例子的8 * 2标记16），如果现在就标记显然会重复标记，所以如果当前数字可以被质数整除的话就没必要继续标记了，后面还会标记到
==2.==现在到数字8也只是标记了16，至于16前后的数字的标记情况：
2：标记4
3：标记6，9
4：标记8
5：标记10，15，25
6：标记12
7：标记14，21，35，49
8：标记16
9：标记18，27
10：标记20
11：标记22，33，55，77，121

$$代码实现$$
```python
	n=int(input())
	pri=[True]*(n+1)
	res=[]
	
	pri[0]=pri[1]=False
	for i in range(2, n+1):
	  if pri[i]:
		res.append(i)
	  for j in res:
		if j*i>n:
		  break
		pri[j*i]=False
		if i%j==0:
		  break
	print([i for i in range(n+1) if pri[i]])
	print(res)
```
