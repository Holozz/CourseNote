## 题目描述

给出n个非负整数a1​,a2​,…,an​，求一段连续的子序列ai​,ai+1​,…,aj−1​，使得这个区间的长度乘以区间内的最小值最大。输出这个最大值，即
$$\mathrm{ans}=\max_{1\leq i\leq j\leq n}\left((j-i)\times\min_{i\leq k<j}a_k\right).$$
### 输入描述
第一行，一个整数n (1≤n≤2×105)，表示数组的长度。  
第二行，n个整数$$a_1​,a_2​,…,a_n​ (0≤a_i​≤10^9)$$，表示数组的元素。
### 输出描述
输出一个整数，表示最大值。
### 输入样例1

```

2 3 5 6 4 1
```
### 输出样例1

```
12
```
### 提示

- 注意潜在的溢出问题。
- 使用O(n2)的算法会超时。本题有多种解法，可以考虑使用单调栈
## 解答
~~~cpp
	#include <iostream>
	#include <stack>
	#include <vector>
	using namespace std；
	
	int main() {
	    int n; cin >> n;
	    stack<long long> st;
	    vector<long long> a(n), left(n,0), right(n,0), s(n,0);

	    for(int i=0; i<n; i++) {
	        cin >> a[i];
	        while(!st.empty() && a[i] < a[st.top()]) st.pop();
	        left[i] = st.empty() ? i : i - st.top() - 1;
	        st.push(i);
	    }
	
	    st = stack<long long>();
	    long long maxArea = 0;
	
	    for(int i=n-1; i>=0; i--) {
	        while(!st.empty() && a[i] <= a[st.top()]) st.pop();
	        right[i] = st.empty() ? n-1-i : st.top() - i - 1;
	        st.push(i);
	  
	        s[i] = a[i]*(left[i]+right[i]+1);
	        if(s[i] > maxArea) maxArea = s[i];
	    }
	    cout << maxArea;
	    return 0;
	}
~~~
