## 一、集合关系与函数（Lecture 1）
### 1.1 集合基本概念

| 概念       | 说明                                                                  |
| -------- | ------------------------------------------------------------------- |
| **外延原则** | 两集合元素完全相同则相等，与名字无关                                                  |
| **定义方法** | 枚举法 `{1,2,3}`、性质概括法 `{x\|P(x)}`、归纳定义法（基本元素 + 构造规则）                  |
| **幂集**   | $\mathcal{P}(A) = \{X \mid X \subseteq A\}$，$\mathcal{P}(A)= 2^{A}$ |

### 1.2 等价关系与商集
- **等价关系**：自反 + 对称 + 传递
- **等价类**：$[a] = \{x \in A \mid x R a\}$
- **商集**：$A/R = \{[a] \mid a \in A\}$
- **划分**：$A$ 的一个划分是 $A$ 的子集族，两两不交且并为 $A$
- ⚠️ 等价关系与划分**一一对应**
- **同余关系**：集合上等价关系 + 与运算可置换（保持运算）
### 1.3 函数

| 类型 | 定义 | 判定 |
|------|------|------|
| **单射（injection）** | $f(a_1)=f(a_2) \Rightarrow a_1=a_2$ | $\ker f$ 是平凡等价关系 |
| **满射（surjection）** | $\forall b \in B,\ \exists a \in A,\ f(a)=b$ | $\text{im } f = B$ |
| **双射（bijection）** | 单射 + 满射 | 存在逆函数 |

### 1.4 集合等势
- **等势**：存在双射 $f: A \to B$
- **可数集**：与 $\mathbb{N}$ 等势的集（如 $\mathbb{Z},\ \mathbb{Q}$）
- **不可数集**：如 $\mathbb{R},\ [0,1]$
- 无穷集 $\iff$ 与它的某个真子集等势

## 二、运算与代数一般概念（Lecture 2）

### 2.1 运算及其性质
> **n 元运算**：$f: A^n \to A$（本文主要研究**二元运算** $\circ: A \times A \to A$）

| 性质 | 定义（$\forall a,b,c \in A$） |
|------|-------------------------------|
| **封闭性** | $a \circ b \in A$ |
| **交换律** | $a \circ b = b \circ a$ |
| **结合律** | $(a \circ b) \circ c = a \circ (b \circ c)$ |
| **幂等律** | $a \circ a = a$ |
| **消去律** | $a \circ b = a \circ c \Rightarrow b = c$（左），$b \circ a = c \circ a \Rightarrow b = c$（右） |
| **分配律** | $a \circ (b * c) = (a \circ b) * (a \circ c)$（$\circ$ 对 $*$ 左分配） |
| **吸收律** | $a \circ (a * b) = a$，$a * (a \circ b) = a$ |

### 2.2 特殊元素

| 元素 | 定义（$\forall a \in A$） | 唯一性 |
|------|--------------------------|--------|
| **单位元 $e$** | $e \circ a = a \circ e = a$ | 若有则唯一 |
| **零元 $\theta$** | $\theta \circ a = a \circ \theta = \theta$ | 若有则唯一 |
| **逆元 $a^{-1}$** | $a \circ a^{-1} = a^{-1} \circ a = e$ | 结合律下唯一 |

⚠️ **消去律与零元/逆元关系**：当运算有单位元且每个元素有逆元时 $\Rightarrow$ 满足消去律；反之不真
### 2.3 代数系统
- **代数** $(A, \Omega)$：基集 $A$ + 一组运算 $\Omega$
- **子代数**：$B \subseteq A$ 且对 $\Omega$ 中所有运算封闭
- **同余关系**：等价关系 $\sim$ 且与所有运算可置换（$a_1\sim a_2, b_1\sim b_2 \Rightarrow a_1\circ b_1 \sim a_2\circ b_2$）
- **商代数** $(A/{\sim}, \Omega)$：等价类上的代数，$[a]\circ[b] = [a\circ b]$
- **同态** $f: A \to B$：$f(a_1 \circ_A a_2) = f(a_1) \circ_B f(a_2)$
- **同构**：双射同态 $\Rightarrow$ 两个代数有完全相同的代数性质
### 2.4 代数同态基本定理
- **子代数 ↔ 单同态**一一对应
- **商代数 ↔ 满同态**一一对应
- 同态基本定理：$A/\ker f \cong \text{im } f$
## 三、整数、高斯整数与多项式（Lecture 2）
### 3.1 整数整除与同余
#### 整除
> **定义**：$a \mid b \iff \exists k \in \mathbb{Z}$ s.t. $b = ak$
**性质**：$\forall a,b,c \in \mathbb{Z}$
1. $a \mid b \land b \mid c \Rightarrow a \mid c$（传递）
2. $a \mid b \land a \mid c \Rightarrow a \mid (b \pm c)$
3. $a \mid b \Rightarrow a \mid bc$
4. $a \mid b \land b \mid a \Rightarrow a = \pm b$
#### 带余数除法
> **定理**：$\forall a,b \in \mathbb{Z}, b>0$，存在**唯一** $q,r$ 使 $a = bq + r,\ 0 \le r < b$
#### 最大公因数与辗转相除法
- **$\gcd(a,b)$**：最大的 $d$ 满足 $d \mid a$ 且 $d \mid b$
- **$\gcd(a,b) = \gcd(b, a \bmod b)$**（辗转相除法核心）
> **算法**（欧几里得算法）：
> ```
> while b ≠ 0:
>     r = a mod b
>     a, b = b, r
> return a
> ```
#### 贝祖定理（Bézout）
> **定理**：$\exists x,y \in \mathbb{Z}$ s.t. $ax + by = \gcd(a,b)$

> [!tip] 可用于求逆元：$a$ 在模 $n$ 下的逆元 $\iff \gcd(a,n)=1$
#### 同余
- **定义**：$a \equiv b \pmod n \iff n \mid (a-b)$
- **模 $n$ 剩余类**：$\bar{a} = \{a + kn \mid k \in \mathbb{Z}\}$
- **完全剩余系**：$\mathbb{Z}_n = \{0,1,\dots,n-1\}$（每个剩余类取一个代表）
- $\mathbb{Z}_n$ 上模加和模乘构成代数系统
⚠️ 模 $7$ 加与模 $8$ 加在模式上没有差别，但**模 $7$ 乘与模 $8$ 乘有本质区别**——模 $8$ 有零因子
### 3.2 高斯整数 $\mathbb{Z}[i]$
> **定义**：$\mathbb{Z}[i] = \{a+bi \mid a,b \in \mathbb{Z}\}$，其中 $i^2 = -1$
> **范数**：$N(a+bi) = a^2 + b^2$

**整除**：$\alpha \mid \beta \iff \exists \gamma \in \mathbb{Z}[i]$ s.t. $\beta = \alpha\gamma$
**单位元**：$1$；**单位**（可逆元）：$\{\pm1, \pm i\}$，范数均为 $1$
#### 高斯整数带余数除法
> $\forall \alpha,\beta \in \mathbb{Z}[i], \beta \neq 0$，$\exists \gamma,\rho$ s.t.
> $\alpha = \beta\gamma + \rho$ 且 $N(\rho) \le \frac12 N(\beta)$

- 辗转相除法同样适用 $\Rightarrow$ 贝祖定理成立
- $\gcd(\alpha,\beta)$ 定义为**范数最大的公因数**（复数不能比较大小）
### 3.3 数域上的多项式 $F[x]$
> **定义**：$f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$，$a_i \in F$（数域）
> **次数** $\deg f$：最高次项指数（$a_n \neq 0$）

**运算**：
- 加法：对应系数相加
- 乘法：卷积 $c_k = \sum_{i+j=k} a_i b_j$
- $\deg(f+g) \le \max(\deg f, \deg g)$
- $\deg(fg) = \deg f + \deg g$（当系数域无零因子）
> [!important] 多项式消去律成立：$fg = fh$ 且 $f \neq 0 \Rightarrow g = h$（系数域上）

**带余数除法**：$\forall f(x), g(x) \in F[x], g \neq 0$，存在**唯一** $q(x), r(x)$ 使
$f = gq + r$，$\deg r < \deg g$（要求 $g$ 首项系数可逆，数域上成立）
**贝祖定理**：$\exists u(x), v(x)$ s.t. $fu + gv = \gcd(f,g)$
**完全剩余系**：$\{r(x) \mid \deg r < \deg m\}$（当除式为 $m(x)$ 时，有 $n^{\deg m}$ 个元素，$n$ 为系数集大小）
## 四、群的定义与基本性质（Lecture 3）
### 4.1 群的定义
> 群 $(G, \circ)$：非空集合 $G$ + 二元运算 $\circ$，满足：
> 1. **封闭性**：$\forall a,b \in G,\ a \circ b \in G$
> 2. **结合律**：$\forall a,b,c \in G,\ (a \circ b) \circ c = a \circ (b \circ c)$
> 3. **单位元**：$\exists e \in G,\ \forall a \in G,\ e \circ a = a \circ e = a$
> 4. **逆元**：$\forall a \in G,\ \exists a^{-1} \in G,\ a \circ a^{-1} = a^{-1} \circ a = e$

- **交换群（阿贝尔群）**：运算还满足交换律
- **加群**：运算表示为 $+$，单位元 $0$，逆元 $-a$；乘群则记为 $e$ 或 $1$，逆元 $a^{-1}$
### 4.2 基本性质
1. 单位元**唯一**
2. 每个元素的逆元**唯一**
3. 消去律成立：$ab = ac \Rightarrow b = c$，$ba = ca \Rightarrow b = c$
4. $(a^{-1})^{-1} = a$
5. $(ab)^{-1} = b^{-1}a^{-1}$（⚠️ 顺序颠倒）
6. $a^n a^m = a^{n+m}$，$(a^n)^m = a^{nm}$
### 4.3 群的判定定理
非空集 $G$ + 结合运算 $\circ$ 构成群 $\iff$ $\forall a,b \in G$，方程 $a \circ x = b$ 和 $y \circ a = b$ 在 $G$ 中都有解

> [!tip] 等价地：非空有限集 $G$ + 结合运算 + 满足消去律 $\Rightarrow$ 构成群（有限集特例）
### 4.4 重要群例

| 例子 | 描述 | 阶 | 交换？ |
|------|------|:--:|:----:|
| $(\mathbb{Z},+)$ | 整数加群 | $\infty$ | ✓ |
| $(\mathbb{Q},+),(\mathbb{R},+),(\mathbb{C},+)$ | 有理数/实数/复数加群 | $\infty$ | ✓ |
| $(\mathbb{Z}_n,+)$ | 模 $n$ 剩余类加群（$\{0,1,\dots,n-1\}$） | $n$ | ✓ |
| $(\mathbb{Q}^*,\times)$ | 非零有理数乘群 | $\infty$ | ✓ |
| $(\{1,-1\},\times)$ | 单位根群 | $2$ | ✓ |
| $U_n = \{k \mid \gcd(k,n)=1\}$ 模 $n$ 乘群 | 模 $n$ 单位群（$\varphi(n)$ 个元素） | $\varphi(n)$ | ✓ |
| $S_n$ | $n$ 元置换群（对称群） | $n!$ | $n\ge 3$时否 |
| $A_n$ | $n$ 元交错群（偶置换全体） | $n!/2$ | $n\ge 4$时否 |
| $D_n$ | $n$ 阶二面体群（正 $n$ 边形对称群） | $2n$ | $n\ge 3$时否 |
| $C_n = \langle a \mid a^n = e \rangle$ | $n$ 阶循环群 | $n$ | ✓ |
| $K_4$（Klein 四元群） | $\{e,a,b,ab\}$，$a^2=b^2=e$，$ab=ba$ | $4$ | ✓ |
| $Q_8$（四元数群） | $\{\pm1,\pm i,\pm j,\pm k\}$，$i^2=j^2=k^2=-1$ | $8$ | 否 |

> [!example] **Klein 四元群** $K_4 \cong \mathbb{Z}_2 \times \mathbb{Z}_2$
> 运算表：每个元素的逆元都是自身，任意两个不同非单位元之积等于第三个

> [!example] **最小非交换群 $S_3$**
> $S_3 = \{(1), (12), (13), (23), (123), (132)\}$，6 阶
> 非交换：$(12)(13) \neq (13)(12)$

## 五、群元素的阶（Lecture 3）
### 5.1 定义
> 元素 $a$ 的阶 $|a|$：使 $a^n = e$ 的最小正整数 $n$（若不存在则称**无限阶**）
> - **加群版本**：使 $na = 0$ 的最小正整数 $n$
### 5.2 阶的性质
1. $|a| = 1 \iff a = e$
2. $|a| = |a^{-1}|$
3. $|ab| = |ba|$（不一定等于 $|a||b|$）
4. $|a^k| = \dfrac{|a|}{\gcd(|a|, k)}$
5. $a^n = e \iff |a| \mid n$
6. 若 $|a| = n$，则 $a^k = e \iff n \mid k$
7. $a^m = a^n \iff |a| \mid (m-n)$
8. 有限群中每个元素的阶都是**有限的**
> [!important] 考点
> $|a^k| = \frac{|a|}{\gcd(|a|,k)}$ 是**最常见的阶计算工具**
## 六、子群与生成子群（Lecture 3）

### 6.1 子群定义
> **子群** $H \le G$：$H \subseteq G$ 且 $H$ 在 $G$ 的运算下构成群
> - **平凡子群**：$\{e\}$ 和 $G$ 自身
> - **真子群**：$H \neq G$
### 6.2 子群判定定理
> **定理（一步判定）**：$H \le G \iff H \neq \varnothing$ 且 $\forall a,b \in H,\ ab^{-1} \in H$
> **定理（二步判定）**：$H \le G \iff$ 对运算封闭 + 对取逆运算封闭

> [!tip] 证明子群固定流程：
> 1. 非空（通常证 $e \in H$）
> 2. $\forall a,b \in H$，证 $ab \in H$（封闭）
> 3. $\forall a \in H$，证 $a^{-1} \in H$（逆元）
> 或直接用一步判定 $ab^{-1} \in H$
### 6.3 常见子群
- $\mathbb{Z}$ 的子群：$n\mathbb{Z} = \{nk \mid k \in \mathbb{Z}\}$（所有子群形如 $n\mathbb{Z}$）
- $\mathbb{Z}_n$ 的子群：每个 $d \mid n$ 对应一个 $d$ 阶子群
- $S_n$ 的子群：交错群 $A_n$（指数为 $2$ 的正规子群）
### 6.4 子群的交
族 $\{H_i\}_{i\in I}$ 为 $G$ 的子群 $\Rightarrow$ $\bigcap_{i\in I} H_i$ 也是 $G$ 的子群
### 6.5 生成子群
$\langle S \rangle$：包含 $S$ 的**最小子群**（$G$ 中所有包含 $S$ 的子群的交）
**生成子群的形式**：
- $\langle a \rangle = \{a^k \mid k \in \mathbb{Z}\}$（由一个元素生成）
- $\langle S \rangle = \{s_1^{\pm1} s_2^{\pm1} \cdots s_k^{\pm1} \mid s_i \in S\}$
> [!warning] $\langle a \rangle$ 可能是无限群（$a$ 无限阶）或有限群（$|a|=n$ 时 $\langle a \rangle = \{e,a,\dots,a^{n-1}\}$）
## 七、循环群（Lecture 4）
### 7.1 定义与例子
> **循环群**：存在 $a \in G$ 使 $G = \langle a \rangle$（$a$ 称为**生成元**）

| 例子 | 类型 | 生成元 | 阶 |
|:----|:----:|:------:|:--:|
| $(\mathbb{Z},+)$ | 无限循环群 | $\pm 1$ | $\infty$ |
| $(\mathbb{Z}_n,+)$ | $n$ 阶循环群 | 与 $n$ 互素的数 | $n$ |
| $U_n$ 单位群 | 有时循环、有时不 | 需具体判断 | $\varphi(n)$ |
| $n$ 次单位根群 | $n$ 阶循环群 | 本原单位根 $\omega = e^{2\pi i/n}$ | $n$ |

### 7.2 分类定理
> **定理**：循环群只有两种（同构意义下）：
> - **无限循环群** $\cong (\mathbb{Z},+)$
> - **$n$ 阶循环群** $\cong (\mathbb{Z}_n,+)$
### 7.3 生成元的判定
> **无限循环群** $G = \langle a \rangle$：生成元为 $a$ 和 $a^{-1}$（仅两个）
> **$n$ 阶循环群** $G = \langle a \rangle$：$a^k$ 是生成元 $\iff \gcd(k,n) = 1$
> ⇒ 生成元个数 = $\varphi(n)$（欧拉函数）

### 7.4 循环群的所有子群
> **定理**：循环群的子群也是循环群
> **无限循环群** $\langle a \rangle$ 的子群：$\{e\}$ 和 $\langle a^k \rangle,\ k \ge 1$（每个非零整数 $k$ 对应一个子群）
> **$n$ 阶循环群** $\langle a \rangle$ 的子群：
> - 每个 $d \mid n$ 对应唯一的 $d$ 阶子群 $\langle a^{n/d} \rangle$
> - 对每个 $d \mid n$，恰有一个 $d$ 阶子群
> - 子群个数 = $n$ 的正因子个数

> [!example] **$\mathbb{Z}_{12}$ 的所有子群**
> $d \mid 12$：$d=1,2,3,4,6,12$
> - $\langle 0 \rangle = \{0\}$（1阶）
> - $\langle 6 \rangle = \{0,6\}$（2阶）
> - $\langle 4 \rangle = \{0,4,8\}$（3阶）
> - $\langle 3 \rangle = \{0,3,6,9\}$（4阶）
> - $\langle 2 \rangle = \{0,2,4,6,8,10\}$（6阶）
> - $\langle 1 \rangle = \mathbb{Z}_{12}$（12阶）

### 7.5 子群格
> **无限循环群**：子群格同构于 $(\mathbb{N}, \mid)$ 的偏序结构
> **$n$ 阶循环群**：子群格同构于 $(D(n), \mid)$，$D(n)$ 为 $n$ 的正因子集
## 八、置换群（Lecture 4）
### 8.1 置换的定义
> **置换**：集合 $\{1,2,\dots,n\}$ 到自身的双射
> **$n$ 次对称群 $S_n$**：所有 $n$ 元置换在复合运算下构成的群（$|S_n| = n!$）
**记号**：$\sigma = \begin{pmatrix}1&2&\cdots&n\\ \sigma(1)&\sigma(2)&\cdots&\sigma(n)\end{pmatrix}$
### 8.2 置换的复合
> 从右向左复合：$(\sigma\tau)(i) = \sigma(\tau(i))$
### 8.3 轮换表示
> **$r$-轮换** $(a_1\ a_2\ \cdots\ a_r)$：$a_1 \to a_2 \to \cdots \to a_r \to a_1$
> **不相交轮换可交换**

> **定理**：每个置换都可**唯一**（不考虑顺序）表示为不相交轮换的乘积

**算法**：从 $1$ 开始追踪映射，直到回到起点；接着找下一个未出现的数重复
> [!example] $\sigma = \begin{pmatrix}1&2&3&4&5&6\\3&1&2&5&4&6\end{pmatrix}$
> $1 \to 3 \to 2 \to 1$ → $(1\ 3\ 2)$，$4 \to 5 \to 4$ → $(4\ 5)$，$6 \to 6$ → $(6)$
> $\sigma = (1\ 3\ 2)(4\ 5)(6)$，通常省略 1-轮换：$\sigma = (1\ 3\ 2)(4\ 5)$
### 8.4 对换表示
> **任意轮换** $(a_1\ a_2\ \cdots\ a_r) = (a_1\ a_r)(a_1\ a_{r-1})\cdots(a_1\ a_2)$
> **对换表示不唯一**（但奇偶性唯一）
### 8.5 置换的奇偶性
> 偶数个对换之积 → **偶置换**
> 奇数个对换之积 → **奇置换**

**奇偶性计算**：$\text{sgn}(\sigma) = (-1)^{n-r}$（$r$ 为不相交轮换个数（含 1-轮换））
> [!example] $\sigma = (1\ 3\ 2)(4\ 5)$，不相交轮换 $r=2$（$(1\ 3\ 2)$ 和 $(4\ 5)$）
> $n-r = 4-2 = 2$，偶数 ⇒ 偶置换
### 8.6 交错群
> **交错群 $A_n$**：所有 $n$ 元偶置换构成的子群
> - $|A_n| = n!/2$（$n \ge 2$）
> - $A_n \trianglelefteq S_n$（正规子群）
> - $S_n/A_n \cong \mathbb{Z}_2$
### 8.7 $S_3$ 与 $D_3$ 的关系
> 正三角形的对称群 $\cong S_3$（6 个元素：恒等、2 个旋转、3 个翻转）
> - 旋转：$(1), (1\ 2\ 3), (1\ 3\ 2)$ — 偶置换（$A_3$）
> - 翻转：$(1\ 2), (1\ 3), (2\ 3)$ — 奇置换

> **$D_n$（二面体群）**：正 $n$ 边形的对称变换群，$|D_n| = 2n$
> - $n$ 个旋转（含恒等），$n$ 个翻转
> - $D_n$ 嵌入 $S_n$ 作为子群

## 十一、子群的陪集（Lecture 5）
### 11.1 群子集的运算
> $AB = \{ab \mid a \in A, b \in B\}$，$aH = \{a\}H$，$Ha = H\{a\}$

⚠️ 子集乘法**不满足交换律**，也**没有消去律**
**性质**（证明集合相等）：
1. $(AB)C = A(BC)$
2. $A\{e\} = \{e\}A = A$
3. $(AB)^{-1} = B^{-1}A^{-1}$
4. $A(B \cup C) = AB \cup AC$，$A(B \cap C) \subseteq AB \cap AC$
### 11.2 陪集的定义
> **左陪集** $aH = \{ah \mid h \in H\}$（$H$ 是 $G$ 的子群，$a \in G$）
> **右陪集** $Ha = \{ha \mid h \in H\}$

- $H$ 本身既是左陪集又是右陪集（$eH = He = H$）
- $a \in aH$（取 $h=e$）
### 11.3 陪集的性质
> **定理**（陪集相等判定）：
> $aH = bH \iff a^{-1}b \in H \iff b \in aH$（左陪集）
> $Ha = Hb \iff ab^{-1} \in H \iff b \in Ha$（右陪集）

> **定理**（陪集要么相等要么不交）：
> $aH \cap bH \neq \varnothing \Rightarrow aH = bH$

> [!important] 陪集导出等价关系
> $a \sim b \iff a^{-1}b \in H$，等价类为左陪集 $aH$
### 11.4 陪集性质汇总
1. $aH = H \iff a \in H$
2. $aH = bH \iff a^{-1}b \in H$
3. $aH \cap bH = \varnothing$ 或 $aH = bH$
4. $\bigcup_{a \in G} aH = G$
5. $|aH| = |H|$（等势）
### 11.5 拉格朗日定理
> **定理**（Lagrange）：设 $G$ 为有限群，$H \le G$，则
> $$|G| = |H| \cdot [G:H]$$
> 其中 $[G:H]$ 为 $H$ 在 $G$ 中的**指标**（陪集个数）

**推论**：
1. 有限群中元素的阶整除群的阶：$|a| \mid |G|$
2. 群中 $a^{|G|} = e$
3. 阶为素数的群必为循环群
4. 有限群 $G$ 中满足 $a^2 = e$ 的元素个数为奇数

> [!warning] ⚠️ 注意
> 拉格朗日定理的逆不成立——存在因子但不一定有对应阶的子群（如 $A_4$ 有 12 阶但没有 6 阶子群）

> [!example] 应用
> 设 $|G| = p$（素数），$a \neq e$，则 $|a| \mid p$ 且 $|a| \neq 1$，故 $|a| = p$，$G = \langle a \rangle$ 是循环群

## 十二、正规子群与商群（Lecture 6）
### 12.1 正规子群定义
> **正规子群** $N \trianglelefteq G$：$\forall g \in G,\ gN = Ng$
> 等价地：$\forall g \in G,\ \forall n \in N,\ gng^{-1} \in N$
### 12.2 正规子群的例子

| 群 | 正规子群 | 说明 |
|:---|:---------|:-----|
| 任意群 $G$ | $\{e\}$、$G$ 自身 | 平凡正规子群 |
| 交换群 | **所有**子群都是正规子群 | 因为 $gH = Hg$ |
| $S_n$ | $A_n$（交错群） | $[S_n:A_n] = 2$ |
| $D_n$ | 旋转子群 $\langle r \rangle$ | 指数为 2 |
| $G \times H$ | $G \times \{e\}$、$\{e\} \times H$ | 直积因子 |

### 12.3 正规子群判定
1. $N \trianglelefteq G \iff \forall g \in G,\ gNg^{-1} = N$
2. $N \trianglelefteq G \iff \forall g \in G,\ gNg^{-1} \subseteq N$
3. **指数为 2 的子群必是正规子群**
4. 若 $N \trianglelefteq G$ 且 $K \trianglelefteq G$，则 $N \cap K \trianglelefteq G$ 且 $NK \trianglelefteq G$
### 12.4 商群
> **定理**：若 $N \trianglelefteq G$，则 $G/N = \{aN \mid a \in G\}$ 在运算
> $$(aN)(bN) = (ab)N$$
> 下构成群，称为 $G$ 关于 $N$ 的**商群**

- **单位元**：$N = eN$
- **逆元**：$(aN)^{-1} = a^{-1}N$
- **阶**：$|G/N| = [G:N]$
- 结合性、单位元、逆元均继承自 $G$

> [!example] 重要商群例子
> - $\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$（整数模 $n$ 加群）
> - $S_n/A_n \cong \mathbb{Z}_2$（置换群模交错群）
> - $G/G \cong \{e\}$，$G/\{e\} \cong G$
### 12.5 商群元素阶的性质
- $|aN|$ 整除 $|a|$（在 $G/N$ 中，$aN$ 的阶是使 $a^k \in N$ 的最小 $k$）
- 若 $G$ 是交换群，则 $G/N$ 也是交换群
- 若 $|a| = n$ 且 $a^k \in N$，则 $|aN| \mid k$
## 十三、群的同态与同构（Lecture 7）
### 13.1 群同态定义
> **群同态** $f: G \to H$：$\forall a,b \in G$，$f(ab) = f(a)f(b)$

**分类**：

| 类型 | 条件 | 结论 |
|:----|:-----|:------|
| 单同态 | $f$ 为单射 | $\ker f = \{e\}$ |
| 满同态 | $f$ 为满射 | $\text{im } f = H$ |
| 同构 | $f$ 为双射 | $G \cong H$ |
| 自同态 | $G = H$ | $f: G \to G$ |
| 自同构 | 同构 + $G = H$ | $\text{Aut}(G)$ |

### 13.2 同态保持的单位元与逆元
1. $f(e_G) = e_H$
2. $f(a^{-1}) = f(a)^{-1}$
3. $f(a^n) = f(a)^n$（可用归纳法证）
### 13.3 重要同态例子

| 映射 | 类型 | 核 |
|:----|:----:|:--:|
| $\pi: \mathbb{Z} \to \mathbb{Z}_n,\ \pi(k)=k \bmod n$ | 满同态 | $n\mathbb{Z}$ |
| $\det: GL_n(\mathbb{R}) \to \mathbb{R}^*$ | 满同态 | $SL_n(\mathbb{R})$ |
| $\text{sgn}: S_n \to \{\pm1\}$ | 满同态 | $A_n$ |
| $\sigma: G \to S_G,\ \sigma(g)(x)=gx$（左正则表示）| 单同态 | $\{e\}$ |
| $\varphi: G \to \text{Aut}(G),\ \varphi(g)(x)=gxg^{-1}$（内自同构）| 同态 | $Z(G)$ |

### 13.4 凯莱定理（Cayley）
> **定理**：任意群 $G$ 同构于某个置换群的子群
> 即 $G \cong \bar{G} \le S_G$（左正则表示给出单同态 $G \to S_G$）
### 13.5 循环群的结构定理
> 1. **无限循环群** $\cong (\mathbb{Z},+)$
> 2. **$n$ 阶循环群** $\cong (\mathbb{Z}_n,+)$
> 3. 两个循环群同构 $\iff$ 它们同为无限或同阶有限
### 13.6 群同态性质
**与元素的阶**：若 $f: G \to H$ 是同态，则 $|f(a)| \mid |a|$
**与子群**：
- 若 $H \le G$，则 $f(H) \le H$
- 若 $K \le H$，则 $f^{-1}(K) \le G$
**与正规子群**：
- 若 $N \trianglelefteq G$，则 $f(N) \trianglelefteq f(G)$（像中是正规的）
- 若 $M \trianglelefteq H$，则 $f^{-1}(M) \trianglelefteq G$
### 13.7 群同态的核
> **核**：$\ker f = \{a \in G \mid f(a) = e_H\}$
> **性质**：$\ker f \trianglelefteq G$（同态核是正规子群）

**逆命题**：每个正规子群 $N \trianglelefteq G$ 都是某个同态的核（自然同态 $\pi: G \to G/N$）
### 13.8 群同态基本定理
> **定理**（第一同构定理）：设 $f: G \to H$ 是群同态，则$G/\ker f \cong \text{im } f$

> 自然同态 $\pi: G \to G/N$ 是满同态且 $\ker \pi = N$
### 13.9 第二、第三同构定理
> **第二同构定理**：设 $H \le G$，$N \trianglelefteq G$，则$H/(H \cap N) \cong HN/N$
> **第三同构定理**：设 $M,N \trianglelefteq G$ 且 $M \subseteq N$，则$(G/M)/(N/M) \cong G/N$
## 十四、群的直积（Lecture 8）
### 14.1 外直积
> **定义**：$G \times H = \{(g,h) \mid g \in G, h \in H\}$，运算为分量操作
> $$(g_1,h_1)(g_2,h_2) = (g_1g_2, h_1h_2)$$
> - 单位元：$(e_G, e_H)$
> - 逆元：$(g,h)^{-1} = (g^{-1}, h^{-1})$
> - $|G \times H| = |G| \cdot |H|$
### 14.2 外直积元素阶
> $|(g,h)| = \text{lcm}(|g|, |h|)$（最小公倍数）

> [!example] $\mathbb{Z}_2 \times \mathbb{Z}_3$ 中元素的阶
> $|(0,0)|=1$，$|(1,0)|=2$，$|(0,1)|=3$，$|(1,1)|=\text{lcm}(2,3)=6$
> $\mathbb{Z}_2 \times \mathbb{Z}_3 \cong \mathbb{Z}_6$（循环群！）
### 14.3 直积与循环群关系
> **定理**：$\mathbb{Z}_m \times \mathbb{Z}_n \cong \mathbb{Z}_{mn} \iff \gcd(m,n) = 1$

**推论**：$\mathbb{Z}_n \cong \mathbb{Z}_{p_1^{k_1}} \times \cdots \times \mathbb{Z}_{p_r^{k_r}}$（$n$ 的素因子分解）
### 14.4 内直积
> **定义**：群 $G$ 是其子群 $H,K$ 的**内直积** $G = H \times K$，若
> 1. $H \trianglelefteq G$，$K \trianglelefteq G$
> 2. $H \cap K = \{e\}$
> 3. $G = HK$

**等价条件**：$\forall h \in H, \forall k \in K$，$hk = kh$ 且 $G$ 中每个元素可**唯一**表示为 $hk$
> [!important] 外直积 $\cong$ 内直积
> 若 $G \cong H \times K$（外直积），则 $H \times \{e\}$ 和 $\{e\} \times K$ 是 $G$ 的同构像，构成内直积分解
## 十五、环的定义与基本性质（Lecture 9）

### 15.1 环的定义
> **环** $(R,+,\cdot)$：
> 1. $(R,+)$ 是**交换群**（加群，单位元 $0$，逆元 $-a$）
> 2. $(R,\cdot)$ 满足结合律（乘群半群）
> 3. **分配律**：$a(b+c) = ab + ac$，$(a+b)c = ac + bc$

**环乘法的重要关注点**：
- 乘法不要求交换
- 乘法不要求有单位元
- 可能有零因子
### 15.2 整环与域

| 类型 | 定义 |
|:----|:------|
| **交换环** | 乘法满足交换律 |
| **含幺环** | 乘法有单位元 $1$ |
| **无零因子环** | $ab=0 \Rightarrow a=0 \lor b=0$ |
| **整环** | 交换含幺环 + 无零因子 |
| **除环** | 至少两元素 + 含幺 + 每个非零元有乘法逆（非交换时也称"体"） |
| **域** | 交换除环 |

⚠️ 可逆元都不是零因子！因此域都是整环
### 15.3 环的重要例子

| 环 | 交换？ | 含幺？ | 整环？ | 域？ | 说明 |
|:---|:-----:|:-----:|:-----:|:---:|:-----|
| $\mathbb{Z}$ | ✓ | ✓ | ✓ | ✗ | 整数环 |
| $\mathbb{Z}_n$ | ✓ | ✓ | $n$ 为素数 | $n$ 为素数 | 模 $n$ 剩余类环 |
| $\mathbb{Z}[i]$ | ✓ | ✓ | ✓ | ✗ | 高斯整环 |
| $\mathbb{Q},\mathbb{R},\mathbb{C}$ | ✓ | ✓ | ✓ | ✓ | 有理数/实数/复数域 |
| $F[x]$ | ✓ | ✓ | ✓ | ✗ | 域上多项式环 |
| $M_n(R)$ | $n\ge 2$ 否 | ✓（$n\ge 2$） | 否 | 否 | $n$ 阶全矩阵环 |
| $\mathbb{H}$ | 否 | ✓ | （有零因子？无） | 否（非交换） | Hamilton 四元数体 |
| $2\mathbb{Z}$ | ✓ | 否 | 不构成（无 $1$） | 否 | 偶数环 |

> [!example] **有限非交换环的例子**
> $M_2(\mathbb{Z}_2)$（$2$ 阶矩阵环，模 $2$）

> [!example] **无单位元的无限非交换环**
> $M_n(R)$ 中所有只有有限个非零元的矩阵集合
### 15.4 倍数法则与指数法则
**倍数法则**（$\forall m,n \in \mathbb{Z}$）：
1. $m(a+b) = ma + mb$
2. $(m+n)a = ma + na$
3. $m(na) = (mn)a$
4. $(ma)b = m(ab) = a(mb)$
**指数法则**（$\forall n \in \mathbb{Z}^+$）：$(a+b)^n = \sum_{k=0}^n \binom{n}{k} a^{n-k}b^k$
（交换环中二项式定理成立；非交换环中需注意顺序）
### 15.5 无零因子与消去律
> 环 $R$ 无零因子 $\iff$ 乘法消去律成立（$a\neq 0, ab=ac \Rightarrow b=c$）
### 15.6 子环
> **子环** $S \le R$：$S \subseteq R$ 且 $S$ 在 $+$ 和 $\cdot$ 下构成环
**判定定理**：$S \le R \iff S \neq \varnothing$ 且 $\forall a,b \in S$，$a-b \in S$ 且 $ab \in S$

> [!warning] ⚠️ 环与子环的异同
> - 子环的单位元可能与环的单位元不同（甚至子环未必有 $1$ 而环有）
> - 子环的可逆元不一定是环的可逆元（反之亦然）
## 十六、环的理想与商环（Lecture 10）
### 16.1 理想的定义
> **理想** $I \trianglelefteq R$：$I$ 是 $R$ 的**加法子群**，且 $\forall r \in R,\ \forall a \in I$：
> - **左理想**：$ra \in I$
> - **右理想**：$ar \in I$
> - **双边理想**：同时是左理想和右理想（本文中"理想"指双边理想）

> [!warning] 理想是环的加法子群，但通常不是子环（因为不含 $1$ 且不必对乘法封闭）
### 16.2 理想的例子

| 环 | 理想 | 形式 |
|:---|:-----|:-----|
| $\mathbb{Z}$ | $n\mathbb{Z} = \{nk \mid k \in \mathbb{Z}\}$ | 所有理想形如 $n\mathbb{Z}$ |
| $\mathbb{Z}_n$ | $d\mathbb{Z}_n$（$d \mid n$） | 由 $n/d$ 生成的理想 |
| $F[x]$ | $\langle f(x) \rangle$ | 由 $f(x)$ 生成的主理想 |
| $\mathbb{Z}[i]$ | $\langle a+bi \rangle$ | 高斯整数主理想 |

### 16.3 主理想
> **主理想** $\langle a \rangle$：由一个元素 $a$ 生成的理想
> - 在有单位元的交换环中：$\langle a \rangle = aR = \{ar \mid r \in R\}$
> - 非交换环：$\langle a \rangle = \{\sum r_i a s_i \mid r_i,s_i \in R\}$

### 16.4 理想的和与交
- **和**：$I+J = \{a+b \mid a\in I, b\in J\}$（仍是理想，且是包含 $I\cup J$ 的最小理想）
- **交**：$I \cap J$（仍是理想）
- **积**：$IJ = \{\sum a_i b_i \mid a_i \in I, b_i \in J\}$（有限和，$IJ \subseteq I \cap J$）

### 16.5 商环

> **定理**：若 $I \trianglelefteq R$，则 $R/I = \{a+I \mid a \in R\}$ 在以下运算下构成环：
> - **加法**：$(a+I)+(b+I) = (a+b)+I$
> - **乘法**：$(a+I)(b+I) = ab+I$
> **单位元**：$1+I$（若 $R$ 有单位元 $1$）
> **零元**：$I = 0+I$

> [!example] 重要商环
> - $\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$
> - $\mathbb{Z}[i]/\langle 2+i \rangle \cong \mathbb{Z}_5$
> - $F[x]/\langle f(x) \rangle$ 是域 $\iff f(x)$ 是不可约多项式

## 十七、环的同态与环的特征（Lecture 11）

### 17.1 环同态定义
> **环同态** $f: R \to S$：$\forall a,b \in R$
> 1. $f(a+b) = f(a)+f(b)$（加法群同态）
> 2. $f(ab) = f(a)f(b)$（乘法保持）
>
> 环同态是同时保持加法和乘法的函数

### 17.2 环同态的例子

| 映射 | 类型 |
|:----|:----:|
| $\pi: \mathbb{Z} \to \mathbb{Z}_n,\ \pi(k)=k \bmod n$ | 满同态 |
| $\iota: \mathbb{Z} \to \mathbb{Q},\ \iota(n)=n$ | 单同态（嵌入） |
| $f: \mathbb{Z}[x] \to \mathbb{Z},\ f(p(x))=p(0)$ | 满同态（求值同态） |
| $\varphi: R \to R/I,\ \varphi(a)=a+I$ | 满同态（自然同态） |

### 17.3 环同态基本性质

- $f(0_R) = 0_S$
- $f(-a) = -f(a)$
- $f(na) = nf(a)$（$\forall n \in \mathbb{Z}$）
- $f(a^n) = f(a)^n$（$\forall n \in \mathbb{N}$）
- 若 $R$ 含 $1$ 且 $f$ 是满同态，则 $f(1_R) = 1_S$
- 若 $f$ 是环同构，则 $f(1_R) = 1_S$

### 17.4 环同态与子环、理想

- 若 $S \le R$，则 $f(S) \le f(R)$
- 若 $T \le f(R)$，则 $f^{-1}(T) \le R$
- 若 $I \trianglelefteq R$ 且 $f$ 是满同态，则 $f(I) \trianglelefteq f(R)$
- 若 $J \trianglelefteq f(R)$，则 $f^{-1}(J) \trianglelefteq R$

### 17.5 环同态核
> **核**：$\ker f = \{a \in R \mid f(a) = 0_S\}$
> **性质**：$\ker f \trianglelefteq R$（核是理想）

### 17.6 环同态基本定理
> **定理**：设 $f: R \to S$ 是环同态，则
> $$R/\ker f \cong \text{im } f$$
### 17.7 第二同构定理
> **定理**：设 $S \le R$，$I \trianglelefteq R$，则
> $$S/(S \cap I) \cong (S+I)/I$$
### 17.8 挖补定理（环的扩张定理）
> 若环 $R$ 不是整环，则存在一种**挖补**方法将其扩张为整环
> 核心思想：模仿 $\mathbb{Z}$ 到 $\mathbb{Q}$ 的构造（整环的商域）
### 17.9 环的特征
> **特征 $\text{char}(R)$**：使 $n \cdot 1_R = 0$ 的最小正整数 $n$；若不存在则为 $0$

| 环 | 特征 |
|:---|:----:|
| $\mathbb{Z},\mathbb{Q},\mathbb{R},\mathbb{C}$ | $0$ |
| $\mathbb{Z}_n$ | $n$ |
| $\mathbb{F}_{p^n}$（$p$ 元域） | $p$ |
| $\mathbb{Z}_n[i]$（高斯整数模 $n$） | $n$ |

### 17.10 整环的特征
> **定理**：整环的特征为 $0$ 或素数
> **推论**：域的特征为 $0$ 或素数
### 17.11 素域
> **素域**：不含任何真子域的域
> 所有域都包含唯一的素域：
> - $\text{char}(F)=0$ ⇒ 素域 $\cong \mathbb{Q}$
> - $\text{char}(F)=p$ ⇒ 素域 $\cong \mathbb{Z}_p$
## 十八、素理想与极大理想、有限域（Lecture 12）
### 18.1 素理想
> **素理想** $P$：$P \trianglelefteq R$ 且 $\forall a,b \in R$，$ab \in P \Rightarrow a \in P \lor b \in P$
> （类比素数性质：$p \mid ab \Rightarrow p\mid a \lor p\mid b$）

> [!important] 素理想与整环的关系
> 在有单位元的交换环 $R$ 中：
> $$P \text{ 是素理想} \iff R/P \text{ 是整环}$$

| 环 | 素理想 |
|:---|:-------|
| $\mathbb{Z}$ | $\langle p \rangle$，$p$ 为素数（以及整个环 $\mathbb{Z}$ 自身？通常排除） |
| $F[x]$ | $\langle f(x) \rangle$，$f(x)$ 不可约 |

### 18.2 极大理想

> **极大理想** $M$：$M \trianglelefteq R$，$M \neq R$，且不存在理想 $I$ 使 $M \subsetneq I \subsetneq R$

> [!important] 极大理想与域的关系
> 在有单位元的交换环 $R$ 中：
> $$M \text{ 是极大理想} \iff R/M \text{ 是域}$$

**极大理想与素理想的关系**：
- 极大理想 ⇒ 素理想（在有单位元的交换环中）
- 素理想 $\nRightarrow$ 极大理想
  - 反例：$\langle x \rangle$ 在 $\mathbb{Z}[x]$ 中是素理想但不是极大理想
  - $\mathbb{Z}[x]/\langle x \rangle \cong \mathbb{Z}$（整环而非域）

> [!example] **$\mathbb{Z}$ 的极大理想**
> $\langle p \rangle$（$p$ 为素数），因为 $\mathbb{Z}/\langle p \rangle \cong \mathbb{Z}_p$ 是域

> [!example] **$\mathbb{Z}[i]$ 的极大理想**
> $\langle 2+i \rangle$：$\mathbb{Z}[i]/\langle 2+i \rangle \cong \mathbb{Z}_5$ 是域
### 18.3 有限域
#### 基本定理
> **定理**：有限域的阶必为 $p^n$（$p$ 为素数，$n \ge 1$）
> - 对每个素数 $p$ 和正整数 $n$，存在唯一的 $p^n$ 阶域，记作 $\mathbb{F}_{p^n}$
> - 同构意义下唯一
#### 有限域的构造
> $\mathbb{F}_{p^n} \cong \mathbb{Z}_p[x]/\langle f(x) \rangle$，其中 $f(x)$ 是 $\mathbb{Z}_p$ 上的 $n$ 次不可约多项式
#### 本原元
> **本原元**：$\mathbb{F}_{p^n}^* = \mathbb{F}_{p^n} \setminus \{0\}$ 在乘法下是 $p^n-1$ 阶循环群
> 其生成元称为 $\mathbb{F}_{p^n}$ 的**本原元**
#### 有限域的子域
> **定理**：$\mathbb{F}_{p^m} \subseteq \mathbb{F}_{p^n} \iff m \mid n$
> $\mathbb{F}_{p^n}$ 的子域全体的格同构于 $n$ 的因子格
#### 有限域乘法群的结构
> $\mathbb{F}_{p^n}^* \cong \mathbb{Z}_{p^n-1}$（循环群）
> - $\mathbb{F}_{p^n}^*$ 中恰有 $\varphi(d)$ 个 $d$ 阶元（$d \mid p^n-1$）
