输入手机号密码 1. 点击登录按钮
表单验证 2. validate()
调用登录函数 3. login(phone, pwd)
发送 HTTP 请求 4. POST /api/auth/login
附加 Authorization Bearer <token>
验证账号密码 5. 生成 JWT
返回响应 6. { code:0, data:{token, user} }
响应拦截器检查 code=0 → 通过
返回数据 7. ApiResponse<LoginResponse>
写入 Store 8. setLoginInfo(data)
持久化 token 9. setItem('token', ...)
持久化 userInfo setItem('userInfo', ...)
跳转首页 10. router.push('/home')
