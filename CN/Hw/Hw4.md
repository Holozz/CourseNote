## 4

最小：2
	第一个时隙：依次输入X、Y、Z
	第二个时隙：依次输入_、X、Y
最大：3
	因为一共存在两个冲突：两个X和两个Y，而每次时隙如果遇到冲突就会阻塞某个输入，但也会把这个冲突给解决掉。这样的话经过两次冲突会将第一个和第二个输入队列完全清空而且第三个队列只剩Z，第三个时隙就可以输入完毕

## 8
a.转发表：

| 目的地址前缀              | CIDR            | 链路接口 |
| ------------------- | --------------- | ---- |
| `11100000 00`       | `224.0.0.0/10`  | 0    |
| `11100000 01000000` | `224.64.0.0/16` | 1    |
| `1110000`           | `224.0.0.0/7`   | 2    |
| `11100001 1`        | `225.128.0.0/9` | 3    |
| 其他（空前缀）             | `0.0.0.0/0`     | 3    |
其中，`224.0.0.0/7` 覆盖 224 和 225 开头的所有地址，因此有三条例外：
- `224.0.0.0`～`224.63.255.255`：匹配更长的 `/10`，转接口 0
- `224.64.0.0`～`224.64.255.255`：匹配更长的 `/16`，转接口 1
- `225.128.0.0`～`225.255.255.255`：匹配更长的 `/9`，转接口 3

b.
`11001000 10010001 01010001 01010101`：110匹配到第3位发现为其他，接口3
`11100001 01000000 11000011 00111100`：11100001匹配到第8位发现不符合接口0、1，11100001 0匹配到第9位发现不符合接口3，所以选择接口2
`11100001 10000000 00010001 01110111`：11100001 1匹配到第9位发现符合接口3，选择接口3
