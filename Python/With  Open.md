`with open()` 是 Python 中用来打开文件的一种方式，它可以简化文件操作，确保在文件操作完成后自动关闭文件，避免手动调用 `file.close()` 的麻烦。这个结构使用了 **上下文管理器（Context Manager）**，可以保证文件的打开和关闭都在“上下文”中进行，确保代码更加简洁、安全。

# #语法

```python
with open(file, mode, encoding) as file_object:
    ...
```

### 参数说明

- `file`：要打开的文件路径。
    
- `mode`：文件的打开模式，常见的有：
    
    - `'r'`：读取（默认）
        
    - `'w'`：写入（会覆盖原文件，如果文件不存在，会自动创建文件）
        
    - `'a'`：追加（在文件末尾追加内容）
        
    - `'b'`：二进制模式（如 `'rb'` 或 `'wb'`）
        
- `encoding`：文件的编码格式（如 `'utf-8'`），一般在处理文本文件时使用。
    

### 工作原理

- `with open()` 会在 `open()` 调用时自动创建一个文件对象并将其赋值给 `file_object` 变量。
    
- 在代码块执行完毕（无论是否出现异常），`with` 会自动调用文件对象的 `__exit__()` 方法，从而保证文件被正确关闭。
