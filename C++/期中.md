##
  1. 友元 (friend)

	  你作业里出现在 第9周课堂1 - ModBuffer：
		~~~cpp
		  class ModBuffer {
		  private:
		      int *data;
		      int n;
		  public:
		      // ...
		      friend ostream& operator<<(ostream& os, const ModBuffer& buffer);
		  };
		~~~
	 语法要点：
	  - friend 声明写在类内部，但 friend 函数不是成员函数，它是外部普通函数
	  - 被声明为友元后，这个外部函数可以访问类的 private 成员
	  - 为什么 operator<< 必须用友元？因为 << 的左操作数是 ostream，不是你的类 — 写成成员函数的话会变成 buffer << cout，反直觉
		  // 实现时不能再写 friend，也不用写类名限定符::
		~~~ cpp 
			ostream& operator<<(ostream& os, const ModBuffer& buffer) {
			  for (int i = 0; i < buffer.n; i++) {  // 直接访问私有成员 buffer.n
				  os << buffer.data[i];
			  }
			  return os;
		  }
		~~~
		常见考法：
		  - 友元函数 vs 成员函数的区别
		  - 什么场景必须用友元（二元运算符，左操作数不是本类对象）

  2. 重载 (Overloading)

  你的作业里出现了这几种重载：

  2.1 运算符重载 — operator=

  第8周大量练习。标准写法（三步曲）：
~~~cpp
  MyString& MyString::operator=(const MyString& other) {
      if (this == &other)        // ① 自赋值检查
          return *this;

      delete[] str;              // ② 释放旧资源

      str = new char[strlen(other.str) + 1];  // ③ 分配新资源并拷贝
      strcpy(str, other.str);

      return *this;              // 返回引用，支持 a = b = c
  }
~~~
  必考点：
  - 返回值是 MyString&（不是 MyString），支持链式赋值 a = b = c
  - 参数是 const MyString&（避免不必要的拷贝）
  - 自赋值检查 if (this == &other) 必不可少

  2.2 运算符重载 — operator[]

  第8周课后3 / 第9周课堂1：
~~~~cpp
  // 非 const 版本：可读写
  int& ModBuffer::operator[](int i) {
      int idx = (i % n + n) % n;
      return data[idx];  // 返回引用，所以外部可以 buf[0] = 5;
  }

  // const 版本：只读，const 对象会自动调用这个
  const int& ModBuffer::operator[](int i) const {
      int idx = (i % n + n) % n;
      return data[idx];
  }
~~~~
  为什么要有两个版本？ const ModBuffer 对象不能调用非 const 成员函数，如果没有 const 版本的 []，const
  对象就不能下标访问了。

  2.3 运算符重载 — ++ / --

  第8周课后4 Counter：
~~~cpp
  // 前置 ++：先加后用，返回引用
  Counter& Counter::operator++() {
      ++value;
      return *this;
  }

  // 后置 ++：先用后加，返回旧值副本
  Counter Counter::operator++(int) {  // int 是假的参数，仅用来区分
      Counter temp = *this;
      ++value;
      return temp;  // 返回值（不是引用），因为是局部临时对象
  }
~~~
  区分方式： 后置有一个 int 占位参数，编译器调用时自动传 0。它不是真的用这个参数，纯粹是为了让函数签名不同。

  返回值差异：

  ┌──────────┬──────────────────┬──────────────────┐
  │          │       前置       │       后置       │
  ├──────────┼──────────────────┼──────────────────┤
  │ 返回类型 │ T&（引用）       │ T（值）          │
  ├──────────┼──────────────────┼──────────────────┤
  │ 语义     │ 返回修改后的自身 │ 返回修改前的副本 │
  └──────────┴──────────────────┴──────────────────┘

  2.4 运算符重载 — operator() 函数对象

  第9周课堂2：
~~~cpp
  class ComparatorBuilder {
      bool ascending;
      bool absMode;
  public:
      bool operator()(int a, int b) const {  // 让对象可以像函数一样调用
          int va = absMode ? myabs(a) : a;
          int vb = absMode ? myabs(b) : b;
          return ascending ? va < vb : va > vb;
      }
  };

  // 使用：
  ComparatorBuilder cmp(true, true);  // 升序，绝对值模式
  cmp(3, 5);  // 像调用函数一样使用对象
~~~

  3. 拷贝 (Copying)

  3.1 拷贝构造函数

  第7周大量练习。调用时机有三种：

  Test t1(10);           // 普通构造
  Test t2(t1);           // ① 显式拷贝构造
  Test t3 = t1;          // ② 用 = 初始化（注意：这是拷贝构造，不是赋值！）
  // ③ 函数传参/返回（按值传递/返回时）

  区分「拷贝构造」和「赋值」的关键：
  - 拷贝构造：对象尚不存在，正在被创建 → Test t3 = t1;
  - 赋值：对象已存在，把另一个对象的值赋给它 → t3 = t1;

  3.2 深拷贝 vs 浅拷贝

  这是最重要的考点（第7周课堂4、第8周整周）：
~~~cpp
  // 浅拷贝（默认的拷贝构造函数）→ 危险！
  // 两个对象的 data 指向同一块内存，析构时 double free

  // 深拷贝（自己写的）
  Seq::Seq(const Seq& other) : n(other.n) {
      data = new int[n];              // ① 分配自己的内存
      for (int i = 0; i < n; ++i)
          data[i] = other.data[i];    // ② 逐元素复制值
      total++;                         // ③ 维护 static 计数器
  }
~~~
  什么时候必须自己写深拷贝？ 类中有指向动态内存的指针时。你作业里的 MyString、IntArray、Seq、Matrix、StringList、Person
  全部如此。

  4. 继承 (Inheritance)

  第10周的内容：
~~~cpp
  // 基类
  class Shape {
  protected:              // protected：派生类可访问，外部不可
      string name;
  public:
      Shape(string n) : name(n) {}
      void printName() { cout << name; }
      ~Shape() { cout << "Shape " << name << " destroyed" << endl; }
  };

  // 派生类
  class Rectangle : public Shape {  // public 继承
      int width, height;
  public:
      // 调用基类构造函数初始化基类部分
      Rectangle(string n, int w, int h) : Shape(n), width(w), height(h) {}

      int getArea() { return width * height; }
      ~Rectangle() { cout << "Rectangle destroyed" << endl; }
  };

  // 再派生
  class Square : public Rectangle {
  public:
      Square(string n, int side) : Rectangle(n, side, side) {}
      ~Square() { cout << "Square destroyed" << endl; }
  };
~~~
  关键考点：

  5. 构造顺序：基类 → 派生类。Square 构造时先调 Rectangle，Rectangle 先调 Shape
  6. 析构顺序：反向，派生类 → 基类。你的输出样例验证了这点：
  Square destroyed     ← 先析构 Square
  Rectangle destroyed  ← 再 Rectangle
  Shape Sq destroyed   ← 最后 Shape
  7. protected vs private：protected 成员派生类可以用，private 不行
  8. 派生类构造必须调基类构造：Square(string n, int s) : Rectangle(n, s, s) {}

  9. 隐式转换与 explicit

  你这个学期作业没考到，但它是经典考点。简单说：

  没有 explicit 时 — 允许隐式转换
~~~cpp
	  class MyString {
		  public:
		      MyString(const char* s);  // 单参数构造函数
		  };
		
		  void foo(MyString s) { ... }
		
		  foo("hello");  // ✅ 编译器自动把 const char* 隐式转换成 MyString
```
	 // 这就是隐式转换 — 编译器看到需要 MyString 的地方给了 const char*，发现有一个单参数构造函数能转换，就自动调用了。加上 explicit — 禁止隐式转换	  
	  class MyString {
	  public:
	      explicit MyString(const char* s);  // 加 explicit
	  };
	
	  foo("hello");         // ❌ 编译错误，不能隐式转换
	  foo(MyString("hello")); // ✅ 显式构造，可以
~~~
  什么时候用？ 大多数单参数构造函数都应该加 explicit，防止意外的隐式转换导致 bug。你作业里 Student(int id, ...)
  如果只有一个 int 参数就该加 explicit。
